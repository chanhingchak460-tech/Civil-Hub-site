Lab 01

はりの曲げとたわみ

Objective単純支持はりについて、加えた荷重、曲げモーメント、表面ひずみ、たわみを関連付ける。

Method

  1. 支持点を所定のスパンに設定し、はりが水平であることを確認する。
  2. スパン中央にひずみゲージを取り付け、読み取り装置に接続する。
  3. 荷重を段階的に加え、ひずみとダイヤルゲージの読みを記録する。
  4. 除荷し、読みがほぼゼロに戻ることを確認する。

Precautions

  • はりを弾性範囲を超えて過負荷にしない。
  • ダイヤルゲージを軽く叩き、自由に動くことを確認する。
  • たわみを読む前に、はりが安定するのを待つ。
  • 荷重ハンガーが揺れないようにする。

Lab 02

円形軸のねじり

Objectiveトルク作用下での軸のねじれ角を測定し、せん断弾性係数を推定する。

Method

  1. 軸を固定し、トルクアームと分度器を取り付ける。
  2. トルクを等しい増分で加える。
  3. 各増分でねじれ角を読み取る。
  4. トルクを解放し、永久変形がないか確認する。

Precautions

  • トルクはゆっくり加え、衝撃を避ける。
  • 軸が真円でスケールがないことを確認する。
  • 毎回同じ目の高さから分度器を読む。
  • 弾性トルク範囲を超えない。
Lab 03

支柱の座屈

Objective端部条件と細長比が支柱の座屈荷重に及ぼす影響を観察する。

Method

  1. 支柱の長さと断面を測定する。
  2. 所定の端部条件を設定し、支柱を位置合わせする。
  3. 横たわみを監視しながら軸荷重を徐々に増加させる。
  4. たわみが急速に増大する荷重を記録する。

Precautions

  • 荷重が偏心せず軸方向であることを確認する。
  • 載荷中はフレームにもたれかからない。
  • 大きなたわみが支柱を損傷する前に停止する。
  • ナイフエッジが正しく設置されていることを確認する。

Lab 04

鋼の引張試験

Objective軟鋼および高強度鋼の応力–ひずみ挙動を観察し、降伏、極限強度、破断を特定し、延性を比較する。

Method

  1. 試験片の直径を複数の位置で測定し、平均を取る。
  2. 標点距離をマークし、伸び計を取り付ける。
  3. 記録計を開始し、破断まで安定して荷重を加える。
  4. 破壊位置と破面の外観を記録する。

Precautions

  • 試験片が治具の中心にあることを確認し、曲げを避ける。
  • 荷重が増加している間は伸び計に触れない。
  • 試験片が治具内で滑った場合は直ちに停止する。
  • 破断時は機械から離れる。
Lab 05

コンクリート立方体の圧縮とスランプ

Objectiveコンクリート立方体を製作・試験し、ワーカビリティを配合割合と関連付ける。

Method

  1. フレッシュコンクリートでスランプ試験を行う。
  2. 立方体型枠に層状に充填し、各層を締め固める。
  3. 所定の条件で立方体を養生する。
  4. 立方体を圧縮試験し、破壊モードを検査する。

Precautions

  • 手袋と保護眼鏡を着用する；セメントはアルカリ性である。
  • 均一に締め固め、ハニカムを避ける。
  • 各立方体にラベルを付け、養生記録を保持する。
  • 試験機の中心に立方体を置く。

Lab 06

オリフィスとベンチュリ流量

Objectiveオリフィスとベンチュリメータを通る流量を測定し、理論流量と比較する。

Method

  1. ポンプを起動し、定常流を確立する。
  2. マノメータのタッピングから空気を排出する。
  3. 圧力水頭と時間当たりの採取体積を記録する。
  4. 流量を変更して繰り返す。

Precautions

  • マノメータラインから気泡を除去する。
  • 計時前に流れを安定させる。
  • 目の高さでメニスカスを読む。
  • ポンプを空運転しない。

Lab 07

土の分類と締固め

Objective粒度とコンシステンシー限界から土を分類し、その締固め特性を求める。

Method

  1. 試料を乾燥させ、四分法で分割する。
  2. ふるい分析と比重計分析を行う。
  3. 液性限界と塑性限界を求める。
  4. 含水比を増加させながら試料を締め固め、乾燥密度曲線を描く。

Precautions

  • 試料は指定温度でのみ炉乾燥する。
  • ふるいを清掃し、過負荷にしない。
  • 比重計試験には蒸留水を使用する。
  • 含水比変化を防ぐため試料を密封する。
Lab 08

透水係数：定水位法と変水位法

Objective土の排水特性に適した方法を用いて透水係数を測定する。

Method

  1. 土供試体を準備し飽和させる。
  2. 定水位式または変水位式の装置を設置する。
  3. 読み取り前に流れが安定するのを待つ。
  4. 水頭、体積または時間、温度を記録する。

Precautions

  • 供試体を完全に飽和させる；閉じ込められた空気は結果を変える。
  • 供試体周囲の漏れを確認する。
  • 可能であれば脱気水を使用する。
  • 粘度補正のため水温を記録する。
Lab 09

圧密試験（oedometer）

Objective飽和粘土の圧縮・膨張特性を取得し、圧密パラメータを推定する。

Method

  1. 供試体を圧密リングに整形する。
  2. セルを組み立て、初期載荷を加える。
  3. 段階的に荷重を増加させ、各段階間で圧密を進行させる。
  4. 段階的に除荷し、膨張を記録する。

Precautions

  • 試験中は供試体を飽和状態に保つ。
  • 整形中に供試体を乱さない。
  • 各段階が完了するのに十分な時間を確保する。
  • 各読み取りの時刻を記録する。
Lab 10

直接せん断試験と三軸試験

Objective制御された排水条件下で土のせん断強度パラメータを求める。

Method

  1. 所定の密度で供試体を準備する。
  2. せん断箱または三軸セルを設置し、拘束応力を加える。
  3. 一定速度で供試体をせん断する。
  4. 該当する場合、せん断荷重、変位、間隙水圧を記録する。

Precautions

  • 指定された排水条件を維持する。
  • 載荷速度が試験タイプに適した遅さであることを確認する。
  • 端部に隙間なく供試体を設置する。
  • 載荷前に計器をゼロ調整する。

Lab 11

水準測量とトラバース測量

Objective閉合水準測量とトラバース測量を行い、座標計算前に閉合差を確認する。

Method

  1. 現場を踏査し、測点をマークする。
  2. 昇降式または器高式の方法で水準測量ループを実施する。
  3. トラバース周りの水平角と距離を観測する。
  4. 観測値を整理し、閉合差を確認する。

Precautions

  • 三脚をしっかり設置し、各読み取り前に気泡を確認する。
  • スタッフを鉛直に保ち、マークした点上に置く。
  • 可能な限り後視と前視の距離をバランスさせる。
  • すべてを直ちに野帳に記録する。

Lab 12

鋼はりの横ねじれ座屈

Objective細長い鋼はりの横ねじれ座屈と、荷重高さおよび拘束の影響を観察する。

Method

  1. はりの断面とスパンを測定する。
  2. 載荷と拘束の配置を設定する。
  3. 荷重を段階的に加え、横たわみを監視する。
  4. 座屈形状と支配的な破壊モードを記録する。

Precautions

  • 意図した箇所ではりが横方向に無拘束であることを確認する。
  • 指定された点を通して荷重を加える。
  • はりが不安定になったら載荷を停止する。
  • 載荷中は試験エリアを清潔に保つ。

Lab 13

管摩擦と形状損失

Objective管内および継手部の損失水頭を測定し、流量と関連付ける。

Method

  1. 管路を開き、定常流を設定する。
  2. 試験区間の圧力タッピングの読みを記録する。
  3. 流量測定のため、時間当たりの採取体積を計測する。
  4. 複数の流量について繰り返す。

Precautions

  • タッピングとマノメータから空気を排出する。
  • 継手部の漏れを確認する。
  • 読み取り前に流れを安定させる。
  • 圧力差に適したマノメータ範囲を使用する。
Lab 14

開水路流れ（水路）

Objective等流および漸変流を観察し、水面形を測定する。

Method

  1. 水路の勾配と下流ゲートを設定する。
  2. 定常流量を確立する。
  3. 複数の断面で水深と流速を測定する。
  4. 制御を変更し、新しい水面形を観察する。

Precautions

  • 測定中は水路内に立ったり妨害したりしない。
  • 水路が横方向に水平であることを確認する。
  • 測定前に波が収まるのを待つ。
  • 電気機器を水から遠ざける。

Lab 15

マーシャル配合設計とCBR

Objectiveマーシャル試験用のアスファルト供試体を製作し、締め固めた土または骨材のCBRを求める。

Method

  1. 指定温度で供試体を準備し締め固める。
  2. かさ密度と空隙特性を測定する。
  3. 安定度とフローを試験するか、CBR貫入試験を行う。
  4. 供試体の詳細と試験条件を記録する。

Precautions

  • 混合と締固めの温度を管理する。
  • アスファルトを扱う際は耐熱手袋を着用する。
  • CBRの載荷板と初期載荷を正しく保つ。
  • 供試体を2回目の試験に再利用しない。
