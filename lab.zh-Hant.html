Lab 01

樑的彎曲與撓度

Objective關聯簡支樑的施加荷載、彎矩、表面應變及撓度。

Method

  1. 將支座設定於所需跨度並檢查樑是否水平。
  2. 在跨中安裝應變計並連接至讀數器。
  3. 分級施加荷載並記錄應變及千分錶讀數。
  4. 卸載並檢查讀數是否回復至接近零。

Precautions

  • 切勿使樑超載超出其彈性範圍。
  • 輕敲千分錶以檢查其是否活動自如。
  • 讓樑穩定後才讀取撓度。
  • 防止荷載吊架擺動。

Lab 02

圓軸扭轉

Objective量度軸在扭矩下的扭轉角並估算剪切模量。

Method

  1. 夾緊軸並安裝扭矩臂及量角器。
  2. 以等量增量施加扭矩。
  3. 讀取每個增量的扭轉角。
  4. 釋放扭矩並檢查是否有永久變形。

Precautions

  • 緩慢施加扭矩，避免衝擊。
  • 檢查軸是否真正圓形且無銹皮。
  • 每次從同一視線水平讀取量角器。
  • 切勿超過彈性扭矩範圍。
Lab 03

支柱屈曲

Objective觀察端部條件及長細比對支柱屈曲荷載的影響。

Method

  1. 量度支柱長度及橫截面。
  2. 設定所需端部條件並對準支柱。
  3. 逐漸增加軸向荷載同時觀察側向撓度。
  4. 記錄撓度迅速增長時的荷載。

Precautions

  • 確保荷載為軸向而非偏心。
  • 加載時切勿倚靠框架。
  • 在大撓度損壞支柱前停止。
  • 檢查刀口是否正確就位。

Lab 04

鋼材拉伸試驗

Objective觀察低碳鋼及高強度鋼的應力—應變行為，辨識屈服、極限強度及斷裂，並比較延性。

Method

  1. 在多個位置量度試樣直徑並取平均值。
  2. 標記標距並安裝引伸計。
  3. 啟動繪圖儀並穩定加載直至斷裂。
  4. 記錄破壞位置及斷裂面外觀。

Precautions

  • 檢查試樣是否在夾具中對中，以避免彎曲。
  • 加載增加時切勿觸碰引伸計。
  • 若試樣在夾具中滑動，立即停止。
  • 斷裂時遠離機器。
Lab 05

混凝土立方體抗壓及坍落度

Objective製備及測試混凝土立方體，並關聯和易性與配合比。

Method

  1. 對新拌混凝土進行坍落度試驗。
  2. 分層填充立方體模具並壓實每層。
  3. 在指定條件下養護立方體。
  4. 對立方體進行抗壓測試並檢查破壞模式。

Precautions

  • 佩戴手套及護目鏡；水泥具鹼性。
  • 均勻壓實以避免蜂窩。
  • 為每個立方體標籤並保留養護記錄。
  • 將立方體置於試驗機中央。

Lab 06

孔口及文丘里流量

Objective量度通過孔口及文丘里流量計的流量並與理論流量比較。

Method

  1. 啟動泵並建立穩定流動。
  2. 從測壓管接頭排出空氣。
  3. 記錄壓力水頭及隨時間收集的體積。
  4. 改變流量並重複。

Precautions

  • 從測壓管管路移除氣泡。
  • 計時前讓水流穩定。
  • 從視線水平讀取彎月面。
  • 切勿讓泵空轉。

Lab 07

土壤分類與壓實

Objective根據級配及稠度界限對土壤進行分類，並確定其壓實特性。

Method

  1. 烘乾並四分法縮分樣本。
  2. 進行篩分及比重計分析。
  3. 確定液限及塑限。
  4. 在遞增含水量下壓實樣本並繪製乾密度曲線。

Precautions

  • 僅在指定溫度下烘乾樣本。
  • 清潔篩子且不要超載。
  • 比重計測試使用蒸餾水。
  • 密封樣本以防止水分變化。
Lab 08

滲透性：常水頭及變水頭

Objective使用適合土壤排水情況的方法量度土壤的滲透係數。

Method

  1. 製備並飽和土壤試樣。
  2. 設置常水頭或變水頭裝置。
  3. 讓水流穩定後才讀取讀數。
  4. 記錄水頭、體積或時間及溫度。

Precautions

  • 完全飽和試樣；滯留空氣會改變結果。
  • 檢查試樣周圍是否滲漏。
  • 如有條件使用去氣水。
  • 記錄水溫以校正黏度。
Lab 09

固結儀固結試驗

Objective獲取飽和黏土的壓縮及膨脹特性並估算固結參數。

Method

  1. 將試樣修整至固結環內。
  2. 組裝固結盒並施加預壓荷載。
  3. 分階段增加荷載，階段之間允許固結。
  4. 分階段卸載並記錄膨脹。

Precautions

  • 整個過程保持試樣飽和。
  • 修整時切勿擾動試樣。
  • 給予足夠時間完成每個階段。
  • 記錄每次讀數的時間。
Lab 10

直剪及三軸試驗

Objective在控制排水條件下確定土壤的抗剪強度參數。

Method

  1. 以所需密度製備試樣。
  2. 設置剪切盒或三軸壓力室並施加圍壓。
  3. 以恆定速率剪切試樣。
  4. 記錄剪力、位移及孔隙水壓力（如適用）。

Precautions

  • 維持指定排水條件。
  • 檢查加載速率是否足夠緩慢以適合試驗類型。
  • 安置試樣時邊緣不得有間隙。
  • 加載前將儀器歸零。

Lab 11

水準及導線測量

Objective進行閉合水準環及導線測量，並在計算坐標前檢查閉合差。

Method

  1. 勘察現場並標記測站。
  2. 使用升降法或儀器高法進行水準環。
  3. 觀測導線周圍的水平角及距離。
  4. 整理觀測數據並檢查閉合差。

Precautions

  • 穩固設置三腳架並在每次讀數前檢查水準氣泡。
  • 保持水準尺垂直並置於標記點上。
  • 盡可能平衡後視及前視距離。
  • 立即在野外記錄簿記錄所有數據。

Lab 12

鋼樑的側向—扭轉屈曲

Objective觀察細長鋼樑的側向—扭轉屈曲及荷載高度與約束的影響。

Method

  1. 量度樑截面及跨度。
  2. 設定加載及約束佈置。
  3. 分級施加荷載並監測側向撓度。
  4. 記錄屈曲形狀及控制破壞模式。

Precautions

  • 檢查樑在預定位置是否無側向約束。
  • 通過指定點施加荷載。
  • 樑變得不穩定時停止加載。
  • 加載時保持試驗區域暢通。

Lab 13

管道摩擦及局部損失

Objective量度沿管道及通過管件的的水頭損失，並關聯流量。

Method

  1. 打開管道迴路並設定穩定流量。
  2. 記錄測試段兩端的測壓管讀數。
  3. 隨時間收集計量體積以計算流量。
  4. 對多個流量重複。

Precautions

  • 從接頭及測壓管排出空氣。
  • 檢查接頭是否洩漏。
  • 讀取前讓水流穩定。
  • 使用正確的測壓管範圍以量度壓差。
Lab 14

水槽明渠流

Objective觀察均勻流及漸變流，並量度水面線。

Method

  1. 設定水槽坡度及尾門。
  2. 建立穩定流量。
  3. 在多個斷面量度水深及流速。
  4. 改變控制並觀察新的水面線。

Precautions

  • 量度時切勿站在水槽中或阻礙水流。
  • 檢查水槽橫向是否水平。
  • 量度前讓波浪平息。
  • 電氣設備遠離水。

Lab 15

馬歇爾配合比設計及CBR

Objective製備瀝青試樣進行馬歇爾試驗，並確定壓實土壤或集料的CBR。

Method

  1. 在指定溫度下製備及壓實試樣。
  2. 量度毛體積密度及空隙特性。
  3. 測試穩定性及流值，或進行CBR貫入試驗。
  4. 記錄試樣詳情及試驗條件。

Precautions

  • 控制拌和及壓實溫度。
  • 處理瀝青時佩戴耐熱手套。
  • 保持CBR荷載板及底座正確。
  • 切勿重複使用試樣進行第二次試驗。
