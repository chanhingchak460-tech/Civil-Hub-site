01対称性は例外である

教科書の断面は通常対称であるため、荷重面と中立軸は直交し、2つの曲げ方向は別々に扱える。実際の部材はそれほど従順ではない：不等辺山形鋼、偏心荷重を受けるチャンネル、Z形パーリン、クレーン軌道はすべて、どちらの図心軸にも一致しない方向に曲がる。

連成は慣性乗積 I_xy = ∫xy dA に起因し、これは面積が4つの象限にどのように広がっているかを測る。これがゼロのとき、一方の軸まわりの曲げは他方の座標で定義される点に応力を生じず、単純な曲げ応力式が適用できる。ゼロでないとき、中立軸は傾く。

慣性乗積
\[I_{xy} = \int x\,y\,\mathrm{d}A\]

02慣性乗積と主軸

長方形から構成される断面では、I_xy は各部分を A_i x̄_i ȳ_i として合計する。長方形は自身の図心軸まわりには寄与しないからである。二重対称断面では I_xy = 0 であり、1つの対称軸を持つ断面もその軸対に関してはゼロである。

主軸とは、I_xy がゼロになる図心軸である。それらを見つけるのは主応力と同じ代数である：角度は tan 2θ_p = 2I_xy/(I_y − I_x) に従い、主二次モーメントは2つの極値の間にある。角度を代入し直して、どの軸がどの値を持つか確認する。

主軸角度
\[\tan 2\theta_p = \frac{2 I_{xy}}{I_y - I_x}\]
主二次モーメント
\[I_{u,v} = \frac{I_x + I_y}{2} \pm \sqrt{\left(\frac{I_x - I_y}{2}\right)^2 + I_{xy}^2}\]

03非対称曲げにおける応力

図心軸 x と y を用いると、ある点の垂直応力は以下の式で与えられ、両モーメントは正の象限に引張を生じるとき正とする。分母は決して負にならない。I_x I_y ≥ I_xy² だからである。

σ = 0 と置くと中立軸が得られる：それは図心を通るが、その傾きはどちらの軸とも無関係である。極値応力は自動的に x または y で最も遠い隅にあるわけではないので、すべての隅を確認する。主軸に関しては連成が消え、おなじみの形 σ = M_v u/I_v + M_u v/I_u に戻る。

非対称曲げ応力
\[\sigma = \frac{(M_y I_x - M_x I_{xy})\,x + (M_x I_y - M_y I_{xy})\,y}{I_x I_y - I_{xy}^2}\]

04せん断流とせん断中心

横せん断は一様ではない。薄肉断面では、壁のどこかで切断し、切断面より先の面積に作用する軸方向力の釣り合いを考える：せん断流は q = VQ/I であり、Q はその面積の曲げ軸まわりの一次モーメント、壁応力は q を厚さで割ったものである。

チャンネルでは、フランジとウェブのせん断流が合成されて1つの鉛直力となり、その作用線は図心ではない。横荷重がねじりを生じない点がせん断中心であり、純粋に幾何学的性質である。チャンネルの場合、ウェブの外側、フランジから離れた側にあり、ウェブ中心線から e = 3b²/(h + 6b) の位置にある。ここで b はフランジ幅、h はフランジ中心線間のせいである。等辺山形鋼のせん断中心はかかと付近にある。

せん断流
\[q = \frac{V Q}{I}\]
チャンネルのせん断中心
\[e = \frac{3 b^2}{h + 6 b}\]
一般的な薄肉断面のせん断中心
断面慣性乗積せん断中心
二重対称I形断面ゼロ図心
チャンネル（1つの対称軸）対称軸に関してゼロウェブの外側、フランジと反対側
等辺山形鋼非ゼロ脚のかかと付近
Z形断面（点対称）一般に非ゼロ図心

05円形軸を超えたねじり

円形軸は反りなしでねじれるため、τ = Tr/J と θ = TL/GJ は厳密である。他の断面は反りを生じる：平面断面は平面を保たず、単純ねじり式は成り立たない。中実非円形棒は図心に最も近い境界で最大せん断応力に達し、その値は係数表から求める。

閉薄肉管は循環するせん断流によってねじりを伝えるため、τ = T/(2A_m t)、J = 4A_m²/∮(ds/t) である。ここで A_m は壁中心線で囲まれた面積である。開断面は流れの閉路がなく、はるかに弱く、J ≈ Σ(1/3)bt³ である。同じ質量の開チャンネルよりも箱形の方がねじりにはるかに強い理由がここにある。

Bredtせん断応力
\[\tau = \frac{T}{2 A_m t}\]
閉管の定数
\[J = \frac{4 A_m^2}{\oint \frac{\mathrm{d}s}{t}}\]
開断面の定数
\[J \approx \sum \frac{1}{3} b t^3\]

06支柱と有効長

完全にまっすぐで中心荷重を受ける柱は、オイラー荷重に達するまでまっすぐである：P_cr = π²EI/(KL)²。ここで KL は端部条件で決まる有効長である。K はピン–ピンで1.0、固定–ピンで0.7、固定–固定で0.5、固定–自由で2.0である。この荷重を超えると直線形状は不安定になり、小さな外乱は成長する。

支配パラメータは細長比 λ = KL/r であり、r = √(I/A) は曲げ軸まわりの断面二次半径である。ずんぐりした柱は座屈する前に降伏し、細長い柱は降伏応力よりはるかに低い応力で座屈する。断面は弱い軸と同じ強さしかない。

オイラー座屈荷重
\[P_{cr} = \frac{\pi^2 E I}{(K L)^2}\]
細長比
\[\lambda = \frac{K L}{r}\]

07不完全性とSouthwellプロット

実在の柱は完全にまっすぐでも完全に中心荷重でもない。初期たわみ δ₀ は軸荷重によって増幅され、中央高さのたわみは δ_max = δ₀/[1 − P/P_cr] となり、最外縁繊維は降伏を超えずに P/A と Pδ_max/Z を加えなければならない。

したがって破壊はオイラー荷重より低い荷重で訪れる：柱は自身の増大するたわみによって降伏に追い込まれ、Perry–Robertson法はこれを同時に解く。Southwellプロットは不安定に達しない試験からオイラー荷重を抽出する：測定たわみを荷重で割ったものをたわみに対してプロットすると、傾き 1/P_cr の直線が得られる。座屈は剛性の漸進的な喪失である。

たわみ増幅
\[\delta_{\max} = \frac{\delta_0}{1 - P/P_{cr}}\]
Southwellプロット
\[\frac{\delta}{P} = \frac{\delta}{P_{cr}} + \frac{\delta_0}{P_{cr}}\]

08近道としてのエネルギー法

ひずみエネルギーは変形の仕事を蓄える：曲げでは U = ∫M²/(2EI) ds であり、軸力、せん断、ねじりでも同様の積分がある。Castiglianoの定理は荷重方向の変位を Δ = ∂U/∂P として与え、微分方程式を積分せずに曲線部材や不静定部材を扱える。

単位荷重法は同じ考えの代数的形式である：変位を求めたい位置に単位荷重を作用させ、それが生じる内部モーメント m を求め、1·Δ = ∫Mm/(EI) ds とする。座屈荷重もエネルギーから導かれ、支柱がたわむときの軸荷重の仕事を蓄えられる曲げエネルギーと等置する。

曲げひずみエネルギー
\[U = \int \frac{M^2}{2 E I}\,\mathrm{d}s\]
Castiglianoの定理
\[\Delta = \frac{\partial U}{\partial P}\]
単位荷重法
\[1 \cdot \Delta = \int \frac{M m}{E I}\,\mathrm{d}s\]

09塑性曲げと形状係数

最外縁繊維が最初に降伏に達すると、弾性理論は破壊と言う — しかし断面はまだ荷重を支える。降伏が内側に広がるにつれて耐力は増大し、断面全体が f_y に達する：塑性モーメントは M_p = f_y S であり、S は塑性断面係数、等面積軸まわりの面積一次モーメントである。長方形では S = bh²/4 に対し弾性 Z = bh²/6 なので、形状係数 M_p/M_y は1.5である；I形断面は1.1–1.2付近である。

塑性ヒンジは M が M_p に達し、一定モーメントで自由に回転する箇所に形成され、部材を機構に変える。この再分配が塑性設計の基礎である：崩壊荷重は最初の降伏点ではなく、機構の幾何学から求まる。

降伏モーメントと塑性モーメント
\[M_y = f_y Z, \quad M_p = f_y S\]
塑性断面係数、長方形
\[S = \frac{b h^2}{4}\]
形状係数
\[\frac{M_p}{M_y} = \frac{S}{Z}\]

10反りねじりとバイモーメント

ねじりを受ける開薄肉断面は平面を保たない：フランジは横方向に曲がり、その結果生じるフランジ応力は反り応力であり、バイモーメントで表される。全トルクはSt Venant部分と反り部分に分かれ、T = T_sv + T_w であり、T_sv = G J θ′、T_w = −E I_w θ″′ である。ここで I_w は反り定数で、長さの6乗の単位を持つ。I形断面では I_w ≈ I_f h²/2 であり、I_f は片方のフランジの断面二次モーメントである。

端部拘束はすべてを変える：ねじり拘束された梁はトルクの多くを反りによって伝えるため、単純な τ = Tr/J の値は開断面では大きく非保守的になり得る。

トルクの分割
\[T = T_{sv} + T_w\]
反りトルク
\[T_w = -E I_w \theta'''\]
反り定数、I形断面
\[I_w \approx \frac{I_f h^2}{2}\]

Key terms

慣性乗積
断面にわたる ∫xy dA の積分；非ゼロは図心軸が主軸でなく、一方の軸まわりの曲げが他方に関連する応力を生じることを意味する。
主軸
慣性乗積がゼロになる一対の図心軸であり、どちらの軸まわりの曲げも相互連成を生じない。
せん断中心
横荷重がねじりを生じないために通過しなければならない断面内の点；材料に依存しない幾何学的性質。
せん断流
薄壁に沿った単位長さあたりのせん断力、q = VQ/I。合成せん断力とせん断中心の位置を求めるのに用いる。
反り
ねじりを受ける非円形断面の面外変形。壁に沿ってせん断ひずみが変化することによって生じる。
有効長
座屈する支柱の変曲点間の距離 KL。端部固定条件から選ばれる。
Perry–Robertson法
弾性座屈と最外縁繊維の降伏を組み合わせて、不完全な支柱の破壊を予測する柱の手法。
Southwellプロット
柱の試験における荷重に対するたわみの比をたわみに対してプロットしたグラフ；その傾きは限界座屈荷重の逆数を与える。
塑性断面係数
等面積軸まわりの面積一次モーメント；降伏応力を掛けると塑性モーメントが得られる。
バイモーメント
拘束された反りによって生じる自己平衡的な一対のフランジモーメント；部材に沿ったその勾配が反りトルクを与える。
Worked example

チャンネルのせん断中心と偏心荷重によるねじり

薄肉チャンネルはフランジ幅 b = 75 mm（ウェブ中心線から測定）、フランジ中心線間のせい h = 200 mm、厚さ t = 6 mm である。長さ2.0 mの部材の図心を通して5 kNの鉛直荷重が作用する。せん断中心、偏心荷重によるトルク、St Venantねじれ角を求めよ（G = 79 GPa）。

  1. 曲げ軸まわりの断面二次モーメント：I_x = t h³/12 + 2 b t (h/2)² = 6 × 200³/12 + 2 × 75 × 6 × 100² = 4.0 × 10⁶ + 9.0 × 10⁶ = 13.0 × 10⁶ mm⁴。
  2. ウェブ中心線からのせん断中心の偏心：e = 3b²/(h + 6b) = 3 × 75²/(200 + 450) = 16 875/650 = 26.0 mm、ウェブのフランジと反対側。
  3. フランジ側への図心の偏心：A = t h + 2 b t = 1200 + 900 = 2100 mm²、よって x̄ = (2 b t)(b/2)/A = 33 750/2100 = 16.1 mm。したがって図心荷重はせん断中心から 26.0 + 16.1 = 42.1 mm の位置にある。
  4. せん断中心まわりのトルク：T = V × e = 5000 N × 0.0421 m = 210 N·m = 210 500 N·mm。
  5. 開断面のねじり定数：J ≈ Σ(1/3) b t³ = (1/3)(200 + 75 + 75)(6³) = 25 200 mm⁴。
  6. ねじれ角：θ = T L/(G J) = (210 500 × 2000)/(79 000 × 25 200) = 0.212 rad、約12°。
  7. 妥当性確認：2 mで12°は屋根部材として許容できない。これがチャンネルをせん断中心を通して載荷するか、シートで拘束するか、閉断面箱に置き換える理由である。反り拘束はこの推定値を減らすが、ゼロにはならない。
Answerせん断中心はウェブ中心線から26.0 mm、フランジと反対側にある。図心荷重はそれに対して0.21 kN·mのトルクを作用させ、St Venantねじれは約0.21 rad（12°）であり、開断面には拘束またはせん断中心を通る荷重経路が必要であることを確認する。

Exam method

  • 非対称曲げの式に代入する前に、M_x と M_y の符号規約を明記する。失点のほとんどは符号の誤りであり、代数ではない。
  • 薄肉断面では、まずせん断流の経路をスケッチする：自由縁では流れはゼロから始まり、角は合力が出会う場所である。
  • ねじりの問題では、式を書く前に断面が閉か開かを述べる。剛性の差は甚大である。
  • 支柱では、オイラー荷重と降伏荷重の両方を示し、与えられた細長比に対してどちらが支配するかを述べる。
  • ねじりを受ける開断面では、J と並べて反り定数を示す。端部拘束により反りトルクが支配項になり得る。

Design strength py used in the Hong Kong steel code. It is the yield strength divided by the material factor for the steel class and capped by the tensile strength divided by a second factor, so the tabulated value falls as the element gets thicker.

Q01断面が非ゼロの慣性乗積を持つ。その曲げ挙動について正しい記述はどれか？

WhyI_xy を介した連成により、x 軸まわりのモーメントは y だけでなく x にも依存する応力を生じ、中立軸は幾何軸から傾く。

Q02チャンネル断面が鉛直荷重を受ける。そのせん断中心はどこにあるか？

Whyチャンネルではフランジのせん断流が偶力を作り、合成せん断力をウェブの外側、フランジと反対側の e = 3b²/(h + 6b) の位置に押し出す。

Q03同じ質量と同じ囲まれた面積を持つ2つの部材、一方は閉管、他方は開チャンネルである。同じトルクに対して、ねじれが小さいのはどちらか？

Why閉管は循環するBredtせん断流によってねじりを伝え、J = 4A_m²/∮(ds/t) を与える；開断面は J ≈ Σbt³/3 で、桁違いに小さい。

Q04長さ L のピン–ピン支柱のオイラー荷重が P である。両端を固定にし、他は何も変えない場合、オイラー荷重はおよそいくらになるか？

Why有効長は L から 0.5L に減少し、P_cr は 1/(KL)² に比例するので、荷重は 1/0.5² = 4 倍になる。

Q05長方形断面の弾性断面係数 Z = bh²/6、塑性断面係数 S = bh²/4 である。その形状係数は？

Why形状係数は S/Z = (bh²/4)/(bh²/6) = 6/4 = 1.5 であり、塑性モーメントが初降伏モーメントの1.5倍であることを意味する。

Q06せん断中心の実験で、チャンネルのせん断中心はどの載荷位置として見つけられるか？

Whyせん断中心を通る荷重はねじりなしの曲げを生じるため、2つの隅の回転ゲージはゼロを読む。
