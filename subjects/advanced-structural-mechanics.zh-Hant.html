非對稱或非圓形構件的載荷路徑：主軸、剪力中心、翹曲扭轉及實際柱的穩定性。解釋為何槽鋼會扭轉，以及為何細長支柱會在低於屈服荷載時失效。

進度只儲存在此瀏覽器。

01對稱是例外

教科書截面通常是對稱的，因此載荷平面與中性軸保持垂直，兩個彎曲方向可以分開處理。實際構件則不那麼順從：不等角鋼、偏心載荷的槽鋼、Z型檁條和起重機軌道，其彎曲方向與任一形心軸都不一致。

耦合來自慣性積 I_xy = ∫xy dA，它衡量面積在四個象限的分佈。當它為零時，繞一軸彎曲不會在由另一坐標定義的點產生應力，簡單彎曲公式適用。當它不為零時，中性軸會傾斜。

慣性積
\[I_{xy} = \int x\,y\,\mathrm{d}A\]

02慣性積與主軸

對於由矩形組成的截面，I_xy 按各部分的 A_i x̄_i ȳ_i 求和，因為矩形對其自身形心軸的貢獻為零。雙對稱截面的 I_xy = 0；具有一個對稱軸的截面，關於該對軸的 I_xy 也為零。

主軸是使 I_xy 為零的形心軸。求主軸與求主應力的代數相同：角度滿足 tan 2θ_p = 2I_xy/(I_y − I_x)，主二次矩介於兩個極值之間。將角度代回以檢查哪個軸對應哪個值。

主角
\[\tan 2\theta_p = \frac{2 I_{xy}}{I_y - I_x}\]
主二次矩
\[I_{u,v} = \frac{I_x + I_y}{2} \pm \sqrt{\left(\frac{I_x - I_y}{2}\right)^2 + I_{xy}^2}\]

03非對稱彎曲中的應力

以形心軸 x 和 y 為準，某點的的正應力由下式給出，當兩個彎矩在正象限產生拉力時取正。分母永遠非負，因為 I_x I_y ≥ I_xy²。

令 σ = 0 得到中性軸：它通過形心，但其斜率與任一軸無關。最大應力不一定在 x 或 y 方向最遠的角點，因此需檢查每個角點。關於主軸，耦合消失，熟悉的公式回歸，即 σ = M_v u/I_v + M_u v/I_u。

非對稱彎曲應力
\[\sigma = \frac{(M_y I_x - M_x I_{xy})\,x + (M_x I_y - M_y I_{xy})\,y}{I_x I_y - I_{xy}^2}\]

04剪力流與剪力中心

橫向剪力並非均勻。在薄壁截面中，在某處切開牆壁並平衡切口以外區域的縱向力：剪力流為 q = VQ/I，其中 Q 是該區域關於彎曲軸的一次矩，牆壁應力為 q 除以厚度。

對於槽鋼，翼緣和腹板的剪力流合成一個垂直力，其作用線不在形心。橫向載荷不產生扭轉的點稱為剪力中心，這是純幾何性質。對於槽鋼，它位於腹板外側、遠離翼緣，距腹板中心線 e = 3b²/(h + 6b)，其中 b 是翼緣寬度，h 是翼緣中心線之間的深度。等邊角鋼的剪力中心靠近角頂。

剪力流
\[q = \frac{V Q}{I}\]
槽鋼的剪力中心
\[e = \frac{3 b^2}{h + 6 b}\]
常見薄壁截面的剪力中心
截面慣性積剪力中心
雙對稱工字鋼截面零在形心
槽鋼（一個對稱軸）關於對稱軸為零腹板外側，翼緣對面
等邊角鋼非零靠近肢的角頂
Z型截面（點對稱）通常非零在形心

05超越圓軸的扭轉

圓軸扭轉時不翹曲，因此 τ = Tr/J 和 θ = TL/GJ 是精確的。任何其他截面都會翹曲：平面截面不再保持平面，簡單扭轉公式失效。實心非圓形桿的最大剪應力出現在最靠近形心的邊界上，其值取自係數表。

閉合薄壁管通過循環剪力流傳遞扭矩，因此 τ = T/(2A_m t) 和 J = 4A_m²/∮(ds/t)，其中 A_m 是牆壁中線圍成的面積。開口截面沒有閉合路徑供剪力流動，因此弱得多，J ≈ Σ(1/3)bt³。這就是為什麼相同質量的箱形截面比開口槽鋼抗扭好得多。

Bredt 剪應力
\[\tau = \frac{T}{2 A_m t}\]
閉合管常數
\[J = \frac{4 A_m^2}{\oint \frac{\mathrm{d}s}{t}}\]
開口截面常數
\[J \approx \sum \frac{1}{3} b t^3\]

06支柱與有效長度

完全筆直、中心載荷的柱在達到歐拉荷載前保持筆直：P_cr = π²EI/(KL)²，其中 KL 是由端部條件設定的有效長度。K 對於鉸接-鉸接為 1.0，固定-鉸接為 0.7，固定-固定為 0.5，固定-自由為 2.0。超過該荷載，直線形狀不穩定，任何小擾動都會增長。

控制參數是長細比 λ = KL/r，其中 r = √(I/A) 是關於彎曲軸的迴轉半徑。粗短柱在屈曲前屈服；細長柱在遠低於屈服的應力下屈曲。截面的強度取決於其較弱軸。

歐拉屈曲荷載
\[P_{cr} = \frac{\pi^2 E I}{(K L)^2}\]
長細比
\[\lambda = \frac{K L}{r}\]

07缺陷與 Southwell 圖

沒有實際柱是完全筆直或完全中心載荷的。初始彎曲 δ₀ 被軸向荷載放大，因此中高撓度變為 δ_max = δ₀/[1 − P/P_cr]，極端纖維必須加上 P/A 和 Pδ_max/Z 而不超過屈服。

因此失效在歐拉荷載之前發生：柱被自身增長的撓度驅使屈服，Perry–Robertson 方法同時解決此問題。Southwell 圖從未達到不穩定的試驗中提取歐拉荷載：繪製測量撓度除以荷載對撓度的圖，得到斜率為 1/P_cr 的直線。屈曲是剛度的逐漸喪失。

撓度放大
\[\delta_{\max} = \frac{\delta_0}{1 - P/P_{cr}}\]
Southwell 圖
\[\frac{\delta}{P} = \frac{\delta}{P_{cr}} + \frac{\delta_0}{P_{cr}}\]

08能量法作為捷徑

應變能儲存變形功：對於彎曲 U = ∫M²/(2EI) ds，軸力、剪力和扭轉有類似的積分。Castigliano 定理然後給出沿載荷方向的位移為 Δ = ∂U/∂P，這無需積分微分方程即可處理曲線和超靜定構件。

單位載荷法是同一思想的代數形式：在需要位移的地方施加單位載荷，求出其產生的內彎矩 m，然後 1·Δ = ∫Mm/(EI) ds。屈曲荷載也可由能量得出，通過將支柱彎曲時軸向載荷的功等於儲存的彎曲能。

彎曲應變能
\[U = \int \frac{M^2}{2 E I}\,\mathrm{d}s\]
Castigliano 定理
\[\Delta = \frac{\partial U}{\partial P}\]
單位載荷法
\[1 \cdot \Delta = \int \frac{M m}{E I}\,\mathrm{d}s\]

09塑性彎曲與形狀係數

當極端纖維首次達到屈服時，彈性理論認為失效——但截面仍能承載。隨著屈服向內擴展，承載力增長，直到整個截面達到 f_y：塑性彎矩為 M_p = f_y S，其中 S 是塑性模量，即關於等面積軸的面積一次矩。對於矩形，S = bh²/4，而彈性 Z = bh²/6，因此形狀係數 M_p/M_y 為 1.5；工字鋼截面約為 1.1–1.2。

塑性鉸在 M 達到 M_p 並在恒定彎矩下自由轉動處形成，將構件變成機構。這種重分佈是塑性設計的基礎：倒塌荷載來自機構幾何，而非首次屈服點。

屈服與塑性彎矩
\[M_y = f_y Z, \quad M_p = f_y S\]
塑性模量，矩形
\[S = \frac{b h^2}{4}\]
形狀係數
\[\frac{M_p}{M_y} = \frac{S}{Z}\]

10翹曲扭轉與雙彎矩

開口薄壁截面在扭轉下不保持平面：翼緣側向彎曲，產生的翼緣應力為翹曲應力，由雙彎矩描述。總扭矩分為聖維南和翹曲部分，T = T_sv + T_w，其中 T_sv = G J θ′ 和 T_w = −E I_w θ″′，I_w 是翹曲常數，單位為長度的六次方。對於工字鋼截面，I_w ≈ I_f h²/2，其中 I_f 是一個翼緣的二次矩。

端部約束改變一切：扭轉約束梁通過翹曲承擔大部分扭矩，因此簡單的 τ = Tr/J 值對於開口截面可能嚴重不安全。

扭矩拆分
\[T = T_{sv} + T_w\]
翹曲扭矩
\[T_w = -E I_w \theta'''\]
翹曲常數，工字鋼截面
\[I_w \approx \frac{I_f h^2}{2}\]

關鍵詞

慣性積
截面上的積分 ∫xy dA；非零表示形心軸不是主軸，繞一軸彎曲會引起與另一軸相關的應力。
主軸
慣性積為零的一對形心軸，因此繞任一軸彎曲不會產生交叉耦合。
剪力中心
截面中橫向載荷必須通過以不引起扭轉的點；是與材料無關的幾何性質。
剪力流
沿薄壁單位長度的剪力，q = VQ/I，用於定位合剪力和剪力中心。
翹曲
非圓形截面在扭轉下的平面外變形，由沿牆壁變化的剪應變引起。
有效長度
屈曲支柱反彎點之間的距離 KL，根據端部約束選擇。
Perry–Robertson 方法
一種柱設計方法，結合彈性屈曲與極端纖維屈服來預測缺陷支柱的失效。
Southwell 圖
柱試驗中撓度除以荷載對撓度的圖；其斜率給出臨界屈曲荷載的倒數。
塑性模量
關於等面積軸的面積一次矩；乘以屈服應力得到塑性彎矩。
雙彎矩
由約束翹曲引起的自平衡翼緣彎矩對；其沿構件的梯度給出翹曲扭矩。
計算示例

槽鋼的剪力中心與偏心載荷引起的扭轉

薄壁槽鋼的翼緣寬度 b = 75 mm（從腹板中心線量起），翼緣中心線之間的深度 h = 200 mm，厚度 t = 6 mm。一垂直載荷 5 kN 作用在 2.0 m 長構件的形心上。求剪力中心、偏心載荷引起的扭矩以及聖維南扭轉角（G = 79 GPa）。

  1. 關於彎曲軸的二次矩：I_x = t h³/12 + 2 b t (h/2)² = 6 × 200³/12 + 2 × 75 × 6 × 100² = 4.0 × 10⁶ + 9.0 × 10⁶ = 13.0 × 10⁶ mm⁴。
  2. 剪力中心距腹板中心線的偏移：e = 3b²/(h + 6b) = 3 × 75²/(200 + 450) = 16 875/650 = 26.0 mm，在腹板遠離翼緣的一側。
  3. 形心向翼緣偏移：A = t h + 2 b t = 1200 + 900 = 2100 mm²，因此 x̄ = (2 b t)(b/2)/A = 33 750/2100 = 16.1 mm。因此形心載荷距剪力中心 26.0 + 16.1 = 42.1 mm。
  4. 關於剪力中心的扭矩：T = V × e = 5000 N × 0.0421 m = 210 N·m = 210 500 N·mm。
  5. 開口截面扭轉常數：J ≈ Σ(1/3) b t³ = (1/3)(200 + 75 + 75)(6³) = 25 200 mm⁴。
  6. 扭轉角：θ = T L/(G J) = (210 500 × 2000)/(79 000 × 25 200) = 0.212 rad，約 12°。
  7. 合理性檢查：2 m 上 12° 對於屋頂構件是不可接受的，這就是為什麼槽鋼通過剪力中心載荷、由屋面板約束或替換為閉合箱形截面。翹曲約束會減小此估計，但不會減至零。
Answer剪力中心距腹板中心線 26.0 mm，在翼緣對面。形心載荷對其施加 0.21 kN·m 的扭矩，聖維南扭轉約為 0.21 rad（12°），證實開口截面需要約束或通過剪力中心的載荷路徑。

應試方法

  • 在代入非對稱彎曲公式前，先說明 M_x 和 M_y 的正負號約定；大多數失分是符號錯誤，而非代數錯誤。
  • 對於任何薄壁截面，先繪製剪力流路徑：自由邊緣從零剪力流開始，角點是合力相交處。
  • 在扭轉問題中，寫公式前先說明截面是閉合還是開口；剛度差異巨大。
  • 對於支柱，引用歐拉荷載和屈服荷載，然後說明對於給定的長細比哪個控制。
  • 對於扭轉下的開口截面，同時引用翹曲常數和 J——端部約束可使翹曲扭矩成為主導項。

自我測驗

先作答，再查看解釋。錯誤答案比熟悉的一頁更有用。

Q01某截面的慣性積非零。關於其彎曲行為，哪個說法正確？

解釋通過 I_xy 的耦合意味著繞 x 的彎矩產生的應力隨 x 和 y 變化，中性軸偏離幾何軸。

Q02槽鋼截面承受垂直載荷。其剪力中心在哪裡？

解釋對於槽鋼，翼緣剪力流形成力偶，將合剪力推到腹板外側、翼緣對面，位置為 e = 3b²/(h + 6b)。

Q03兩個構件質量相同、圍成面積相同，一個是閉合管，一個是開口槽鋼。對於相同扭矩，哪個扭轉較小？

解釋閉合管通過循環的 Bredt 剪力流傳遞扭矩，給出 J = 4A_m²/∮(ds/t)；開口截面的 J ≈ Σbt³/3，小幾個數量級。

Q04長度為 L 的鉸接-鉸接支柱歐拉荷載為 P。如果兩端改為固定且其他不變，歐拉荷載約變為：

解釋有效長度從 L 降至 0.5L，而 P_cr 隨 1/(KL)² 變化，因此荷載增加 1/0.5² = 4 倍。

Q05矩形截面的彈性模量 Z = bh²/6，塑性模量 S = bh²/4。其形狀係數為：

解釋形狀係數為 S/Z = (bh²/4)/(bh²/6) = 6/4 = 1.5，意味著塑性彎矩比首次屈服彎矩大一半。

Q06在剪力中心實驗中，槽鋼的剪力中心通過載荷位置確定，該位置滿足：

解釋通過剪力中心的載荷產生彎曲而無扭轉，因此兩個角點的旋轉千分表讀數為零。
