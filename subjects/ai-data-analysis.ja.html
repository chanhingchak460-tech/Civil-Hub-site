01モデルの前にデータ

分析は、ソフトウェアに何ができるかではなく、何が記録されたかから始まる。各変数は測定された特性——圧縮強度、塩化物含有量、分単位の遅延——であり、その型が許される算術を決める：

  • 名義尺度のラベルは数えることしかできない
  • 順序尺度は順位付けできる
  • 間隔尺度の値は差を取れる
  • 真のゼロを持つのは比率尺度だけ

工学的データのほとんどは、より大きな母集団からの標本であるため、あらゆる要約は推定値である。行がどのように選ばれたかを問うこと。便宜的な標本は、対象そのものと同じくらい標本抽出法を測っている。

02データセットの要約

最初の一巡は記述的で安価である：中心、ばらつき、形状。平均はつり合い点、中央値は中央の値、最頻値は最も頻繁なカテゴリである。ばらつきは、データと同じ単位を持つ標準偏差、または無次元で変数間で比較可能な変動係数として報告する。歪みは平均を長い裾へ引き寄せるが中央値はほとんど動かない。だからこそ修繕費や降雨量は中央値で示される。要約のそばには必ず標本サイズを添えること。

標本平均
\[\bar{x} = \frac{\sum x_i}{n}\]
n 個の観測値
標本標準偏差
\[s = \sqrt{\frac{\sum (x_i - \bar{x})^2}{n - 1}}\]
n − 1 は標本サイズを補正する
変動係数
\[\mathrm{CV} = \frac{s}{\bar{x}}\]
無次元
4つの要約統計量と、それぞれが誤解を招く場面
統計量要約するもの誤解を招く場面
平均すべての値のつり合い点極端な値に引っ張られる
中央値順位付け後の中央の値ほとんどの値の大きさを無視する
標準偏差平均からの典型的な距離対称なばらつきを仮定する
変動係数平均に対する相対的なばらつき平均がゼロに近いと不安定になる

03相関は傾きでも原因でもない

まずプロットする。2つの変数が明瞭な曲線に従っていても、相関係数がゼロ近くになることがある。ピアソン係数 r は線形の関連しか測らないからである。r は単位を持たず、−1 から +1 の範囲をとり、傾きではない：r = 0.9 は x の1単位あたり y がどれだけ変化するかを教えてくれない。相関は因果でもない。第三の要因が両方の変数を動かしているかもしれないし、因果の矢印が逆向きかもしれないし、標本が結果に基づいて選ばれているかもしれない。因果を述べるには、無作為化、対照群、または自然実験が必要である。

ピアソン相関係数
\[r = \frac{\sum (x_i - \bar{x})(y_i - \bar{y})}{\sqrt{\sum (x_i - \bar{x})^2 \cdot \sum (y_i - \bar{y})^2}}\]
−1 ≤ r ≤ +1；線形の関連のみを検出する

04最小二乗法による直線の当てはめ

単純線形回帰は、各観測値と直線の間の垂直方向の差の二乗和を最小にする直線を選ぶことで ŷ = a + b x を当てはめる。二乗することで正と負の外れを同等に扱い、大きな外れを最も厳しく罰するため、1つの外れ値が当てはめを傾けることがある。傾き b は x が1単位増えるごとの y の予測変化量である。切片 a は x = 0 での予測値であり、測定範囲の外にあることが多く、物理的に無意味なこともある。どちらも単位を添えて示し、外挿した予測をあたかも測定値のように提示してはならない。

最小二乗の傾き
\[b = \frac{\sum (x_i - \bar{x})(y_i - \bar{y})}{\sum (x_i - \bar{x})^2}\]
x の単位変化あたりの y の変化
切片
\[a = \bar{y} - b\,\bar{x}\]
当てはめた直線は ŷ = a + b x

05当てはめの評価

決定係数 R² は、モデルが説明する y の変動の割合である：1 はすべての点が直線上にあることを、0 はモデルが平均を予測する以上のものではないことを意味する。モデルの形が正しいかどうかは何も語らない——狭い範囲に当てはめた曲線でも高いスコアを出せる。正直な検証は残差プロットである。パターンがあればモデルは誤特定であり、じょうご形なら分散が x とともに変化しており、ごく少数の非常に大きな残差は影響力のある点を示す。R² だけでなく典型的な誤差を報告すること。

決定係数
\[R^2 = 1 - \frac{\mathrm{SS}_{\mathrm{res}}}{\mathrm{SS}_{\mathrm{tot}}}\]
SS_res = Σ(yᵢ − ŷᵢ)²、SS_tot = Σ(yᵢ − ȳ)²

06モデルを正直に検証する

モデルは、まだ見ていないデータで性能を発揮して初めて有用である。チューニングの前にテストセットを分離するか、標本が小さい場合は交差検証を行う。そうしなければ、モデルは訓練行を丸暗記して優秀に見えることがある。数値予測では、平均絶対誤差または二乗平均平方根誤差を y の単位で報告する。二乗平均平方根は大きな外れをより厳しく罰する。適切に選ばれたテストセットでの低い誤差は証拠であり、訓練セットでの低い誤差は単なる算術である。

二乗平均平方根誤差
\[\mathrm{RMSE} = \sqrt{\frac{1}{n} \sum (y_i - \hat{y}_i)^2}\]

07データ品質の落とし穴

モデリングの失敗のほとんどはデータの失敗である。欠損値には理由があるかもしれない——しきい値を超えると飽和するセンサーなど——ので、不完全な行を削除すると記述している母集団が静かに変わってしまう。外れ値は調査に値する：転記ミスなら修正だが、本物の極端値なら情報である。リークは、予測時には存在しない情報を予測子が含むときに起こり、テストスコアは素晴らしいが実運用では役に立たないモデルになる。単位、重複、変動を隠す丸め、行の順序を確認すること。未来で訓練されたモデルは予測ではない。

08出所・バイアス・推論（SBI）

3つの問いが分析を正直に保つ。出所：誰が、どの計器で、どのような条件下で数値を集めたのか？ バイアス：この標本が体系的に見落としている物語の部分はどこか——上限のあるセンサー、便宜的な現場、「その他」にまとめられたカテゴリなど？ 推論：証拠は実際どこまで及ぶのか、推定値のそばに置くべき不確実性は何か？ 最後の問いこそ、試験の答案が忘れがちなものである。10点に当てはめた傾きが支えるのは方向とおおよその大きさであり、精密な予測ではない：標本サイズ、残差誤差、当てはめた範囲を述べること。

09分類：スコアが判断になる

結果がカテゴリ——不良か健全か、合格か不合格か——のとき、モデルはスコアを出力し、しきい値がそれを判断に変える。ロジスティック回帰は線形スコアをシグモイドに通して出力を確率にする。しきい値0.5は既定値であり法則ではなく、動かせば一方の誤りと他方の誤りを交換することになる。分類器は精度だけでなく混同行列で評価すること。適合率は陽性と判定された事例のうち真に陽性である割合であり、再現率は真の陽性のうち見つけられた割合である。両者は相反する誤りを罰する。不均衡データでは、何も陽性と判定しないモデルが高い精度を出しながら何も見つけられない。

ロジスティック確率
\[p = \frac{1}{1 + e^{-s}}, \quad s = b_0 + b_1 x_1 + \cdots\]
線形スコア s が0から1の間の確率に写像される
適合率と再現率
\[\mathrm{precision} = \frac{TP}{TP + FP}, \quad \mathrm{recall} = \frac{TP}{TP + FN}\]
TP、FP、FN は混同行列から得られる

10特徴量エンジニアリングとスケーリング

モデルに渡す列がモデルの半分である。標準化は変数をゼロ中心にし、標準偏差1に再スケールする。これにより数値の大きい変数が当てはめを支配するのを防ぐ。対数変換はコストや濃度のような右に歪んだ変数をならす。ワンホットエンコーディングは名義カテゴリを指示列に変える。スケーリングとエンコーディングは訓練セットのみから計算した統計量で行い、その後で同一の変換をテストセットに適用する。先に全データでスケーリングすると、テストセットが静かに訓練に漏れ、あらゆる結果が良く見えてしまう。

標準化
\[z = \frac{x - \mu}{\sigma}\]
μ と σ は訓練セットの平均と標準偏差
変換は訓練データのみで当てはめる 平均、標準偏差、カテゴリ水準は訓練分割から計算し、テストセットで再利用すること。そうしなければ評価は楽観的になる。

11ベースラインと正直な比較

モデルは抽象的に良し悪しが決まるのではなく、ベースラインと比べて良し悪しが決まる。何かを当てはめる前に、最も単純で擁護できる代替案——過去の平均、前期の値、または1ルールの分類器——を同じテストセットで採点し、モデルのそばに報告する。候補は同一の分割で同一の指標により比較し、単位を文字通りに読むべき場合は平均絶対誤差を好む：典型的な外れを直接報告するのに対し、二乗平均平方根誤差はまれな大きな外れを増幅するからである。取るに足らないベースラインに勝てないモデルは、どれほど巧妙でも改善ではない。

平均絶対誤差
\[\mathrm{MAE} = \frac{1}{n} \sum |y_i - \hat{y}_i|\]
y の単位での典型的な誤差

Key terms

残差
観測値と、当てはめたモデルが予測した値との間の垂直方向の差。
決定係数
当てはめたモデルが説明する応答変数の変動の割合。
最小二乗法
残差の二乗和を最小にすることでパラメータを選ぶ当てはめ規則。
標本
実際に測定され、そこから推定が行われる母集団の部分集合。
外れ値
データの残りから大きく離れた観測値であり、記録ミスか本物の極端値のいずれかである。
データリーク
予測を行わなければならない時点では利用できない情報を含む予測子を使うこと。
混同行列
真陽性、偽陽性、偽陰性、真陰性の表で、分類器がどこで誤るかを示す。
標準化
通常は訓練セットから取った統計量を用いて、変数を平均ゼロ・標準偏差1に再スケールすること。
Worked example

養生時間に対する強度の当てはめ

小規模な試験で、5つの材齢における x 日間の養生後のコンクリート強度 y（MPa）を測定した：(1, 10)、(2, 12)、(3, 15)、(4, 18)、(5, 20)。最小二乗直線を当てはめ、R² を求め、傾きを解釈せよ。

  1. 要約：Σx = 15 より x̄ = 3 日；Σy = 75 より ȳ = 15 MPa。
  2. 平均からの偏差より Σ(xᵢ − x̄)² = 4 + 1 + 0 + 1 + 4 = 10、Σ(xᵢ − x̄)(yᵢ − ȳ) = 10 + 3 + 0 + 3 + 10 = 26。
  3. 傾き：b = 26 / 10 = 2.60 MPa/日。切片：a = ȳ − b x̄ = 15 − 2.60 × 3 = 7.2 MPa、よって ŷ = 7.2 + 2.60x。
  4. 予測値は 9.8、12.4、15.0、17.6、20.2 MPa となり、残差は 0.2、−0.4、0、0.4、−0.2。すると SS_res = 0.40、SS_tot = 25 + 9 + 0 + 9 + 25 = 68。
  5. R² = 1 − 0.40/68 = 0.994 となり、この5つの材齢における強度の変動の99.4%を直線が説明する。
Answerŷ = 7.2 + 2.60x（MPa）、R² = 0.994。養生が1日増えるごとに予測強度は約2.6 MPa高くなるが、5点で範囲が1〜5日しかないため、この直線を28日設計強度へ外挿してはならない。

Exam method

  • 傾きの単位（x 単位あたりの y 単位）と切片の単位を示すこと——数値だけでは点を失う。
  • R² を精度と呼んではならない：それは説明された変動の割合であり、正しい予測の割合ではない。
  • どの当てはめを擁護する前にも、まずデータを、次に残差をプロットすること。残差にパターンがあればモデルは誤りである。
  • 当てはめた範囲と標本サイズを述べ、予測が外挿であるときはそう言うこと。
  • モデルが良いと主張する前に、同じテストセットで単純なベースラインを報告すること。スコアは何かと比べて初めて意味を持つ。
