數據的價值取決於你向它提出的問題。本頁涵蓋描述數據集、擬合與判斷迴歸直線，以及找出會令自信答案出錯的品質問題。

進度只儲存在此瀏覽器。

01先有數據，後有模型

分析始於記錄了什麼，而非軟件能做什麼。每個變數都是一項量度屬性——抗壓強度、氯化物含量、延誤分鐘數——其類型決定合法的算術運算：

  • 名義標籤只能計數
  • 有序等級可排序
  • 區間數值可相減
  • 只有比率尺度才有真正的零點

大多數工程數據都是從較大母體抽取的樣本，因此每個摘要都是估計值。要問清楚各行是如何選取的；便利樣本量度的既是研究對象，也是抽樣方法。

02摘要數據集

第一輪是描述性且成本低廉：中心、離散度和形狀。平均值是平衡點，中位數是中間值，眾數是最常見的類別。離散度以標準差報告，其單位與數據相同；或以變異係數報告，其無量綱，可跨變數比較。偏態會把平均值拉向長尾，而中位數幾乎不動，這就是維修成本和降雨量以中位數引述的原因；任何摘要旁都應保留樣本量。

樣本平均值
\[\bar{x} = \frac{\sum x_i}{n}\]
n 個觀測值
樣本標準差
\[s = \sqrt{\frac{\sum (x_i - \bar{x})^2}{n - 1}}\]
n − 1 校正樣本量
變異係數
\[\mathrm{CV} = \frac{s}{\bar{x}}\]
無量綱
四種摘要統計量及各自誤導之處
統計量摘要什麼誤導之處
平均值所有數值的平衡點受極端值拉扯
中位數排序後的中間值忽略大多數數值的大小
標準差距平均值的典型距離假設對稱分佈
變異係數相對於平均值的離散度平均值接近零時不穩定

03相關既非斜率，亦非因果

先繪圖。兩個變數可以呈現明顯曲線，卻仍得出接近零的相關係數，因為 Pearson 係數 r 只量度線性關聯。它無單位，由 −1 到 +1，且不是斜率：r = 0.9 不會告訴你 x 每增加一單位 y 改變多少。相關亦非因果。第三個因素可以同時驅動兩個變數，因果箭頭可能反向，或樣本可能按結果選取。隨機化、對照組或自然實驗才可支持因果陳述。

Pearson 相關係數
\[r = \frac{\sum (x_i - \bar{x})(y_i - \bar{y})}{\sqrt{\sum (x_i - \bar{x})^2 \cdot \sum (y_i - \bar{y})^2}}\]
−1 ≤ r ≤ +1；只偵測線性關聯

04以最小二乘法擬合直線

簡單線性迴歸透過選擇使每個觀測值與直線之間垂直差距平方和最小的直線，來擬合 ŷ = a + b x。平方處理使正負誤差一視同仁，並對大誤差懲罰最重，因此一個離群值就能令擬合傾斜。斜率 b 是 x 每增加一單位時 y 的預測變化。截距 a 是 x = 0 時的預測值，通常超出量度範圍且物理上無意義。兩者都應連單位引述，且絕不可把外推預測當作已量度值呈現。

最小二乘斜率
\[b = \frac{\sum (x_i - \bar{x})(y_i - \bar{y})}{\sum (x_i - \bar{x})^2}\]
x 每改變一單位時 y 的變化
截距
\[a = \bar{y} - b\,\bar{x}\]
擬合直線為 ŷ = a + b x

05判斷擬合

決定係數 R² 是模型所解釋 y 變異的比例：1 表示每個點都在直線上，0 表示模型不比預測平均值好。它完全不說明模型形式是否正確——在窄範圍內擬合的曲線仍可得分很高。殘差圖才是誠實的檢驗。有規律表示模型設定錯誤，呈漏斗形表示變異隨 x 改變，少數極大殘差則標示影響點。應報告典型誤差，而非只報 R²。

決定係數
\[R^2 = 1 - \frac{\mathrm{SS}_{\mathrm{res}}}{\mathrm{SS}_{\mathrm{tot}}}\]
SS_res = Σ(yᵢ − ŷᵢ)² 及 SS_tot = Σ(yᵢ − ȳ)²

06誠實地檢驗模型

模型只有在未見過的數據上表現良好才有用。調參前先分出一組測試集，樣本小時則用交叉驗證；否則模型可記住訓練行而看似極佳。對於數值預測，報告平均絕對誤差或均方根誤差，兩者均以 y 的單位表示；均方根對大誤差懲罰更重。在精心選擇的測試集上誤差低是證據；在訓練集上誤差低只是算術。

均方根誤差
\[\mathrm{RMSE} = \sqrt{\frac{1}{n} \sum (y_i - \hat{y}_i)^2}\]

07數據品質陷阱

大多數建模失敗都是數據失敗。缺失值可能是有原因的缺失——感測器在閾值以上飽和——因此刪除不完整行會悄然改變所描述的母體。離群值值得調查：轉錄錯誤是修正，但真實極端值是資訊。洩漏發生於預測變數含有預測時不存在的信息，導致測試分數極佳但部署模型無用。檢查單位、重複、掩蓋變異的捨入及行序。以未來訓練的模型不是預測。

08來源、偏差、推論（SBI）

三個問題可令分析保持誠實。來源：誰收集這些數字，用什麼儀器，在什麼條件下？偏差：這個樣本系統性漏掉故事的哪部分——上限感測器、便利地點、被歸入「其他」的類別？推論：證據實際能延伸多遠，估計值旁應附什麼不確定性？最後一問是考試答案常忘記的。以十個點擬合的斜率支持方向及粗略幅度，而非精確預測：說明樣本量、殘差誤差及擬合範圍。

09分類：分數變成決策

當結果是類別——有缺陷或完好、合格或不合格——模型輸出分數，閾值把它變成決策。邏輯迴歸把線性分數經 sigmoid 壓縮，使輸出為概率；閾值 0.5 是預設而非定律，移動它會以一種錯誤換另一種。用混淆矩陣而非單靠準確率判斷分類器。精確率是被標記個案中真正陽性的比例，召回率是真正陽性中被找出的比例；它們懲罰相反的錯誤。在類別不平衡數據上，從不標記任何東西的模型可得高準確率卻什麼也找不到。

邏輯概率
\[p = \frac{1}{1 + e^{-s}}, \quad s = b_0 + b_1 x_1 + \cdots\]
線性分數 s 映射為 0 與 1 之間的概率
精確率與召回率
\[\mathrm{precision} = \frac{TP}{TP + FP}, \quad \mathrm{recall} = \frac{TP}{TP + FN}\]
TP、FP 及 FN 來自混淆矩陣

10特徵工程與縮放

交給模型的欄位就是模型的一半。標準化把變數中心化至零並重新縮放至單位標準差，防止某個大數值變數主導擬合；對數變換可馴服右偏變數如成本及濃度；獨熱編碼把名義類別轉為指示欄位。縮放及編碼須只用訓練集計算的統計量，然後把相同變換套用於測試集。先對全部數據縮放會悄然把測試集洩漏進訓練，令每個結果都偏樂觀。

標準化
\[z = \frac{x - \mu}{\sigma}\]
μ 及 σ 為訓練集的平均值及標準差
只在訓練數據上擬合變換 從訓練分割計算平均值、標準差及類別水平，然後在測試集重用；否則評估會過於樂觀。

11基線與誠實比較

沒有模型在抽象上好不好；只有相對於基線好不好。擬合任何東西前，先在同一測試集上為最簡單可辯護的替代方案評分——歷史平均值、上一期數值或單規則分類器——並在模型旁報告。在相同分割及相同指標上比較候選模型，當單位應字面理解時偏好平均絕對誤差：它直接報告典型誤差，而均方根誤差會放大罕見的大誤差。無法勝過平凡基線的模型不是改進，無論多巧妙。

平均絕對誤差
\[\mathrm{MAE} = \frac{1}{n} \sum |y_i - \hat{y}_i|\]
以 y 的單位表示的典型誤差

關鍵詞

殘差
觀測值與擬合模型預測值之間的垂直差距。
決定係數
擬合模型所解釋的反應變數變異比例。
最小二乘法
透過最小化殘差平方和來選擇參數的擬合規則。
樣本
實際量度的母體子集，並由此作出估計。
離群值
遠離其餘數據的觀測值，可能是記錄錯誤或真實極端值。
數據洩漏
使用含有作出預測時無法獲得的信息的預測變數。
混淆矩陣
真陽性、假陽性、假陰性及真陰性的表格，顯示分類器出錯之處。
標準化
把變數重新縮放至零平均值及單位標準差，通常使用訓練集的統計量。
計算示例

擬合強度對養護時間

一項小型試驗在五個齡期量度混凝土養護 x 天後的強度 y（MPa）：(1, 10)、(2, 12)、(3, 15)、(4, 18)、(5, 20)。擬合最小二乘直線，求 R²，並解釋斜率。

  1. 摘要：Σx = 15，故 x̄ = 3 天；Σy = 75，故 ȳ = 15 MPa。
  2. 對平均值的偏差給出 Σ(xᵢ − x̄)² = 4 + 1 + 0 + 1 + 4 = 10 及 Σ(xᵢ − x̄)(yᵢ − ȳ) = 10 + 3 + 0 + 3 + 10 = 26。
  3. 斜率：b = 26 / 10 = 2.60 MPa 每天。截距：a = ȳ − b x̄ = 15 − 2.60 × 3 = 7.2 MPa，故 ŷ = 7.2 + 2.60x。
  4. 預測值為 9.8、12.4、15.0、17.6 及 20.2 MPa，殘差為 0.2、−0.4、0、0.4 及 −0.2。於是 SS_res = 0.40，SS_tot = 25 + 9 + 0 + 9 + 25 = 68。
  5. R² = 1 − 0.40/68 = 0.994，故直線解釋這五個齡期強度變異的 99.4%。
Answerŷ = 7.2 + 2.60x（MPa），R² = 0.994。每多一天與預測強度約高 2.6 MPa 相關，但只有五個點且範圍僅 1–5 天，不應把直線外推至 28 天設計強度。

應試方法

  • 寫出斜率的單位（每 x 單位的 y 單位）及截距的單位——只寫數字會失分。
  • 切勿把 R² 描述為準確率：它是所解釋變異的比例，不是正確預測的百分比。
  • 在為任何擬合辯護前先繪數據圖，再繪殘差圖；殘差有規律表示模型錯誤。
  • 說明擬合範圍及樣本量，並指出預測何時屬外推。
  • 聲稱任何模型好之前，先在同一測試集報告樸素基線；分數只有相對於某事物才有意義。

自我測驗

0 / 6 正確

先作答，再查看解釋。錯誤答案比熟悉的一頁更有用。

Q01一個迴歸以養護時間預測混凝土強度並報告 R² = 0.02。最準確的解讀是：

解釋R² 是變異的比例，不是正確預測的百分比；此處直線幾乎不比預測平均值好。

Q02強度對養護時間的最小二乘擬合給出 b = 2.6 MPa 每天。哪句正確？

解釋斜率是 x 每單位時的預測變化；關聯不是因果證明，斜率也不是百分比。

Q03一個模型用混凝土澆築後記錄的延性測試來預測 28 天強度，並在訓練及測試數據上都得分極佳。最可能的問題是：

解釋洩漏讓未來信息進入預測變數；模型看似極佳但預測時無法使用。

Q04對於右偏的維修成本數據，哪一對最能描述典型值及其離散度？

解釋中位數及四分位距不受長尾影響，而平均值及標準差會被拉扯。

Q05一個缺陷偵測器在 400 塊面板上運行：標記 60 塊，其中 45 塊真正有缺陷，另有 25 個真正缺陷未被標記。其精確率是：

解釋精確率是標記面板中真正有缺陷的比例：TP/(TP + FP) = 45/60 = 0.75。

Q06一個團隊在分割前用整個數據集的平均值及標準差標準化變數。可能的後果是：

解釋對所有行計算變換會讓測試集影響訓練流程，誇大所報告的表現。
