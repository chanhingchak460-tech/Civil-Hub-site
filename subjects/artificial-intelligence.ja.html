人工知能とは、知覚し、推論し、学習するシステムを構築する工学である。このページでは、探索、知識表現、学習、ニューラルネットワーク、生成モデル、そしてそれらを誠実に評価する方法を扱う。

01AIがエンジニアに問いかけるもの

AIは単一のアルゴリズムではなく、不確実性のもとで行動するための手法群である。古典的な枠組みでは知覚、推論、学習、行動を分け、システムが何を決定しなければならないか、何を観測できるか、誤った場合にどれだけのコストがかかるかを問う。

実運用されているAIのほとんどは狭いAIである。一つのタスクには優れるが、転用はできない。これは欠陥ではなく設計上の範囲であり、それを明文化することが最初のエンジニアリング上の決定である。

02探索：目標から経路へ

多くの問題は状態空間として定式化される。すなわち状態、行動、開始状態、目標、そして1ステップあたりのコストである。

  • 幅優先探索は最小のステップ数を見つける。
  • 深さ優先探索はメモリを節約するが、迷走することがある。
  • 一様コスト探索は最も安い接頭辞を最初に展開する。
  • A*は残りコストのヒューリスティック推定を加える。

ヒューリスティックが決して過大評価しない場合、つまり許容的であれば、A*はすべてを探索することなく最小コストの経路を返す。ヒューリスティックこそが設計のすべてである。弱すぎればほぼ盲目になり、楽観的すぎれば最適性を失う。

A*の評価関数
\[f(n) = g(n) + h(n)\]
gは開始状態からのコスト、hは目標までの推定コスト

03知識表現

推論システムには、操作可能な世界のモデルが必要である。

  • 論理は事実と規則を表現し、機械的に結論を導出する。
  • フレームや意味ネットワークはオブジェクトの周りに属性をまとめる。
  • オントロジーや知識グラフは共有語彙を定め、異なるシステムが同じ用語で同じ意味を指すようにする。

エンジニアリングの知識は雑然として不確実である。確率モデル、信頼度を伴う規則、明示的な仮定は、何が未知であるかを記録する。これは何が既知であるかと同じくらい重要である。

04機械学習：写像を学習する

教師ありモデルは、例を用いて特徴量からラベルへの写像を学習する。データは訓練、検証、テストの各集合に分割され、テスト集合は汎化を推定するために最後に一度だけ触れられる。

訓練データには適合するが新しいデータでは失敗するモデルは過学習である。対策は複雑さではなく規律である。すなわち代表的なデータ、正則化、より単純なモデル、そしてテストスコアを密かに調整しない検証ループである。常に単純なベースラインを報告すること。

05ニューラルネットワークと深層学習

単一の人工ニューロンは、入力の重み付き和にバイアスを加え、その結果を非線形の活性化関数に通して計算する。層を積み重ねることで複雑な関係を表現できる。

訓練は損失を減らすように重みを調整する。通常は勾配降下法により、誤差逆伝播が各重みの勾配を供給する。

深さが役立つのは、初期の層が一般的な特徴を学習し、後の層がそれらを組み合わせるからである。一方で最適化は難しくなり、データ需要は増し、挙動は解釈しにくくなる。

人工ニューロン
\[a = \varphi\left(\sum_i w_i x_i + b\right)\]
φはReLUやシグモイドなどの非線形活性化関数
勾配降下法の更新
\[w \leftarrow w - \eta \frac{\partial L}{\partial w}\]
ηは学習率、勾配は誤差逆伝播から得られる

06生成モデル

生成モデルは訓練データの分布を学習し、新しいサンプルを生成する。

  • 大規模言語モデルは先行するトークンから次のトークンを予測するため、生成は予測の繰り返しである。
  • 拡散モデルは訓練時にデータにノイズを加え、サンプリング時にその過程を逆転させることを学習する。

生成は想起ではなくサンプリングである。それが流暢さとハルシネーションの両方を説明する。もっともらしい続きは真実の続きではない。

Autoregressive generation
\[p(x_1, \ldots, x_T) = \prod_{t=1}^{T} p(x_t \mid x_{<t})\]
the probability of a sequence is built one token at a time

07評価は設計の一部である

モデルの良し悪しは、それを判断するために用いる証拠の質に等しい。データを誠実に分割し、ホールドアウト集合を確保し、誤りのコストに合った指標を選ぶこと。

欠陥検出では、適合率はフラグを立てた欠陥のうち実際に本物だった割合を問い、再現率は実際の欠陥のうち検出できた割合を問う。常に「欠陥なし」と言う高精度モデルは役に立たない。

評価はまた、レイテンシ、入力の変化に対する頑健性、キャリブレーション、テストデータの漏洩も対象とする。生成出力には、事前に基準を定めたルーブリックに基づく人間の評価が必要である。

評価指標と、それぞれが隠しうる失敗
指標答える問い隠される失敗
精度全体でどれだけのケースが正しくラベル付けされたか稀なクラスでの失敗
適合率フラグを立てたケースのうちどれだけが正しかったか真陽性の見逃し
再現率真のケースのうちどれだけが見つかったか誤警報
F1スコア適合率と再現率のバランス真陰性、および各誤りのコスト
キャリブレーション予測確率が結果と一致するか自信があるが誤った回答

08責任あるAIと専門的判断

AIの導入は結果を伴う専門的な行為である。

  • 説明責任は、モデルが提案を行った場合でもエンジニアに残る。
  • 訓練データのバイアスは意思決定のバイアスになる。
  • 個人データには適法な根拠が必要である。
  • 生成コンテンツは権利を侵害したり、証拠と誤認されたりする可能性がある。

管理策は安全工学でおなじみのものである。データとモデルを文書化し、実際に使用する母集団でテストし、高リスクの出力には人間の判断点を設け、導入後も監視し、システムを説明・撤回できるようにすること。

意思決定の期待コスト
\[E[\text{cost}] = p_{fp} C_{fp} + p_{fn} C_{fn}\]
決定しきい値は2つの誤りの相対コストを反映すべきである

09プロンプトエンジニアリング

言語モデルの出力品質はプロンプト、すなわち生成前に与える指示、文脈、例によって決まる。

  • 効果的なプロンプトはタスクと対象読者について具体的である。
  • 曖昧なヒントではなく、データと例を提供する。
  • 望ましい出力形式を明示する。
  • してはいけないことではなく、代わりに何をすべきかを記述する。
  • モデルに役割（レビュアー、チューター、現場エンジニア）を与えると、使用する語彙の枠組みが定まる。

思考の連鎖プロンプティングは、答える前に中間ステップを踏むようモデルに求めるもので、算術や多段階推論を測定可能なほど改善する。温度はサンプリングのランダム性を制御する。低い値は最も確率の高いトークンを繰り返し、決定的で安全な出力を与える。高い値は流暢さと引き換えに多様性とハルシネーションを増やす。

温度スケーリング付きソフトマックス
\[p(w_i) = \frac{e^{z_i/T}}{\sum_j e^{z_j/T}}\]
T → 0 は最も確率の高いトークンを選び、Tが大きいほど分布は平坦になる

10生成メディア：画像、音声、動画

拡散モデルは、徐々にノイズを加える過程を逆転させることを学習することで画像を生成する。サンプリングは純粋なノイズから始まり、テキスト記述などの条件付けに導かれながら段階的にノイズを除去する。音声モデルは同じ考え方を波形やスペクトログラムに適用して音声や音楽を生成し、動画生成ではさらに連続するフレームの一貫性を保つ必要がある。

生成メディアは原則として証拠性のないものとして扱うこと。合成された顔や声は作るのが安価で、人間には検出しにくい。検証は来歴、すなわちウォーターマーク、署名付きメタデータ、検出ツールに依存し、またラベリングなどのプロセス管理にも依存する。視聴者に偽物を見抜くよう求めることに依存してはならない。

拡散モデルの訓練目的関数
\[L = \mathbb{E}\left\lVert \varepsilon - \varepsilon_\theta(x_t, t) \right\rVert^2\]
ネットワークは劣化したサンプルに加えられたノイズεを予測することを学習する

11コード生成とその限界

大規模言語モデルは自然言語、部分的なプログラム、実行例からコードを書き、コーディングアシスタントはタブ補完とチャットベースの編集を組み合わせる。

  • 定型コード、正規表現、テストの足場づくりは得意である。
  • 文脈が長い場合、ライブラリがマイナーな場合、正解がモデルの見たことのない事実に依存する場合は苦手である。

pass@kは標準的な尺度である。すなわち、k回の生成試行のうち少なくとも1回が提供されたすべてのテストに合格する確率である。したがって評価の質はテストスイートの質に等しい。コンパイルが通るコードでも誤っていることはある。生成コードは人間のコードとまったく同じようにレビューすること。テストを実行し、存在しないライブラリ関数のハルシネーションを確認し、安全に関わるものには人間の責任者を置くこと。

Pass@k
\[\text{pass@}k = 1 - (1 - p)^k\]
pは1つのサンプルが合格する確率、試行を増やすと確率は上がるが計算コストがかかる
ハルシネーションされたAPI 生成コードは存在しない関数やライブラリを呼び出すことがある。信頼する前にテストハーネスで実行し、認証情報や非公開データを公開モデルに貼り付けないこと。

Key terms

許容的ヒューリスティック
残りコストの推定値が真のコストを決して超えないもの。これによりA*探索の最適性が保たれる。
過学習
訓練データに過度に適合し、新しい未見のデータでの性能が低下すること。
適合率
モデルがフラグを立てたケースのうち、実際に陽性である割合。
ハルシネーション
流暢でもっともらしいが、裏付けのない、または虚偽の生成コンテンツ。
拡散モデル
徐々にノイズを加える過程を逆転させることを学習し、サンプルを生成する生成モデル。
汎化
モデルが訓練されていないデータでの性能。ホールドアウトしたテスト集合で推定する。
プロンプトエンジニアリング
言語モデルが望ましい出力を生成するように、指示、文脈、例を設計すること。
温度
トークン確率をスケーリングするサンプリングパラメータ。低い値は決定的、高い値はより多様になる。
Worked example

欠陥検出器の混同行列を読む

ある画像モデルを500枚の検査画像でテストした。92枚の欠陥パネルを正しくフラグし、362枚の良品を正しく合格とした。18枚の良品を誤ってフラグし、28枚の欠陥パネルを見逃した。精度、適合率、再現率を計算し、精度だけがなぜ誤解を招くかを述べよ。

  1. 混同行列：TP = 92、FP = 18、FN = 28、TN = 362、合計500枚。
  2. 精度 = (TP + TN) / 合計 = (92 + 362) / 500 = 454 / 500 = 0.908、すなわち90.8パーセント。
  3. 適合率 = TP / (TP + FP) = 92 / 110 = 0.836、すなわち83.6パーセント。
  4. 再現率 = TP / (TP + FN) = 92 / 120 = 0.767、すなわち76.7パーセント。
  5. F1 = 2PR / (P + R) = 2 × 0.836 × 0.767 / (1.603) = 0.80。
  6. ベースラインの確認：常に良品と言うモデルは何も検出しないまま380 / 500 = 76パーセントの精度を出す。したがって不均衡な集合では精度だけではモデルを過大評価する。
Answer精度は90.8パーセント、適合率は83.6パーセント、再現率は76.7パーセントで、F1は約0.80である。欠陥パネルの約4枚に1枚を見逃しているため、安全に関わる検査タスクでは再現率を上げるようにしきい値を動かし、誤警報のコストを見逃しコストと比較検討すべきである。

Exam method

  • 探索アルゴリズムを論じる前に、状態空間、行動、1ステップのコストを書き下すこと。
  • 適合率と再現率はデータセットと分割とともに示すこと。どちらの数値も単独では意味を持たない。
  • 責任あるAIの問いでは、名前のある人間に説明責任を負わせ、監視ステップがどこにあるかを明示すること。
  • 何かを生成する前に評価ルーブリックを定め、生成出力をそれに照らしてブラインドで採点すること。品質の印象は指標ではない。
