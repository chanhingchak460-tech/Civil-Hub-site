人工智能是建構能夠感知、推理和學習的系統的工程學科。本頁涵蓋搜尋、知識表示、學習、神經網絡、生成模型，以及如何誠實地評估它們。

進度只儲存在此瀏覽器。

01人工智能對工程師的要求

人工智能並非單一演算法，而是一系列在不確定性下採取行動的方法。經典框架將感知、推理、學習和行動分開，並追問系統必須決定甚麼、能夠觀察甚麼，以及出錯的代價是甚麼。

大多數已部署的人工智能都是窄義的：擅長單一任務，無法轉移。這是設計範圍而非缺陷，把它寫下來是第一個工程決定。

02搜尋：從目標到路徑

許多問題都以狀態空間表述：狀態、動作、起點、目標和每步成本。

  • 廣度優先搜尋找到最少步數。
  • 深度優先節省記憶體但可能漫遊。
  • 均勻成本搜尋先擴展最便宜的前綴。
  • A* 加入剩餘成本的啟發式估計。

如果啟發式從不高估——即它是可採納的——A* 會返回最低成本路徑而無需探索一切。啟發式就是整個設計：太弱幾乎等於盲目，過於樂觀則失去最優性。

A* 評估函數
\[f(n) = g(n) + h(n)\]
g 是從起點的成本，h 是到目標的估計成本

03知識表示

推理系統需要一個可操作的世界的模型。

  • 邏輯表示事實和規則，並機械地推導結論。
  • 框架和語義網絡圍繞物件分組屬性。
  • 本體和知識圖譜固定共享詞彙，使不同系統對同一術語有相同含義。

工程知識是混亂和不確定的。概率模型、帶置信度的規則和明確假設記錄了未知的事物，這與已知的事物同樣重要。

04機器學習：學習映射

監督模型使用例子學習從特徵到標籤的映射。數據分為訓練集、驗證集和測試集；測試集只在最後觸碰一次，以估計泛化。

擬合訓練數據但在新數據上失敗的模型是過擬合。補救方法是紀律而非複雜性：具代表性的數據、正則化、更簡單的模型，以及不會悄悄調整測試分數的驗證循環。始終報告一個樸素基線。

05神經網絡與深度學習

單個人工神經元計算其輸入的加權和加上偏置，並將結果通過非線性激活函數。堆疊層表示複雜關係。

訓練調整權重以減少損失，通常通過梯度下降，並由反向傳播為每個權重提供梯度。

深度有幫助，因為早期層學習一般特徵，後期層將它們組合。它也令優化更難、數據需求更大、行為更難解釋。

人工神經元
\[a = \varphi\left(\sum_i w_i x_i + b\right)\]
φ 是非線性激活，例如 ReLU 或 sigmoid
梯度下降更新
\[w \leftarrow w - \eta \frac{\partial L}{\partial w}\]
η 是學習率；梯度來自反向傳播

06生成模型

生成模型學習其訓練數據的分佈並產生新樣本。

  • 大型語言模型從前面的詞元預測下一個詞元，因此生成是重複預測。
  • 擴散模型在訓練中向數據添加噪聲，並在採樣時學習逆轉該過程。

生成是採樣，不是回憶。這解釋了流暢性和幻覺：一個看似合理的續寫並非真實的續寫。

自迴歸生成
\[p(x_1, \ldots, x_T) = \prod_{t=1}^{T} p(x_t \mid x_{<t})\]
序列的概率逐個詞元建立

07評估是設計的一部分

模型的優劣取決於判斷它的證據。誠實地分割數據，保留一個留出集，並選擇與錯誤成本匹配的指標。

在缺陷檢測中，精確率問有多少被標記的缺陷是真實的，而召回率問有多少真實缺陷被捕捉；一個總是說無缺陷的高準確度模型是無用的。

評估還涵蓋延遲、對輸入偏移的穩健性、校準和測試數據洩漏。生成輸出需要基於評分標準的人工評估，標準須事先固定。

評估指標及每個指標可能隱藏的失敗
指標回答的問題隱藏的失敗
準確度總體有多少案例被正確標記在罕見類別上的失敗
精確率在被標記的案例中，有多少是正確的漏掉的真陽性
召回率在真實案例中，有多少被找到誤報
F1 分數精確率和召回率的平衡真陰性，以及每個錯誤的成本
校準預測概率是否與結果匹配自信但錯誤的答案

08負責任的人工智能與專業判斷

部署人工智能是具有後果的專業行為。

  • 問責仍屬於工程師，即使建議是由模型提出的。
  • 訓練數據中的偏見會變成決策中的偏見。
  • 個人數據需要合法依據。
  • 生成的內容可能侵犯權利或被誤認為證據。

控制措施在安全工程中很熟悉：記錄數據和模型，在將使用它的群體上測試，為高風險輸出保留人類決策點，部署後監控，並能夠解釋和撤回系統。

決策的預期成本
\[E[\text{cost}] = p_{fp} C_{fp} + p_{fn} C_{fn}\]
決策閾值應反映兩種錯誤的相對成本

09提示工程

語言模型的輸出質量由其提示決定：生成前給出的指令、上下文和例子。

  • 有效的提示對任務和受眾具體明確。
  • 提供數據和例子，而非模糊的提示。
  • 指明所需的輸出格式。
  • 描述要做甚麼，而非不要做甚麼。
  • 給模型一個角色——審閱者、導師、現場工程師——框定它將使用的詞彙。

思維鏈提示要求模型在回答前逐步推理，這可測量地改善算術和多步推理。溫度控制採樣隨機性：低值重複最可能的詞元，給出確定、安全的輸出；高值以流暢性換取多樣性和幻覺。

溫度縮放的 softmax
\[p(w_i) = \frac{e^{z_i/T}}{\sum_j e^{z_j/T}}\]
T → 0 選擇最可能的詞元；較大的 T 使分佈更平坦

10生成媒體：圖像、音頻和視頻

擴散模型通過學習逆轉一個逐漸添加噪聲的過程來生成圖像：採樣從純噪聲開始，在文本描述或其他條件的引導下逐步去噪。音頻模型將同樣的想法應用於波形或頻譜圖，用於語音和音樂，而視頻生成還必須保持連續幀的一致性。

默認將生成的媒體視為無證據：合成面孔和聲音製作成本低廉，人們難以察覺。驗證依賴於來源——水印、簽名元數據和檢測工具——以及流程控制如標籤，而非要求觀眾識別假貨。

擴散訓練目標
\[L = \mathbb{E}\left\lVert \varepsilon - \varepsilon_\theta(x_t, t) \right\rVert^2\]
網絡學習預測添加到損壞樣本中的噪聲 ε

11代碼生成及其局限

大型語言模型從自然語言、部分程序或執行例子編寫代碼，編碼助手結合製表符補全與基於聊天的編輯。

  • 擅長樣板代碼、正則表達式和測試腳手架。
  • 在上下文長、庫不常見或正確答案依賴模型從未見過的事實時較弱。

pass@k 是標準度量：k 次生成嘗試中至少一次通過所有提供測試的概率。因此評估的優劣取決於測試套件——能編譯的代碼仍可能是錯的。像審查人類代碼一樣審查生成的代碼：運行測試，檢查幻覺的庫函數，並為任何涉及安全的內容保留人類負責人。

Pass@k
\[\text{pass@}k = 1 - (1 - p)^k\]
p 是一個樣本通過的機會；更多嘗試提高機率但消耗算力
幻覺的 API 生成的代碼可能調用不存在的函數或庫；在信任它之前在測試框架中運行，並且永遠不要將憑證或私人數據粘貼到公共模型中。

關鍵詞

可採納啟發式
剩餘成本的估計從不超過真實成本，這使 A* 搜尋保持最優。
過擬合
過於緊密地擬合訓練數據，以致在新的、未見數據上的性能下降。
精確率
模型標記的案例中真正為陽性的比例。
幻覺
流暢、看似合理但缺乏支持或虛假的生成內容。
擴散模型
一種生成模型，學習逆轉逐漸加噪的過程以產生樣本。
泛化
模型未經訓練的數據上的性能，用留出測試集估計。
提示工程
設計指令、上下文和例子，使語言模型產生所需的輸出。
溫度
一種採樣參數，縮放詞元概率；低值確定性高，高值更多樣。
計算示例

解讀缺陷檢測器的混淆矩陣

一個視覺模型在 500 張檢測圖像上測試。它正確標記 92 塊缺陷面板，正確清除 362 塊完好面板。它錯誤標記 18 塊完好面板，漏掉 28 塊缺陷面板。計算準確度、精確率和召回率，並說明為何單獨的準確度會誤導。

  1. 混淆矩陣：TP = 92，FP = 18，FN = 28，TN = 362，總計 500 張圖像。
  2. 準確度 = (TP + TN) / 總數 = (92 + 362) / 500 = 454 / 500 = 0.908，即 90.8%。
  3. 精確率 = TP / (TP + FP) = 92 / 110 = 0.836，即 83.6%。
  4. 召回率 = TP / (TP + FN) = 92 / 120 = 0.767，即 76.7%。
  5. F1 = 2PR / (P + R) = 2 × 0.836 × 0.767 / (1.603) = 0.80。
  6. 基線檢查：一個總是說完好的模型得分 380 / 500 = 76% 準確度，卻檢測不到任何東西，因此在不平衡集上單獨的準確度會美化模型。
Answer準確度為 90.8%，精確率 83.6%，召回率 76.7%，F1 約為 0.80。約四分之一的缺陷面板被漏掉，因此對於安全相關的檢測任務，應移動閾值以提高召回率，並權衡誤報成本與漏檢缺陷成本。

應試方法

  • 在討論任何搜尋演算法之前，寫下狀態空間、動作和一步的成本。
  • 將精確率和召回率與數據集和分割一起引用；單獨的數字毫無意義。
  • 在負責任人工智能問題中，保留一個具名的人類負責人，並說明監督步驟的位置。
  • 在生成任何東西之前固定評估標準，並盲評生成輸出；質量的印象不是指標。
