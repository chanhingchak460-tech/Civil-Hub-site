Rは測定値のスプレッドシートを、弁護可能な論証へと変える。データを整え、記述し、プロットし、当てはめ、予測する。その技能の大半は、これらの手順の順序と、他の誰かが再実行できるスクリプトにある。

01データフレームから始める

データフレームが作業の単位である。各行は1つの観測、各列は1つの変数である。Rは列をベクトルとして保持するため、測定値は数値のまま保たれ、カテゴリは因子にすべきである。

read.csv()はファイルを読むだけであり、その後str()とhead()で形状を確認する。整然データ（tidy data）とは、1行につき1ケース、1列につき1変数、1セルにつき1値という形式である。その後のトラブルの多く——数値がテキストとして取り込まれる、日付が文字列として保存される——はここで見え、早期に修正する方がモデルを後から修繕するより安く済む。

モデル化の前に記述する。summary()は範囲、四分位数、欠損数を与え、mean()、median()、sd()、IQR()は引用する数値を与える。平均が中央値から大きく離れていれば、歪みや外れ値の存在を示唆する。

読み込み、確認、記述 
pm <- read.csv('data/pm.csv')
str(pm); dim(pm); head(pm)
summary(pm$value); sd(pm$value, na.rm = TRUE)
相対パスはスクリプトを移植可能に保つ

02ループではなく動詞で整える

データ整形は小さな動詞の連続であり、それぞれが1つのことを行う：
- filter()は行を保持する
- select()は列を保持する
- mutate()は列を追加する
- arrange()は並べ替える
- group_by()とsummarise()はグループごとに1つの要約行を与える

パイプ|&gt;は各結果を次のステップへ渡すため、コードは推論の順序で読める。ステップに名前を付けにくいなら、それは2つの仕事をしており、分割すべきである。group_by()とsummarise()は、カテゴリごとの手書きループの大半も置き換える。

小さなグループ化パイプライン 
daily <- pm |>
  filter(!is.na(value)) |>
  mutate(month = format(date, '%m')) |>
  group_by(month) |>
  summarise(mean_pm = mean(value), n = n())
月ごとに1行、平均の隣に件数

03欠損値と外れ値を探す

欠損値は中立ではない。標本を縮小し、ある期間やある地点に集中していれば平均に偏りをもたらす。mean(is.na(x))で数え、削除・補完・モデル化のいずれかを決め、その決定を書き留める。

外れ値にも決定が必要である。他より20倍大きい測定値は、実際の事象かもしれないし入力ミスかもしれず、両者は異なる扱いに値する。箱ひげ図は形状を示し、対数スケールは長い裾をしばしば鎮める。

欠損値の割合
mean(is.na(x))
件数ではなく0から1の割合

04プロットはデータについての論証である

グラフィックスの文法はプロットをデータ、美的マッピング、ジオメトリに分ける。ggplot()ではaes()がどの変数がx、y、色、形を制御するかを示し、ジオメトリが何を描くかを示す。ジオメトリを変えれば主張が変わる。

色は変数を符号化すべきであり、装飾すべきではない。facet_wrap()はスモールマルチプルを作り、5本の重ねた線よりしばしば明確である。両軸にラベルを付け、タイトルには要点を与える。ggsave()は図を再現可能に保つ。

色をマッピングした点
ggplot(pm, aes(x = date, y = value, colour = site)) + geom_point() + labs(x = 'Date', y = 'PM2.5 (µg/m³)')
色が地点を符号化する

05回帰：法則ではなく当てはめた直線

lm(y ~ x, data = pm)は最小二乗直線を当てはめる。傾きはxの1単位変化あたりのyの期待変化であり、その単位が重要で、符号は物理的に意味を持たねばならない。R²はモデルが説明するyの分散の割合であり、モデルが正しい確率ではない。

常に残差を確認する。曲線は関係が線形でないことを意味し、扇状は分散が変化することを意味し、少数の極端な点が当てはめを支配しているかもしれない。相関は因果ではなく、観測範囲を超えた外挿は証拠ではない。

単純線形モデル
\[y = \beta_0 + \beta_1 x + \varepsilon\]
εは直線が説明しないものを集める
決定係数
\[R^2 = 1 - \frac{\mathrm{SSE}}{\mathrm{SST}}\]
説明される変動の割合

06時系列、季節性、ARIMA

時系列は順序を持つため、隣接する値は関連し、通常の回帰の仮定は成り立たない。月次データならts(x, frequency = 12)で変換し、プロットする。トレンド、繰り返す季節性、ノイズが見えるはずである。decompose()は系列をそれらの部分に分解する。

系列が定常であるとは、その平均、分散、自己相関が時間とともに漂わないことである。差分はトレンドを除去し、自己相関プロットと偏自己相関プロットがARIMA(p, d, q)の次数を示唆する。pは自己回帰項、dは差分、qは移動平均項である。auto.arima()は探索し、forecast()は広がる予測区間とともに値を報告する。その区間のない予測は半分の答えである。

加法分解
\[y_t = T_t + S_t + E_t\]
トレンド、季節、残差
一階差分
\[\Delta y_t = y_t - y_{t-1}\]
線形トレンドを除去する
ARIMAモデル
\[\varphi(B)(1 - B)^d y_t = \theta(B)\,\varepsilon_t\]
Bは後退シフト演算子

07他の誰かが実行できるスクリプト

結果はその背後にあるスクリプトの良さにしかならない。シミュレーションの前にset.seed()でシードを設定し、相対パスでデータを読み、生ファイルを手で編集してはならない。クリーニングはコードとして保つ。出力は入力とは別のフォルダに保存する。

なぜをコメントし、長い作業を関数に分割し、パッケージのバージョンを記録する。スクリプトの実行方法を述べた短いreadmeは分析の一部である。再現可能なスクリプトは数値を検証可能にする。

乱数シードを固定する 
set.seed(1234)
同じシード、同じシミュレート標本

08Rでの仮説検定

Rは古典的な検定をワンライナーとしてパッケージ化しており、規律は紙の上と同じである。何かを実行する前に帰無仮説を述べる。t.test(x, mu = 40)は1標本を値に対して検定し、t.test(x, y)は2群を比較し、paired = TRUEは差の検定に切り替える。chisq.test(table)は度数を扱い、aov()は分散分析を当てはめる。

出力は全体として読む。p値は有意性に答え、信頼区間は効果の大きさを示し、自由度はその背後にどれだけの証拠があるかを示す。極小のp値と微小な区間は、統計的に有意でありながら実質的に無関係でありうる。

1標本および2標本t検定
t.test(x, mu = 40) t.test(x, y, alternative = 'two.sided', paired = FALSE)
alternativeとpairedを明示する。デフォルトは検定の意味を黙って変えうる

09テーブルの結合と整形

実際の分析が1つの整然ファイルで届くことはまれである。結合は共有キーでテーブルを組み合わせる。left_join(a, b, by = 'site')はaの全行を保持しbから一致する列を持ち込み、inner_join()は両方に存在する行のみを保持し、anti_join()は一致しない行を見つける——欠落地点を特定する道具である。

整形は同じ値をワイド形式とロング形式の間で移す。pivot_longer()は多数の列をキーと値の行に集め、pivot_wider()はそれらを広げて戻す。ロング形式はggplot()とグループ化要約が求めるものである。結合の前後で行数を確認する。重複キーは黙って行を増殖させる。

結合とピボット 
readings <- left_join(sites, readings, by = 'site')
long <- readings |>
  pivot_longer(cols = starts_with('month'), names_to = 'month', values_to = 'value')
ピボット後は地点-月ごとに1行

10glm()による一般化線形モデル

二値の結果——合格か不合格か、不良か良品か——は通常の最小二乗ではうまく当てはめられない。直線は0と1の外の確率を予測するからである。glm(y ~ x, family = binomial)はロジスティック回帰を当てはめ、線形スコアをシグモイドに通して予測を0と1の間に保つ。

predict(model, newdata, type = 'response')は確率を返す。type = 'response'がなければ対数オッズを返し、誤読しやすい。確率を選んだ閾値でクラスに変換し、全体の正解率ではなく少数クラスの適合率と再現率を報告する。

ロジスティックリンク
\[p = \frac{1}{1 + e^{-(\beta_0 + \beta_1 x)}}\]
シグモイドは線形スコアを(0, 1)に写す
当てはめと予測 
fit <- glm(pass ~ strength, data = cubes, family = binomial)
pred <- predict(fit, newdata = new_cubes, type = 'response')
type = 'response'は対数オッズではなく確率を与える
確率を明示的に要求する 二項glmに対するpredict()は、type = 'response'を設定しない限り対数オッズを返す。引数を忘れると0.80が−1.39になる。

Key terms

データフレーム
各列が変数、各行が観測である表であり、Rの基本作業オブジェクト。
整然データ
1行につき1ケース、1列につき1変数、1セルにつき1値というレイアウト。
パイプ
あるステップの結果を次のステップの第1引数として渡す演算子であり、コードが実行順に読める。
残差
観測値と当てはめたモデルによる予測値との差。
定常性
平均、分散、自己相関が時間とともに変化しない時系列の性質。
決定係数
R²であり、当てはめたモデルが説明する応答の全変動の割合。
一般化線形モデル
線形スコアを非正規の結果にリンクするglm()で当てはめるモデルであり、二値応答に対するロジスティック回帰など。
左結合
最初のテーブルの全行を保持し、2番目のテーブルから一致する列を追加するテーブル結合。
Worked example

日次測定値の要約を読み取り解釈する

あるファイルに1台のモニターからの10日分のPM2.5測定値（µg/m³）が入っている：18.0, 21.5, 19.2, 24.8, 60.1, 22.3, 20.6, 23.4, 19.9, 21.0。Rで値を読み取り、平均、中央値、標準偏差、四分位範囲を計算せよ。このモニターでの典型的な日について、数値が何を意味するか述べよ。

  1. ファイルをデータフレームに読み込み、列を取り出す：d <- read.csv('pm.csv'); x <- d$value。length(x)でn = 10を確認する。
  2. 平均：sum(x)/length(x) = 250.8/10 = 25.1 µg/m³。
  3. 中央値：中央の2つの値は21.0と21.5なので、中央値は21.25 ≈ 21.3 µg/m³。
  4. 標準偏差：偏差平方和は約1398なので、標本分散は1398/9 ≈ 155.3、sd ≈ 12.5 µg/m³。
  5. 四分位数：Q1 = 20.1、Q3 = 23.1なので、IQR = 3.0 µg/m³。
  6. 平均25.1と中央値21.3を比較する。60.1という単一の測定値を除くと平均は21.2となり、ほぼ中央値と一致する。
Answer平均25.1 µg/m³、中央値21.3 µg/m³、sd 12.5 µg/m³、IQR 3.0 µg/m³。10日のうち9日は21 µg/m³付近にあり、平均は1つのスパイクに引き上げられているため、中央値の方が典型的な日をよく表す。sdも同じ点によって膨らんでいる。中心とともに必ずばらつきを報告すること。

Exam method

  • 各要約統計量が何を仮定するかを述べる：平均は極端値に敏感で、中央値はそうでない。
  • 回帰の傾きを解釈するよう求められたら、その単位を示し、符号が物理的に意味を持つか確認する。
  • 時系列の問題では、トレンド、季節周期、ARIMA次数を示す前に系列に差分が必要かを名指しする。
  • どのレポートでも再現性（シード、相対パス、保存スクリプト）に言及する。それは埋め草ではなく得点になる文である。
  • t.test()ではalternative =とpaired =を明示する。デフォルトは検定の意味を静かに変える。
