R은 측정값 스프레드시트를 논증 가능한 주장으로 바꿔 줍니다. 데이터를 정돈하고, 기술하고, 시각화하고, 적합시키고, 예측하는 것입니다. 이 기술의 대부분은 그 단계들의 순서와 다른 사람이 다시 실행할 수 있는 스크립트에 달려 있습니다.

01데이터 프레임에서 시작하기

데이터 프레임은 작업의 단위입니다. 각 행은 하나의 관측값이고 각 열은 하나의 변수입니다. R은 열을 벡터로 유지하므로 측정값은 수치형으로 남고 범주는 팩터여야 합니다.

read.csv()는 파일을 읽기만 합니다. 그런 다음 str()과 head()로 형태를 확인하세요. 정돈된 데이터(tidy data)란 사례당 한 행, 변수당 한 열, 셀당 한 값을 의미합니다. 이후의 대부분의 문제 — 숫자가 텍스트로 가져와지거나 날짜가 문자로 저장되는 것 — 는 여기서 드러나며, 이를 일찍 고치는 것이 모델을 나중에 패치하는 것보다 저렴합니다.

모델링 전에 기술하세요. summary()는 범위, 사분위수, 결측 개수를 제공하고, mean(), median(), sd(), IQR()은 인용하게 될 숫자를 제공합니다. 중앙값에서 멀리 떨어진 평균은 왜도나 이상 관측값을 암시합니다.

읽기, 검사, 기술 
pm <- read.csv('data/pm.csv')
str(pm); dim(pm); head(pm)
summary(pm$value); sd(pm$value, na.rm = TRUE)
상대 경로는 스크립트를 이식 가능하게 유지합니다

02루프가 아닌 동사로 데이터 다루기

데이터 다루기는 각각 한 가지 일만 하는 작은 동사들의 연속입니다:
- filter()는 행을 유지합니다
- select()는 열을 유지합니다
- mutate()는 열을 추가합니다
- arrange()는 정렬합니다
- group_by()와 summarise()는 그룹당 하나의 요약 행을 제공합니다

파이프 |&gt;는 각 결과를 다음 단계로 넘기므로 코드가 추론 순서대로 읽힙니다. 어떤 단계의 이름을 붙이기 어렵다면 그것은 두 가지 일을 하고 있으므로 분리해야 합니다. group_by()와 summarise()는 또한 범주에 대한 대부분의 수작업 루프를 대체합니다.

작은 그룹화 파이프라인 
daily <- pm |>
  filter(!is.na(value)) |>
  mutate(month = format(date, '%m')) |>
  group_by(month) |>
  summarise(mean_pm = mean(value), n = n())
월당 한 행, 평균 옆에 개수 포함
일반적인 데이터 작업과 이를 수행하는 도구
작업도구주의할 점
표 읽기read.csv()먼저 str() 확인
행 유지filter()열에 대한 조건
열 추가mutate()길이가 일치해야 함
그룹별 요약summarise()group_by() 이후

03결측값과 이상값 찾기

결측값은 중립적이지 않습니다. 표본을 줄이고, 한 기간이나 한 지점에 몰려 있으면 평균을 편향시킵니다. mean(is.na(x))로 개수를 세고, 제거할지, 대체할지, 모델링할지 결정하세요 — 그리고 그 결정을 기록하세요.

이상값도 결정이 필요합니다. 다른 값의 20배인 판독값은 실제 사건일 수도 있고 입력 오류일 수도 있으며, 둘은 다른 처리를 받아야 합니다. 상자 그림은 형태를 보여주고, 로그 스케일은 때때로 긴 꼬리를 길들입니다.

결측값 비율
mean(is.na(x))
개수가 아닌 0에서 1 사이의 비율

04그래프는 데이터에 대한 주장이다

그래픽의 문법은 그래프를 데이터, 심미적 매핑, 기하학으로 나눕니다. ggplot()에서 aes()는 어느 변수가 x, y, 색상 또는 모양을 제어하는지 말하고, geom은 무엇이 그려지는지 말합니다. 기하학을 바꾸면 주장이 바뀝니다.

색상은 장식이 아니라 변수를 부호화해야 합니다. facet_wrap()은 작은 다중 패널을 만들며, 종종 다섯 개의 겹친 선보다 명확합니다. 두 축에 레이블을 붙이고 제목에 핵심 메시지를 담으세요. ggsave()는 그림을 재현 가능하게 유지합니다.

색상이 매핑된 점
ggplot(pm, aes(x = date, y = value, colour = site)) + geom_point() + labs(x = 'Date', y = 'PM2.5 (µg/m³)')
색상이 지점을 부호화합니다

05회귀: 법칙이 아닌 적합된 직선

lm(y ~ x, data = pm)은 최소제곱 직선을 적합합니다. 기울기는 x의 1단위 변화당 y의 기대 변화이므로 그 단위가 중요하고 부호가 물리적으로 타당해야 합니다. R²는 모델이 설명하는 y의 분산 비율이지, 모델이 옳을 확률이 아닙니다.

항상 잔차를 검사하세요. 곡선은 관계가 선형이 아님을, 부채꼴 모양은 분산이 변함을, 몇 개의 극단점이 적합을 지배할 수 있음을 의미합니다. 상관은 인과가 아니며, 관측 범위를 넘어선 외삽은 증거가 아닙니다.

단순 선형 모델
\[y = \beta_0 + \beta_1 x + \varepsilon\]
ε는 직선이 설명하지 못하는 것을 모읍니다
결정 계수
\[R^2 = 1 - \frac{\mathrm{SSE}}{\mathrm{SST}}\]
설명된 변동의 비율

06시계열, 계절성, ARIMA

시계열은 순서가 있으므로 이웃 값들이 관련되어 있고 일반 회귀 가정이 실패합니다. 월별 데이터의 경우 ts(x, frequency = 12)로 변환한 다음 그래프로 그리세요. 추세, 반복되는 계절성, 잡음이 보여야 합니다. decompose()는 시계열을 그 부분들로 분해합니다.

시계열이 정상(stationary)이라는 것은 평균, 분산, 자기상관이 시간에 따라 표류하지 않을 때입니다. 차분은 추세를 제거하고, 자기상관 및 편자기상관 그림은 ARIMA(p, d, q)의 차수를 제안합니다. p는 자기회귀 항, d는 차분, q는 이동평균 항입니다. auto.arima()는 탐색하고, forecast()는 넓어지는 예측 구간과 함께 값을 보고합니다 — 그 구간 없는 예측은 절반의 답입니다.

가법 분해
\[y_t = T_t + S_t + E_t\]
추세, 계절, 잔차
1차 차분
\[\Delta y_t = y_t - y_{t-1}\]
선형 추세를 제거합니다
ARIMA 모델
\[\varphi(B)(1 - B)^d y_t = \theta(B)\,\varepsilon_t\]
B는 후방 이동 연산자입니다

07다른 사람이 실행할 수 있는 스크립트

결과는 그 뒤에 있는 스크립트만큼만 좋습니다. 시뮬레이션 전에 set.seed()로 시드를 설정하고, 상대 경로로 데이터를 읽고, 원본 파일을 손으로 편집하지 마세요 — 정제를 코드로 유지하세요. 출력은 입력과 다른 폴더에 저장하세요.

왜 그런지 주석을 달고, 긴 작업을 함수로 나누고, 패키지 버전을 기록하세요. 스크립트 실행 방법을 설명하는 짧은 readme는 분석의 일부입니다. 재현 가능한 스크립트는 숫자를 검증 가능하게 만듭니다.

난수 시드 고정 
set.seed(1234)
같은 시드, 같은 시뮬레이션 표본

08R에서의 가설 검정

R은 고전적 검정을 한 줄로 패키징하며, 규율은 종이에서와 같습니다. 무엇이든 실행하기 전에 귀무가설을 진술하세요. t.test(x, mu = 40)은 한 표본을 값과 검정하고, t.test(x, y)는 두 그룹을 비교하며, paired = TRUE는 차이에 대한 검정으로 전환합니다. chisq.test(table)는 개수를 처리하고 aov()는 분산 분석을 적합합니다.

출력은 전체로 읽으세요. p-값은 유의성을 답하고, 신뢰구간은 효과의 크기를 보여주며, 자유도는 그 뒤에 얼마나 많은 증거가 있는지 말합니다. 아주 작은 구간과 함께한 아주 작은 p-값은 통계적으로 유의하지만 실질적으로 무관할 수 있습니다.

일표본 및 이표본 t 검정
t.test(x, mu = 40) t.test(x, y, alternative = 'two.sided', paired = FALSE)
alternative와 paired를 명시하세요; 기본값이 조용히 검정을 바꿀 수 있습니다

09표 결합과 재구성

실제 분석은 하나의 정돈된 파일로 도착하는 경우가 드뭅니다. 결합(join)은 공유 키로 표를 결합합니다. left_join(a, b, by = 'site')는 a의 모든 행을 유지하고 b에서 일치하는 열을 가져오며, inner_join()은 양쪽에 모두 있는 행만 유지하고 anti_join()은 일치하지 않는 행을 찾습니다 — 누락된 지점을 찾는 도구입니다.

재구성은 동일한 값을 넓은 형식과 긴 형식 사이에서 이동시킵니다. pivot_longer()는 여러 열을 키-값 행으로 모으고, pivot_wider()는 다시 펼칩니다. 긴 형식은 ggplot()과 그룹화된 요약이 원하는 것입니다. 모든 결합 전후에 행 개수를 확인하세요. 중복된 키는 조용히 행을 배수로 늘리기 때문입니다.

결합과 피벗 
readings <- left_join(sites, readings, by = 'site')
long <- readings |>
  pivot_longer(cols = starts_with('month'), names_to = 'month', values_to = 'value')
피벗 후 지점-월당 한 행

10glm()을 사용한 일반화 선형 모델

이진 결과 — 합격 또는 불합격, 불량 또는 양호 — 는 보통 최소제곱으로 잘 적합될 수 없습니다. 직선은 0과 1 밖의 확률을 예측하기 때문입니다. glm(y ~ x, family = binomial)은 로지스틱 회귀를 적합하며, 선형 점수를 시그모이드를 통과시켜 예측이 0과 1 사이에 머물게 합니다.

predict(model, newdata, type = 'response')는 확률을 반환합니다. type = 'response' 없이는 로그 오즈를 반환하며, 이는 잘못 읽기 쉽습니다. 확률을 선택한 임계값으로 클래스로 변환하고, 소수 클래스에 대해 정밀도와 재현율을 보고하세요 — 전체 정확도가 아니라.

로지스틱 링크
\[p = \frac{1}{1 + e^{-(\beta_0 + \beta_1 x)}}\]
시그모이드는 선형 점수를 (0, 1)로 매핑합니다
적합과 예측 
fit <- glm(pass ~ strength, data = cubes, family = binomial)
pred <- predict(fit, newdata = new_cubes, type = 'response')
type = 'response'는 로그 오즈가 아닌 확률을 제공합니다
확률을 명시적으로 요청하세요 이항 glm에서 predict()는 type = 'response'를 설정하지 않으면 로그 오즈를 반환합니다. 인수를 잊으면 0.80이 −1.39로 바뀝니다.

Key terms

데이터 프레임
각 열이 변수이고 각 행이 관측값인 표로, R의 기본 작업 객체입니다.
정돈된 데이터
사례당 한 행, 변수당 한 열, 셀당 한 값의 배치입니다.
파이프
한 단계의 결과를 다음 단계의 첫 번째 인수로 넘기는 연산자로, 코드가 실행 순서대로 읽히게 합니다.
잔차
관측값과 적합된 모델이 예측한 값의 차이입니다.
정상성
평균, 분산, 자기상관이 시간에 따라 변하지 않는 시계열의 성질입니다.
결정 계수
R²로, 적합된 모델이 설명하는 반응 변수의 총 변동 비율입니다.
일반화 선형 모델
선형 점수를 비정규 결과에 연결하는 glm()으로 적합된 모델로, 이진 반응에 대한 로지스틱 회귀 등이 있습니다.
왼쪽 결합
첫 번째 표의 모든 행을 유지하고 두 번째 표에서 일치하는 열을 추가하는 표 결합입니다.
Worked example

일일 판독값 요약 읽기와 해석

한 파일에 한 모니터의 10일간 PM2.5 판독값(µg/m³)이 있습니다: 18.0, 21.5, 19.2, 24.8, 60.1, 22.3, 20.6, 23.4, 19.9, 21.0. R에서 값을 읽고 평균, 중앙값, 표준편차, 사분위 범위를 계산하세요. 이 숫자들이 이 모니터의 전형적인 하루에 대해 무엇을 암시하는지 말하세요.

  1. 파일을 데이터 프레임으로 읽고 열을 추출하세요: d <- read.csv('pm.csv'); x <- d$value. length(x)로 n = 10을 확인하세요.
  2. 평균: sum(x)/length(x) = 250.8/10 = 25.1 µg/m³.
  3. 중앙값: 가운데 두 값은 21.0과 21.5이므로 중앙값은 21.25 ≈ 21.3 µg/m³입니다.
  4. 표준편차: 편차 제곱합은 약 1398이므로 표본 분산은 1398/9 ≈ 155.3이고 sd ≈ 12.5 µg/m³입니다.
  5. 사분위수: Q1 = 20.1, Q3 = 23.1이므로 IQR = 3.0 µg/m³입니다.
  6. 평균 25.1과 중앙값 21.3을 비교하세요. 60.1이라는 단일 판독값을 제거하면 평균은 21.2로, 거의 정확히 중앙값입니다.
Answer평균 25.1 µg/m³, 중앙값 21.3 µg/m³, sd 12.5 µg/m³, IQR 3.0 µg/m³. 10일 중 9일은 21 µg/m³ 근처에 있으므로 평균은 하나의 급등에 의해 끌어올려졌고 중앙값이 전형적인 하루를 더 잘 설명합니다. sd도 같은 점에 의해 부풀려집니다. 항상 중심과 함께 산포를 보고하세요.

Exam method

  • 각 요약 통계가 무엇을 가정하는지 말하세요: 평균은 극단값에 민감하고 중앙값은 그렇지 않습니다.
  • 회귀 기울기를 해석하라는 요청을 받으면 단위를 제시하고 부호가 물리적으로 타당한지 확인하세요.
  • 시계열 문제에서는 추세, 계절 주기, ARIMA 차수를 인용하기 전에 시계열에 차분이 필요한지 명시하세요.

Q01기본 R에서 선형 회귀 모델을 적합하는 함수는?

Whylm()은 최소제곱으로 선형 모델을 적합합니다. glm()은 일반화 선형 모델을 적합하고 나머지는 전혀 다른 일을 합니다.

Q02pm |> filter(value > 0)와 같은 파이프라인에서 filter는 무엇을 받습니까?

Why파이프는 왼쪽 객체를 오른쪽 함수의 첫 번째 인수에 넣으며, 여기서는 데이터 프레임입니다.

Q03시계열에 명확한 상승 추세가 있습니다. 이를 정상성에 가장 직접적으로 가깝게 만드는 단계는?

Why차분은 추세를 제거하여 차분된 시계열의 평균이 더 이상 표류하지 않게 하며, 이것이 ARIMA의 d 항입니다.

Why각 그룹이 하나의 요약 행으로 축소되므로 결과는 서로 다른 월의 수만큼 행을 가집니다.

Whyt.test(x, mu = 40)은 가설 평균 40에 대한 일표본 t 검정을 실행합니다. 다른 형식은 인수를 잘못 사용합니다.
