R 能將一份測量數據的試算表，轉化為站得住腳的論證：整理數據、描述數據、繪圖、擬合模型，然後預測。這門技能大部分在於這些步驟的次序，以及在於別人能夠重新執行的腳本。

進度只儲存在此瀏覽器。

01由數據框開始

數據框（data frame）是工作的單位：每一行是一個觀測，每一列是一個變數。R 將每一列保留為向量，所以測量值保持數值型，而類別則應為因子（factor）。

read.csv() 只負責讀取檔案；之後用 str() 和 head() 檢查其形狀。整潔數據（tidy data）是指每個個案一行、每個變數一列、每個儲存格一個值。日後大部分的麻煩——數字被匯入成文字、日期被儲存成字元——都在這裏看得見，及早修正比事後修補模型便宜得多。

先描述，後建模。summary() 給出範圍、四分位數和缺失值數目；mean()、median()、sd() 和 IQR() 給出你將會引用的數字。平均值遠離中位數，暗示有偏態或離群觀測。

Read, inspect, describe 
pm <- read.csv('data/pm.csv')
str(pm); dim(pm); head(pm)
summary(pm$value); sd(pm$value, na.rm = TRUE)
relative paths keep the script portable

02用動詞整理，而非用迴圈

數據整理是一連串細小的動詞，每個只做一件事：
- filter() 保留行
- select() 保留列
- mutate() 新增一列
- arrange() 排序
- group_by() 配合 summarise() 為每組給出一行摘要

管道 |&gt; 將每一步的結果傳入下一步，所以程式碼按推理次序閱讀。如果某一步難以命名，它就是在做兩件事，應該拆分。group_by() 配合 summarise() 亦取代了大部分手寫的類別迴圈。

一個小型的分組管道 
daily <- pm |>
  filter(!is.na(value)) |>
  mutate(month = format(date, '%m')) |>
  group_by(month) |>
  summarise(mean_pm = mean(value), n = n())
每月一行，平均值旁邊附有計數
常見數據任務及執行它們的工具
任務工具注意事項
讀取表格read.csv()先檢查 str()
保留行filter()以某一列為條件
新增一列mutate()長度必須相符
按組摘要summarise()在 group_by() 之後
擬合直線lm()檢查殘差

03追查缺失值與離群值

缺失值並非中性：它們會縮小樣本，而且如果集中在某個時段或某個地點，就會令平均值出現偏差。用 mean(is.na(x)) 計算它們，然後決定是捨棄、插補還是建模處理——並把決定記錄下來。

離群值同樣需要決定。一個讀數是其他讀數的二十倍，可能是真實事件，也可能是輸入錯誤，兩者應有不同的處理。箱形圖顯示形狀；對數尺度有時能馴服長尾。

缺失值的比例
mean(is.na(x))
由 0 到 1 的比例，而非計數

04圖表是關於數據的論證

圖形語法（grammar of graphics）將圖表拆分為數據、美學映射和幾何物件。在 ggplot() 中，aes() 說明哪個變數控制 x、y、顏色或形狀，而 geom 說明繪畫什麼。改變幾何物件就改變了論斷。

顏色應該編碼一個變數，而非作裝飾。facet_wrap() 製作小多圖，通常比五條疊加的線更清晰。為兩軸加上標籤，並在標題寫出重點；ggsave() 令圖表可重現。

以映射顏色繪製的點
ggplot(pm, aes(x = date, y = value, colour = site)) + geom_point() + labs(x = 'Date', y = 'PM2.5 (µg/m³)')
顏色編碼地點

05迴歸：一條擬合直線，而非定律

lm(y ~ x, data = pm) 擬合最小平方直線。斜率是 x 每改變一個單位時 y 的預期變化，所以其單位很重要，而其正負號必須在物理上合理。R² 是模型所解釋的 y 變異比例，而非模型正確的概率。

務必檢查殘差：曲線表示關係並非線性，扇形表示變異數改變，而少數極端點可能主導擬合。相關不等於因果，而超出觀測範圍的外推並非證據。

簡單線性模型
\[y = \beta_0 + \beta_1 x + \varepsilon\]
ε 收集直線未能解釋的部分
決定係數
\[R^2 = 1 - \frac{\mathrm{SSE}}{\mathrm{SST}}\]
所解釋的變異比例

06時間序列、季節性與 ARIMA

時間序列是有序的，所以相鄰數值彼此相關，而普通迴歸的假設會失效。用 ts(x, frequency = 12) 轉換月度數據，然後繪圖：趨勢、重複的季節性和雜訊應該可見。decompose() 將序列拆分成這些部分。

當序列的平均值、變異數和自相關不隨時間漂移時，它就是平穩（stationary）的。差分可移除趨勢；自相關和偏自相關圖隨後提示 ARIMA(p, d, q) 的階數：p 個自迴歸項、d 次差分、q 個移動平均項。auto.arima() 進行搜尋，而 forecast() 報告數值及逐漸擴闊的預測區間——沒有該區間的預測只是半個答案。

加法分解
\[y_t = T_t + S_t + E_t\]
趨勢、季節和餘項
一階差分
\[\Delta y_t = y_t - y_{t-1}\]
移除線性趨勢
ARIMA 模型
\[\varphi(B)(1 - B)^d y_t = \theta(B)\,\varepsilon_t\]
B 是後移運算子

07別人能夠執行的腳本

結果的好壞取決於背後的腳本。在任何模擬之前用 set.seed() 設定種子，透過相對路徑讀取數據，並且絕不手動編輯原始檔案——將清理工作保留為程式碼。將輸出儲存在與輸入不同的資料夾。

註解說明「為何」，將冗長的工作拆分成函數，並記錄套件版本。一份簡短的 readme 說明如何執行腳本，是分析的一部分：可重現的腳本令數字可被核實。

固定隨機種子 
set.seed(1234)
相同種子，相同模擬樣本

08R 中的假設檢定

R 將經典檢定包裝成一行指令，而紀律與紙上一樣：在執行任何東西之前先陳述虛無假設。t.test(x, mu = 40) 檢定單一樣本是否等於某個值，t.test(x, y) 比較兩組，而 paired = TRUE 則轉為檢定差值。chisq.test(table) 處理計數，而 aov() 擬合變異數分析。

整體閱讀輸出：p 值回答顯著性，置信區間顯示效應的大小，而自由度說明背後有多少證據。一個極小的 p 值配以極微小的區間，可能在統計上顯著，但在實際上無關重要。

單樣本和雙樣本 t 檢定
t.test(x, mu = 40) t.test(x, y, alternative = 'two.sided', paired = FALSE)
明確陳述 alternative 和 paired；預設值可能悄悄改變檢定

09合併與重塑表格

真實的分析很少以單一 tidy 檔案的形式出現。合併（joins）以共用的鍵組合表格：left_join(a, b, by = 'site') 保留 a 的每一行，並從 b 帶入相符的列，而 inner_join() 只保留兩者皆有的行，anti_join() 找出沒有相符的行——這是找出缺失地點的工具。

重塑（reshaping）在寬和長佈局之間移動相同的值。pivot_longer() 將多個列收集成鍵值行，而 pivot_wider() 將它們展開回去。長格式正是 ggplot() 和分組摘要所需的。每次合併前後都要檢查行數，因為重複的鍵會悄悄令行數倍增。

合併與樞紐轉換 
readings <- left_join(sites, readings, by = 'site')
long <- readings |>
  pivot_longer(cols = starts_with('month'), names_to = 'month', values_to = 'value')
樞紐轉換後每個地點-月份一行

10用 glm() 的廣義線性模型

二元結果——合格或不合格、有缺陷或完好——無法由普通最小平方妥善擬合，因為直線會預測出 0 和 1 以外的概率。glm(y ~ x, family = binomial) 擬合邏輯迴歸，它將線性分數通過 sigmoid 函數，令預測值保持在 0 與 1 之間。

predict(model, newdata, type = 'response') 返回概率；沒有 type = 'response' 則返回對數勝算（log-odds），容易誤讀。用你選定的閾值將概率轉為類別，並報告少數類別的準確率和召回率，而非整體準確率。

邏輯連結
\[p = \frac{1}{1 + e^{-(\beta_0 + \beta_1 x)}}\]
sigmoid 將線性分數映射到 (0, 1)
擬合與預測 
fit <- glm(pass ~ strength, data = cubes, family = binomial)
pred <- predict(fit, newdata = new_cubes, type = 'response')
type = 'response' 給出概率，而非對數勝算
明確要求概率 對二項式 glm 使用 predict() 時，除非你設定 type = 'response'，否則會返回對數勝算；忘記這個參數會將 0.80 變成 −1.39。

關鍵詞

數據框
一個表格，其中每一列是一個變數，每一行是一個觀測，是 R 中的基本工作物件。
整潔數據
每個個案一行、每個變數一列、每個儲存格一個值的佈局。
管道
將一步的結果作為下一步的第一個參數傳遞的運算子，令程式碼按執行次序閱讀。
殘差
觀測值與擬合模型預測值之間的差。
平穩性
時間序列的一種性質，其平均值、變異數和自相關不隨時間改變。
決定係數
R²，即擬合模型所解釋的反應變數總變異比例。
廣義線性模型
用 glm() 擬合的模型，將線性分數連結到非正態結果，例如用於二元反應的邏輯迴歸。
左合併
一種表格合併，保留第一張表的每一行，並加入第二張表中相符的列。
計算示例

讀取並詮釋每日讀數的摘要

一個檔案載有來自一個監測儀的十個每日 PM2.5 讀數（µg/m³）：18.0、21.5、19.2、24.8、60.1、22.3、20.6、23.4、19.9、21.0。在 R 中讀取這些值，並計算平均值、中位數、標準差和四分位距。說明這些數字對這個監測儀的典型一天有何含意。

  1. 將檔案讀入數據框並取出該列：d <- read.csv('pm.csv'); x <- d$value。用 length(x) 確認 n = 10。
  2. 平均值：sum(x)/length(x) = 250.8/10 = 25.1 µg/m³。
  3. 中位數：中間兩個值是 21.0 和 21.5，所以中位數是 21.25 ≈ 21.3 µg/m³。
  4. 標準差：偏差平方和約為 1398，所以樣本變異數是 1398/9 ≈ 155.3，而 sd ≈ 12.5 µg/m³。
  5. 四分位數：Q1 = 20.1，Q3 = 23.1，所以 IQR = 3.0 µg/m³。
  6. 比較平均值 25.1 與中位數 21.3。移除單一讀數 60.1 後，平均值為 21.2，幾乎正好等於中位數。
Answer平均值 25.1 µg/m³，中位數 21.3 µg/m³，標準差 12.5 µg/m³，IQR 3.0 µg/m³。十天的其中九天都接近 21 µg/m³，所以平均值被一個尖峰拉高，而中位數更能描述典型的一天；標準差亦被同一點所誇大。報告中心值時務必同時報告離散程度。

應試方法

  • 說明每個摘要統計量假設了什麼：平均值對極端值敏感，中位數則否。
  • 當被要求詮釋迴歸斜率時，給出它的單位，並檢查其正負號在物理上是否合理。
  • 對於時間序列問題，指出趨勢、季節週期，以及序列在引用 ARIMA 階數前是否需要差分。
  • 在任何報告中提及可重現性（種子、相對路徑、已儲存的腳本）；這是能得分的句子，而非填充。
  • 在 t.test() 中明確設定 alternative = 和 paired = ——預設值會悄悄改變檢定的意義。

自我測驗

先作答，再查看解釋。錯誤答案比熟悉的一頁更有用。

Q01在 base R 中，哪個函數擬合線性迴歸模型？

解釋lm() 以最小平方擬合線性模型；glm() 擬合廣義線性模型，其餘的則做完全不同的工作。

Q02在如 pm |> filter(value > 0) 的管道中，filter 接收：

解釋管道將左邊的物件放入右邊函數的第一個參數，在此即為數據框。

Q03一個時間序列有明顯的上升趨勢。哪一步最直接令它更接近平穩？

解釋差分移除趨勢，令差分後序列的平均值不再漂移，這就是 ARIMA 中的 d 項。

Q04group_by(month) 之後接 summarise(mean_pm = mean(value)) 會返回：

解釋每一組被壓縮成一行摘要，所以結果的行數等於不同月份的數目。

Q05哪一行指令檢定 x 的平均值是否等於 40？

解釋t.test(x, mu = 40) 對假設平均值 40 執行單樣本 t 檢定；其他形式誤用參數。

Q06一個寬表格每個月有一列。將它轉為每個月一行、並有月份名稱和讀數兩列的函數是：

解釋pivot_longer() 將多個列收集成鍵值行，產生長而整潔的佈局。
