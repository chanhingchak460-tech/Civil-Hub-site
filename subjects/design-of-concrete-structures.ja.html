鉄筋コンクリート設計は、要求される強度を鉄筋量、鉄筋径、かぶりに変換する。限界状態荷重を曲げ、せん断、スラブ、柱の検討に結びつけ、最後に配筋詳細と使用性で締めくくる。

01コンクリートの限界状態設計

コンクリートは圧縮にはよく抵抗するが引張には弱いため、部材がひび割れる箇所に鉄筋を配置する。限界状態設計では、単一の全体安全率を、荷重と材料に別々に適用する部分係数に置き換える。

  • 終局限界状態（ULS）では、部材は崩壊してはならない。
  • 使用限界状態（SLS）では、通常使用時のたわみとひび割れが許容範囲内でなければならない。
  • コンクリートの特性強度 f_cu は28日立方体強度、f_y は鉄筋の特性降伏強度である。

二つの状態を混同してはならない。断面はULSを満たしても、許容できないほどたわんだりひび割れたりする可能性があり、SLS検討は崩壊について何も語らない。

設計荷重
\[w_u = 1.4G_k + 1.6Q_k\]

02単鉄筋断面の曲げ

曲げを受ける長方形断面は、コンクリートの応力ブロックと鉄筋の引張力から設計する。K値はコンクリートがどれだけ厳しく応力を受けているかを表す：

K = M / (f_cu b d²)

ここで b は断面幅、d は圧縮縁から引張鉄筋の図心までの有効高さである。

  • 限界値 K′ = 0.156 未満では、断面は単鉄筋とできる。
  • レバーアームは z = d [0.5 + √(0.25 − K/0.9)] で、0.95d を上限とする。
  • 鉄筋量は A_s = M / (0.87 f_y z) から求まる。
K値
\[K = \frac{M}{f_{cu} b d^2}\]
MはN mm、f_cuはN/mm²、bとdはmm
レバーアーム
\[z = d\left[0.5 + \sqrt{0.25 - \frac{K}{0.9}}\right] \le 0.95d\]
必要引張鉄筋量
\[A_s = \frac{M}{0.87 f_y z}\]

03連続梁のモーメント係数

等分布荷重を受ける連続梁では、次の三条件が成り立つ場合、完全な弾性解析を表化されたモーメント係数で置き換えられる：

  • スパンの差が最長スパンの約15%以内であること、
  • 荷重がほぼ等分布であること、
  • 活荷重が死荷重を超えないこと。

設計モーメントは M = β F L となる。ここで F = w L はスパン上の総設計荷重、βは位置に対する係数である。代表値は、外側支点で0.04F、端スパンの中央付近で0.075F、最初の内側支点で0.086F、内側スパンの中央と内側支点で0.063Fである。最初の内側支点のモーメントが最大であり、そこでは上端鉄筋が最も多くなる理由である。関連するせん断力は同じ表から、または各スパンの自由体から求める。

係数は一体打ちの施工と、梁に沿ってほぼ一様な剛性を仮定している。大きくハンチを付けた不規則な架構では、代わりに弾性解析が必要である。

係数による設計モーメント
\[M = \beta F L\]
F = w L はスパン上の総設計荷重、βは位置に依存する
代表的な連続梁のモーメント係数（等分布荷重、ほぼ等スパン）
位置F = w L に対する係数 β
外側支点0.04
端スパンの中央付近0.075
最初の内側支点0.086
内側スパンの中央0.063
内側支点0.063

04フランジ付き梁と圧縮鉄筋

スラブと一体で打設された梁は、スラブの幅が圧縮域に加わるため、T形またはL形断面として働く。有効フランジ幅はスパンと梁間隔の割合に制限されるため、ウェブに近いスラブのみが計上される。

応力ブロックの位置を確認する：その深さは s = 2(d − z) である。s がフランジ厚 h_f を超えなければ、断面はフランジ全幅の長方形として挙動し、通常の K と z の式が適用できる。ブロックがウェブに達する場合は、真のT形断面として設計する。

K が K′ を超える場合は、梁を深くするか、超過モーメントと鉄筋層間の深さから圧縮鉄筋を算定して追加する。

05有効フランジ幅とT形梁の手順

T形梁はスラブの一部のみをフランジとして計上する。ウェブの両側の張り出しは、隣接梁までの純間隔の約0.2倍に有効スパンの0.1倍を加えた値に制限され、端部（L形）梁ではスパン項がその約85%に低減される。梁間隔4 m、スパン5 mの梁グリッドで計算すると、有効フランジ幅は680 mmとなり、250 mmのウェブを加えると合計930 mmとなった — 全間隔よりはるかに小さい。

設計手順は次のとおり固定される：

  • フランジ幅でKを計算する、
  • zを求める、
  • 応力ブロック深さ s = 2(d − z) を確認する。

sがフランジ厚h_f以内にとどまれば、断面は幅b_fの長方形として設計する。sがウェブに入り込む場合は、ウェブ内の圧縮を別途扱わなければならない。フランジとウェブの幅比は約4未満に保ち、最小鉄筋はフランジ全体ではなくウェブ面積に対して検討する。

有効フランジ幅、内側T形梁
\[b_{\mathrm{eff}} = b_w + 0.2\,b_1 + 0.1\,\ell\]
b₁はウェブ間の純間隔、ℓは有効スパン。端部梁ではスパン項を約0.85に低減する
応力ブロック深さの確認
\[s = 2(d - z)\]
s ≤ h_f なら断面は幅b_fの長方形として挙動する

06せん断とリンク筋

せん断は一部をコンクリートが、一部をリンク筋（スターラップ）が負担する。作用応力度は v = V/(b_v d) で、支点面から d の位置で検討する。コンクリートの負担分 v_c はコードの表から得られ、軸方向鉄筋比とコンクリート強度等級に依存する。

超過分はリンク筋が負担する：A_sv/s_v ≥ (v − v_c) b_v / (0.87 f_yv)。せん断がピークとなる支点付近では間隔を詰め、応力度は約 0.8√f_cu の圧壊限界以下に保たなければならない。

リンク筋はまたコンクリートを拘束し、主筋を保持し、鉄筋籠をまとめる役割を果たすため、計算上不要な箇所でもコードは最小リンク筋量を要求する。

必要リンク筋量
\[\frac{A_{sv}}{s_v} \ge \frac{(v - v_c)b_v}{0.87 f_{yv}}\]

07一方向および二方向スラブ

スラブは対向する二辺で支持されると一方向、長スパンが短スパンの約2倍未満であれば二方向である。二方向スラブは両方向に曲げが生じるため、各帯は荷重の一部のみを負担する。

厚さは通常、曲げではなくたわみで決まる。基本的なスパン対有効高さ比は、単純支持スラブで約20、連続スラブで約26であり、配筋量に応じて修正する。連続スラブでは架構解析の代わりに表化されたモーメント係数を用いてよい。

主筋と直交する方向に分布鉄筋を配置してひび割れを制御し、柱周りのパンチングせん断を検討する。集中反力が薄いスラブを突き抜ける可能性があるためである。

08柱：軸力と細長比

主に軸力を受ける短柱の公称耐力は

N = 0.4 f_cu A_c + 0.75 f_y A_sc

であり、A_c は純コンクリート面積、A_sc は鉄筋面積である。係数は立方体強度と部材強度の差およびひずみ適合を考慮している。

細長比は状況を変える：細長い柱は曲げ変形し、そのたわみによる追加モーメントが作用モーメントに加算される。設計では両軸方向の細長比を検討し、最小偏心を適用し、二軸曲げを考慮する。

配筋詳細も適用される：鉄筋量は少なくとも約1%、最大4〜6%、長方形断面では最小4本、リンク筋間隔は鉄筋径の12倍または最小寸法以下とする。

短柱の軸耐力
\[N = 0.4f_{cu}A_c + 0.75f_yA_{sc}\]

09かぶり、耐久性、配筋詳細

公称かぶりは表面から鉄筋外面までの距離である。水や塩化物を鉄筋から遠ざけ、火災時に鉄筋を断熱するため、暴露条件と耐火性によって決まる。

鉄筋はまたその力を定着させなければならない。定着長さは鉄筋径と応力度とともに増加し、概ね l_b = f_y φ / (4 f_b) である。ここで f_b は設計付着応力度である。重ね継手は、2本の鉄筋が一つのコンクリート長さを共有するため、より長くなる。

骨材が通過できるよう鉄筋間隔を十分に保ち、リンク筋を主筋にフックする。配筋詳細は計算を施工可能にする段階である：鉄筋は収まり、固定され、締め固められたコンクリートに囲まれなければならない。

暴露条件別の目安となる公称かぶり（代表的な範囲。プロジェクト仕様が優先する）
暴露条件代表的な公称かぶり（mm）主な脅威
軽微：乾燥した保護された屋内25〜30炭酸化
中程度：湿潤で遮蔽された環境35〜40炭酸化と湿気

10モーメント再分配と配筋詳細のまとめ

十分に鉄筋が配置されたコンクリート断面は延性的であるため、断面に回転能力があれば、支点の弾性ピークモーメントを再分配できる — 低減し、他の箇所で再配分する。中立軸が浅い x/d ≤ 0.5 の範囲では約30%までの再分配が許され、x/d = 0.6 で線形的にゼロまで低減する。

再分配は支点での経済性をもたらすが、延性を要求する：せん断耐力に余裕のある軽鉄筋断面は適合するが、重鉄筋断面は適合しない。

次に配筋詳細が解析を確定させる：

  • 鉄筋量は b h の約0.13%の最小値と、コンクリート総面積の約4%の最大値の間に収めなければならない。
  • 低モーメント域で鉄筋を切断する。
  • ひび割れを制御できる程度に間隔を詰め、かつ骨材が通過できる程度に広く保つ。
  • 力をコンクリートに伝える必要があるすべての鉄筋を定着または折り曲げる。

まだ必要な位置で終わる鉄筋は、設計に組み込まれたひび割れである。

再分配と中立軸の限界
\[\frac{x}{d} \le 0.6 - 0.33\,\beta\]
βは再分配されるモーメントの割合。β = 0.3 で x/d ≤ 0.5
最小引張鉄筋量
\[A_{s,\min} \approx 0.0013\,b\,h\]
総断面の約0.13%。最大は約4%

11使用性：たわみとひび割れ

たわみはスパン対高さ比を制限するか、スパン/250などの限界に対する計算で制御する。クリープと収縮は短期弾性たわみに加算されるため、持続荷重には長期推定が必要である。

ひび割れは引張縁付近に鉄筋を分散配置し、鉄筋間隔を制限することで制御する。計算幅は次の形をとる：

w_k = 3 a_cr ε_m / [1 + 2(a_cr − c_min)/(h − x)]

ここで a_cr は最寄り鉄筋までの距離、ε_m は平均ひずみ、c_min は最小かぶり、x は中立軸深さである。

鉄筋応力度を適度に保ち、鉄筋間隔を詰めれば、幅は通常0.3 mmの限界付近にとどまる。

ひび割れ幅
\[w_k = \frac{3a_{cr}\varepsilon_m}{1 + 2\frac{a_{cr} - c_{min}}{h - x}}\]

Worked example

長方形梁の引張鉄筋を設計する

幅250 mm、せい500 mmの単純支持梁が、設計終局モーメント200 kNmを受ける。有効高さは450 mm、f_cu = 30 N/mm²、f_y = 500 N/mm²である。断面が単鉄筋とできるかを判定し、必要な引張鉄筋量を求めよ。実用的な鉄筋配置を示せ。

  1. K = M / (f_cu b d²) = (200 × 10⁶) / (30 × 250 × 450²) = 0.132。
  2. K′ = 0.156 と比較する：Kは小さいため、圧縮鉄筋は不要である。
  3. z = d [0.5 + √(0.25 − K/0.9)] = 450 [0.5 + √(0.25 − 0.1463)] = 450 × 0.822 = 370 mm。
  4. 上限を確認する：0.95d = 427 mmであるため、計算値z = 370 mmを用いる。
  5. A_s = M / (0.87 f_y z) = (200 × 10⁶) / (0.87 × 500 × 370) = 1243 mm²。
  6. 最小鉄筋量を確認する：b × h の約0.13% = 0.0013 × 250 × 500 = 163 mm²であるため、曲げの要求が支配する。
  7. 妥当性確認：4本のH20鉄筋を配置すると、A_s = 1256 mm²。100A_s/(b d) = 1.12%で、最大約4%を下回る。
Answer引張側に4本のH20鉄筋（1256 mm²）を配置する。K = 0.132 は K′ を下回るため、梁は単鉄筋として十分である。

Exam method

  • Kを使う前にすべてをニュートンとミリメートルに換算し、最終答えはkNm、mm²、MPaで示す。
  • 常にKとK′を比較する。圧縮鉄筋を必要とする梁は単鉄筋とは別の計算である。
  • レバーアームは0.95dを上限とし、その上限を明記する — 試験官はこの確認に点を与える。
  • 答えの中でULSとSLSを分ける：強度検討とたわみ・ひび割れ検討は異なる要求として採点される。
  • モーメント係数を使う前に三条件 — ほぼ等スパン、等分布荷重、活荷重が死荷重を超えないこと — を述べ、問題に対して確認する。
