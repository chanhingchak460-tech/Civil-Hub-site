交差点や鉄道線は、占有する空間ではなく、提供すべき容量によって規模が決まる。本ページでは、優先交差点、ラウンドアバウト、信号容量、鉄道の運転時隔、およびそれらを支える基準について扱う。

01設計は容量の問題である

交通施設は、生の車両数ではなく、1時間あたりの乗用車換算台数で表される設計年次需要に対して設計される。大型貨物車は乗用車より多くの道路空間を占めるためである。重要な比率は需要を容量で割った飽和度であり、重要な出力は遅延と待ち行列長である。

容量だけでは交差点形式を選べない。安全性、用地、歩行者、コスト、周辺ネットワークがすべて答えを制約する。だからこそ基準は一つの解ではなく、複数のレイアウトを提示するのである。

交差点形式とその容量を支配する要因
形式容量の支配要因長所短所

02優先交差点：ギャップ受容

一時停止・譲り合い交差点では、従道路が主要交通流の中にギャップを見つけなければならない。したがってその容量は、交錯する交通量が増えるにつれて低下し、その低下の形はギャップ受容理論に従う。運転者は出る前に臨界ギャップを必要とし、後続車両は追従時間で続く。

実務的な結論は、従道路アプローチがボトルネックであり、その容量は主要道路の交通量、視距、転向比率に敏感であるということだ。追加の従道路車線やテーパーは、制約がギャップではなく車線である場合にのみ役立つ。

従道路容量（ギャップ受容）
\[C = \frac{q e^{-q t_c/3600}}{1 - e^{-q t_f/3600}}\]
qは交錯する主要交通量（pcu/h）、t_cは臨界ギャップ、t_fは追従時間（秒）

03ラウンドアバウト：環道交通量が流入容量を決める

ラウンドアバウトの流入部は環道交通量に譲るため、流入容量はすでに環道にある交通の関数である。以下の線形式の経験モデルは観測された挙動に適合させたものであり、係数は普遍的な定数ではなく流入部の幾何構造に依存する。

幾何構造が重要であるのは、それが速度とギャップ受容を支配するからだ。流入部の偏向、流入幅、テーパー長、島の半径はすべて、車両がどれだけ速く流入できるかを変える。ミニラウンドアバウトは交差点を単純化するが、島が走行可能で車線が共有されるため、すぐに過負荷になりうる。

ラウンドアバウト流入容量
\[C_{\mathrm{entry}} = a - b\,q_c\]
q_cは環道交通量（pcu/h）、aとbは流入部の幾何構造に適合させた係数

04信号：飽和交通流率と青時間比

信号アプローチは、青時間が完全に使われている間、その飽和交通流率で流出する。理想的な条件下では車線あたりおよそ1,800〜2,000 pcu/hである。サイクル長C、有効青時間gのとき、容量は飽和交通流率に青時間比を掛けたものである。

流率比 y = q/s は需要がどれだけの飽和交通流率を必要とするかを測り、飽和度 X = q/c は需要と容量を比較する。損失時間（各現示の起動とクリアランス）があるため、短いサイクルは青時間のより大きな割合を浪費し、Websterの式はその浪費と長いサイクルの遅延をトレードオフする。

アプローチ容量
\[c = s \left( \frac{g}{C} \right)\]
sはpcu/h、gは有効青時間、Cはサイクル長（同じ時間単位）
Webster最適サイクル
\[C_o = \frac{1.5L + 5}{1 - Y}\]
Lは1サイクルあたりの総損失時間、Yは臨界流率比の合計

05現地での飽和交通流率の測定

飽和交通流率は仮定するよりも測定するのが最善である。現地手法は飽和サイクル（待ち行列が残ったまま青時間が終わる期間）中に流出する車両を数え、信頼できるためには少なくとも約5台の待ち行列車両が必要である。最初の数台はまだ起動損失時間を克服しているため除外し、定常的な車頭時間の部分のみを数える：

s = 3600 n / t_g、

ここでnは長さt_gの青時間の飽和部分で数えた車両数である。

  • 勾配、転向半径、車線幅、車種構成はそれぞれ補正係数を正当化する。
  • 測定は、アプローチの代表的な車線（専用転向車線ではなく直進車線または混合車線）で十分なサイクルを平均しなければならない。1分間の混雑は飽和交通流率ではないからである。
  • 交差点がそれを正当化する場合、直接測定は経験的な補正式に勝る。だからこそマニュアルは詳細な信号計画に対してそれを規定している。
現地飽和交通流率
\[s = \frac{3600\,n}{t_g}\]
nは青時間の飽和部分で数えた車両数、t_gは秒。各待ち行列の最初の数台は除外する

06歩行者と自転車利用者は設計対象のユーザーである

すべての交差点は歩行者の横断箇所でもある。車両の掃引軌跡で決まる隅角半径は横断距離を長くし、人々を本来横断すべき場所ではなく横断できる場所で横断させる。小さな半径、避難島、レベル横断、適切な現示は、横断を短く見通しよく保つ。

自転車利用者には連続的で予測可能な空間が必要である。交差点で途切れる自転車車線、または転向車両が必ず横切る位置にある自転車車線は、取り除くはずだった交錯を再現してしまう。設計基準は車線の連続性、視距包絡線、信号現示によってこれに対処する。

横断部の信号タイミング照査
\[t_{\mathrm{needed}} = \frac{L}{v} + t_s\]
設計上の歩行速度はしばしば約1.2 m/sとされる

07鉄道容量は運転時隔の計算である

鉄道では、容量は1時間に1地点を通過する列車数であるため、すべては最小運転時隔に帰着する。信号は各列車に閉塞時間を定義し、駅は停車時間に加えて発進してホームを空けるまでの時間を加える。

一次近似の駅運転時隔は、停車時間＋加速時間＋制動時間＋列車とクリアランスが通過する時間に、信号余裕を加えたものである。1時間あたりの列車数はその運転時隔から導かれる。

最小駅運転時隔
\[h_{\min} \approx t_{\mathrm{dwell}} + \frac{v}{a} + \frac{v}{b} + \frac{L_{\mathrm{train}} + L_{\mathrm{clear}}}{v} + t_{\mathrm{margin}}\]
vはm/s、加速度はm/s²、長さはm、hは秒で得られる
運転時隔からの線路容量
\[C = \frac{3600}{h} c_{\mathrm{train}}\]
c_trainは1列車の限界乗車人員（人）

08数値で見る鉄道容量：提供容量と利用容量

鉄道容量の計算は車両から積み上げる。車両の容量は座席と立席を合わせたものである：

C_vehicle = S_seats + A_stand × ρ、

ここでρは立席密度であり、通常の計画では1平方メートルあたり約4人である。150席の車両がそれぞれ45 m²の立席空間を提供する6両編成の列車は、1両あたり約330人、1列車あたり1,980人を運ぶ。

提供線路容量は C_offered = c_train × 3600 / h であり、利用容量は実際の混雑を反映する約1.1の設計乗車率を適用する：C_utilised = C_offered × F_load。135秒のピーク時運転時隔は、約52,800人/時を提供する。

最小運転時隔が上限を定める。駅運転時隔（停車時間＋クリアランス時間に安全率を掛けたもの）が通常は支配的だが、制動による運転時隔も確認しなければならない：

h_way ≈ [v/a + (L_train + L_clear)/v] × f_safety。大きい方の運転時隔がダイヤを支配し、線路容量はそこから導かれる。したがって5秒の停車時間短縮は実際の容量増加である。

車両容量
\[C_{\mathrm{vehicle}} = S_{\mathrm{seats}} + A_{\mathrm{stand}}\,\rho\]
ρは立席密度、計画では約4人/m²
利用線路容量
\[C_{\mathrm{utilised}} = C_{\mathrm{offered}}\,F_{\mathrm{load}}\]
F_loadは設計乗車率、約1.1
最小路線運転時隔
\[h_{\mathrm{way}} \approx \left[\frac{v}{a} + \frac{L_{\mathrm{train}} + L_{\mathrm{clear}}}{v}\right] f_{\mathrm{safety}}\]
制動時間＋列車とクリアランスが通過する時間に安全率を掛けたもの

09駅と乗換施設

駅は容量装置である。ホーム幅、階段、エスカレーター、改札はそれぞれ流率を持ち、最も遅いリンクが乗換時間を決める。単純な2面ホームの駅は長い停車時間を許容するが、混雑する乗換駅にはより広いホーム、より多くの垂直移動経路、バリアフリーアクセスが必要である。

乗換設計は歩行距離と混雑をトレードオフする。長くても案内の良い歩行は、短くても混雑した歩行に勝ることがあり、対面乗換はレベルチェンジを完全に取り除くため最も強力な接続である。案内表示とアクセシビリティは後付けではなく設計に組み込まなければならない。

10交通影響評価：範囲と手順

交通影響評価（TIA）は、提案開発が周辺交通ネットワークに何をもたらすかを問い、固定された範囲に従う。

  • 調査対象地域と対象年次（通常は開業年と設計年）を設定する。
  • 土地利用から発生交通量と集中交通量を推定する。
  • 交通をモードと経路ごとにネットワークへ配分する。
  • 開発が影響する交差点、横断部、アクセス点を検証する。
  • 交差点性能を飽和度で判断する。アプローチは待ち行列が回復できるよう約85〜90%未満に保つべきである。
  • アクセス幾何構造、サービス車両、乗降、バスと歩行者への影響を網羅する。
  • ネットワークが破綻する場合、緩和策（段階的整備、車線変更、アクセス管理）を設計・再検証し、当局が判断できるよう残存影響を報告する。

TIAはその発生原単位の質を超えられない。他の都市から借用した原単位や、調査せずに仮定したモード分担は、自信ありげに見えるがほとんど意味のない数値を生む。

発生原単位がすべてを決める 借用した発生原単位と検証されていないモード分担に基づくTIAは、軟らかい入力から精密な出力を生む。結論を擁護する前に、すべての原単位の出典を明示せよ。

11基準、モデル、判断

設計ガイドは幾何構造、容量式、安全基準を与える。交通モデルは式ができないことを加える。時間依存の需要、交差点間で広がる待ち行列、1つの過負荷アプローチがネットワーク全体に及ぼす影響である。

経験的手法は速いが一様な条件を仮定する。シミュレーションは相互作用を捉えるがキャリブレーションを要する。技術者は両者を整合させ、仮定を明示し、モデルを観測交通量に対して検証する。ソフトウェアの出力は証拠であり決定ではない。レイアウトは依然として安全で、施工可能で、利用者に受け入れられるものでなければならない。

Key terms

飽和度
アプローチにおける需要と容量の比。1に近い値は待ち行列が容易に増大することを意味する。
飽和交通流率
車線群の青時間が完全に使われている間の流出率。通常、車線あたり約1,800 pcu/h。
臨界ギャップ
運転者が交差点に進入する前に受け入れる、交錯交通における最小のギャップ。
環道交通量
ラウンドアバウトの環道をすでに走行している交通。流入交通はこれに譲らなければならない。
閉塞時間
1列車のために軌道区間が予約される時間。接近とクリアランスを含み、信号運転時隔を定める。
停車時間
列車がホームに停車し、乗客が乗降する時間。
起動損失時間
待ち行列の最初の車両が停止線を通過するのに要する余分な秒数。飽和交通流率の測定時には除外する。
設計乗車率
名目車両容量を容量計画で仮定する乗車量に変換する係数。混雑を考慮する。
Worked example

固定運転時隔を持つ地下鉄の線路容量

地下鉄路線は6両編成で、各車両は長さ20 mである。停車時間は30秒、路線速度は45 km/h、加速度と常用制動はともに約1.0 m/s²、列車と安全クリアランスは145 m、信号と性能の余裕は10秒である。最小駅運転時隔、1時間あたりの列車数、各列車が1,200人を運ぶ場合の線路容量を計算せよ。

  1. 路線速度を換算する：45 km/h = 12.5 m/s。
  2. 加速と制動はそれぞれ v/a = 12.5 / 1.0 = 12.5秒かかる。
  3. 列車とクリアランスが1地点を通過するのに (145 m) / (12.5 m/s) = 11.6秒かかる。
  4. 最小運転時隔 = 30 + 12.5 + 12.5 + 11.6 + 10 = 76.6秒、切り上げて77秒。
  5. 1時間あたりの列車数 = 3600 / 77 = 46.8、したがって達成可能なサービスは整数の46列車/時である。
  6. 線路容量 = 46 × 1,200 = 55,200人/時/方向。
  7. 妥当性確認：40,000人/時の需要は線路容量の40,000 / 55,200 = 72%を使用し、回復のための有用な余裕を残す。
Answer最小駅運転時隔は約77秒で、46列車/時、線路容量は55,200人/時/方向となる。停車時間と発停サイクルが運転時隔を支配するため、停車時間を5秒短縮すれば容量はおよそ3列車/時増加する。

Exam method

  • 交差点形式を比較する前に、需要をpcu/hに換算し飽和度を明示する。
  • 信号容量では飽和交通流率に青時間比を掛ける。ある現示に青時間を追加すれば、別の現示から必ず奪うことになる。
  • 鉄道の問題では秒単位で項ごとに計算し、v、a、長さの単位を一貫させる。
  • モデルとマニュアル計算が一致しない場合、どちらを信頼するかを選ぶ前にそれぞれの仮定を説明する。
  • 飽和交通流率の問題では、車両数を飽和青時間で割る前に起動車両を除外する。含めるとsを過小評価する。
