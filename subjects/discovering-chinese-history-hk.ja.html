香港の植民地史の前と外側にある過去：移住と宗族社会、漁業と製塩経済、石切労働、戦時の断絶と戦後の産業。また、歴史家が碑文、族譜、景観をどう読み解くかについての教訓でもある。

01条約ではなく、その土地を読む

香港の歴史はしばしば1842年から数えられるが、それは植民地的な枠組みである。何世紀もの間、この地域は珠江デルタの行政的・文化的世界に属し、番禺 Panyu、東莞 Dongguan、そして最終的には新安 Xin'an といった県を経てきた。

中国側から過去を読むことは、移住、宗族社会、沿岸交易と海から始め、植民地時代をより長い物語の一章として扱うことを意味する。

史料批判
Provenance → Purpose → Perspective → Corroboration
文書はその主題の証拠であると同時に、それ自体の証拠でもある

02移住と大族

新界のほとんどの定住共同体は、宋・元時代の移住に祖先をたどる。記録に残るのは主に五つの宗族——鄧 Tang、侯 Hau、廖 Liu、文 Man、彭 Pang——であり、通常 新界五大族 と呼ばれる。

宗族は単なる家族以上のものだった：
- 祠堂
- 族譜 宗族の系譜
- 信託で保有される共有地
- 圍村 囲壁村

これらによって宗族は労働を組織し、資源を守り、地位を主張できた。族譜は有用だが部分的である：宗族が記憶されたいと望んだことを記録している。

推論の連鎖
Claim → Evidence → Context → Qualification
試験官に問われる前に、主張の限界を述べておく

03漁業、製塩、海洋経済

産業以前、海が生計を支えていた。西岸、特に 大澳 Tai O 周辺の塩田は帝国国家に収入をもたらし、漁業共同体——蛋家 Tanka として知られる舟上生活の集団を含む——は沿岸水域と市場で働いた。

屯門 Tuen Mun は唐代にはすでに認められた停泊地・交易停泊地であり、外国船がモンスーンを待った。天后 Tin Hau 廟はこの世界を示しており、その碑文にはしばしば寄進者と廟を維持するために寄進された土地が列記されている。

04花崗岩、石切場、石工

花崗岩はこの地域の多くを下支えしており、石切は輸出産業へと成長した。石匠 石工たちは 鯉魚門 Lei Yue Mun から 鑽石山 Diamond Hill までの現場で働き、地元の建築や遠方の港向けに石材を切り出した。

石は重いため、この交易は石切場周辺の道路、桟橋、集落を形作った。石切の歴史は地質、労働、海運を結びつけ、景観そのものが歴史的史料になり得ることを示している。

05植民地開発、占領、産業

植民地時代は海岸を急速に変えた：
- 1841–42年の香港島の割譲
- 九龍の追加
- 1898年の新界の租借

これらは測量、道路、鉄道、貯水池、そして新たな法秩序をもたらした。1941–45年の日本占領はその体系を破壊し、人口を減少させ、飢えを残した。

1945年以降、経済は中継貿易から製造業、そしてサービス業へと移り、公営住宅、ニュータウン、コンテナ港が続いた。

06証拠を読む

歴史は証拠から論じられ、香港には多くの種類がある：考古学的発見、廟や 碑銘 石碑の碑文、族譜、土地証書、植民地時代の地図や文書、新聞、口述証言。

それぞれがいくつかの問いに答え、他のことには沈黙する——碑文は寄進者を列記しても、読めなかった参拝者については語らない。解釈はさらに層を加える。なぜなら、復元された建物もまた、どの過去を提示するかについての選択だからである。史料が語ることと、歴史家が推論することを分けて考えよ。

異なる種類の史料が示せることと示せないこと
史料適していること見えないこと
廟の碑文寄進者、年代、土地と廟の財産寄進できないほど貧しい人々
族譜宗族の主張と移住の記憶養子や省略された成員
植民地地図ある時点の道路、区画、海岸線権原のない人々による利用
口述歴史生きた経験と記憶正確な年代と数値

07宗族以前：墓と宋の朝廷

考古学は文字が沈黙する領域に届く。1950年代に発見された後漢の磚室墓である 李鄭屋漢墓（Lei Cheng Uk tomb）には、大吉番禺——「大いなる幸運、番禺」——と刻印された磚があり、この地域が植民地条約の約1,800年前に番禺県の行政下にあった証拠である。これは、この地域の文字記録に深く埋もれた前史があることを思い起こさせる。

伝説はもう一層を加える：宋皇臺（Sung Wong Toi）の岩は、1270年代のモンゴル征服前に南方へ逃れた幼い皇帝たちの物語と結びついており、その出来事はこの地域を一時的に王朝政治に引き込み、大族の移住物語の種を蒔いた。

三者照合
Archaeology + Text + Memory
各種の証拠は異なる問いに答える；一緒に用いよ

08史料分析の五層

あらゆる文書の方法論的な読解は五つの層を通る：
- 来歴とジャンルを確定する（誰が、いつ、何の用途で作ったか）
- 用語を注釈し、人名をたどりながらテキストを精読する
- それが触れる主題に対する意義を量る
- 史学史の中に位置づける——学者がそれをどう用いたか、あるいは争ったか
- それが促すさらなる研究を記す

1743年の塔門碑文に適用すると、各層は石が語ること（二家族が天后廟に税田を寄進し、土地の横領者が知県の裁定を失った）と、語らないこと（小作人の生活、一般の参拝者、そのような寄進がどれほど典型的だったか）を分ける。この枠組みは引用を議論へと変える。

1743年塔門碑文に適用した五層
層問いこの石についての答え
来歴誰が、いつ、何の用途で作ったか？廟にある公共の石、寄進した家族が費用を負担
精読用語と人名は何を語るか？女神に与えられた税田 稅田；土地は「新安に所在し、税は東莞に掛かる」
意義どの主題に触れるか？廟の財産、土地紛争、官の裁定
史学史学者はどう用いてきたか？廟の荘園と地域の訴訟の証拠
さらなる研究次に何を促すか？証書や地方志と照合する；この事例がどれほど典型的だったかを問う

09廟、儀礼、地域の国家

廟は神を祀る以上のことをした。天后信仰 天后信仰は海洋経済とともに広がり、廟の財産——祭礼の費用を賄うために寄進された田——は廟を法人としての地主、紛争の調停者、役人との接点とした。

1743年の塔門の事例はその循環を示す：寄進、侵占、知県の裁定、そして裁定を永続させるために建てられた石。

儀礼は村々を結びつけた：打醮 醮の祭礼は行列、供物、演劇を通じて共同体の守護を更新し、その記録は寄進者名簿、土地台帳、参加した村の名前など、歴史的史料を兼ねる。祭礼を制度として読むことは、地図だけでは示せない社会的地図を回復する。

聖なる財産の循環
Donation → 廟產 temple estate → Dispute → Official ruling → Inscription
各段階が異なる種類の史料を残す

10地方志、証書、口述の記憶

地方史 地方志——新安県志のような県志——は、役人の目を通して行政、税制、慣習、著名な場所を記録するため、国家が統治したいと考えたことを強調する。

土地証書や契約は境界、地代、相続という実務の世界を記録し、族譜は宗族が記憶することを選んだことを記録し、口述歴史は長老が伝えることを選んだことを記録する。

中立な史料は存在しない。だからこそ照合がこの学問の中心的な習慣である：碑文を地方志と照合し、族譜を証書と照合する。史料が対立する場合、その対立自体が証拠である——競合する主張、働く記憶、各筆者が記録に語らせたかったことの証拠である。

照合の網
Stone ⇄ Gazetteer ⇄ Deed ⇄ Oral memory
ジャンルを横断して照合する；不一致自体が証拠である

Key terms

族譜（系譜）
出自、婚姻、栄誉を記録した宗族の記録であり、情報提供だけでなく地位を確立するために書かれた。
圍村（囲壁村）
沿岸の新界で宗族が防御のために建てた、壁、しばしば堀で囲まれた集落。
碑銘（碑文）
石に刻まれた文章で、通常は寄進、廟の創建、官の決定を記録する。
中継貿易
商品がそこで生産も消費もされずに港を通過する貿易。
照合
主張を受け入れる前に、一つの史料を別の独立した史料と突き合わせること。
遺産解釈
場所や物を公衆に提示する際に行われる選択であり、何を説明し何を省くかを含む。
地方志（県志）
行政のために編纂された地方史で、役人の視点から税制、慣習、著名な場所を記録する。
打醮（醮の祭礼）
行列、供物、演劇を伴う定期的な共同体の更新儀礼で、その記録は歴史的史料を兼ねる。
Worked example

廟の碑文を証拠として読む

18世紀半ばに刻まれた碑文は、二つの名を記された家族が税田と山地を廟に寄進したこと、後に他の者たちがその土地を主張したこと、知県が寄進を確認したことを記録している。この史料はどのような歴史的主張を合理的に支持でき、何を支持できないか？

  1. ジャンルと来歴を特定する：廟に建てられた石碑で、寄進者が費用を負担したため、公共的で一部は自己に都合のよい記録である。
  2. その目的を述べる：寄進を永続させ、将来の主張者に財産が官の裁定で保護されていると警告すること。
  3. それが実際に行う主張を抽出する：土地が寄進され、紛争が起こり、知県が記された日付に寄進者側に有利な裁定を下した。
  4. その沈黙に注意する：土地を耕した小作人、参拝者の規模、そのような寄進がどれほど典型的だったかについては何も語らない。
  5. この一つの廟を超えて一般化する前に、土地証書、県志、または第二の碑文で照合する。
Answerこの碑文は廟の財産、寄進者間の競争、土地を守るための官の裁定の利用について強い証拠である。一般的な繁栄や寄進できない人々の生活については弱い証拠であり、より広い主張には独立した照合が必要である。

Exam method

  • 史料問題では、内容を抽出する前に来歴と目的を確定せよ；方法は事実と同じくらい点になる。
  • 中国語の用語には短い英語の注釈を付け、読者が推論を追えるよう英語で論じよ。
  • 植民地の物語を1841年以前と1997年以降の証拠で均衡させ、答えが一方的にならないようにせよ。
  • 史料から一つの語句を引用して注釈を付けよ——来歴と注釈付き引用が方法の点を取る。
