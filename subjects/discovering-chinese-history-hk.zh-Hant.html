香港喺殖民故事之前同以外嘅歷史：移民同宗族社會、漁業同鹽業經濟、石礦勞動、戰時斷裂同戰後工業。呢個亦係一堂關於歷史學家點樣閱讀碑銘、族譜同地景嘅課。

進度只儲存在此瀏覽器。

01讀地方，唔止讀條約

香港嘅歷史通常由1842年開始計，但呢個係殖民框架。幾百年嚟，呢個地區屬於珠江三角洲嘅行政同文化世界，先後隸屬番禺、東莞，最後係新安等縣。

從中國一方閱讀過去，意味住要由移民、宗族社會、沿海貿易同海洋開始，然後先至將殖民時期視為更長故事入面嘅其中一章。

史料批判
Provenance → Purpose → Perspective → Corroboration
一份文獻既係關於其主題嘅證據，亦係關於自身嘅證據

02移民同大族

新界大部分定居社群嘅祖先都可追溯至宋元時期嘅移民。五個宗族主導咗文字記錄——鄧氏、侯氏、廖氏、文氏同彭氏，通常稱為新界五大族。

宗族唔止係一個家庭：
- 祠堂
- 族譜
- 以信託形式持有嘅 communal 土地
- 圍村

呢啲令宗族可以組織勞動力、保衛資源同彰顯地位。族譜既有用又片面：佢哋記錄嘅係宗族希望被記住嘅嘢。

推理鏈
Claim → Evidence → Context → Qualification
喺考官要求之前，先講明論點嘅限制

03漁業、鹽業同海洋經濟

工業之前，海洋養活咗呢度。西岸嘅曬鹽場，尤其係大澳一帶，為帝國政府帶來收入，而漁業社群——包括被稱為蛋家嘅水上人——喺沿海水域同市場作業。

屯門喺唐代已經係公認嘅錨地同貿易站，外國船隻喺度等候季候風。天后廟標誌住呢個世界；廟內碑銘經常列出捐贈者同為維持廟宇而捐出嘅土地。

04花崗岩、石礦場同石匠

花崗岩構成呢個地區大部分地質，採石業發展成出口貿易。石匠喺鯉魚門到鑽石山等地點開採，切割石塊用於本地建築同更遠嘅港口。

因為石頭好重，呢門行業塑造咗石礦場周圍嘅道路、碼頭同聚落。石礦歷史連結地質、勞動同航運，亦顯示地景本身可以係歷史資料來源。

05殖民發展、佔領同工業

殖民時期迅速重塑海岸：
- 1841–42年割讓香港島
- 增闢九龍
- 1898年租借新界

呢啲帶來測量、道路、鐵路、水塘同新法律秩序。1941–45年日本佔領打破咗呢個制度，令人口減少同捱餓。

1945年之後，經濟由轉口貿易轉向製造業，然後轉向服務業，伴隨公共房屋、新市鎮同貨櫃港口。

06閱讀證據

歷史係基於證據論證，而香港有好多種類：考古發現、廟宇同碑銘石刻、族譜、地契、殖民地图同檔案、報紙同口述證言。

每種證據都回答某啲問題，對其他問題則沉默——碑銘可能列出捐贈者，但唔會記錄唔識字嘅善信。詮釋再加一層，因為修復過嘅建築亦係關於呈現邊個過去嘅選擇。要分清資料講咗乜，同歷史學家推斷咗乜。

不同種類資料可以同唔可以顯示乜嘢
資料擅長顯示睇唔到
廟宇碑銘捐贈者、日期、土地同廟產太窮而無法捐贈嘅人
族譜宗族主張同移民記憶被收養或省略嘅成員
殖民地图某日期嘅道路、地段同海岸線冇業權嘅人嘅使用
口述歷史生活經驗同記憶準確日期同數字

07宗族之前：墓葬同宋室

考古學去到文字沉默之處。李鄭屋漢墓，一座1950年代發現嘅東漢磚墓，磚上印有「大吉番禺」——證據顯示呢個地區喺殖民條約之前約1,800年已經喺番禺縣管轄之內。呢個提醒我哋，呢個地區嘅文字歷史有一個深厚、埋藏嘅前奏。

傳說提供另一層：宋皇臺岩石同1270年代蒙古征服前南逃嘅幼帝故事相連，呢件事短暫將呢個地區拉入王朝政治，亦孕育咗大族嘅移民故事。

三方核對
Archaeology + Text + Memory
每種證據回答唔同問題；要一齊使用

08史料分析五層

有條理咁閱讀任何文獻要經過五層：
- 確立來源同體裁（邊個製作、幾時、為咗乜嘢用途）
- 細讀文本，註解詞語同追蹤人名
- 衡量佢對所涉主題嘅意義
- 將佢置於史學之中——學者點樣使用或質疑佢
- 記低佢邀請乜嘢進一步研究

套用於1743年塔門碑銘，呢啲層次分開咗石頭講乜（兩個家族捐出稅田俾天后廟，而霸佔土地者敗訴於知縣裁決）同佢冇講乜（佃農生活、普通善信、呢類捐贈有幾典型）。呢個框架將引文變成論證。

五層套用於1743年塔門碑銘
層次問題呢塊石頭嘅答案
來源邊個製作、幾時、為咗乜嘢用途？廟宇嘅公開石碑，由捐贈家族出資
細讀詞語同人名講乜？稅田捐俾神；土地「坐落新安，稅懸東莞」
意義觸及乜嘢主題？廟產、土地糾紛、官方裁決
史學學者點樣使用佢？廟宇產業同地方訴訟嘅證據
進一步研究邀請下一步做乜？同地契同縣志核對；問呢個案例有幾典型

09廟宇、儀式同地方國家

廟宇唔止供奉神明。天后信仰隨海洋經濟傳播，而廟產——捐贈土地嘅租金用嚟支付節慶——令廟宇成為法人地主、糾紛調解者同與官員接觸嘅節點。

1743年塔門案例顯示呢個循環：捐贈、侵佔、知縣裁決，同立石令裁決永久化。

儀式跨村莊連結社群：打醮節慶透過巡遊、祭品同神功戲更新社群庇佑，而佢哋嘅記錄同時係歷史資料——捐贈者名單、土地登記、參與村莊名稱。將節慶視為制度嚟閱讀，可以恢復單靠地图顯示唔到嘅社會地圖。

神聖財產循環
Donation → 廟產 temple estate → Dispute → Official ruling → Inscription
每個階段留下唔同種類嘅資料

10縣志、地契同口述記憶

地方志——例如新安縣志等縣志——透過官員視角記錄行政、稅收、風俗同名勝，所以佢哋強調國家想管治嘅嘢。

地契同合約記錄邊界、租金同繼承嘅實際世界；族譜記錄宗族選擇記住嘅嘢；口述歷史記錄長者選擇傳落去嘅嘢。

冇資料係中立嘅，所以互相印證係呢門學科嘅核心習慣：碑銘對縣志，族譜對地契。當資料衝突，衝突本身就係證據——關於對立主張、記憶運作、每個作者需要記錄講乜。

互相印證網絡
Stone ⇄ Gazetteer ⇄ Deed ⇄ Oral memory
跨體裁交叉核對；分歧本身就係證據

關鍵詞

族譜 (genealogy)
記錄世系、婚姻同榮譽嘅宗族記錄，既用嚟確立地位，亦用嚟提供資訊。
圍村 (walled village)
由牆圍繞、通常有護城河嘅聚落，由宗族喺沿海新界為防衛而建。
碑銘 (inscription)
刻喺石上嘅文字，通常記錄捐贈、廟宇創建或官方決定。
轉口貿易
貨物經港口轉運，但唔喺當地生產或消費嘅貿易。
互相印證
接受某項主張之前，用另一個獨立資料核對。
遺產詮釋
向公眾呈現一個地方或物件時所作嘅選擇，包括解釋乜嘢同省略乜嘢。
地方志 (county gazetteer)
為行政而編纂嘅地方史，從官方觀點記錄稅收、風俗同名勝。
打醮 (jiao festival)
定期舉行嘅社群更新儀式，有巡遊、祭品同神功戲，其記錄同時係歷史資料。
計算示例

將廟宇碑銘作為證據閱讀

一塊十八世紀中葉雕刻嘅碑銘記錄兩個具名家族將稅田同山地捐俾一間廟，後來其他人聲稱擁有該土地，而知縣確認咗捐贈。呢個資料可以合理支持乜嘢歷史主張，又唔可以支持乜嘢？

  1. 辨識體裁同來源：一塊立於廟宇嘅石碑，由捐贈者出資，所以係公開且部分自利嘅記錄。
  2. 說明其目的：令捐贈永久化，並警告未來聲稱者該產業受官方裁決保護。
  3. 提取佢確實提出嘅主張：土地被捐出、發生糾紛、知縣喺指定日期判捐贈者勝訴。
  4. 注意其沉默：佢冇講耕作該土地嘅佃農、信眾規模，或呢類捐贈有幾典型。
  5. 喺推廣到呢間廟以外之前，用地契、縣志或第二塊碑銘互相印證。
Answer碑銘係廟產、捐贈者競爭同用官方裁決保衛土地嘅有力證據。對於普遍繁榮或無法捐贈者嘅生活，則係薄弱證據，任何更廣泛嘅主張都需要獨立互相印證。

應試方法

  • 答資料題時，先確立來源同目的，然後先提取內容；方法同史實一樣咁多分。
  • 俾中文詞語加簡短英文註解，然後用英文論證，令讀者可以跟隨推理。
  • 用1841年前同1997年後嘅證據平衡殖民敘事，令答案唔會片面。
  • 引用資料中一句並加以註解——來源加註解引文可以攞到方法分。

Q01新界五大族最好描述為：

解釋鄧、侯、廖、文同彭氏係宗族，其祠堂、信託同族譜塑造咗該地區留存嘅記錄。

Q02記錄捐贈土地嘅廟宇碑銘最有用於顯示：

解釋碑銘通常記錄捐贈、權利同糾紛，而唔係日常出席或總人口。

Q03點解1842年係香港歷史嘅誤導起點？

解釋聚落、宗族社會同沿海貿易遠早於條約，所以1842年係政權更替而唔係開始。

Q04李鄭屋漢墓出土印有「大吉番禺」嘅磚係證據顯示：

解釋印文命名番禺縣，顯示該地區喺1842年前幾百年已喺其行政管轄之內。

Q05喺1743年塔門碑銘中，描述為「坐落新安，稅懸東莞」嘅土地主要顯示：

解釋土地位於新安縣，但稅務登記仍喺東莞，係1573年兩縣分治嘅遺留。
