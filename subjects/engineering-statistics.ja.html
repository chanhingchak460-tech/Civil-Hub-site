エンジニアのための不確実性の言語：サンプルを記述し、分布を選び、推定値に範囲を与え、主張を検定する。それは測定と現場での意思決定をつなぐ橋である。

01サンプルの記述

ほとんどのデータは2つの特徴で要約できる：どこに位置するか、どれだけばらついているか。平均はつり合い点であり、中央値は外れ値に強い影響を受けにくく、最頻値は最も頻繁に現れる値である。

ばらつきについては、サンプルの標準偏差はnではなくn − 1で割ることで、サンプルが母集団の変動を過小評価する傾向を補正する。要約する前に必ずプロットせよ：ヒストグラムは平均では捉えられない歪み、隙間、外れ値を示す。

  • 平均と中央値を比較することは、歪みの簡単な確認である。
  • 変動係数（sをx̄で割ったもの）は、異なる尺度で測定された変数間のばらつきを比較する。
サンプル平均
\[\bar{x} = \frac{1}{n} \sum x_i\]
サンプル標準偏差
\[s = \sqrt{\frac{\sum (x_i - \bar{x})^2}{n - 1}}\]
n − 1 自由度

02確率と確率変数

確率は事象に0から1の間の数を割り当てる。乗法規則は条件付き確率を導入する：P(A | B)はBが起こったという条件下でのAの確率である。P(A | B) = P(A)のとき事象は独立であり、そのときに限り同時確率はP(A) P(B)として因数分解される。

確率変数は結果を数値に写像する。その期待値E(X)は長期的な平均であり、分散Var(X)はその周りのばらつきを測る。

  • 変数をシフトすると平均は変わるが、ばらつきは変わらない。
  • 変数をスケーリングすると、ばらつきはスケール係数倍になる。
条件付き確率
\[P(A \mid B) = \frac{P(A \cap B)}{P(B)}\]
線形変換
\[E(aX + b) = a\,E(X) + b; \quad \mathrm{Var}(aX + b) = a^2\,\mathrm{Var}(X)\]

03正規分布

正規分布N(μ, σ²)は対称で釣鐘型であり、平均と標準偏差だけで完全に決まる。値の約68%は平均から1標準偏差以内に、95%は2標準偏差以内に、99.7%は3標準偏差以内に収まる — 経験則により、迅速な妥当性チェックが可能になる。

表を使うには、まず標準化し、次にz値に対する裾の面積を求め、両側の質問では裾を組み合わせる。曲線を描き、求めたい面積を陰影付けし、表を読む前にラベルを付けよ；符号と裾の誤りが、理解不足ではなく、失点のほとんどを引き起こす。

標準得点
\[z = \frac{x - \mu}{\sigma}\]
xが平均から何標準偏差離れているか

04二項分布とポアソン分布

二項分布は、同じ確率pを持つ固定回数の独立試行における成功回数を数える：固定のn、2つの結果、一定のp、独立性。その平均はnp、分散はnp(1 − p)である。

ポアソン分布は、一定の率λで独立に発生する事象の、固定された時間または空間の区間内での回数を数える；その平均と分散はともにλである。ポアソン分布はλ = npの二項分布の大n・小p極限であり、バッチあたりの欠陥や1時間あたりの通話のような稀な事象に適している。

  • まず仮定を確認せよ：試行回数が固定でない場合は二項分布を排除する。
  • 率が大きく変動する場合はポアソン分布を排除する。
二項確率
\[P(X = x) = \binom{n}{x} p^x (1 - p)^{n - x}\]
ポアソン確率
\[P(X = x) = \frac{e^{-\lambda} \lambda^x}{x!}\]
二項分布を近似する場合、λ = np
分布の選択
分布モデル化するものパラメータ平均分散
正規中心周りの連続測定値μ, σμσ²
二項n回の独立試行における成功回数n, pnpnp(1 − p)
ポアソン区間内の稀な事象の回数λλλ
tσが未知のときの標準化された平均自由度0ν/(ν − 2)

05標本抽出と中心極限定理

サンプルから計算された統計量はそれ自体が確率変数である：標本抽出を繰り返せば平均は変化する。平均の標本分布は平均μと標準誤差σ/√nを持ち、サンプルを4倍にすると標準誤差は半分になる。

中心極限定理は、nが大きければ母集団の形状にかかわらず標本平均は近似的に正規分布に従うことを述べ、これが正規分布に基づく手法が歪んだデータでも通用する理由である。おおよそ30個の観測で十分なことが多いが、強い歪みにはより多くが必要である。

σが未知のときはsで置き換え、t分布を用いる。その重い裾が追加の不確実性を説明する。

平均の標準誤差
\[\mathrm{SE} = \frac{\sigma}{\sqrt{n}}\]

06信頼区間

信頼区間は推定値の周りに範囲を与え、不確実性を述べる。σが既知のとき区間はx̄ ± z σ/√n；σが未知のときはsとn − 1自由度のt臨界値を用いる。

95%区間は90%区間より広く、nが増えると狭くなる。解釈は単一の区間ではなく手法についてである：標本抽出を何度も繰り返せば、この方法で作られた区間の95%がμを含む。この特定の固定区間がμを含む確率が95%ということではない。

区間は単位と信頼水準とともに報告せよ。

信頼区間（σ既知）
\[\bar{x} \pm z_{\alpha/2} \frac{\sigma}{\sqrt{n}}\]
信頼区間（σ未知）
\[\bar{x} \pm t_{\alpha/2,\,n-1} \frac{s}{\sqrt{n}}\]

07仮説検定

検定はデータが帰無仮説H₀と整合するかを問う。H₀は通常、効果なしまたは差なしである。対立仮説を選び、有意水準αを設定し、検定統計量を計算して臨界値またはp値と比較する。p < αのときH₀を棄却する；棄却しないことはH₀が真であることを証明しない。

2種類の誤りが可能である：第1種の誤りは真のH₀を棄却し、その確率はαであり、第2種の誤りは偽のH₀を棄却しないことである。信頼区間と両側検定は、区間が仮説値を除外するとき一致する。

仮定 — 独立性、正規性、または大標本 — を述べよ。検定はそのモデルの良さにしかならないからである。

1標本t統計量
\[t = \frac{\bar{x} - \mu_0}{s/\sqrt{n}}\]
両側検定ではt_(α/2, n−1)と比較

08相関と回帰

相関係数rは−1から1の間で線形関係の強さと方向を測る。rがゼロに近いことは線形傾向がないことを意味し、関係がないことではない。また単一の外れ値がrを大きく動かしうる。相関は因果ではない。

最小二乗回帰はŷ = a + b xを当てはめる。傾きはxの1単位あたりのyの単位を持ち、r²は説明される変動の割合である。

観測範囲を超えて外挿してはならず、予測を信頼する前に残差プロットを確認せよ。

回帰係数
\[b = \frac{S_{xy}}{S_{xx}}, \quad a = \bar{y} - b\,\bar{x}\]
S_xyは補正された積和

09統計的品質管理

品質管理は同じ推論を生産に適用する。管理図はサンプル統計量をx̄ ± 3σ/√nのような限界に対してプロットし、共通原因変動と特殊原因シグナルを分離する；限界外の点、または片側に連続する点は、調整ではなく調査を促す。

工程能力指数C_pkは規格幅を3σと比較し、工程が管理状態にあっても公差を満たせるかを示す。工程は安定していても能力不足でありうる：管理図は変動を記述し、能力はその変動を規格が要求するものと比較する。

管理図の限界
\[\mathrm{UCL},\, \mathrm{LCL} = \bar{x} \pm \frac{3\sigma}{\sqrt{n}}\]
工程能力
\[C_{pk} = \frac{\min(\mathrm{USL} - \mu,\, \mu - \mathrm{LSL})}{3\sigma}\]
USLとLSLは規格限界

10寿命と待ち時間：指数分布と幾何分布

ポアソン過程が率λで事象を生み出すとき、指数分布は次の事象までの時間をモデル化する：車両到着間の間隔、最初の欠陥までの時間、または部品の使用寿命。その密度はf(x) = λe^(−λx)、平均と標準偏差はともに1/λであり、累積形式F(x) = 1 − e^(−λx)は時間xまでの故障確率を与える。

無記憶性は過去が何の意味も持たないことを述べる：s時間生き残った部品は新品同様であり、P(X > s + t | X > s) = P(X > t)である。実際の材料は劣化するので、それに依拠する前に仮定を検証せよ。

幾何分布は離散的ないとこである — 最初の成功までを含む試行回数で、平均は1/pである。

指数分布の密度と累積分布関数
\[f(x) = \lambda e^{-\lambda x}, \quad F(x) = 1 - e^{-\lambda x}\]
平均と標準偏差はともに1/λ
無記憶性
\[P(X > s + t \mid X > s) = P(X > t)\]
幾何確率
\[P(X = x) = (1 - p)^{x-1} p\]
最初の成功までを含むx回の試行

11カイ二乗適合度検定

計数データには異なる検定が必要である。カイ二乗適合度検定は各カテゴリの観測度数を帰無仮説の下での期待度数と比較する；統計量が大きいことはモデルの適合が悪いことを意味する。二次元表に適用すると、同じ統計量が2つのカテゴリ変数間の独立性を検定する。

自由度：完全に指定された分布ではk − 1、データから推定された各パラメータごとにさらに1を引く；r × c表では(r − 1)(c − 1)。

検定は近似であるため、すべての期待度数が約5に達するまでカテゴリを併合し、常に割合ではなく度数を比較せよ。

カイ二乗統計量
\[\chi^2 = \sum_i \frac{(O_i - E_i)^2}{E_i}\]
O_iは観測度数、E_iはカテゴリiの期待度数
二次元表の期待度数
\[E = \frac{\text{row total} \times \text{column total}}{\text{grand total}}\]
小さいカテゴリを併合せよ 期待度数が約5未満であるとカイ二乗統計量が膨らみ、p値が信頼できなくなる；まず隣接カテゴリを統合せよ。

12検出力とサンプルサイズ

H₀を棄却しないことは、検定が効果を見つけられた場合にのみ情報を持つ。検定の検出力は対立仮説が真のときにH₀を棄却する確率である：検出力 = 1 − β、ここでβは第2種の誤り率である。それはサンプルサイズn、有意水準α、真の効果の大きさとともに増大し、データがノイズが多いほど低下する。

平均の両側z検定では、差δを検出力1 − βで検出するのに必要なサンプルはおよそ(z_(α/2) + z_β)² σ² / δ²である。臨界値が二乗で入るため、効果の半分を検出するには4倍のサンプルが必要である。

検定が有意でないときは検出力を報告せよ — 小さなサンプルからの帰無結果は何も証明しない。

必要なサンプルサイズ（両側z検定）
\[n \approx \frac{(z_{\alpha/2} + z_\beta)^2 \sigma^2}{\delta^2}\]
δは検出する価値のある最小の差

Key terms

標準誤差
サンプル統計量の標準偏差であり、推定値が繰り返しのサンプル間でどれだけ変動するかを示す。
信頼区間
母集団パラメータの妥当な値の範囲であり、95%などの信頼水準とともに報告される。
帰無仮説
効果なしまたは差なしというデフォルトの主張であり、有意性検定がそれに対する証拠を見つけようとするもの。
p値
帰無仮説が真であると仮定して計算された、観測結果と少なくとも同程度に極端な結果が得られる確率。
中心極限定理
大きなサンプルでは母集団の形状にかかわらず標本平均が近似的に正規分布に従うという結果。
第1種の誤り
実際には真である帰無仮説を棄却すること；その確率は有意水準αである。
無記憶性
将来の待ち時間がすでに経過した時間に依存しないという指数分布の特徴。
検出力
対立仮説が真のときに検定が正しく帰無仮説を棄却する確率であり、1 − βに等しい。
Worked example

コンクリート供試体強度の信頼区間とt検定

9個のコンクリート供試体を28日で試験したところ、平均強度42.0 MPa、サンプル標準偏差3.0 MPaが得られた。規格目標は平均40 MPaである。平均強度の95%信頼区間を構築し、5%有意水準で平均強度が40 MPaと異なるか（両側）を検定せよ。

  1. モデルを述べる：n = 9、x̄ = 42.0 MPa、s = 3.0 MPaでσは未知なので、n − 1 = 8自由度のt分布を用いる。
  2. 標準誤差：SE = s/√n = 3.0/√9 = 1.0 MPa。
  3. 8自由度の95%両側区間の臨界値：t_(0.025, 8) = 2.306。
  4. 信頼区間：42.0 ± 2.306 × 1.0 = 42.0 ± 2.31、すなわち39.69 MPaから44.31 MPa。
  5. 検定統計量：t = (42.0 − 40.0) / 1.0 = 2.00、8自由度。
  6. 両側検定の臨界値も2.306であり、2.00 < 2.306なのでH₀を棄却しない；p値は0.05より大きい。
  7. 妥当性チェック：区間39.7から44.3 MPaは40 MPaを含み、帰無仮説を棄却しないことと一致する。
Answer平均強度の95%信頼区間は39.7から44.3 MPaである。両側t検定は8自由度でt = 2.00を与え、これは2.306より小さいため、5%水準で平均強度が40 MPaと異なると結論する十分な証拠はない。

Exam method

  • 計算する前に帰無仮説と対立仮説および有意水準を書き、採択ではなく棄却しないと述べよ。
  • すべての質問をz値またはt値に変換し、陰影付きの面積とともに曲線を描け；誤りのほとんどは符号または裾の誤りである。
  • 各分布の仮定 — 独立性、固定n、一定p、既知σ — を学べ。仮定の確認に点が与えられることが多い。
  • 信頼区間は信頼水準と単位とともに報告し、1つのサンプルではなく手法の観点から解釈せよ。
  • カイ二乗の質問では、すべての期待度数が少なくとも5であることを確認し、表を読む前に自由度を述べよ。

Q01正規分布において、観測値のおよそどの割合が平均から1標準偏差以内に収まるか？

Why経験則により、1標準偏差以内に約68%、2標準偏差以内に95%、3標準偏差以内に99.7%が収まる。

Q02機会が多く欠陥率が小さいとき、バッチあたりに発生する稀な欠陥の数の自然なモデルとなる分布はどれか？

Whyポアソン分布は区間内の稀な事象の回数をモデル化し、二項分布の大n・小p極限である。

Q03母平均の95%信頼区間が(12.1, 15.9)である。正しい解釈はどれか？

Why信頼水準は手法の長期的な成功率を表し、この固定区間が平均を含む確率を表すのではない。

Q04仮説検定が有意水準0.05でp値0.03を返した。正しい結論はどれか？

Why0.03 < 0.05なので、5%水準で帰無仮説は棄却される；小さいp値はH₀に反する証拠であり、H₀を支持する証拠ではない。

Q05交差点への連続する車両到着間の間隔が率λ = 4/分の指数分布に従う。次の間隔が1分を超える確率は：

Why指数変数ではP(X > t) = e^(−λt)；t = 1、λ = 4でこれはe^(−4)であり、0.02を少し下回る。

Q06適合度検定に6つのカテゴリがあり、仮説分布の1つのパラメータがデータから推定された。カイ二乗統計量の自由度はいくつか？

Why自由度はk − 1から推定された各パラメータにつき1を引いたものである：6 − 1 − 1 = 4。
