地盤工学設計は、地盤調査を、破壊に対して安全で沈下が許容範囲内にある基礎、擁壁構造物、斜面へと変換する。ほとんどすべての判断は有効応力、排水、地下水位に依存する。

01地盤調査と地盤モデル

すべての地盤工学設計は、現場を地盤モデルに変換することから始まる。すなわち、土と岩の層の配列、それらの強度と剛性、そして地下水位の位置である。

  • まず地図や記録による机上調査を行い、次にボーリング孔と原位置試験、そして室内試験を行う。
  • 標準貫入試験とコーン貫入試験は、深さに伴う密度と強度の連続的な感覚を与える。サンプリングは、原位置試験では得られないパラメータを与える。
  • 間隙水圧は有効応力を低下させ、すべての強度計算と沈下計算を変える。

1本のボーリング孔は1点を証明するだけで、現場全体を証明するものではない。そのためパラメータは特性値として選定され、部分係数と組み合わされる。

02極限支持力

支持力は、地盤がせん断破壊を起こさずに基礎荷重を支えられるかどうかを問う。帯基礎の極限圧力は

q_u = c′ N_c + q′ N_q + 0.5 γ B N_γ

である。ここでc′は有効粘着力、q′は基礎底面レベルでの上載圧、γは土の単位重量、Bは基礎幅、Nは摩擦角とともに増大する支持力係数である。

  • 形状係数は正方形基礎や円形基礎に対する結果を補正する。
  • 破壊領域内の地下水位は有効単位重量を低下させる。
  • 安全率または一連の部分係数が、極限支持力を許容値または設計値まで低減する。
Terzaghi支持力、帯基礎
\[q_u = c' N_c + q' N_q + 0.5\gamma B N_\gamma\]
N係数はφ′に依存する。地下水位以下では有効応力を用いる

03偏心荷重と接地圧

実際の柱は荷重だけでなくモーメントも伴って作用するため、基礎下の接地圧が一様になることはほとんどない。偏心量はe = M/Qである。

  • 合力が底面の中央三分の一内にとどまる間（e ≤ B/6）、底面全体が接地し、圧力は台形分布となる：q_max,min = Q/(B L) (1 ± 6e/B)。
  • eがB/6を超えると、底面の一部が浮き上がり、荷重側から幅B − 2eにわたって接地が失われる。そのとき最大圧力は縁部付近に集中する：q_max = 4Q / [3 L (B − 2e)]。

設計上の対応は有効面積の概念である。基礎を載荷領域B′ = B − 2eまで縮小し、低減した寸法で支持力を検討し、小さなモーメントを受ける広い基礎の方が、大きなモーメントを受ける狭い基礎より通常は優れていることを受け入れる。

最大圧力、合力が中央三分の一内
\[q_{\max} = \frac{Q}{B L}\left(1 + \frac{6e}{B}\right)\]
e = M/Q。e ≤ B/6のとき最小圧力はQ/(BL)(1 − 6e/B)
最大圧力、部分接地
\[q_{\max} = \frac{4Q}{3L(B - 2e)}\]
e > B/6。非載荷側で接地が失われ、圧力は縁部付近に集中する
偏心荷重下の接地圧の状態
条件接地圧力分布最大圧力
e = 0全面一様Q / (B L)
e < B/6全面台形Q/(B L)(1 + 6e/B)
e = B/6全面、縁部ゼロ三角形2Q / (B L)
e > B/6部分B − 2eにわたる三角形4Q / [3L(B − 2e)]

04沈下と使用性

使用性は沈下を推定することによって検討される。砂は主に弾性圧縮によってほぼ即時に沈下する。粘土は過剰間隙水が排水されるにつれてゆっくり沈下し、これが圧密である。

  • 弾性沈下はしばしばS_e = q B (1 − ν²) I / Eとして推定される。ここでqは作用圧力、νはポアソン比、Eは地盤の弾性係数、Iは形状と深さに対する影響係数である。
  • 正規圧密粘土層では、一次元圧密沈下はS_c = [C_c H / (1 + e_0)] log[(σ′_0 + Δσ′)/σ′_0]である。圧縮指数C_c、初期間隙比e_0、層厚H、有効応力増分Δσ′を用いる。

総沈下も重要だが、構造物にひび割れを生じさせるのは不同沈下であるため、隣接する支持点間で検討される。

圧密沈下
\[S_c = \frac{C_c H}{1 + e_0}\log\frac{\sigma'_0 + \Delta\sigma'}{\sigma'_0}\]
σ′はkPa、Hはメートル、logは底10

05杭：支持力と群効果

杭は先端の先端支持と長さ方向の周面摩擦によって荷重を支える：

Q_u = Q_p + Q_s = A_p q_p + Σ p L f_s

ここでA_pは先端面積、q_pは先端圧力、pは周長、f_sは各層の周面摩擦である。

  • 砂では先端抵抗は深さと有効応力とともに増大する。粘土では周面摩擦は非排水強度に関係する。
  • 基準は各土質ごとの相関式を与える。手法は土質と施工法に適合しなければならない。
  • 杭は、浅い基礎が良好な地盤に到達できない場合、引抜きや水平荷重が支配的な場合、または沈下を制限する必要がある場合に用いられる。

杭群は単杭の単純な合計ではない。応力球の重なりが沈下を増大させるため、群効率を検討しなければならない。打込み杭は砂を締め固めるが振動を生じる。場所打ち杭は静かだが残土を生じる。

杭の極限支持力
\[Q_u = Q_p + Q_s = A_p q_p + \sum p L f_s\]

06杭支持力：標準的な手法

Q_u = Q_p + Q_sの背後にある手法は土質によって異なる。

  • 飽和粘土では、先端はQ_p = 9 c_u A_pを負担する。これは先端面積に対する非排水せん断強度の9倍であり、単に深い支持力係数である。周面は付着係数を通じて非排水強度の一部を発揮する：f_s = α c_u。αは軟弱粘土で約1.0から、硬質粘土で0.5以下まで低下する。
  • 砂では、先端支持力は先端での有効上載圧とともに増大し、上限で制限された支持力係数を通じて表される。周面摩擦はf_s = K σ′_v tan δに従う。ここでKは側圧係数、δは境界面摩擦角である。

軟弱粘土には落とし穴がある。盛土の沈下や地下水位の低下は杭を下方に引きずり、その負の周面摩擦は抵抗するのではなく作用荷重に加算される。沈下する地盤中の杭は、堅固で沈下しない層に到達するのに十分な長さが必要である。

先端支持力、飽和粘土中の杭
\[Q_p = 9\,c_u A_p\]
c_uは先端での非排水せん断強度、A_pは先端面積
周面摩擦、粘土中の杭
\[f_s = \alpha\,c_u\]
αは付着係数で、粘土の剛性に応じて概ね0.5〜1.0
周面摩擦、砂中の杭
\[f_s = K\,\sigma'_v \tan\delta\]
Kは側圧係数、σ′_vは有効鉛直応力、δは境界面摩擦

07マット基礎

マット基礎またはラフト基礎は建物の平面全体を覆い、荷重を広い面積に分散する。弱い地盤、大きな柱荷重、地下室、個別フーチングが重なり合うような現場に適する。

  • 接地圧はラフトと地盤の相対剛性に依存する。柔なラフトは荷重パターンに従い、剛なラフトは均等に沈下して圧力を再配分する。
  • 地下室が上部構造物とほぼ同じ重量の土を排除する場合、補償基礎となり、正味の載荷を小さくできる。

ラフトは上部構造物と一体で解析されることが多く、柱位置の押抜きせん断や、地下水位が高い場合の浮力による揚圧に対して検討される。

08擁壁と土圧

擁壁は土を保持する。水平圧力は壁がどれだけ移動するかに依存する。

  • 主働圧力は、壁がわずかに変位して土が緩むときに生じる。
  • 受働圧力は、壁が土を押し、土が抵抗するときに生じる。
  • 乾燥した粘着力のない裏込め土では、Rankineの係数はK_a = tan²(45° − φ′/2)であり、全主働力は0.5 γ H² K_aとして増大する。

設計では3つのモードを検討する。つま先まわりの転倒、底面に沿った滑動、つま先下の支持力である。水は通常の破壊原因であるため、排水、水抜き孔、壁背後のフィルター層は追加要素ではなく設計の一部である。

Rankine主働土圧係数
\[K_a = \tan^2\left(45^\circ - \frac{\phi'}{2}\right)\]
水平裏込めに対する受働係数はその逆数である

09比率問題としての壁の安定性

壁の3つの検討は、目標値をもつ比率として表すのが最もよい。そうすれば形状と部分係数が可視化されたままになる。

  • 滑動は、底面に沿った水平抵抗と水平推力とを比較する：F_sliding = ΣR / ΣH。ここでΣRは底面に沿った摩擦と付着の合計（およびつま先で期待できる受働土圧）であり、ΣHは全水平推力である。通常、少なくとも約1.5が要求される。
  • 転倒は、つま先まわりの抵抗モーメントと推力による転倒モーメントとを比較する。これも目標値は約1.5〜2.0であり、合力が中央三分の一に入るように底面幅を選ぶ。これはフーチングを支配するのと同じe ≤ B/6の規則である。
  • 次に、偏心接地圧を用いてつま先下の支持力を検討する。

これら3つの検討の間で反復することが実際の設計である。底面を広くすると3つすべてに有利だが、掘削とコンクリートのコストが増す。

滑動に対する安全率
\[F_{\mathrm{sliding}} = \frac{\sum R}{\sum H}\]
ΣRは底面に沿った抵抗せん断力。少なくとも約1.5を目標とする

10斜面安定

斜面安定は、想定されるすべり面に沿って利用可能なせん断強度と、移動を引き起こすのに必要なせん断応力とを比較する。均一な斜面における円形すべりでは、分割法が土塊を分割し、モーメントまたは力を合計する。その比率が安全率である。

F_s = Σ [c′ l + (W cos α − u l) tan φ′] / Σ W sin α

これは単純なFellenius法であり、Wはスライスの重量、αはその底面の傾斜、uは間隙水圧である。

浸透は有効応力を低下させ、したがって安定性を低下させる。そのため斜面は豪雨後にしばしば崩壊する。安定化には、より緩い勾配、排水、擁壁構造物、土釘またはロックボルト、そして浸食に対する表面保護が用いられる。

Fellenius安全率
\[F_s = \frac{\sum\left[c' l + (W\cos\alpha - u l)\tan\phi'\right]}{\sum W\sin\alpha}\]

11地盤改良

地盤改良は、通常の基礎が成立するように地盤を変化させる。

  • 締固めは密度を増大させ沈下を低減する。置換は弱い材料を除去する。
  • プレファブリケーテッドバーチカルドレーンは排水経路を短縮し、盛土載荷下の施工中に圧密を進行させる。
  • 石柱や深層混合処理工法は補強と剛性を加える。グラウトは空隙を充填し透水性を低下させる。ジオテキスタイルやジオグリッドは引張補強と層の分離を加える。

選択は、地盤の何が問題か（強度、剛性、透水性、ばらつき）と、構造物が載荷されるまでの利用可能な時間に依存する。

Key terms

有効応力
全応力から間隙水圧を差し引いたもの。土の強度と圧縮を支配する。
特性値
設計のための地盤パラメータの慎重な推定値であり、試験データの量と品質に注意して選定される。
圧密
過剰間隙水が排水され有効応力が上昇するにつれて、飽和土が時間依存的に体積減少すること。
主働土圧
壁が裏込めからわずかに離れる方向に移動したときに、壁に作用する低減された水平圧力。
先端支持
杭の支持力のうち、先端の圧力によって負担される部分。
群効率
杭群の支持力と、個々の杭の支持力の合計との比。
補償基礎
掘削によって上部構造物とほぼ同じ重量の土を除去し、正味沈下を低減する基礎。
中央三分の一の規則
荷重合力を底面の中央三分の一内（e ≤ B/6）に保ち、底面全体が圧縮状態にとどまるようにすること。
付着係数
粘土における杭の周面摩擦と非排水せん断強度の比であり、f_s = α c_uの形で用いられる。
Worked example

正方形フーチングの許容支持力

幅2.0 mの正方形フーチングが、φ′ = 30°、c′ = 0、単位重量17.5 kN/m³の中密な砂の地盤に、地表面から1.2 mの深さで設置されている。地下水位は破壊領域より下にある。Terzaghiの正方形フーチング式と、極限支持力に対する安全率3を用いて、許容支持力と許容柱荷重を求めよ。

  1. 正方形フーチングでは、q_u = 1.3 c′ N_c + q′ N_q + 0.4 γ B N_γである。c′ = 0なので第1項は消える。
  2. 表からφ′ = 30°に対してN_q = 22.5、N_γ = 19.1をとる。
  3. 基礎底面レベルでの上載圧：q′ = γ D_f = 17.5 × 1.2 = 21.0 kPa。
  4. q_u = 21.0 × 22.5 + 0.4 × 17.5 × 2.0 × 19.1 = 472 + 268 = 740 kPa。
  5. 許容圧力：q_all = 740/3 = 247 kPa。
  6. 許容柱荷重：Q_all = q_all × B² = 247 × 4.0 = 988 kN。
  7. 妥当性確認：247 kPaは中密な砂として妥当な値であり、フーチングは狭いため、実際には一般せん断ではなく押抜きせん断が支配する可能性がある。
Answer許容支持力は約247 kPaであり、2.0 m正方形フーチング上の許容柱荷重は約990 kNとなる。

Exam method

  • 支持力や土圧の式に触れる前に、有効応力と間隙水圧を計算すること。
  • 単位はすべてkNとメートルで通し、最後に単位換算せずに圧力がkPaで出るようにすること。
  • 両方の限界状態に答えること：ULSでの支持力、滑動、転倒、およびSLSでの沈下。
  • 排水条件（短期非排水か長期排水か）を明記すること。パラメータと解析の両方が変わるため。
  • 偏心モーメントがあればe = M/Qに変換し、接地圧の式を選ぶ前にB/6と比較すること。接地が失われると式が変わる。
