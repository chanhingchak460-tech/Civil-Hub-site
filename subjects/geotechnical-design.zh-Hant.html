岩土設計將地面勘探轉化為基礎、擋土結構和邊坡，使其在破壞方面安全，並在沉降方面可接受。幾乎每個決定都取決於有效應力、排水和水位。

進度只儲存在此瀏覽器。

01場地勘察與地層模型

每個岩土設計都始於將場地轉化為地層模型：土層和岩層的序列、其強度和剛度，以及水位的位置。

  • 首先進行地圖和記錄的文獻研究，然後是鑽孔和現場測試，再進行實驗室測試。
  • 標準貫入試驗和錐形貫入試驗提供隨深度變化的密度和強度的連續感覺；取樣提供現場測試無法獲得的參數。
  • 孔隙水壓力降低有效應力，並改變每個強度和沉降計算。

一個鑽孔證明一個點，而不是一個場地，因此參數被選為特徵值並與分項係數結合。

02極限承載力

承載力詢問地面能否承受基礎荷載而不發生剪切破壞。對於條形基礎，極限壓力為

q_u = c′ N_c + q′ N_q + 0.5 γ B N_γ，

其中 c′ 是有效黏聚力，q′ 是基礎水平處的超載，γ 是土單位重量，B 是基礎寬度，N 是隨摩擦角增長的承載力係數。

  • 形狀係數調整方形和圓形基礎的結果。
  • 破壞區內的水位降低有效單位重量。
  • 安全係數或一組分項係數將極限承載力降至容許或設計值。
Terzaghi 承載力，條形基礎
\[q_u = c' N_c + q' N_q + 0.5\gamma B N_\gamma\]
N 係數取決於 φ′；在水位以下使用有效應力

03偏心荷載與接觸壓力

實際柱既傳遞荷載也傳遞彎矩，因此基礎下的接觸壓力很少是均勻的。偏心距為 e = M/Q。

  • 當合力保持在基底的中間三分之一範圍內 — e ≤ B/6 — 整個基底保持接觸，壓力呈梯形：q_max,min = Q/(B L) (1 ± 6e/B)。
  • 一旦 e 超過 B/6，部分基底抬起，從荷載側起寬度 B − 2e 範圍內失去接觸；峰值壓力集中在邊緣附近：q_max = 4Q / [3 L (B − 2e)]。

設計對策是有效面積概念：將基礎縮小到受荷區 B′ = B − 2e，在縮小後的尺寸上檢查承載力，並接受帶小彎矩的寬基礎通常優於帶大彎矩的窄基礎。

峰值壓力，合力在中間三分之一內
\[q_{\max} = \frac{Q}{B L}\left(1 + \frac{6e}{B}\right)\]
e = M/Q；當 e ≤ B/6 時，最小壓力為 Q/(BL)(1 − 6e/B)
峰值壓力，部分接觸
\[q_{\max} = \frac{4Q}{3L(B - 2e)}\]
e > B/6；在無荷載側失去接觸，壓力集中在邊緣附近
偏心荷載下的接觸壓力狀態
條件接觸壓力分佈峰值壓力
e = 0全部均勻Q / (B L)
e < B/6全部梯形Q/(B L)(1 + 6e/B)
e = B/6全部，邊緣為零三角形2Q / (B L)
e > B/6部分在 B − 2e 上呈三角形4Q / [3L(B − 2e)]

04沉降與正常使用極限狀態

正常使用極限狀態通過估算沉降來檢查。砂幾乎立即沉降，主要通過彈性壓縮；黏土隨著超孔隙水排出而緩慢沉降，即固結。

  • 彈性沉降通常估算為 S_e = q B (1 − ν²) I / E，其中 q 是施加的壓力，ν 是泊松比，E 是土模量，I 是形狀和深度的影響係數。
  • 對於正常固結黏土層，一維固結沉降為 S_c = [C_c H / (1 + e_0)] log[(σ′_0 + Δσ′)/σ′_0]，其中壓縮指數 C_c、初始孔隙比 e_0、層厚 H 和有效應力增量 Δσ′。

總沉降很重要，但差異沉降才是使結構開裂的原因，因此在相鄰支撐之間進行檢查。

固結沉降
\[S_c = \frac{C_c H}{1 + e_0}\log\frac{\sigma'_0 + \Delta\sigma'}{\sigma'_0}\]
σ′ 以 kPa 為單位，H 以米為單位，log 以 10 為底

05樁：承載力與群樁

樁通過底部的端承和沿長度的樁側摩擦承載荷載：

Q_u = Q_p + Q_s = A_p q_p + Σ p L f_s，

其中 A_p 是底面積，q_p 是底部壓力，p 是周長，f_s 是每層的樁側摩擦。

  • 在砂中，端阻力隨深度和有效應力增長；在黏土中，樁側摩擦與不排水強度相關。
  • 規範給出每種土類型的相關關係；方法必須適合土質和安裝方式。
  • 當淺基礎無法到達勝任地層、上拔或側向荷載主導、或必須限制沉降時，使用樁。

群樁不是單樁的簡單總和：重疊的應力泡增加沉降，必須檢查群樁效率。打入樁使砂密實但會振動；鑽孔樁較安靜但產生棄土。

樁極限承載力
\[Q_u = Q_p + Q_s = A_p q_p + \sum p L f_s\]

06樁承載力：標準方法

Q_u = Q_p + Q_s 背後的方法因土類型而異。

  • 在飽和黏土中，底部承載 Q_p = 9 c_u A_p — 底面積上不排水抗剪強度的九倍，這只是一個深基礎承載係數 — 樁側通過黏著係數調動不排水強度的一部分：f_s = α c_u，其中 α 從軟黏土的約 1.0 降至硬黏土的 0.5 或更低。
  • 在砂中，端承通過承載係數隨底部有效超載增長，並受上限限制，樁側摩擦遵循 f_s = K σ′_v tan δ，其中 K 是側壓力係數，δ 是界面摩擦角。

軟黏土帶來一個陷阱：沉降填土或降低地下水可能將樁向下拖曳，這種負摩擦力增加到施加荷載而不是抵抗它 — 沉降地面中的樁必須足夠長以到達堅實、不沉降的地層。

端承，飽和黏土中的樁
\[Q_p = 9\,c_u A_p\]
c_u 是底部的不排水抗剪強度，A_p 是底面積
樁側摩擦，黏土中的樁
\[f_s = \alpha\,c_u\]
α 是黏著係數，根據黏土剛度大致為 0.5–1.0
樁側摩擦，砂中的樁
\[f_s = K\,\sigma'_v \tan\delta\]
K 側壓力係數，σ′_v 有效垂直應力，δ 界面摩擦

07筏板基礎

筏板基礎覆蓋整個佔地面積並將荷載分佈到大面積上。它適用於軟弱地面、重柱荷載、地下室，以及獨立基礎會重疊的場地。

  • 接觸壓力取決於筏板和土的相對剛度：柔性筏板跟隨荷載模式，而剛性筏板均勻沉降並重新分佈壓力。
  • 當地下室置換的土重與上部結構重量大致相同時，結果是補償基礎，淨荷載可以很小。

筏板通常與上部結構一起分析，並檢查柱處的沖切剪切和水位高處的浮力上舉。

08擋土牆與土壓力

擋土牆擋住土體。水平壓力取決於牆的移動量。

  • 當牆略微屈服且土體鬆弛時，產生主動壓力。
  • 當牆推入土體且土體抵抗時，產生被動壓力。
  • 對於乾燥的無黏性回填，Rankine 係數為 K_a = tan²(45° − φ′/2)，總主動力增長為 0.5 γ H² K_a。

設計檢查三種模式：繞牆趾的傾覆、沿基底的滑動，以及牆趾下的承載力。水是破壞的常見原因，因此排水、洩水孔和牆後的濾層是設計的一部分，而不是附加物。

Rankine 主動土壓力係數
\[K_a = \tan^2\left(45^\circ - \frac{\phi'}{2}\right)\]
對於水平回填，被動係數是其倒數

09牆穩定性作為比率問題

三項牆檢查最好寫成具有目標值的比率，因為幾何形狀和分項係數然後保持可見。

  • 滑動比較沿基底的水平和抗力與水平推力：F_sliding = ΣR / ΣH，其中 ΣR 是沿基底的摩擦和黏聚力之和（加上牆趾處可依賴的任何被動土），ΣH 是總側向推力。通常要求至少約 1.5。
  • 傾覆比較繞牆趾的恢復力矩與推力產生的傾覆力矩，同樣目標接近 1.5–2.0，並選擇基底寬度使合力落在中間三分之一 — 與控制基礎的相同 e ≤ B/6 規則。
  • 然後在牆趾下用偏心接觸壓力檢查承載力。

在這三項檢查之間迭代是實際設計：更寬的基底有助於所有三項，代價是開挖和混凝土。

抗滑安全係數
\[F_{\mathrm{sliding}} = \frac{\sum R}{\sum H}\]
ΣR 是沿基底的抗剪阻力；目標至少約 1.5

10邊坡穩定性

邊坡穩定性比較潛在破壞面上可用的抗剪強度與引起運動所需的剪應力。對於均勻邊坡中的圓形滑動，條分法將土體分割並求和力矩或力；比率是安全係數。

F_s = Σ [c′ l + (W cos α − u l) tan φ′] / Σ W sin α

對於簡單的 Fellenius 方法，其中 W 是條塊重量，α 是其底部的傾角，u 是孔隙水壓力。

滲流降低有效應力從而降低穩定性，這就是邊坡在大雨後經常破壞的原因。加固使用較緩的坡度、排水、擋土結構、土釘或岩石錨桿，以及防止侵蝕的表面保護。

Fellenius 安全係數
\[F_s = \frac{\sum\left[c' l + (W\cos\alpha - u l)\tan\phi'\right]}{\sum W\sin\alpha}\]

11地基處理

地基處理改變地面，使普通基礎變得可行。

  • 壓實增加密度並減少沉降；置換移除軟弱材料。
  • 預製垂直排水板縮短排水路徑，使固結在施工期間在超載下發生。
  • 碎石樁和深層土壤混合增加加固和剛度；灌漿填充空隙並降低滲透性；土工布和土工格柵增加抗拉加固並分隔層次。

選擇取決於地面的問題所在 — 強度、剛度、滲透性或變異性 — 以及結構加載前的可用時間。

關鍵詞

有效應力
總應力減去孔隙水壓力；它控制土的強度和壓縮。
特徵值
設計用地面參數的謹慎估計，選擇時注意測試數據的數量和質量。
固結
飽和土隨超孔隙水排出和有效應力上升而隨時間減小的體積。
主動土壓力
牆略微離開回填土移動時，牆上減小的水平壓力。
端承
樁承載力中由底部壓力承擔的部分。
群樁效率
群樁承載力與其單樁承載力之和的比率。
補償基礎
開挖移除的土重與結構重量大致相同，從而減少淨沉降的基礎。
中間三分之一規則
將荷載合力保持在基底中間三分之一內，e ≤ B/6，使整個基底保持受壓。
黏著係數
黏土中樁側摩擦與不排水抗剪強度之間的比率，用於 f_s = α c_u 形式。
計算示例

方形基礎的容許承載壓力

一個 2.0 m 寬的方形基礎位於地面以下 1.2 m，置於中等密實砂上，φ′ = 30°，c′ = 0，單位重量 17.5 kN/m³。水位在破壞區以下。使用 Terzaghi 方形基礎表達式和極限承載力安全係數 3，求容許承載壓力和容許柱荷載。

  1. 對於方形基礎，q_u = 1.3 c′ N_c + q′ N_q + 0.4 γ B N_γ；當 c′ = 0 時，第一項消失。
  2. 從表中取 φ′ = 30° 的 N_q = 22.5 和 N_γ = 19.1。
  3. 基礎水平處的超載：q′ = γ D_f = 17.5 × 1.2 = 21.0 kPa。
  4. q_u = 21.0 × 22.5 + 0.4 × 17.5 × 2.0 × 19.1 = 472 + 268 = 740 kPa。
  5. 容許壓力：q_all = 740/3 = 247 kPa。
  6. 容許柱荷載：Q_all = q_all × B² = 247 × 4.0 = 988 kN。
  7. 合理性檢查：247 kPa 對於中等密實砂是合理值，且基礎狹窄，因此實際上可能由沖切剪切而非一般剪切控制。
Answer容許承載壓力約為 247 kPa，在 2.0 m 方形基礎上給出約 990 kN 的容許柱荷載。

應試方法

  • 在接觸承載力或土壓力方程之前，先計算有效應力和孔隙水壓力。
  • 全程使用 kN 和米，使壓力以 kPa 為單位出現，無需在最後進行單位換算。
  • 回答兩種極限狀態：承載力、滑動或傾覆在 ULS，以及沉降在 SLS。
  • 說明排水條件 — 短期不排水或長期排水 — 因為參數和分析都會改變。
  • 將任何偏心彎矩轉化為 e = M/Q，並在選擇接觸壓力公式之前與 B/6 比較；一旦失去接觸，公式就會改變。
