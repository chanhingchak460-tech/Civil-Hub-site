01水の流れ方の2種類

開水路流れは大気圧下の自由水面を持ち、重力によって駆動され、水深は上下しうる。管路流れは満水で流れ、圧力勾配によって駆動され、断面は固定されている。開水路の水深は河床勾配と下流側の制御によって決まり、満水管の損失水頭は流量と粗度から決まる。

水深・断面積・流速が区間に沿って変化しないとき、流れは等流である——重力と摩擦の平衡である。漸変流は堰の背後などのようにゆっくり変化し、急変流は跳水のように数水深の範囲で変化する。

02Manningの式

Manningの式は水路の形状、河床勾配、粗度係数から平均流速を推定する。摩擦は周辺に沿って作用するため、径深 R = A/P（断面積を潤辺で割ったもの）を用いる。これは導出ではなく、測定値への当てはめである。

粗度係数 n は経験的で、植生や河床の不規則性を吸収する。値は目安であり、滑らかなコンクリートで約0.012–0.015、土水路で0.020–0.030、植生のある河川ではより大きい。1/n の形はSI単位系にのみ適用される。

Manning流速
\[V = \frac{1}{n} R^{2/3} S^{1/2}\]
SI単位系；Rはメートル、Sは勾配

03比エネルギーと限界水深

比エネルギーは水路床に対する水の水頭であり、E = y + V²/(2g) である。単位幅流量 q が一定のとき、E–y 曲線は最小値を持つ放物線となり、そのエネルギーより上の任意のエネルギーに対して2つの可能な水深——交代水深——が存在する。最小値が限界水深であり、Fr = 1 のときである。

Fr < 1 のとき流れは常流（下流から制御される）、Fr > 1 のとき射流（上流から制御される）である。堰などの制御は水深を限界水深に強制し、上流側の水面形を固定する。

比エネルギー
\[E = y + \frac{V^2}{2g}\]
yは水深、Vは平均流速
限界水深（矩形断面）
\[y_c = \left(\frac{q^2}{g}\right)^{1/3}\]
qは単位幅流量
Froude数
\[\mathrm{Fr} = \frac{V}{\sqrt{gD}}\]
Dは水力水深、A/T

04跳水

射流が障害物や下流水深の上昇に遭遇すると、短い乱流遷移を経て常流へと跳水する。水深は上昇し、流速は低下し、運動エネルギーの多くが熱として散逸する——これが、下流の河床を保護するために余水吐の下に跳水を設ける理由である。

エネルギー損失は事前にわからないため、水深の変化は運動量から求められる。矩形断面では、共役水深は接近するFroude数の関係式に従い、損失は跳水の強さとともに急激に増大する。振動跳水は不安定であり、設計で避けるべきである。

共役水深
\[\frac{y_2}{y_1} = \frac{1}{2}\left(\sqrt{1 + 8\,\mathrm{Fr}_1^2} - 1\right)\]
矩形断面、接近Froude数 Fr₁

05管路網と摩擦

満水管では損失水頭は2つの部分からなる：長さと流速の二乗に比例する摩擦と、曲がり・弁・継手での形状損失であり、係数 K で表される。Darcy–Weisbachの式が標準形であり、f はMoody線図から求め、Reynolds数と相対粗度 ε/D に依存する。

管路網では各接合点で連続式が成り立ち、各節点で単一の水頭が定まる。並列管路は同じ損失水頭を共有するため、流量は抵抗に反比例して分流する。直列管路は同じ流量を共有し、損失を加算する。大規模な管路網は、水頭が一致するまで流量を調整して反復的に解く。

Darcy–Weisbach損失水頭
\[h_f = f\,\frac{L}{D}\,\frac{V^2}{2g}\]
fはMoody線図から

06不圧帯水層の井戸水理学

不圧帯水層の井戸で揚水すると動水低下円錐が生じる：放射状の流れが井戸に集中し、円錐上でDarcyの法則を積分すると、距離 r₁ と r₂ にある2つの観測井の水位で流量が表される：

Q = π k (h₂² − h₁²) / ln(r₂/r₁),

ここで k は透水係数、h は各井戸での飽和厚である。

したがって揚水試験は、小さな試料ではなく原位置で実規模の k を測定する：一定流量で水位が安定するまで揚水し、h₁ と h₂ を読み取って k を解く。仮定には注意が必要である——水平放射状流れ、均質な帯水層、定常状態——なぜなら実際の低下は平衡に達するまで時間がかかり、成層地盤は均質性を静かに破るからである。同じ式を逆に解けば、井戸の揚水量を決めたり、隣接するボーリング孔での低下を予測したりでき、新たな取水が既存の取水から水を奪う可能性がある場合に重要となる。

不圧帯水層の井戸流量
\[Q = \frac{\pi k\,(h_2^2 - h_1^2)}{\ln(r_2/r_1)}\]
h₁ と h₂ は観測井 r₁ と r₂ での飽和厚

07流域、降雨、損失

水文学は降雨をある地点の流量に変換する。流域はその地点に排水する面積であり、その応答は面積、勾配、土壌、地被、降雨パターンに依存する。時間的に記録された降雨はハイエトグラフであり、流域から流出する流量はハイドログラフである。

雨の一部のみが流出となる。水は遮断され、地表の窪地を満たし、土壌に浸透する。残りが有効降雨である。洪水到達時間は流域の最遠点から出口までの移動時間であり、ハイドログラフがどれだけ早くピークに達しうるかを決める。都市化による舗装はこれを短縮し、ピークを高める。

08合理式

小流域では、合理式は流出係数 C、設計継続時間に対する降雨強度 i、流域面積 A からピーク流量を推定する。係数は土壌、勾配、土地利用をまとめたもので、値は裸地の約0.1から不透水舗装の0.9に及ぶ。

この方法は、流域全体が寄与するのに十分な継続時間の降雨を仮定するため、設計強度は洪水到達時間に対して取られる。ピーク流量のみを与え——ハイドログラフも体積も与えない——C と選択した強度–継続時間–頻度曲線に敏感である。

合理式
\[Q = \frac{C\,i\,A}{3.6}\]
Qはm³/s、iはmm/h、Aはkm²

09単位ハイドログラフ

単位ハイドログラフは、指定継続時間に流域全体へ一様に降った1単位（通常1 mm）の有効降雨によって生じる直接流出ハイドログラフである。仮定は流域が線形に応答することである：降雨が2倍なら流量も2倍となり、畳み込みによって降雨を加算し時間移動できる。

これにより設計ハイドログラフを構築する：記録降雨を有効降雨ブロックに分離し、各ブロックに単位ハイドログラフを適用し、移動した応答を合計する。この方法は基底流量が一定で流域が不変であると仮定する。都市化、貯留、異なる降雨継続時間はいずれもこれを損なう。

有効降雨の畳み込み
\[Q(t) = \sum P(\tau)\,U(t - \tau)\]
Pは有効降雨、Uは単位ハイドログラフ

10再現期間と設計リスク

再現期間 T は、ある規模の事象間の平均間隔であり、スケジュールではない：100年確率の暴風雨は毎年1%の超過確率を持つ。50年の設計寿命では、そのような事象が少なくとも1回起こる確率は約39%である。

設計暴風雨は、選択した継続時間と再現期間に対する強度–継続時間–頻度曲線から得られる。気候変動により、過去の曲線は出発点であり保証ではない。

n年間のリスク
\[R = 1 - \left(1 - \frac{1}{T}\right)^n\]
年超過確率は p = 1/T

Key terms

Froude数
流れの流速と浅水波の速度の比。1未満で常流、1超で射流。
径深
流水断面積を潤辺で割ったもので、Manningの式の長さスケールとして用いられる。
限界水深
比エネルギーが最小となり、Froude数が1に等しくなる水深。
跳水
射流から常流への急激な遷移であり、水深が上昇しエネルギーが散逸する。
洪水到達時間
流域の最遠点から水が出口に到達するまでの移動時間。
単位ハイドログラフ
指定継続時間に流域全体へ一様に降った1単位の有効降雨による直接流出ハイドログラフ。
再現期間
ある規模以上に等しいか超える事象間の平均間隔であり、年超過確率の逆数に等しい。
動水低下円錐
揚水井の周囲で地下水位が漏斗状に低下する領域であり、放射状の流れが集中する。
Chezy係数
Chezy式における粗度依存の流速係数であり、Manningのnと C = R^(1/6)/n で関係づけられる。
Worked example

矩形断面の等流

幅3.0 mの矩形断面が、河床勾配0.001で水深1.2 mの等流を流れている。Manningのnは0.015である。流量、平均流速、Froude数を求め、流れが常流か射流かを述べよ。

  1. 流水断面積 A = b y = 3.0 × 1.2 = 3.6 m²。潤辺 P = b + 2y = 3.0 + 2.4 = 5.4 m。
  2. 径深 R = A/P = 3.6/5.4 = 0.667 m、よって R^(2/3) = 0.763。
  3. 流速：V = (1/0.015)(0.763)(0.001^(1/2)) = (66.67)(0.763)(0.0316) = 1.61 m/s。
  4. 流量：Q = A V = 3.6 × 1.61 = 5.79 m³/s。
  5. 水力水深 D = A/T = 3.6/3.0 = 1.2 m、よって Fr = V/√(gD) = 1.61/√(9.81 × 1.2) = 1.61/3.43 = 0.47。
  6. 検算：q = 5.79/3.0 = 1.93 m²/s より y_c = (1.93²/9.81)^(1/3) = 0.724 m。実際の水深1.2 mは限界水深より上であり、常流と整合する。
AnswerQ ≈ 5.79 m³/s、V ≈ 1.61 m/s、Fr ≈ 0.47 であり、流れは常流である。水深は限界水深0.72 mを十分に上回り、区間は緩勾配にある。

Exam method

  • Manningの式を書くときはRとSの横に単位を添える；1/nの形はSI単位系のみ。
  • まず流れを分類する：Froude数と区間が等流か不等流かで適用する式が決まる。
  • ピーク流量法とハイドログラフ法を混同しない：合理式はピークを与え、単位ハイドログラフは形状を与える。
  • 再現期間は確率として扱う；Tだけでなく設計寿命におけるリスクを述べる。
  • 管路流れでは、損失水頭の計算の前にまず流動状態を特定する——層流は f = 64/Re、乱流はMoody線図が必要。
