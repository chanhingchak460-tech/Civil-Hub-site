水在流向大海的途中：明渠中的均勻流與非均勻流、Manning 方程、比能與水躍，然後是管道損失、降雨—徑流鏈、合理化方法與重現期。

進度只儲存在此瀏覽器。

01水的兩種流動方式

明渠流具有自由表面，處於大氣壓力下；由重力驅動，水深可升可降。管道流為滿管流動，由壓力梯度驅動，斷面固定。明渠水深由河床坡度和下游控制決定；滿管的水頭損失則由流量和粗糙度決定。

當水深、面積和流速沿河段不變時，流動為均勻流——即重力與摩擦之間的平衡。漸變流變化緩慢，如水壩後方；急變流在數個水深的距離內發生變化，如水躍處。

02Manning 方程

Manning 方程根據渠道幾何、河床坡度和粗糙係數估算平均流速。它採用水力半徑 R = A/P——面積除以濕周——因為摩擦沿濕周發生。它並非推導而來，而是對實測數據的擬合。

粗糙係數 n 為經驗值，涵蓋植被和河床不規則性。數值僅供參考：光滑混凝土約 0.012–0.015，土渠 0.020–0.030，植被河道更高。1/n 形式僅適用於 SI 單位。

Manning 流速
\[V = \frac{1}{n} R^{2/3} S^{1/2}\]
SI 單位；R 以米計，S 為坡度

03比能與臨界水深

比能是水相對於渠底的總水頭：E = y + V²/(2g)。在單位寬度流量 q 固定時，E–y 曲線為一條有最小值的拋物線，對於任何高於該最小值的能量，都有兩個可能的水深——即交替水深。最小值即臨界水深，此時 Fr = 1。

當 Fr < 1 時流動為緩流（由下游控制），當 Fr > 1 時為急流（由上游控制）。控制（如水壩）迫使水深達到臨界值，並固定上游的水面線。

比能
\[E = y + \frac{V^2}{2g}\]
y 為水深，V 為平均流速
矩形渠道臨界水深
\[y_c = \left(\frac{q^2}{g}\right)^{1/3}\]
q 為單位寬度流量
Froude 數
\[\mathrm{Fr} = \frac{V}{\sqrt{gD}}\]
D 為水力水深，A/T

04水躍

當急流遇到障礙物或尾水上升時，會在短暫的湍流過渡段內躍變為緩流。水深上升，流速下降，大部分動能作為熱量耗散——這就是為何在溢洪道下方設置水躍以保護下游河床。

水深變化由動量方程求得，因為能量損失無法預先得知。對於矩形渠道，共軛水深遵循與來流 Froude 數相關的關係式，損失隨水躍強度急劇增加。振盪水躍不穩定，應在設計中避免。

共軛水深
\[\frac{y_2}{y_1} = \frac{1}{2}\left(\sqrt{1 + 8\,\mathrm{Fr}_1^2} - 1\right)\]
矩形渠道，來流 Froude 數 Fr₁

05管網與摩擦

在滿管中，水頭損失有兩部分：摩擦，與長度和流速平方成正比；以及彎頭、閥門和管件處的局部損失，以係數 K 表示。Darcy–Weisbach 方程為標準形式；f 由 Moody 圖查得，取決於雷諾數和相對粗糙度 ε/D。

管網在每個節點增加連續性方程，並在每個節點設定單一水頭。並聯管道共享相同的水頭損失，因此流量按阻力反比分配；串聯管道共享相同流量，損失相加。大型管網通過調整流量直至水頭閉合來迭代求解。

Darcy–Weisbach 水頭損失
\[h_f = f\,\frac{L}{D}\,\frac{V^2}{2g}\]
f 由 Moody 圖查得

06無壓含水層中的井水力學

在無壓含水層中抽水會形成降落漏斗：徑向流匯聚於井，對漏斗積分 Darcy 定律可得流量與兩個觀測井（距離 r₁ 和 r₂）水位之間的關係：

Q = π k (h₂² − h₁²) / ln(r₂/r₁)，

其中 k 為滲透係數，h 為各井處的飽和厚度。

因此，抽水試驗可在現場全尺度測量 k，而非在小樣本中測量：以恆定流量抽水直至水位穩定，讀取 h₁ 和 h₂，求解 k。其假設值得重視——水平徑向流、均質含水層、穩定條件——因為實際降深需要時間才能達到平衡，而層狀地層會悄然違反均質性假設。同一方程反解，可確定井的產水量或預測鄰近鑽孔處的降深，這在新增取水可能搶奪現有井水時尤為重要。

無壓含水層井流量
\[Q = \frac{\pi k\,(h_2^2 - h_1^2)}{\ln(r_2/r_1)}\]
h₁ 和 h₂ 為觀測井 r₁ 和 r₂ 處的飽和厚度

07集水區、降雨與損失

水文學將降雨轉化為某點的流量。集水區是匯流至該點的區域；其響應取決於面積、坡度、土壤、土地覆蓋和暴雨模式。隨時間記錄的降雨為雨量歷線；離開集水區的流量為流量歷線。

只有部分降雨變成徑流。水被截留、填充地表窪地並下滲入土壤；其餘為有效降雨。集流時間是從集水區最遠點到出口的旅行時間，它決定流量歷線達到洪峰的速度。城市硬化縮短集流時間並提高洪峰。

08合理化方法

對於小集水區，合理化方法根據徑流係數 C、設計歷時的降雨強度 i 和集水區面積 A 估算洪峰流量。該係數綜合了土壤、坡度和土地利用：數值範圍從開闊地面的約 0.1 到不透水鋪面的 0.9。

該方法假設暴雨持續時間足以讓整個集水區貢獻徑流，因此設計強度取集流時間對應的值。它僅給出洪峰流量——沒有流量歷線，沒有體積——且對 C 和所選的強度—歷時—頻率曲線敏感。

合理化方法
\[Q = \frac{C\,i\,A}{3.6}\]
Q 以 m³/s 計，i 以 mm/h 計，A 以 km² 計

09單位歷線

單位歷線是由一單位有效降雨——通常為 1 mm——在指定歷時內均勻降落在集水區上所產生的直接徑流歷線。其假設是集水區響應為線性：兩倍降雨產生兩倍流量，暴雨可通過卷積疊加並在時間上平移。

這可構建設計流量歷線：將記錄的暴雨分離為有效降雨塊，對每塊應用單位歷線，並將平移後的響應相加。該方法假設基流恆定且集水區不變；城市化、蓄水或不同的暴雨歷時都會破壞這一假設。

有效降雨卷積
\[Q(t) = \sum P(\tau)\,U(t - \tau)\]
P 為有效降雨，U 為單位歷線

10重現期與設計風險

重現期 T 是給定規模事件之間的平均間隔，而非時間表：百年一遇暴雨每年有 1% 的超越概率。在 50 年設計壽命內，此類事件至少發生一次的機率約為 39%。

設計暴雨來自所選歷時和重現期的強度—歷時—頻率曲線；氣候變化使歷史曲線成為起點，而非保證。

n 年內的風險
\[R = 1 - \left(1 - \frac{1}{T}\right)^n\]
年超越概率為 p = 1/T
Manning 粗糙係數參考值（請查閱項目指引）
渠道表面Manning n備註
光滑混凝土0.012–0.015清潔、順直、表面良好
土渠，順直清潔0.020–0.025邊緣有少量植被
礫石河床，天然溪流0.030–0.050強烈取決於河床材料
茂密植被，洪泛平原0.050–0.150範圍寬廣；須現場核實

計算示例

矩形渠道中的均勻流

一條寬 3.0 m 的矩形渠道在坡度為 0.001 的河床上以 1.2 m 的均勻水深輸水。Manning n 為 0.015。求流量、平均流速和 Froude 數，並說明流動為緩流還是急流。

  1. 過流面積 A = b y = 3.0 × 1.2 = 3.6 m²。濕周 P = b + 2y = 3.0 + 2.4 = 5.4 m。
  2. 水力半徑 R = A/P = 3.6/5.4 = 0.667 m，故 R^(2/3) = 0.763。
  3. 流速：V = (1/0.015)(0.763)(0.001^(1/2)) = (66.67)(0.763)(0.0316) = 1.61 m/s。
  4. 流量：Q = A V = 3.6 × 1.61 = 5.79 m³/s。
  5. 水力水深 D = A/T = 3.6/3.0 = 1.2 m，故 Fr = V/√(gD) = 1.61/√(9.81 × 1.2) = 1.61/3.43 = 0.47。
  6. 合理性檢查：q = 5.79/3.0 = 1.93 m²/s 得 y_c = (1.93²/9.81)^(1/3) = 0.724 m。實際水深 1.2 m 高於臨界水深，與緩流一致。
AnswerQ ≈ 5.79 m³/s，V ≈ 1.61 m/s，Fr ≈ 0.47，故流動為緩流。水深明顯高於臨界水深 0.72 m，表明該河段處於緩坡。

應試方法

  • 寫 Manning 方程時在 R 和 S 旁標明單位；1/n 形式僅適用於 SI。
  • 先分類流動：Froude 數以及河段是均勻流還是非均勻流決定適用哪些方程。
  • 將洪峰流量方法與流量歷線方法分開：合理化方法給出洪峰，單位歷線給出形狀。
  • 將重現期視為概率；說明設計壽命內的風險，而不僅僅是 T。
  • 對於管道流，先確定流態——層流用 f = 64/Re，湍流需查 Moody 圖——再進行任何水頭損失計算。

自我測驗

0 / 6 正確

先作答，再查看解釋。錯誤答案比熟悉的一頁更有用。

Q01矩形渠道中的流動 Froude 數為 0.5。以下哪項正確？

解釋Fr 低於 1 表示緩流（靜流），擾動可向上游傳播，因此下游控制（如水壩）決定水深。

Q02在溢洪道下方故意設置水躍的主要目的是：

解釋水躍將快速急流轉化為較慢的緩流，並在到達河床前耗散大部分能量。

Q03合理化方法的主要限制是它：

解釋合理化方法產生洪峰流量，而非流量歷線或徑流體積，其設計強度假設整個集水區貢獻徑流。

Q04重現期為 50 年的暴雨，其年超越概率為：

解釋p = 1/T = 1/50 = 0.02，即任一年為 2%；50 年內至少發生一次的機率約為 64%。

Q05對於層流管道流，Darcy–Weisbach 摩擦因子為：

解釋低於約 Re = 2000 時流動為層流，f = 64/Re 精確成立，與壁面粗糙度無關。

Q06無壓含水層中的抽水試驗使用兩個觀測井。滲透係數與以下哪項成正比？

解釋重排井方程 Q = πk(h₂² − h₁²)/ln(r₂/r₁) 得 k = Q ln(r₂/r₁)/[π(h₂² − h₁²)]。
