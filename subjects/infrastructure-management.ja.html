建設された資産を数十年にわたって有効に使い続けること：台帳、状態評価、劣化、維持管理戦略、リスク、ライフサイクルコスト、そしてデータをまとめるデジタルツール。既に存在するものに適用する工学経済学である。

01資産と台帳

資産とは、サービスを提供する物理的な構成要素である：橋、ポンプ場、管、標識など。その管理は資産台帳から始まる。これは各項目に識別子、位置、属性、状態、重要度、価値、履歴を与える構造化された目録である。

  • 階層が重要である — ネットワーク、施設、構成要素 — なぜなら意思決定は異なるレベルで行われるからである。
  • 台帳は最新である場合にのみ有用であるため、所有権と更新ルールはソフトウェアよりも重要である。

02状態評価

状態は点検によって判断される：日常的な目視確認、詳細点検、損傷後の特別調査。点検者は定義された尺度（例えば1から5）に対して損傷を記録し、写真と測定値を添える。評価は全員が同じ定義を適用して初めて意味を持つ。

  • 非破壊試験 — かぶり厚測定器、半電池電位、超音波厚さ測定 — は構造物を開かずに証拠を追加する。
  • サンプリングは避けられないため、結果は事実ではなく信頼区間を持つ推定値である。

03劣化

資産はさまざまな形で劣化する。腐食、疲労、摩耗、沈下、風化はすべて、経年、荷重、環境、維持管理履歴に依存するため、同一の構成要素でも大きく異なる経年変化を示すことがある。

  • 劣化モデルは確率的である：マルコフモデルは、ある期間にある状態から別の状態へ移行する確率を与える。
  • 生存曲線は、各年齢でまだ使用可能な割合を表す。
  • モデルは時期の決定を支援するが、その良し悪しは背後にある点検データ次第である。
マルコフ状態遷移
\[C_{t+1} = C_t P\]
Cは状態間の分布、Pは点検記録から推定される遷移確率行列である

04信頼性、可用性、故障率

信頼性は、資産が故障するまでどれだけ機能するかを問う。設備群では、平均故障間隔は総稼働時間を故障回数で割ったものであり、その逆数が故障率である。可用性は信頼性と修理性を平均修復時間を通じて組み合わせる：故障は稀だが修理に数か月かかる資産は、頻繁に故障するが数時間で修理される資産よりも可用性が低くなり得る。

  • 直列の構成要素は可用性を乗算する：それぞれ99%の10個のリンクは、せいぜい約90%の可用性である — 並列冗長が追加のナインを買う。
  • MTBFはその維持管理の文脈とともに示すべきである。なぜなら設計変更や先送りされた保守は、機器自体よりもMTBFを大きく動かすからである。
平均故障間隔
\[\mathrm{MTBF} = \frac{\text{operating time}}{\text{failures}}\]
設備群の指標：総稼働時間を故障回数で割ったもの
故障率
\[\lambda = \frac{1}{\mathrm{MTBF}}\]
単位時間あたりの故障回数；MTBFの逆数
可用性
\[A = \frac{\mathrm{MTBF}}{\mathrm{MTBF} + \mathrm{MTTR}}\]
MTTRは平均修復時間；両方を同じ単位で表すこと
直列可用性
\[A = A_1 A_2 \cdots A_n\]
依存するリンクの連鎖は可用性を乗算するため、長い連鎖には冗長性が必要である

05維持管理戦略

維持管理は事後対応（壊れたら直す）から計画予防（暦に従って保守）、状態基準（点検が閾値を示したら行動）、予測（データが故障の接近を示したら行動）まで幅がある。資産に対する選択肢は通常、何もしない、修理、補修、更新である。

  • 事後対応の作業は、故障が道路や水道本管を閉鎖するまでは安価である。
  • 予防作業は予測可能だが、健全な部品を交換する可能性がある。
  • 状態基準の作業には信頼できるモニタリングが必要である。
維持管理戦略とそのトレードオフ
戦略トリガー強み弱み
事後対応故障が発生した計画コストが最も低い計画外の混乱と安全リスク
予防暦または使用間隔予測可能で単純健全な構成要素を交換する可能性
状態基準点検またはセンサーの閾値証拠に基づいて行動信頼できるモニタリングが必要
予測故障接近の予測理論上最良のタイミングデータを大量に必要とする；モデルリスク

06サービス水準と性能測定

資産はサービス水準を提供するために資金供給されるため、管理には資産ではなくサービスを記述する指標が必要である。道路なら：旅行時間、平坦性、通行止め；水なら：圧力、断水、対応時間。性能指標は生データを比較可能な数値に変え、目標はそれを意思決定に変える。

  • 顧客損失分は事故に継続時間と影響顧客数を掛ける。
  • バックログは状態目標を下回るネットワークの割合である。
  • 指標は今年の数値だけでなく傾向とともに報告すること — ネットワークは今四半期は問題なく見えても、バックログが静かに積み上がっていることがある。
顧客損失分
\[\mathrm{CML} = n \times d \times c\]
混乱を規模と長さで重み付けする；サービス目標と比較する

07リスクと優先順位付け

資金は常に不足しているため、作業はリスクによって優先順位付けされる。リスク = 発生可能性 × 影響度であり、発生可能性は状態と劣化から、影響度は安全、サービス混乱、コスト、環境、評判で測られる。

  • リスクマトリクスは資産を帯域に分類する。
  • 重要度ランキングは、故障が最も重要となる構成要素を保護する。
  • レジリエンスはネットワークの視点を加える：単一の管は単独では低リスクでも、病院への唯一の供給経路であることがある。
リスクスコア
\[R = L \times C\]
乗算する前に、定義された尺度で発生可能性と影響度を評価する

08多基準意思決定分析

リスクで資産をランク付けすることは何を直すかに答えるが、常に何を建設するかに答えるわけではない：選択肢はしばしばコスト、安全、環境、混乱、公共の選好で同時に異なる。多基準分析は各選択肢を重み付き基準で評価し、スコア×重みを合計して1つの比較可能な数値にする。重みはスコアが判明する前に合意されるため、作業が誘導されることはない。

  • 便益費用比は同じ論理を経済学に折り込む：便益を費用で割ったもので、便益には節約時間、回避事故、削減排出が含まれ、明示的に評価される。
  • どちらの方法も客観的ではなく透明である — 価値は明示された重みと評価にあり、常にそれらを示し、動かしたときにランキングがどう変わるかを検証すべきである。
重み付きスコア
\[S = \sum w_i s_i\]
重みの合計は1；重み付けの前にすべての選択肢をすべての基準で評価する
便益費用比
\[\mathrm{BCR} = \frac{\mathrm{PV}_{\mathrm{benefits}}}{\mathrm{PV}_{\mathrm{costs}}}\]
両方の流列を現在価値に割り引く；1を超える比率は経済的テストに合格する

09ライフサイクルコスト

ライフサイクルコスト計算は、資本価格だけでなく資産の寿命にわたって選択肢を比較する：建設、運用、維持管理、更新、処分を現在価値に割り引く。正味現在価値は将来コストを選択された割引率で変換する。

  • 選択肢の寿命が異なる場合、等価年費用がそれらを共通の年次基準に置く。
  • 割引率は政策選択であり、長期の結果を支配するため、答えを正確なものとして扱うのではなく感度を検証すべきである。
正味現在価値
\[\mathrm{NPV} = \sum \frac{C_t}{(1 + i)^t}\]
C_tは年tの正味コスト、iは割引率である
等価年費用
\[\mathrm{EUAC} = P (A/P, i, n) - S (A/F, i, n) + A\]
Pは資本、Sは残存価値、(A/P)は資本回収係数、(A/F)は減債基金係数

10更新時期とバスタブ曲線

ほとんどの資産はバスタブ曲線に従う：初期故障の早期期間、低くほぼ一定の故障率での長い有効寿命、そして故障率が上昇する摩耗期間。

  • 保証期間内に初期欠陥を修正し、平坦な中間期を通じて監視し、摩耗が故障を頻繁にし修理を高価にする前に更新する。
  • 最適な更新点は、資産を保持する年換算コストが交換する年換算コストを上回る点である — 同じ等価年費用の計算を、資産の経年に応じて再実行する。
  • 早期更新は残存寿命を浪費し、遅延更新は計画外停止で支払うため、時期の決定は感傷的ではなく経済的である。
割引率が答えを左右する 長期の比較は割引率が変わると逆転することがある。選択肢を推奨する前に、より低い率とより高い率で計算を繰り返すこと。

11BIM、GIS、デジタル資産

GISはどこにを答える：位置、ネットワーク接続性、集水域、近接性。BIMは何をを答える：形状、構成要素、特性、関係。両者は台帳を、照会、シミュレーション、更新が可能なデジタルモデルへと運ぶ。

  • 資産情報は実用完了時に引き渡されるべきであり、数年後に再構築されるべきではない。だからこそ情報要件は早期に指定される。
  • 難しい部分はモデルではなく、相互運用性、データ所有権、そしてツインを最新に保つことである。

Key terms

資産台帳
各資産の識別子、位置、属性、状態、重要度、履歴を記録する構造化された目録。
状態評価
観察された劣化の深刻度を記録する、定義された尺度上のスコア。尺度が一貫して適用されて初めて比較可能となる。
重要度
資産の故障がどれほど重要かを、影響度と故障の発生可能性を組み合わせてランク付けしたもの。
ライフサイクルコスト
建設から運用、更新、処分までの資産の総割引コスト。
等価年費用
資本費と運用費を均等な年額に変換し、異なる寿命の選択肢を比較できるようにしたもの。
マルコフ劣化モデル
遷移確率に従って状態が時間とともに移行することを表す確率的モデル。
可用性
資産がサービスを実行できる時間の割合であり、故障頻度と修復時間を組み合わせたもの。
サービス水準
資産ネットワークが提供すべきサービスを、目標を持つ測定可能な指標で表現した定義済みの記述。
Worked example

年費用による2つの更新選択肢の比較

2つのポンプ選択肢が同じサービスを提供する。選択肢Aは設置に1,200,000、寿命8年、残存価値100,000、年間維持費20,000を要する。選択肢Bは800,000、寿命5年、残存価値60,000、年間維持費35,000を要する。割引率6%を用いた場合、どちらの選択肢が等価年費用が低いか？

  1. 選択肢Aについて、資本回収係数(A/P, 6%, 8) = 0.1610、減債基金係数(A/F, 6%, 8) = 0.1010である。
  2. Aの資本と残存価値を年換算する：1,200,000 × 0.1610 − 100,000 × 0.1010 = 193,200 − 10,100 = 183,100。
  3. 年間維持費を加える：EUAC_A = 183,100 + 20,000 = 年間203,100。
  4. 選択肢Bについて、(A/P, 6%, 5) = 0.2374、(A/F, 6%, 5) = 0.1774であるため、800,000 × 0.2374 − 60,000 × 0.1774 = 189,920 − 10,644 = 179,276。
  5. 維持費を加える：EUAC_B = 179,276 + 35,000 = 年間214,300で、選択肢Aより約11,200高い。
Answer選択肢Aは資本価格が高いにもかかわらず、寿命が長く維持費が低いため、等価年費用が低く、約203,100対214,300である。ランキングが変わり得るため、この結論は他の割引率でも検証すべきである。

Exam method

  • 経済比較の問題では、何かを比較する前にすべての選択肢を同じ基準 — 現在価値または年費用 — に変換すること。
  • リスクをランク付けする際は影響度のカテゴリを述べること。理由のない単なる「高リスク」というラベルはほとんど評価されない。
  • 劣化の問題では、モデルの仮定、特に遷移確率と点検間隔を明示すること。
  • 可用性の問題では単位を混ぜないこと：割る前にMTBFとMTTRを同じ単位で表し、答えを時間の割合として示すこと。
