讓已建成的資產在數十年間保持有用：資產登記冊、狀況評估、劣化、維修策略、風險、全生命周期成本，以及把數據整合在一起的數碼工具。這是應用於已存在事物的工程經濟學。

進度只儲存在此瀏覽器。

01資產與登記冊

資產是提供服務的實體組成部分：橋樑、泵站、管道、標誌。管理資產始於資產登記冊，這是一份結構化的清單，為每個項目賦予識別碼、位置、屬性、狀況、關鍵性、價值和歷史。

  • 層級很重要——網絡、設施、組件——因為決策在不同層級作出。
  • 登記冊只有在保持最新時才有用，因此擁有權和更新規則比軟件更重要。

02狀況評估

狀況透過檢查判斷：例行目視檢查、詳細檢查，以及損壞後的特別調查。檢查員按既定尺度（例如 1 至 5）記錄缺陷，並附上照片和量度；只有當所有人採用相同定義時，評級才有意義。

  • 無損檢測——鋼筋探測儀、半電池電位、超聲波測厚——可在不打開結構的情況下提供證據。
  • 抽樣不可避免，因此結果是帶有置信範圍的估計，而非事實。

03劣化

資產以不同方式衰退。腐蝕、疲勞、磨損、沉降和風化都取決於齡期、荷載、環境和維修歷史，因此兩個相同的組件可以以非常不同的方式老化。

  • 劣化模型是概率性的：馬爾可夫模型給出在一段時間內從一個狀況狀態轉移到另一個狀況狀態的概率。
  • 存活曲線描述在每個齡期仍可使用的比例。
  • 模型支持時間安排決策，但其質素取決於背後的檢查數據。
馬爾可夫狀況轉移
\[C_{t+1} = C_t P\]
C 是狀況狀態上的分佈，P 是轉移概率矩陣，由檢查記錄估計

04可靠性、可用性和故障率

可靠性問的是資產在故障前能工作多久。對於一個機隊，平均故障間隔時間是總運行時間除以故障次數，其倒數是故障率。可用性透過平均修復時間把可靠性和可修復性結合起來：一個很少故障但需要數月修復的資產，其可用性可能低於一個經常故障但數小時內修復的資產。

  • 串聯組件的可用性相乘：十個各 99% 的環節最多約 90% 可用——並聯冗餘換取額外的九。
  • 引用 MTBF 時要說明其維修背景，因為設計變更或延遲保養對它的影響比設備本身更大。
平均故障間隔時間
\[\mathrm{MTBF} = \frac{\text{operating time}}{\text{failures}}\]
機隊指標：總運行小時除以故障次數
故障率
\[\lambda = \frac{1}{\mathrm{MTBF}}\]
每單位時間的故障次數；MTBF 的倒數
可用性
\[A = \frac{\mathrm{MTBF}}{\mathrm{MTBF} + \mathrm{MTTR}}\]
MTTR 是平均修復時間；兩者須以相同單位表示
串聯可用性
\[A = A_1 A_2 \cdots A_n\]
一串相依環節的可用性相乘，因此長鏈需要冗餘

05維修策略

維修從事後維修（壞了才修）到計劃預防（按日曆保養）、狀態為本（檢查顯示達到閾值時才行動），再到預測性（數據顯示故障臨近時才行動）。資產的選項通常是甚麼都不做、修理、修復或更換。

  • 事後維修成本低，直到一次故障封閉道路或爆水管。
  • 預防維修可預測，但可能更換健康的部件。
  • 狀態為本的維修需要可靠的監測。
維修策略及其取捨
策略觸發條件優點缺點
事後維修故障已發生計劃成本最低非計劃中斷和安全風險
預防維修日曆或使用間隔可預測且簡單可能更換健康組件
狀態為本檢查或傳感器閾值基於證據行動需要可靠監測
預測性預測故障臨近理論上時機最佳需要大量數據；模型風險

06服務水平和績效衡量

資產獲得撥款是為了提供服務水平，因此管理需要描述服務而非資產的指標。對於道路：行車時間、平整度和封閉次數；對於供水：水壓、中斷和響應時間。績效指標把原始數據轉化為可比較的數字，而目標則把它轉化為決策。

  • 客戶損失分鐘把事故次數乘以持續時間和受影響客戶數。
  • 積壓是低於狀況目標的網絡比例。
  • 報告指標時要連同趨勢，而不只是今年的數字——網絡本季可能看似良好，而積壓卻在悄悄累積。
客戶損失分鐘
\[\mathrm{CML} = n \times d \times c\]
按規模和時長加權中斷；與服務目標比較

07風險與優先排序

資金總是短缺，因此工作按風險排序。風險 = 可能性 × 後果，可能性由狀況和劣化提供依據，後果以安全、服務中斷、成本、環境和聲譽衡量。

  • 風險矩陣把資產分為不同等級。
  • 關鍵性排名保護那些故障影響最大的組件。
  • 韌性加入網絡視角：單一管道單獨來看可能風險低，但可能是醫院的唯一供應路線。
風險評分
\[R = L \times C\]
相乘前先按既定尺度評分可能性和後果

08多準則決策分析

按風險排列資產回答的是修甚麼，但不總是建甚麼：選項往往同時在成本、安全、環境、中斷和公眾偏好上有所不同。多準則分析按加權準則為每個選項評分，把分數乘以權重求和成一個可比較的數字，權重在分數已知之前商定，以免過程被操縱。

  • 效益成本比把同樣的邏輯納入經濟學：效益除以成本，其中效益包括節省的時間、避免的事故和減少的排放，並明確估值。
  • 兩種方法都是透明而非客觀——價值在於所陳述的權重和估值，因此總要展示它們，並測試當它們變動時排名如何變化。
加權分數
\[S = \sum w_i s_i\]
權重之和為 1；加權前先為每個選項在每項準則上評分
效益成本比
\[\mathrm{BCR} = \frac{\mathrm{PV}_{\mathrm{benefits}}}{\mathrm{PV}_{\mathrm{costs}}}\]
兩股現金流均折現至現值；比率大於 1 通過經濟測試

09全生命周期成本

全生命周期成本在資產壽命期內比較選項，而不只是資本價格：建造、運營、維修、更新和處置，折現至現值。淨現值按選定的折現率把未來成本換算。

  • 當選項壽命不同時，等額年成本把它們放在共同的年度基礎上。
  • 折現率是政策選擇，主導長期結果，因此要測試其敏感性，而不是把答案當作精確值。
淨現值
\[\mathrm{NPV} = \sum \frac{C_t}{(1 + i)^t}\]
C_t 是第 t 年的淨成本，i 是折現率
等額年成本
\[\mathrm{EUAC} = P (A/P, i, n) - S (A/F, i, n) + A\]
P 資本，S 殘值，(A/P) 資本回收因子，(A/F) 償債基金因子

10更新時機與浴缸曲線

大多數資產遵循浴缸曲線：早期是嬰兒故障期，然後是漫長的使用壽命期，故障率低且大致恆定，最後是損耗期，故障率攀升。

  • 在保養期內及早修復缺陷，在平穩的中段監測，並在損耗使故障頻繁和維修昂貴之前更新。
  • 最佳更新點是保持資產的年化成本超過更換的年化成本之處——同樣的等額年成本計算，隨資產老化重新運行。
  • 過早更新浪費剩餘壽命；過晚更新則以非計劃停機付出代價，因此時機決策是經濟性的，而非感情用事。
折現率主導答案 當折現率改變時，長期比較可能翻轉。在推薦選項之前，以較低和較高的折現率重複計算。

11BIM、GIS 與數碼資產

GIS 回答在哪裡：位置、網絡連通性、集水區和鄰近程度。BIM 回答是甚麼：幾何、組件、屬性和關係。兩者結合把登記冊帶入一個可查詢、模擬和更新的數碼模型。

  • 資產資訊應在實際竣工時移交，而不是多年後重建，這就是為何資訊要求要及早指定。
  • 困難的部分不是模型，而是互操作性、數據擁有權和保持孿生模型最新。

關鍵詞

資產登記冊
一份結構化清單，記錄每項資產的識別碼、位置、屬性、狀況、關鍵性和歷史。
狀況評級
按既定尺度記錄觀察到的劣化嚴重程度的評分，只有在尺度一致應用時才可比較。
關鍵性
資產故障影響程度的排名，結合後果與故障可能性。
全生命周期成本
資產從建造、運營、更新到處置的總折現成本。
等額年成本
把資本和運營成本換算為相等的年度金額，使壽命不同的選項可以比較。
馬爾可夫劣化模型
一種概率模型，狀況按轉移概率隨時間在狀態之間移動。
可用性
資產能夠執行其服務的時間比例，結合故障頻率和修復時間。
服務水平
對資產網絡必須提供的服務的明確陳述，以可量度的指標和目標表達。
計算示例

按年度成本比較兩個更新選項

兩個泵送選項提供相同的服務。選項 A 安裝成本 1,200,000，壽命 8 年，殘值 100,000，每年維修費 20,000。選項 B 成本 800,000，壽命 5 年，殘值 60,000，每年維修費 35,000。採用 6% 折現率，哪個選項的等額年成本較低？

  1. 對於選項 A，資本回收因子 (A/P, 6%, 8) = 0.1610，償債基金因子 (A/F, 6%, 8) = 0.1010。
  2. 把 A 的資本和殘值年化：1,200,000 × 0.1610 − 100,000 × 0.1010 = 193,200 − 10,100 = 183,100。
  3. 加上年度維修費：EUAC_A = 183,100 + 20,000 = 每年 203,100。
  4. 對於選項 B，(A/P, 6%, 5) = 0.2374，(A/F, 6%, 5) = 0.1774，所以 800,000 × 0.2374 − 60,000 × 0.1774 = 189,920 − 10,644 = 179,276。
  5. 加上維修費：EUAC_B = 179,276 + 35,000 = 每年 214,300，比選項 A 多約 11,200。
Answer選項 A 的等額年成本較低，約 203,100 對 214,300，儘管其資本價格較高，因為它壽命更長且維修成本更低。結論應在其他折現率下測試，因為排名可能改變。

應試方法

  • 在經濟比較題中，比較任何東西之前，先把每個選項換算到相同基礎——現值或年度成本。
  • 排列風險時要說明後果類別；沒有理由的「高風險」標籤得分很少。
  • 對於劣化問題，要說出模型的假設，特別是轉移概率和檢查間隔。
  • 對於可用性問題，切勿混合單位：相除前把 MTBF 和 MTTR 以相同單位表示，並把答案表述為時間分數。

先作答，再查看解釋。錯誤答案比熟悉的一頁更有用。

Q01在資產管理中，風險通常評估為：

解釋風險結合故障的可能性和它會造成的傷害程度，通常按既定尺度評分。

Q02狀態為本的維修由甚麼觸發：

解釋狀態為本的工作基於量度到的劣化證據行動，而非時間或故障。

Q03兩個服務壽命不同的更新選項應使用甚麼比較：

解釋把兩個選項年化使它們處於共同的每年基礎上，單憑現值做不到這一點。

Q04GIS 在資產管理中最有用於：

解釋GIS 處理位置和空間關係，而 BIM 處理組件的詳細幾何和屬性。

Q05一項資產的 MTBF 為 900 小時，MTTR 為 100 小時。其可用性為：

解釋A = MTBF / (MTBF + MTTR) = 900 / 1000 = 0.9，因此該資產有 90% 的時間可用。

Q06浴缸曲線的損耗期特徵是：

解釋在平穩的使用壽命中段之後，老化推高故障率，這是更新而非繼續修理的信號。
