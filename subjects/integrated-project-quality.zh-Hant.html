01質量是計劃出來的，不是檢驗出來的

質量管理系統是一套職責、程序和記錄，使質量可重複而非偶然。它運行於一個過程循環：同意要求什麼，計劃如何實現，執行工作，對照規範檢查結果，並對差距採取行動。

  • 質量保證是預防——方法說明、樣板、培訓、供應商評估、設計檢查。
  • 質量控制是檢測——對照驗收標準進行檢驗、測試和測量。
  • 完全依賴控制的項目是在花錢發現自己的錯誤。
  • 質量成本是這種權衡如何變得可見。

02檢驗和測試計劃

檢驗和測試計劃（ITP）為每項活動列出：檢查什麼、依據哪個驗收標準、由誰檢查、以什麼頻率檢查，以及什麼記錄證明其已發生。它在工作開始前編寫，並遵循施工順序，因此兼作質量計劃。

  • 停檢點：檢驗通過並簽字前，工作不能繼續。
  • 見證點：檢驗員被邀請，但工作可以繼續。
    編寫ITP是一項風險練習：對那些晚期發現會代價高昂或不安全的點設置停檢，其餘的設為見證。

03檢驗、測試和不符合項

檢驗跟隨工作：對交付材料進行接收檢驗，施工期間進行過程檢驗，移交前進行最終檢驗。測試可以是破壞性的（立方體、芯樣）或非破壞性的（保護層測厚儀、回彈儀、超聲波、半電池電位），而結果若無方法和抽樣計劃則意義不大。

當某項不合格時，回應是一份不符合報告：
- 控制該項目
- 記錄事實
- 商定處置方式（返工、修復、讓步接受或拒收）
- 找出根本原因
- 關閉糾正措施

將每份報告視為孤立投訴會掩蓋模式；按工種或位置分組才是改進所在。

04七種基本質量工具

七種簡單工具完成了質量工程師所需的大部分分析。

  • 檢查表在事件發生時收集計數。
  • 直方圖顯示測量的分佈。
  • 帕累托圖按頻率排列缺陷原因，以便首先處理關鍵少數。
  • 因果圖通過材料、方法、人員、設備和環境追溯效果。
  • 散點圖檢驗兩個變量是否一起變動。
  • 控制圖隨時間區分普通原因變異和特殊原因。
  • 流程圖繪製過程以便改進。

這些工具成本低廉，因為它們依賴誠實：只有當數據在工作點收集、標註產生它的過程並據此採取行動時，它們才有效。未經分類的缺陷帕累托圖是一幅圖畫，不是一個決策。

七種工具及其各自回答的問題
工具回答的問題
檢查表每個事件發生多少次？
直方圖測量值如何分佈？
帕累托圖哪少數原因產生大部分缺陷？
因果圖什麼可能驅動這個效果？
散點圖兩個變量是否一起變動？
控制圖過程是穩定的還是失控的？
流程圖實際的過程步驟是什麼？

05過程能力和控制限

受控的過程不一定有能力。控制限描述過程在做什麼；規格限描述客戶將接受什麼。將樣本均值對照控制限繪製可揭示漂移和特殊原因，而能力指數將自然變異與公差進行比較。

  • Cp 問的是變異是否適合公差。
  • Cpk 還問過程是否居中。
  • Cp高於1.33而Cpk接近0.6意味著過程一致但瞄準不佳——調整設置，而不是檢驗頻率。

抽樣計劃然後決定為達到所需置信度要測試多少項目，這就是為什麼驗收標準總是將方法與抽樣率配對。

過程能力
\[C_p = \frac{\mathrm{USL} - \mathrm{LSL}}{6\sigma}\]
USL和LSL是規格限，σ是過程標準差
居中能力
\[C_{pk} = \min\left(\frac{\mathrm{USL} - \mu}{3\sigma},\, \frac{\mu - \mathrm{LSL}}{3\sigma}\right)\]
較小的一側起決定作用；居中與變異同樣重要
樣本均值的控制限
\[\bar{x} \pm \frac{3\sigma}{\sqrt{n}}\]
對於大小為n的樣本；超出限的點表明特殊原因

06MiC和DfMA將質量移入工廠

組裝合成建築法（MiC）和為製造與裝配而設計（DfMA）將工作從現場轉移到受控的工廠。模塊到達時已安裝飾面、服務，有時還有配件，因此質量問題改變了形態：重複提高一致性並使檢驗更容易，但設計必須更早凍結，公差必須誠實地累積，模塊與現場結構之間的接口成為新的風險。

質量然後取決於夾具、樣板、工廠檢驗計劃、數字記錄和可追溯性，以及運輸和吊裝期間的保護。在現場，工作是連接、密封和對齊，而這幾項操作承擔了不成比例的風險份額。

07BIM協調和共用數據環境

BIM只有在信息可信時才有用。協調聯合各專業模型，運行碰撞檢測並在接口成為現場爭論之前解決它們；模型還支持工程量、排序和放樣。

信息通過共用數據環境（CDE）交換，具有明確的狀態——進行中工作、共享、已發布和已存檔——以及命名、修訂和狀態代碼。絕不能依據未經授權的模型施工。在移交時，模型成為資產信息模型，因此運營所需的數據必須在開始時請求，而不是在結束時重建。

08BIM數據質量和數字QA/QC

數字QA/QC將模型視為任何其他交付物。

  • 視覺檢查檢查幾何形狀和表達。
  • 完整性檢查確認屬性已定義、合理且唯一。
  • 基於規則的檢查驗證每個商定用途所需的信息是否存在。

命名和狀態代碼使檢查可自動化——未命名的文件無法對照其交付物進行檢查。對於模塊化工作，同樣的紀律跟隨模塊：二維碼標識符、每個停檢點的工廠照片、養護或運輸條件的傳感器讀數，以及鏈接到模型的數字記錄。可追溯性是關鍵：當現場出現缺陷時，記錄應在一次查詢中識別模塊、批次、檢驗員和測試結果，而不是花一周翻檔案。

檢查按計劃運行 模型檢查在每次信息交換前和每個工作期結束時安排，而不是在項目結束時執行一次。

09階段、角色和移交

項目經歷簡介、可行性和設計、招標、施工、調試、移交和運營。每個階段以一個信息交付結束，下一階段依賴於此，這就是為什麼後期變更如此昂貴：它們使已檢查的工作失效。

角色被有意分開：
- 客戶設定要求。
- 項目經理控制時間、成本和協調。
- 設計師編寫規範。
- 承包商計劃和建造。
- 監督或工程監督獨立檢驗。
- 工料測量師控制成本。

移交需要完整的資料包——竣工記錄、測試證書、保修、操作手冊和培訓——而缺陷責任期是劣質工藝作為成本回歸的地方。

10合同、記錄和移交證據

質量義務既存在於合同中，也存在於規範中。誰擁有模型數據及其知識產權，誰可以依賴共享信息，以及當已檢查的交付物結果錯誤時會發生什麼，必須在委任文件中說明，而不是在爭議後才發現。清晰的起草使模型成為協調工具，而不是索賠來源。

記錄是證據：檢驗表、測試證書、交付檢查表和照片應命名、註明日期、鏈接到元素並在移交時可檢索。完整、結構化的記錄包保護雙方，本身就是交付物。在合同沉默的地方，CDE規則和責任矩陣成為事實上的合同——同樣仔細地編寫它們。

11計劃可靠性和日常紀律

質量既是技術問題，也是進度問題。每週計劃列出任務、負責人和日期，前瞻計劃覆蓋未來幾週，每日報告實際完成的工作，形成反饋循環。

計劃完成百分比衡量承諾的工作按計劃完成了多少；低值預示中斷、返工和匆忙收尾。風險以同樣方式管理：記錄、評分、分配負責人、審查。只寫一次從不重新打開的風險登記冊是裝飾。

質量成本
CoQ = prevention + appraisal + failure
計劃完成百分比
\[\mathrm{PPC} = \frac{\text{completed tasks}}{\text{planned tasks}} \times 100\%\]
風險評分
\[\text{risk} = \text{likelihood} \times \text{consequence}\]

關鍵詞

檢驗和測試計劃
一份文件，列出將檢查什麼、依據什麼標準、何時、由誰以及用什麼記錄。
停檢點
檢驗計劃中的一個階段，在文件化檢驗通過之前工作不得繼續。
不符合報告
對不符合規範的工作的正式記錄，包括其處置和糾正措施。
共用數據環境
項目信息的單一商定數字來源，具有受控的狀態和修訂狀態。
DfMA
為製造與裝配而設計：設計組件使其能在工廠製造並在現場高效裝配。
質量成本
預防、評估和失敗的綜合成本，用於判斷項目實際需要多少檢驗。
計劃完成百分比
一段時間內實際按計劃完成的計劃任務份額，用作計劃可靠性的衡量。
帕累托圖
按頻率排列原因的條形圖，用於找出值得首先處理的關鍵少數缺陷。
過程能力指數
比較公差寬度與自然過程變異的比率，Cpk對不良居中進行懲罰。
計算示例

模塊化項目的質量成本

一個有300個模塊的體積模塊化項目，施工預算為9600萬港元。12個模塊在工廠被拒收，並在交付前以每個9,500港元返工。檢驗和測試費用為180,000港元，預防活動如樣板、培訓和工廠審核費用為120,000港元。求質量成本、其佔預算的比例，以及歸因於失敗的比例。

  1. 被拒收的模塊在移交前被發現，因此成本是內部失敗：12 × 9,500港元 = 114,000港元。
  2. 預防加評估 = 120,000港元 + 180,000港元 = 300,000港元。
  3. 質量成本 = 預防 + 評估 + 失敗 = 300,000港元 + 114,000港元 = 414,000港元。
  4. 佔預算比例：414,000 / 96,000,000 = 0.0043，約0.43%。
  5. 失敗份額 = 114,000 / 414,000 = 27.5%，而預防佔總額的29.0%。
  6. 合理性檢查：同樣的缺陷若在移交後發現將是外部失敗，帶來維修、 access和責任成本，因此0.43%是下限而非真正的最壞情況。
Answer質量成本為414,000港元，約佔施工預算的0.43%，其中27.5%是失敗成本。該比率表明，更多的價值可能在於預防，而不是在工廠門口發現拒收品。

應試方法

  • 學習保證與控制之間的區別，並準備為每個給出一個項目示例。
  • 對於ITP問題，始終說明驗收標準和記錄，而不僅僅是活動名稱。
  • 在不符合項問題中，分開控制、處置和根本原因；分數通常按階段分配。
  • 當被問及為什麼預防比維修便宜時，使用質量成本類別，並引用失敗份額。
  • 引用Cp和Cpk時，說明各自衡量什麼：Cp測試變異對公差，Cpk增加居中——高Cp低Cpk意味著移動過程，而不是限值。

自我測驗

0 / 6 正確

先作答，再查看解釋。錯誤答案比熟悉的一頁更有用。

Q01檢驗和測試計劃中停檢點的功能是什麼？

解釋停檢點是一個停止：只有在文件化檢驗驗收後才釋放下一階段。

Q02在建築移交後發現已完成模塊的缺陷。此成本屬於：

解釋由客戶或在服務中發現的失敗是外部失敗，是最昂貴的類別，因為它增加了 access、責任和聲譽成本。

Q03在共用數據環境中，哪個狀態標識授權用於施工的信息？

解釋已發布信息已通過檢查和授權；進行中工作和共享狀態未批准用於施工。

Q04哪種質量風險是模塊化建築最典型的？

解釋工廠重複性控制良好，但模塊之間以及模塊與結構之間的接口將剩餘風險集中在現場。

Q05帕累托圖用於：

解釋帕累托圖從最頻繁到最少排列原因，將努力導向大多數缺陷背後的少數原因。

Q06Cp = 1.5但Cpk = 0.5。該過程最好描述為：

解釋Cp顯示變異輕鬆適合公差，但Cpk揭示過程均值遠離目標，因此居中是問題。
