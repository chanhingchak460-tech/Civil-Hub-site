01モビリティモデルが予測するもの

スマートモビリティはセンサー記録を予測に変える：15分後のリンク速度、カメラ画像中の道路標識のクラス、歩行者が次に進む経路。

最初の判断はタスク種別であり、これがラベル、損失関数、評価を決める。

  • 教師あり学習：各例は特徴ベクトルxと既知のターゲットyの組である。
  • 回帰：数値を予測する。
  • 分類：カテゴリを予測する。
  • 教師なし手法はターゲットなしで構造を見つける。例えば類似した移動のクラスタリングなど。

02回帰：移動に直線を当てはめる

線形モデルはターゲットを入力の重み付き和として予測する：ŷ = w · x + b。学習は予測が観測値に近づくように重みを選び、通常は平均二乗誤差を最小化する。

二乗は大きな外れを最も強く罰する — 速度予測では大きな誤差が最も問題になるため妥当である。

損失は重み空間上の曲面である。勾配降下法は下り坂に進み、方向には微分を、歩幅には学習率を用いる。

線形回帰モデル
\[\hat{y} = \mathbf{w}\cdot\mathbf{x} + b\]
x は特徴、w は重み、b はバイアス
平均二乗誤差
\[\mathrm{MSE} = \frac{1}{n}\sum (y_i - \hat{y}_i)^2\]
n は訓練例の数
勾配降下法の更新
\[w \leftarrow w - \eta \frac{\partial L}{\partial w}\]
η は学習率

03分類、ラベル、データ分割

分類器は各クラスのスコアを出力し、2クラスではシグモイド、多クラスではソフトマックスによって確率に変換される。予測ラベルは最高スコアのものであり、2つのスコアが並ぶ面が決定境界である。

チューニングの前に、モデルが決して見ないテストセットを確保する。自分の訓練行で採点されたモデルは、単に記憶力を確認されているにすぎない。

小規模データセットでは、交差検証がホールドアウトを回転させ、すべての行が一度はテストされるようにする。

04過学習は既定の失敗である

訓練損失は容量が増えるにつれてほぼ常に下がるが、検証損失こそが誠実な信号である。検証損失が底を打ってから上昇する一方で訓練損失が下がり続けるとき、モデルはノイズを当てはめ始めている。

このギャップが過学習であり、パターンに対して単純すぎるモデルは未学習で、どちらの損失も高いままである。

制御手段には以下がある：
- 特徴や層を減らす
- 大きな重みに罰則を与える正則化
- 実効データセットを拡大する拡張
- 検証損失が最小の時点での早期停止

正則化損失
\[L = \mathrm{loss} + \lambda \sum w_i^2\]
λ は罰則の強さを決める

05ニューラルネットワーク：積み重ねた変換

ニューロンは入力の重み付き和を計算し、バイアスを加え、その結果をReLUなどの非線形活性化に通す。層を積み重ねることでネットワークは独自の特徴を構築できる：初期層は単純なパターンを検出し、後の層がそれらを組み合わせる。

誤差逆伝播は連鎖律を適用して各重みが損失にどう影響したかを見つけ、オプティマイザがすべての重みをまとめて更新する。ミニバッチはノイズの多い勾配と引き換えに速度を得て、データを1回通すことがエポックである。

非線形性がなければ、積み重ねた線形層は1つの線形写像に潰れてしまう。

ニューロンの出力
\[a = f(Wx + b)\]
f は ReLU などの非線形活性化関数

06道路標識のための畳み込みネットワーク

カメラ画像はピクセルの格子であり、平坦化すると近傍構造が壊れる。畳み込み層は小さな学習可能なフィルタを画像上でスライドさせ、すべての位置で重みを共有するので、ある隅で学習したエッジ検出器がすべての隅で機能する。プーリングは特徴マップを圧縮し、小さなずれへの許容性を加える。

道路標識データセットはしばしば小さく不均衡なので、転移学習が標準である：
- 大規模な画像コレクションで訓練されたネットワークから始める
- 初期層を凍結する
- 標識クラス用に最終層を再訓練する

拡張 — 回転、明るさ、クロップ — は訓練セットを広げる。

畳み込みの出力サイズ
\[n_{\mathrm{out}} = \frac{n_{\mathrm{in}} - k + 2p}{s} + 1\]
k はフィルタサイズ、p はパディング、s はストライド

07意思決定に合った評価

クラスが不均衡なとき、精度は誤解を招く：まれな一時停止標識を決して予測しない検出器でも95%を記録しうる。

混同行列は誤りの種類を分離し、適合率と再現率はそれらを異なる形で採点する — 適合率は検出のうちどれだけが正しかったかを問い、再現率は実際の標識のうちどれだけが見つかったかを問う。

速度については、データの単位でのMAEと、大きな外れを罰するRMSEを報告する；MAPEは速度がゼロに近いところで爆発する。テストセット、ベースライン、クラスごとの結果を明記すること。

モビリティタスクの指標と、それぞれが隠すもの
指標タスク読み方隠すもの
精度分類正しくラベル付けされた割合まれなクラスが無視されうる
適合率検出検出のうち正しいものの割合見逃した標識は数えられない
再現率検出実際の標識のうち見つけた割合誤検出は数えられない
MAE と RMSE回帰平均誤差、および大きな外れを強調した誤差RMSE は外れ値に支配される
MAPE回帰平均パーセント誤差速度がゼロに近いと不安定

08モビリティデータは個人データである

軌跡は自宅や職場と結びつけられると個人を特定する。公開前に集約し、パイプラインから識別子を除去し、細粒度の位置情報は既定で機微なものとして扱うこと。

訓練データはバイアスも運ぶ：カメラは一部の道路を他よりよくカバーし、ラベルはそこに誰がいたかではなく誰が観測されたかを記録する。取締りのパターンを模倣するよう教えられたモデルはそれを再現する。

データの出所を文書化し、人間をループに残し、展開された予測をドリフトと不平等な誤差について監視すること。平均精度だけを見てはならない。

09物体検出：ボックスとIoU

道路標識を検出するとは、バウンディングボックスとそのクラスを予測することである。2つのボックスが正確に一致することはまれなので、検出は交差比で採点される：共通面積を合計面積で割ったものである。

予測は、正解ボックスとのIoUがしきい値（一般に0.5）を超えるときヒットと数えられる。クラスごとにヒットを数えると平均適合率が得られ、クラス全体の平均が検出器の代表指標となる。

IoUしきい値を併記すること — 0.5で良いスコアの検出器が0.75では崩壊しうるし、安全にとって重要なのは厳しい方のしきい値である。

交差比
\[\mathrm{IoU} = \frac{\mathrm{area}(A \cap B)}{\mathrm{area}(A \cup B)}\]
0から1の間；約0.5を超えると予測は正解と一致する

10軌跡予測のための系列モデル

軌跡は位置の系列であり、過去のステップが特徴である。時間畳み込みネットワークは拡張率を増やした因果畳み込みを用いるので、パラメータの爆発なしに層が履歴の遠くまで見ることができる；トランスフォーマエンコーダは代わりに時間ステップを直接アテンションする。どちらも観測された経路を隠れ状態に写像し、最終層がそれを次の位置に変換する。

データに適した損失で訓練する：単純な平均絶対誤差は頑健であり、Smooth L1損失は大きな誤差ではL1のように、ゼロ付近では二乗誤差のように振る舞い、微調整中に滑らかな勾配を与えつつ外れ値に耐える。

メートル単位のMAEとRMSEで、ホールドアウトしたシーン上で評価する。

Smooth L1 損失
\[L(x) = \begin{cases} 0.5 x^2 & |x| < 1 \\ |x| - 0.5 & \text{otherwise} \end{cases}\]
x は予測誤差；ゼロ付近では二次、遠くでは線形
拡張畳み込み
\[\text{dilation } d: \quad y_t = \sum_k w_k x_{t - dk}\]
d = 1, 2, 4, … で層を積み重ねると受容野が広がる

11事前学習済み検出器の微調整

モビリティデータセットは検出器をゼロから訓練するのに十分な大きさであることはまれなので、標準的な道筋は転移学習である：大規模な一般画像コレクションで事前学習されたバックボーンから始め、その分類ヘッドを新しいクラス用に差し替え、初期層を凍結したままそのヘッドだけを訓練する。凍結層は学習した特徴を保ち、勾配更新を受けない。

ヘッドが収束したら、はるかに小さい学習率で後方のバックボーン層を解凍し、学習したものを壊さずに特徴を適応させる。

拡張 — 水平反転、色ジッター、リサイズ、正規化 — は実効データセットを拡大し、不変性を教える。テスト画像は訓練と同じパイプラインで前処理すること。さもなければモデルは学習したのと異なるデータ分布を見ることになる。

まず凍結、後で解凍 バックボーンを凍結したまま新しいヘッドを訓練し、その後約10分の1の学習率で解凍する；いきなり完全な微調整に飛びつくと有用な特徴を破壊しがちである。

Key terms

教師あり学習
各入力が正しい出力と対になったラベル付き例から写像を学習すること。
過学習
訓練データのノイズにあまりに密着して当てはめ、未見データでの性能が低下すること。
検証セット
訓練から取り分けられ、最終テストの前にモデルの選択肢を比較するために使われるデータ。
畳み込み層
共有された学習可能なフィルタを画像全体に適用し、平行移動に耐性のある特徴を構築する層。
転移学習
大規模データセットで訓練されたモデルを、より小さな関連タスクの出発点として再利用すること。
再現率
実際の陽性ケースのうち、モデルがうまく見つけた割合。
交差比
予測ボックスと正解ボックスの共通面積をそれらの合計で割ったもので、物体検出における標準的な一致尺度。
微調整
事前学習済みモデルを新しい関連データセットで訓練し続けること。しばしば初期層を凍結して行う。
Worked example

ホールドアウトした速度予測での誤差

あるモデルが5つの連続する区間でリンク速度をkm/hで予測する。観測速度は60、55、70、65、80、予測速度は58、58、66、65、74である。MAEとRMSEを求め、常に訓練平均66 km/hを予測するベースラインと両方を比較せよ。

  1. 誤差（観測 − 予測）：2、−3、4、0、6 km/h。
  2. MAE = (2 + 3 + 4 + 0 + 6) / 5 = 15 / 5 = 3.0 km/h。
  3. 二乗誤差：4、9、16、0、36、合計65。RMSE = √(65/5) = √13 ≈ 3.6 km/h。
  4. 66 km/hからのベースライン誤差：−6、−11、4、−1、14、よってそのMAE = 36/5 = 7.2 km/h。
  5. ベースラインRMSE = √((36 + 121 + 16 + 1 + 196)/5) = √74 ≈ 8.6 km/h。
  6. 健全性チェック：モデルは両指標でベースラインを上回り、6 km/hの外れが重く重み付けされるためRMSEはMAEを超える。
AnswerMAE = 3.0 km/h、RMSE ≈ 3.6 km/h、ベースライン値は7.2 km/hと8.6 km/h。このサンプルでは予測はベースラインより良いが、5区間では一般的な改善を主張するには少なすぎる。

Exam method

  • まずタスクを名指しせよ：回帰と分類は異なる損失と異なる指標を必要とする。
  • 各テストセット指標は単位とベースラインとともに報告せよ；精度だけでは問われたことにほとんど答えられない。
  • 不均衡なクラスでは、全体精度ではなく適合率と再現率を挙げよ。
  • 微調整では最初のパスでバックボーンを凍結し、解凍するときに学習率を約10分の1に下げよ。
