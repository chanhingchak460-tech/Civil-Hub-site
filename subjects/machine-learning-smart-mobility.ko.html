01모빌리티 모델이 예측하는 것

스마트 모빌리티는 센서 기록을 예측으로 바꿉니다: 15분 뒤의 링크 속도, 카메라 프레임 속 도로 표지판의 클래스, 보행자가 다음에 지나갈 경로.

첫 번째 결정은 작업 유형이며, 이는 레이블, 손실 함수, 평가 방식을 고정하기 때문입니다.

  • 지도 학습: 모든 예시가 특징 벡터 x와 알려진 목표 y를 짝지어 줍니다.
  • 회귀: 숫자를 예측합니다.
  • 분류: 범주를 예측합니다.
  • 비지도 방법은 목표 없이 구조를 찾습니다. 예를 들어 유사한 통행을 군집화합니다.

02회귀: 이동에 직선을 맞추기

선형 모델은 목표를 입력의 가중 합 ŷ = w · x + b로 예측합니다. 학습은 보통 평균 제곱 오차를 최소화하여 예측이 관측값에 가깝도록 가중치를 선택합니다.

제곱은 큰 오차를 가장 강하게 벌합니다 — 큰 오류가 가장 중요한 속도 예측에 적합합니다.

손실은 가중치 공간의 표면입니다. 경사 하강법은 미분으로 방향을, 학습률로 보폭을 정해 내리막으로 나아갑니다.

선형 회귀 모델
\[\hat{y} = \mathbf{w}\cdot\mathbf{x} + b\]
x는 특징, w는 가중치, b는 편향
평균 제곱 오차
\[\mathrm{MSE} = \frac{1}{n}\sum (y_i - \hat{y}_i)^2\]
n은 학습 예시 수
경사 하강법 갱신
\[w \leftarrow w - \eta \frac{\partial L}{\partial w}\]
η는 학습률

03분류, 레이블, 그리고 분할

분류기는 각 클래스에 점수를 출력하고, 두 클래스에는 시그모이드, 여러 클래스에는 소프트맥스로 확률로 변환합니다. 예측 레이블은 가장 높은 점수이며, 두 점수가 동점인 표면이 결정 경계입니다.

어떤 튜닝 전에도 모델이 절대 보지 않는 테스트 세트를 따로 보관합니다. 자신의 학습 행으로 채점된 모델은 단지 암기 여부만 검사받는 것입니다.

작은 데이터셋에서는 교차 검증이 홀드아웃을 돌려 모든 행이 한 번씩 테스트되게 합니다.

04과적합은 기본 실패 모드

학습 손실은 용량이 커지면 거의 항상 감소합니다; 검증 손실이 정직한 신호입니다. 검증 손실이 바닥을 찍고 다시 상승하는 동안 학습 손실이 계속 감소하면, 모델은 노이즈를 맞추기 시작한 것입니다.

그 간극이 과적합입니다; 패턴에 비해 너무 단순한 모델은 과소적합이며, 두 손실 모두 높게 유지됩니다.

제어 방법은 다음과 같습니다:
- 특징이나 층 줄이기
- 큰 가중치를 벌하는 정규화
- 유효 데이터셋을 키우는 증강
- 검증 최솟값에서의 조기 종료

정규화 손실
\[L = \mathrm{loss} + \lambda \sum w_i^2\]
λ는 벌점의 강도를 정함

05신경망: 쌓인 변환

뉴런은 입력의 가중 합을 계산하고 편향을 더한 뒤, ReLU 같은 비선형 활성화를 통과시킵니다. 층을 쌓으면 네트워크가 스스로 특징을 만듭니다: 초기 층은 단순 패턴을 감지하고, 후기 층은 이를 결합합니다.

역전파는 연쇄 법칙을 적용해 각 가중치가 손실에 얼마나 영향을 주었는지 찾고, 옵티마이저가 모든 가중치를 함께 갱신합니다. 미니 배치는 노이즈 있는 경사와 속도를 맞바꾸며, 데이터를 한 번 통과하는 것이 에포크입니다.

비선형성이 없으면 쌓인 선형 층은 하나의 선형 변환으로 붕괴합니다.

뉴런 출력
\[a = f(Wx + b)\]
f는 ReLU 같은 비선형 활성화

06도로 표지판을 위한 합성곱 신경망

카메라 이미지는 픽셀 격자이며, 이를 평탄화하면 이웃 구조가 파괴됩니다. 합성곱 층은 작은 학습 가능한 필터를 이미지 위로 슬라이드하며 모든 위치에서 가중치를 공유하므로, 한 모서리에서 학습한 에지 검출기가 모든 모서리에서 작동합니다. 풀링은 특징 맵을 압축하고 작은 이동에 대한 내성을 더합니다.

도로 표지판 데이터셋은 종종 작고 불균형하므로 전이 학습이 표준입니다:
- 큰 이미지 모음으로 학습된 네트워크에서 시작
- 초기 층 동결
- 표지판 클래스에 맞게 마지막 층 재학습

증강 — 회전, 밝기, 자르기 — 은 학습 세트를 넓힙니다.

합성곱 출력 크기
\[n_{\mathrm{out}} = \frac{n_{\mathrm{in}} - k + 2p}{s} + 1\]
k는 필터 크기, p는 패딩, s는 스트라이드

07결정에 맞는 평가

클래스가 불균형하면 정확도는 오해를 부릅니다: 드문 양보 표지판을 절대 예측하지 않는 검출기도 여전히 95%를 기록할 수 있습니다.

혼동 행렬은 오류 유형을 분리하고, 정밀도와 재현율은 이를 다르게 채점합니다 — 정밀도는 검출 중 맞은 비율을, 재현율은 실제 표지판 중 찾은 비율을 묻습니다.

속도의 경우 데이터 단위의 MAE와 큰 오차를 벌하는 RMSE를 보고합니다; MAPE는 속도가 0에 가까울 때 폭발합니다. 테스트 세트, 베이스라인, 클래스별 결과를 명시하세요.

모빌리티 작업별 지표와 각 지표가 숨기는 것
지표작업해석숨기는 것
정확도분류레이블이 맞은 비율희귀 클래스가 무시될 수 있음
정밀도검출검출 중 맞은 비율놓친 표지판은 세지 않음
재현율검출실제 표지판 중 찾은 비율오경보는 세지 않음
MAE와 RMSE회귀평균 오차, 그리고 큰 오차를 강조한 오차RMSE는 이상치에 지배됨
MAPE회귀평균 백분율 오차속도가 0에 가까울 때 불안정

08모빌리티 데이터는 개인 데이터

궤적은 집이나 직장과 결합되는 순간 한 사람을 식별합니다. 공개 전에 집계하고, 파이프라인에서 식별자를 제거하며, 세밀한 위치는 기본적으로 민감 정보로 취급하세요.

학습 데이터는 편향도 담습니다: 카메라는 일부 도로를 다른 도로보다 잘 커버하며, 레이블은 거기에 있었던 사람이 아니라 관측된 사람을 기록합니다. 단속 패턴을 모방하도록 학습된 모델은 그 패턴을 재현합니다.

데이터의 출처를 문서화하고, 루프에 사람을 두며, 배포된 예측의 드리프트와 불균등한 오류를 평균 정확도만이 아니라 모니터링하세요.

09객체 검출: 박스와 IoU

도로 표지판을 검출한다는 것은 경계 상자와 그 클래스를 예측하는 것입니다. 두 상자는 정확히 일치하기 어려우므로, 검출은 교집합 대 합집합 비율로 채점합니다: 공유 면적을 합친 면적으로 나눈 값입니다.

예측은 정답 상자와의 IoU가 임계값(흔히 0.5)을 넘으면 적중으로 간주합니다. 클래스별 적중을 세면 평균 정밀도가 되고, 클래스에 대한 평균이 대표 검출기 지표입니다.

IoU 임계값을 함께 보고하세요 — 0.5에서 좋은 점수를 받는 검출기도 0.75에서는 무너질 수 있으며, 안전에는 더 엄격한 임계값이 중요합니다.

교집합 대 합집합 비율
\[\mathrm{IoU} = \frac{\mathrm{area}(A \cap B)}{\mathrm{area}(A \cup B)}\]
0과 1 사이; 약 0.5를 넘으면 예측이 정답과 일치

10궤적 예측을 위한 시퀀스 모델

궤적은 위치의 시퀀스이며, 과거 단계가 특징입니다. 시간 합성곱 신경망은 팽창이 커지는 인과 합성곱을 사용해 파라미터 폭발 없이 한 층이 먼 과거를 볼 수 있게 합니다; 트랜스포머 인코더는 대신 시간 단계 전반에 직접 어텐션합니다. 둘 다 관측된 경로를 은닉 상태로 매핑하고, 마지막 층이 이를 다음 위치로 바꿉니다.

데이터에 맞는 손실로 학습하세요: 단순 평균 절대 오차는 견고하며, Smooth L1 손실은 큰 오차에는 L1처럼, 0 근처에서는 제곱 오차처럼 작동해 미세 조정 중 매끄러운 경사를 주면서 이상치에 저항합니다.

홀드아웃 장면에서 미터 단위의 MAE와 RMSE로 평가하세요.

Smooth L1 손실
\[L(x) = \begin{cases} 0.5 x^2 & |x| < 1 \\ |x| - 0.5 & \text{otherwise} \end{cases}\]
x는 예측 오차; 0 근처에서는 이차, 멀리서는 선형
팽창 합성곱
\[\text{dilation } d: \quad y_t = \sum_k w_k x_{t - dk}\]
d = 1, 2, 4, …로 층을 쌓으면 수용 영역이 넓어짐

11사전 학습된 검출기 미세 조정

모빌리티 데이터셋은 검출기를 처음부터 학습하기에 충분히 큰 경우가 드물어, 표준 경로는 전이 학습입니다: 큰 일반 이미지 모음으로 사전 학습된 백본에서 시작해 분류 헤드를 새 클래스로 교체하고, 초기 층은 동결한 채 그 헤드만 학습합니다. 동결된 층은 학습된 특징을 유지하고 경사 갱신을 받지 않습니다.

헤드가 수렴하면, 훨씬 작은 학습률로 후기 백본 층을 동결 해제해 특징이 학습된 것을 망가뜨리지 않고 적응하게 합니다.

증강 — 수평 뒤집기, 색상 지터, 크기 조정, 정규화 — 은 유효 데이터셋을 확장하고 불변성을 가르칩니다. 테스트 이미지를 학습과 동일한 파이프라인으로 전처리하세요, 그렇지 않으면 모델은 학습한 것과 다른 데이터 분포를 보게 됩니다.

먼저 동결, 나중에 해제 백본을 동결한 채 새 헤드를 학습한 뒤, 약 10배 작은 학습률로 동결을 해제하세요; 곧바로 전체 미세 조정으로 뛰어들면 유용한 특징이 종종 파괴됩니다.

Key terms

지도 학습
각 입력이 올바른 출력과 짝지어진 레이블 예시로부터 매핑을 학습하는 것.
과적합
학습 데이터의 노이즈에 너무 가깝게 맞추어 보지 못한 데이터에서의 성능이 떨어지는 것.
검증 세트
학습에서 떼어 두고 최종 테스트 전에 모델 선택을 비교하는 데 쓰는 데이터.
합성곱 층
이미지 전반에 공유 학습 가능한 필터를 적용해 이동에 강인한 특징을 만드는 층.
전이 학습
큰 데이터셋으로 학습된 모델을 더 작은 관련 작업의 시작점으로 재사용하는 것.
재현율
모델이 성공적으로 찾아낸 실제 양성 사례의 비율.
교집합 대 합집합 비율
예측 상자와 정답 상자의 공유 면적을 합집합으로 나눈 값으로, 객체 검출의 표준 일치 척도.
미세 조정
사전 학습된 모델을 새롭고 관련된 데이터셋에서 계속 학습하는 것, 종종 초기 층을 동결한 채로.
Worked example

홀드아웃 속도 예측에서의 오차

한 모델이 연속된 다섯 구간에서 링크 속도를 km/h로 예측합니다. 관측 속도는 60, 55, 70, 65, 80이고 예측 속도는 58, 58, 66, 65, 74입니다. MAE와 RMSE를 구하고, 항상 학습 평균 66 km/h를 예측하는 베이스라인과 둘 다 비교하세요.

  1. 오차 (관측 − 예측): 2, −3, 4, 0, 6 km/h.
  2. MAE = (2 + 3 + 4 + 0 + 6) / 5 = 15 / 5 = 3.0 km/h.
  3. 제곱 오차: 4, 9, 16, 0, 36으로 합은 65. RMSE = √(65/5) = √13 ≈ 3.6 km/h.
  4. 66 km/h로부터의 베이스라인 오차: −6, −11, 4, −1, 14이므로 MAE = 36/5 = 7.2 km/h.
  5. 베이스라인 RMSE = √((36 + 121 + 16 + 1 + 196)/5) = √74 ≈ 8.6 km/h.
  6. 검증: 모델은 두 지표 모두에서 베이스라인을 이기며, 6 km/h 오차가 크게 가중되므로 RMSE가 MAE보다 큽니다.
AnswerMAE = 3.0 km/h, RMSE ≈ 3.6 km/h이며, 베이스라인 값은 7.2 km/h와 8.6 km/h입니다. 이 표본에서는 예측이 베이스라인보다 낫지만, 다섯 구간은 일반적 개선을 주장하기에 너무 적습니다.
