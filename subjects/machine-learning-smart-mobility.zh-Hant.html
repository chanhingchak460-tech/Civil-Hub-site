從出行數據中學習：用迴歸預測速度、用分類識別路牌，以及必須能泛化的神經網絡。本頁涵蓋訓練循環、誠實的評估，以及位置記錄所帶來的私隱問題。

進度只儲存在此瀏覽器。

01出行模型預測甚麼

智慧出行將感測器記錄轉化為預測：十五分鐘後的路段速度、相機畫面中路牌的類別、行人下一步會走的路徑。

第一個決定是任務類型，因為它決定了標籤、損失函數和評估方式。

  • 監督式學習：每個樣本將特徵向量 x 與已知目標 y 配對。
  • 迴歸：預測一個數值。
  • 分類：預測一個類別。
  • 非監督式方法在沒有目標的情況下尋找結構，例如將相似的行程聚類。

02迴歸：為移動擬合一條直線

線性模型將目標預測為輸入的加權和，ŷ = w · x + b。訓練會選擇使預測值接近觀測值的權重，通常通過最小化均方誤差來實現。

平方會最嚴厲地懲罰大的誤差——這對速度預測是合理的，因為大的誤差影響最大。

損失是權重空間中的一個曲面。梯度下降沿下坡方向邁步，使用導數確定方向，使用學習率確定步長。

線性迴歸模型
\[\hat{y} = \mathbf{w}\cdot\mathbf{x} + b\]
x 為特徵，w 為權重，b 為偏置
均方誤差
\[\mathrm{MSE} = \frac{1}{n}\sum (y_i - \hat{y}_i)^2\]
n 為訓練樣本數
梯度下降更新
\[w \leftarrow w - \eta \frac{\partial L}{\partial w}\]
η 為學習率

03分類、標籤與數據劃分

分類器為每個類別輸出一個分數，對於兩類問題通過 sigmoid 轉換為概率，對於多類問題通過 softmax 轉換。預測標籤是分數最高的類別，兩個分數相等處的曲面即為決策邊界。

在任何調參之前，保留一個模型從未見過的測試集。在自身訓練行上評分的模型只是在檢查記憶能力。

對於小數據集，交叉驗證輪換保留集，使每一行都恰好被測試一次。

04過擬合是默認的失敗模式

隨著容量增長，訓練損失幾乎總會下降；驗證損失才是誠實的信號。當驗證損失觸底然後上升，而訓練損失繼續下降時，模型已開始擬合噪聲。

這種差距就是過擬合；模型對於模式來說過於簡單則是欠擬合，此時兩種損失都保持高位。

控制方法包括：
- 減少特徵或層數
- 懲罰大權重的正則化
- 擴大有效數據集的數據增強
- 在驗證最小值處早停

正則化損失
\[L = \mathrm{loss} + \lambda \sum w_i^2\]
λ 設定懲罰的強度

05神經網絡：堆疊的變換

一個神經元計算其輸入的加權和，加上偏置，並將結果通過非線性激活函數（如 ReLU）。堆疊層讓網絡構建自己的特徵：早期層檢測簡單模式，後期層將它們組合起來。

反向傳播應用鏈式法則來找出每個權重如何影響損失，優化器則一起更新所有權重。小批量以噪聲梯度換取速度，對數據的一次完整遍歷稱為一個epoch。

沒有非線性，堆疊的線性層會坍縮成一個線性映射。

神經元輸出
\[a = f(Wx + b)\]
f 為非線性激活函數，如 ReLU

06用於路牌的卷積網絡

相機圖像是像素的網格，將其展平會破壞鄰域結構。卷積層在圖像上滑動小的可學習濾波器，在每個位置共享權重，因此在一個角落學到的邊緣檢測器在每個角落都有效。池化壓縮特徵圖並增加對小位移的容忍度。

路牌數據集通常小而類別不平衡，因此遷移學習是標準做法：
- 從在大規模圖像集合上訓練的網絡開始
- 凍結早期層
- 為路牌類別重新訓練最終層

數據增強——旋轉、亮度和裁剪——擴大了訓練集。

卷積輸出尺寸
\[n_{\mathrm{out}} = \frac{n_{\mathrm{in}} - k + 2p}{s} + 1\]
k 為濾波器大小，p 為填充，s 為步長

07與決策相匹配的評估

當類別不平衡時，準確率會產生誤導：一個從不預測罕見讓路標誌的檢測器仍可獲得 95% 的分數。

混淆矩陣區分錯誤類型，精確率和召回率以不同方式對它們評分——精確率問有多少檢測是正確的，召回率問找到了多少真實標誌。

對於速度，報告以數據單位表示的 MAE 和懲罰大誤差的 RMSE；MAPE 在接近零速度時會爆炸。說明測試集、基線和每類結果。

出行任務的指標及每個指標所隱藏的信息
指標任務解讀為隱藏
準確率分類正確標籤的比例可能忽略罕見類別
精確率檢測檢測中正確的比例未計入漏掉的標誌
召回率檢測找到的真實標誌比例未計入誤報
MAE 和 RMSE迴歸平均誤差，以及強調大誤差的誤差RMSE 受異常值主導

08出行數據是個人數據

一旦軌跡與家庭或工作地點關聯，就能識別個人。在發布前進行聚合，從流程中移除標識符，並默認將精細位置視為敏感信息。

訓練數據還帶有偏差：相機對某些道路的覆蓋優於其他道路，標籤記錄的是誰被觀察到，而不是誰在那裡。一個被教導模仿執法模式的模型會複製這些模式。

記錄數據的來源，保持人在迴路中，並監控部署後的預測是否存在漂移和不平等誤差，而不僅僅是平均準確率。

09物體檢測：邊界框與 IoU

檢測路牌意味著為其預測一個邊界框和一個類別。兩個框很少完全重合，因此檢測通過交併比評分：共享面積除以合併面積。

當預測與真實框的 IoU 超過閾值（通常為 0.5）時，該預測計為一次命中。按類別計算命中數得到平均精確率，各類別的平均值即為檢測器的主要指標。

在其旁邊報告 IoU 閾值——在 0.5 下得分良好的檢測器在 0.75 下可能崩潰，而更嚴格的閾值對安全至關重要。

交併比
\[\mathrm{IoU} = \frac{\mathrm{area}(A \cap B)}{\mathrm{area}(A \cup B)}\]
介於 0 和 1 之間；約 0.5 以上預測與真實匹配

10用於軌跡預測的序列模型

軌跡是位置的序列，過去的步驟是特徵。時間卷積網絡使用因果卷積和增長的膨脹率，使一層能看到很遠的歷史而不會導致參數爆炸；transformer 編碼器則直接跨時間步進行注意力計算。兩者都將觀察到的路徑映射到一個隱藏狀態，最終層將其轉換為下一個位置。

使用適合數據的損失進行訓練：普通的平均絕對誤差是穩健的，而 Smooth L1 損失在大誤差時表現得像 L1，在接近零時表現得像平方誤差，在微調期間提供平滑梯度同時抵抗異常值。

在保留場景上以米為單位用 MAE 和 RMSE 評估。

Smooth L1 損失
\[L(x) = \begin{cases} 0.5 x^2 & |x| < 1 \\ |x| - 0.5 & \text{otherwise} \end{cases}\]
x 為預測誤差；接近零時為二次，遠離時為線性
膨脹卷積
\[\text{dilation } d: \quad y_t = \sum_k w_k x_{t - dk}\]
堆疊 d = 1, 2, 4, … 的層可擴大感受野

11微調預訓練檢測器

出行數據集很少大到足以從頭訓練檢測器，因此標準路線是遷移學習：從在大規模通用圖像集合上預訓練的主幹網絡開始，將其分類頭替換為新類別，僅訓練該頭部，而早期層保持凍結。凍結層保留其學習到的特徵，不接收梯度更新。

一旦頭部收斂，以更小的學習率解凍後期主幹層，使特徵適應而不破壞已學到的內容。

數據增強——水平翻轉、顏色抖動、調整大小和歸一化——擴展有效數據集並教導不變性。使用與訓練相同的流程預處理測試圖像，否則模型看到的數據分佈與其學習時不同。

先凍結，後解凍 在凍結主幹的情況下訓練新頭部，然後以約小十倍的學習率解凍；直接跳到完全微調通常會破壞有用的特徵。

關鍵詞

監督式學習
從標記樣本中學習映射，每個輸入都與正確輸出配對。
過擬合
過於緊密地擬合訓練數據中的噪聲，導致在未見數據上的性能下降。
驗證集
從訓練中保留的數據，用於在最終測試前比較模型選擇。
卷積層
在圖像上應用共享的可學習濾波器以構建平移容忍特徵的層。
遷移學習
將在大數據集上訓練的模型作為較小相關任務的起點重用。
召回率
模型成功找到的真實正例的比例。
交併比
預測框與真實框之間的共享面積除以它們的並集，是物體檢測中的標準匹配度量。
微調
在新的相關數據集上繼續訓練預訓練模型，通常凍結早期層。
計算示例

保留速度預測的誤差

一個模型在五個連續區間預測路段速度（km/h）。觀測速度為 60、55、70、65 和 80；預測速度為 58、58、66、65 和 74。求 MAE 和 RMSE，並與始終預測訓練均值 66 km/h 的基線進行比較。

  1. 誤差（觀測 − 預測）：2、−3、4、0 和 6 km/h。
  2. MAE = (2 + 3 + 4 + 0 + 6) / 5 = 15 / 5 = 3.0 km/h。
  3. 平方誤差：4、9、16、0 和 36，總和為 65。RMSE = √(65/5) = √13 ≈ 3.6 km/h。
  4. 基線誤差（從 66 km/h）：−6、−11、4、−1 和 14，因此其 MAE = 36/5 = 7.2 km/h。
  5. 基線 RMSE = √((36 + 121 + 16 + 1 + 196)/5) = √74 ≈ 8.6 km/h。
  6. 合理性檢查：模型在兩個指標上都優於基線，且 RMSE 大於 MAE，因為 6 km/h 的誤差被重點加權。
AnswerMAE = 3.0 km/h，RMSE ≈ 3.6 km/h，而基線值為 7.2 km/h 和 8.6 km/h。在此樣本上預測優於基線，但五個區間太少，不足以聲稱普遍改善。

應試方法

  • 首先命名任務：迴歸和分類需要不同的損失和不同的指標。
  • 報告每個測試集指標時附上單位和基線；僅憑準確率很少能回答所問的問題。
  • 對於不平衡類別，引用精確率和召回率而非總體準確率。
  • 微調時，在最初的幾輪中凍結主幹，並在解凍時將學習率降低約十倍。
