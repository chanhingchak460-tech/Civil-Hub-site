01学習とは関数を当てはめること

機械学習は、ルールを手で書く代わりに、例から関数を当てはめる。

  • 教師あり学習: 各例にラベルが付く。回帰は数値を予測し、分類はカテゴリを予測する。
  • 教師なし手法はラベルなしで構造を探す — クラスタリング、次元削減。
  • 強化学習は報酬から行動を学習する。

推定の良し悪しはサンプル次第である。偏ったデータや代表性のないデータは、実運用で間違っているのに自信過剰なモデルを生む。

02回帰と分類

線形回帰は最小二乗法で数値的な結果に直線を当てはめる。誤差項は直線が捉えられなかった部分を集める。はい/いいえの判断では、ロジスティック回帰が線形スコアをシグモイドに通して0から1の間の確率を出す。

スコアはゼロの位置に境界を定める。出力は確率であり、判定ではない。しきい値がそれをクラスに変換し、偽陽性と偽陰性をトレードオフする。

線形回帰
\[y = \beta_0 + \beta_1 x + \varepsilon\]
εは直線が説明しないyの部分
ロジスティック（シグモイド）モデル
\[p = \frac{1}{1 + e^{-s}}, \quad s = w \cdot x + b\]
pは確率であり、クラスは選んだしきい値から決まる

03訓練：損失と勾配

訓練は、予測がラベルに近づくようにパラメータを選ぶ。

  • 損失関数はその差を測る — 回帰では二乗誤差、分類では交差エントロピー。
  • 勾配降下法は各重みを損失の勾配と逆方向に少し動かす。
  • 学習率は重要な選択である。小さすぎると訓練は遅々として進まず、大きすぎると損失は上下に暴れたり発散したりする。
  • ミニバッチはノイズの多い勾配と引き換えに速度を得る。データを一度通すことが1エポックである。
勾配降下法の更新
\[w \leftarrow w - \eta \frac{\partial L}{\partial w}\]
ηは学習率であり、各ステップは勾配と逆方向

04検証とリーク

学習に使ったデータで採点されたモデルは、自分の宿題を自分で採点しているようなものだ。訓練、検証、テストの集合に分割し、訓練で学習し、検証でハイパーパラメータを選び、テスト集合には最後に一度だけ触れる。k分割交差検証は検証フォールドを回転させ、すべての行を推定に使う。

リークは静かな破壊者である。分割前のスケーリング、集合間の重複レコード、結果の後に記録された特徴などがそれにあたる。時系列データはランダムではなく時間で分割しなければならない。

層化分割と学習
X_tr, X_te, y_tr, y_te = train_test_split(X, y, test_size=0.2, stratify=y) model.fit(X_tr, y_tr) score = model.score(X_te, y_te)
stratifyは両方の部分でクラスバランスを保つ。訓練行だけで学習する

05問いに合った指標

精度は最初の指標であり、しばしば間違った指標である。1,000件のうち60件が陽性である場合、常に「いいえ」と言うモデルは94%の精度を出し、何も捉えない。

  • 混同行列は真陽性、偽陽性、偽陰性、真陰性を分け、そこから適合率と再現率が導かれる。
  • F1は両者のバランスをとり、ROC-AUCはすべてのしきい値にわたるランキングを測る。
  • 回帰の指標は異なる。RMSEは大きな誤差に罰を与え、MAEは元の単位を保ち、R²は説明された変動である。
適合率と再現率
\[\mathrm{precision} = \frac{TP}{TP + FP}, \quad \mathrm{recall} = \frac{TP}{TP + FN}\]
適合率は誤警報に罰を与え、再現率は見逃した陽性に罰を与える
F1スコア
\[F_1 = \frac{2 \cdot \mathrm{precision} \cdot \mathrm{recall}}{\mathrm{precision} + \mathrm{recall}}\]
調和平均なので、どちらかが悪いと全体が引き下げられる
分類指標とそれぞれの落とし穴
指標何に答えるか単独で使った場合の落とし穴
精度全ケースのうち正解した割合多数派クラスに支配される
適合率フラグを立てたもののうち正しかった割合見逃した陽性を無視する
再現率真の陽性のうち見つけた割合誤警報を無視する
F1両者のバランス各エラー種別のコストを隠す
ROC-AUCしきい値にわたるランキング品質選んだしきい値での判断がない

06過学習と正則化

過学習はパターンではなく訓練集合を学習してしまうことである。訓練誤差は下がり続ける一方で検証誤差は上がる。これはデータ量に対してモデルが柔軟すぎることが原因である。

治療法はデータを増やすこと、モデルを単純にすること、または大きな重みに罰を与える正則化である。ドロップアウト、早期停止、データ拡張も抑制の形である。過少適合は逆の失敗であり、パターンを表現できないモデルはどれだけ調整しても直らない。

正則化損失（L2）
\[L_{\mathrm{reg}} = L + \lambda \sum w^2\]
λは大きな重みにどれだけ強く罰を与えるかを制御する

07ニューラルネットワーク

ニューラルネットワークは重み付き和と非線形活性化の層を積み重ねる。深さによって線形モデルでは表現できない相互作用を表現できる。ReLUが一般的な活性化であり、誤差逆伝播が勾配降下法に必要な勾配を計算する。

畳み込み層は画像の局所構造を活用し、系列モデルは順序のあるデータを扱う。ネットワークは古典的モデルより多くのデータと計算を必要とし、解釈が難しいままであり、これは判断が人に影響する場合に重要である。

08倫理と実運用

良いテストスコアは実運用の許可ではない。訓練データに誰が代表されているか、誤差がグループごとに不均等に生じないか、誰が判断に異議を唱えられるかを問うべきである。

分布シフトとは、訓練後に世界が動くことであり、性能は劣化するため監視が必要である。データ、指標、限界を文書化し、誤りのコストが高い場合は人間をループに入れておく。モデルはシステムの一構成要素であり、責任はシステムが負う。

09木のアンサンブル：表形式データの王者

決定木は単純なしきい値の質問でデータを分割し、葉で平均または多数派を予測する。木は過学習しやすいため、アンサンブルで多数の木をまとめる。ランダムフォレストはブートストラップ標本とランダムな特徴部分集合で木を成長させ、勾配ブースティングは木を逐次的に構築し、各木をこれまでのアンサンブルの誤差に当てはめる。

表形式データ — 工学でよくある測定値の表 — では、XGBoostやLightGBMのようなブースティング木が通常最初に試すモデルである。欠損値や混在する単位を扱え、調整がほとんど不要で、ほとんどの小規模・中規模の表で深層ネットワークを上回る。主な調整項目は学習率、木の深さ、木の数であり、小さな学習率と多くの木が既定のレシピである。

ブースティングアンサンブル
\[\hat{y} = \sum_{m=1}^{M} \eta \, h_m(x)\]
各木h_mは残りの誤差に当てはめられる。ηは学習率

10誠実に行うハイパーパラメータ調整

ハイパーパラメータ — 深さ、学習率、正則化の強さ — は試行によって選ばれ、各試行は採点に使うデータの情報を消費する。検証フォールドで調整し、テスト集合では調整しない。テスト集合を繰り返し使うと、それは訓練手順の一部となり、最終スコアは不偏推定でなくなる。

  • 交差検証が主力である。訓練データをフォールドに分割し、1つを除いて訓練し、残したフォールドで検証し、回転させる。
  • クラスが不均衡な場合は層化フォールドを使い、各フォールドで同じクラス比率を保つ。
  • 最良のスコアではなく、フォールドスコアの平均とばらつきを報告する。
  • モデルの結果が重要な場合は、探索全体を入れ子交差検証の外側ループで包む。
層化k分割探索
skf = StratifiedKFold(n_splits=5, shuffle=True) grid = GridSearchCV(pipe, param_grid, cv=skf, scoring='f1') grid.fit(X_train, y_train) final_score = grid.score(X_test, y_test)
調整は訓練データのフォールドのみを使う。テスト集合には一度だけ触れる
テスト集合は触れた時点で消費される テスト集合を見た後に行うすべての決定 — しきい値、特徴、モデルファミリー — はそのスコアを楽観的にする。見るのはちょうど一度だけにすべきである。

11教師なし学習：クラスタリングとPCA

ラベルがない場合、モデルは構造を探す。

  • k-meansクラスタリングは各点を最も近い重心に割り当て、割り当てが変わらなくなるまで重心を再計算する。クラスタ内二乗距離を最小化するため、クラスタ数kはモデリング上の選択であり、目的関数対kのエルボープロットはクラスタを増やす効果が頭打ちになる場所を示す。
  • 主成分分析は分散が最大の方向を見つけ、データをそこに射影し、相関する多くの列を少数の成分に圧縮する。保持される分散の割合が射影が保存するものを測る。累積割合が頭打ちになったら成分を削除する。

クラスタリングの結果は探索的であり、スコアを引用するのではなく下流の目的に対して検証すべきである。

k-meansの目的関数
\[\mathrm{SSE} = \sum_j \sum_{x \in C_j} \lVert x - \mu_j \rVert^2\]
各点からそのクラスタ重心までの二乗距離の和

Key terms

教師あり学習
入力から既知のラベルへの写像を学習すること。数値の回帰とカテゴリの分類を含む。
過学習
訓練データに適合しすぎて、新しいデータでの性能が悪くなること。
適合率
フラグを立てたケースのうち真に陽性である割合。TPをTPとFPの和で割ったもの。
再現率
真の陽性のうちモデルが見つけた割合。TPをTPとFNの和で割ったもの。
交差検証
訓練データを繰り返し分割し、各部分が一度ずつ検証に使われるようにして、より安定した性能推定を得る手法。
正則化
モデルの複雑さや大きな重みに罰を与え、過学習を減らすこと。
分布シフト
実運用で見るデータが訓練データと比べて変化し、性能が劣化すること。
アンサンブル学習
木などの多くの基本モデルを組み合わせ、分散やバイアスを減らして予測を改善すること。
クラスタリング
ラベルなしデータを、同じグループ内の点が他のグループの点より互いに似るようにグループ化すること。
Worked example

スクリーニングモデルの混同行列を読む

あるモデルが1,000件の構造物検査をスクリーニングする。実際には60個の部品が欠陥である。モデルは50個の部品にフラグを立て、そのうち40個は真に欠陥があり、10個はそうではなく、20個の欠陥部品は見逃された。精度、適合率、再現率、F1を計算し、どの指標が判断を導くべきかを述べよ。

  1. 件数をラベル付けする: TP = 40、FP = 10、FN = 20、TN = 930。
  2. 精度 = (TP + TN) / 合計 = (40 + 930) / 1000 = 0.97。
  3. 適合率 = TP / (TP + FP) = 40 / 50 = 0.80。
  4. 再現率 = TP / (TP + FN) = 40 / 60 = 0.667。
  5. F1 = 2 × 0.80 × 0.667 / (0.80 + 0.667) = 0.727。
Answer精度は97%、適合率は0.80、再現率は0.67、F1は0.73である。見出しの精度は、3つの欠陥のうち1つが見逃されていることを隠している。したがって再現率が判断を導くべきである。より多くの欠陥を見つけるためにしきい値を下げ、より多くの誤警報を受け入れ、両方の指標を併せて報告する。

Exam method

  • 分類指標を計算する前に混同行列を描く。計算が簡単で誤りが見える。
  • 問いが実際に必要とする指標を挙げ、精度がなぜ誤解を招くかを一文で説明する。
  • 検証スコアが異常に良く見える場合は、結果として報告する前にリークを確認する。
  • 表形式の工学データでは、ニューラルネットワークより先に勾配ブースティング木を当てはめる。通常より強く、調整も少なくて済む。

Why各ステップが最小点を越えすぎるため、損失は落ち着かずに跳ねたり増えたりする。
