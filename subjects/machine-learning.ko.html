01학습은 함수를 적합시키는 것

머신러닝은 규칙을 직접 작성하는 대신 예시로부터 함수를 적합시킵니다.

  • 지도 학습: 각 예시에 레이블이 붙습니다. 회귀는 숫자를, 분류는 범주를 예측합니다.
  • 비지도 방법은 레이블 없이 구조를 찾습니다 — 군집화, 차원 축소.
  • 강화 학습은 보상으로부터 행동을 학습합니다.

추정치는 표본의 품질을 넘어설 수 없습니다. 편향되었거나 대표성이 없는 데이터는 배포 시 틀리지만 확신에 찬 모델을 만들어냅니다.

02회귀와 분류

선형 회귀는 최소제곱법으로 수치 결과에 직선을 적합시키며, 오차항은 직선이 설명하지 못하는 부분을 모읍니다. 예/아니오 결정의 경우 로지스틱 회귀는 선형 점수를 시그모이드에 통과시켜 0과 1 사이의 확률을 제공합니다.

점수는 0에서 경계를 정의하며, 출력은 판정이 아니라 확률입니다. 임계값이 이를 클래스로 변환하며, 거짓 양성과 거짓 음성 사이에서 균형을 맞춥니다.

선형 회귀
\[y = \beta_0 + \beta_1 x + \varepsilon\]
ε는 직선이 설명하지 못하는 y의 부분
로지스틱(시그모이드) 모델
\[p = \frac{1}{1 + e^{-s}}, \quad s = w \cdot x + b\]
p는 확률이며, 클래스는 선택된 임계값에서 결정됨

03훈련: 손실과 기울기

훈련은 예측이 레이블에 가까워지도록 매개변수를 선택합니다.

  • 손실 함수는 차이를 측정합니다 — 회귀에는 제곱 오차, 분류에는 교차 엔트로피.
  • 경사 하강법은 손실의 기울기에 반대 방향으로 각 가중치를 조금씩 조정합니다.
  • 학습률은 핵심 선택입니다: 너무 작으면 훈련이 느려지고, 너무 크면 손실이 요동치거나 발산합니다.
  • 미니배치는 잡음이 있는 기울기를 속도와 맞바꿉니다. 데이터를 한 번 통과하는 것이 에포크입니다.
경사 하강법 업데이트
\[w \leftarrow w - \eta \frac{\partial L}{\partial w}\]
η는 학습률이며, 각 단계는 기울기의 반대 방향

04검증과 누출

모델이 학습한 데이터로 채점하는 것은 자기 숙제를 스스로 채점하는 것과 같습니다. 훈련, 검증, 테스트 세트로 나누고, 훈련으로 적합시키고, 검증으로 하이퍼파라미터를 선택하며, 테스트 세트는 마지막에 한 번만 사용합니다. k-겹 교차 검증은 검증 폴드를 돌려 추정치가 모든 행을 사용하도록 합니다.

누출은 조용한 킬러입니다: 분할 전 스케일링, 세트 간 중복 레코드, 또는 결과 이후에 기록된 특성. 시간 순서가 있는 데이터는 무작위가 아니라 시간에 따라 분할해야 합니다.

층화 분할 및 적합
X_tr, X_te, y_tr, y_te = train_test_split(X, y, test_size=0.2, stratify=y) model.fit(X_tr, y_tr) score = model.score(X_te, y_te)
stratify는 두 부분에서 클래스 균형을 유지하며, 훈련 행에만 적합함

05질문에 맞는 지표

정확도는 첫 번째 지표이며 종종 잘못된 지표입니다. 1,000건 중 60건이 양성인 경우, 항상 아니오라고 말하는 모델은 94% 정확도를 기록하며 아무것도 잡아내지 못합니다.

  • 혼동 행렬은 진양성, 거짓 양성, 거짓 음성, 진음성을 분리하며, 여기서 정밀도와 재현율이 나옵니다.
  • F1은 둘의 균형을 맞추며, ROC-AUC는 모든 임계값에서의 순위 품질을 측정합니다.
  • 회귀 지표는 다릅니다: RMSE는 큰 오차에 페널티를 주고, MAE는 원래 단위를 유지하며, R²는 설명된 변동입니다.
정밀도와 재현율
\[\mathrm{precision} = \frac{TP}{TP + FP}, \quad \mathrm{recall} = \frac{TP}{TP + FN}\]
정밀도는 거짓 경보에, 재현율은 놓친 양성에 페널티를 줌
F1 점수
\[F_1 = \frac{2 \cdot \mathrm{precision} \cdot \mathrm{recall}}{\mathrm{precision} + \mathrm{recall}}\]
조화 평균이므로 어느 한쪽이 나쁘면 전체가 낮아짐
분류 지표와 각 지표의 함정
지표답하는 질문단독 사용 시 함정
정확도전체 사례 중 정답 비율다수 클래스에 의해 지배됨
정밀도플래그된 것 중 실제로 맞은 비율놓친 양성을 무시함
재현율실제 양성 중 찾아낸 비율거짓 경보를 무시함
F1둘의 균형각 오류 유형의 비용을 숨김
ROC-AUC임계값 전반의 순위 품질선택된 임계값에서의 결정이 없음

06과적합과 정규화

과적합은 패턴이 아니라 훈련 세트를 학습하는 것입니다: 훈련 오차는 계속 줄어들지만 검증 오차는 증가합니다. 이는 데이터 양에 비해 모델이 너무 유연하기 때문에 발생합니다.

해결책은 더 많은 데이터, 더 단순한 모델, 또는 큰 가중치에 페널티를 추가하는 정규화입니다. 드롭아웃, 조기 종료, 증강은 다른 형태의 제약입니다. 과소적합은 반대의 실패이며, 패턴을 표현할 수 없는 모델은 아무리 튜닝해도 고쳐지지 않습니다.

정규화 손실 (L2)
\[L_{\mathrm{reg}} = L + \lambda \sum w^2\]
λ는 큰 가중치에 대한 페널티 강도를 제어함

07신경망

신경망은 가중 합과 비선형 활성화의 층을 쌓습니다. 깊이는 선형 모델이 표현할 수 없는 상호작용을 표현할 수 있게 합니다. ReLU는 일반적인 활성화 함수이며, 역전파는 경사 하강법에 필요한 기울기를 계산합니다.

합성곱 층은 이미지의 국소 구조를 활용하고, 시퀀스 모델은 순서가 있는 데이터를 처리합니다. 신경망은 고전 모델보다 더 많은 데이터와 연산이 필요하며, 해석이 어렵다는 점은 결정이 사람에게 영향을 미칠 때 중요합니다.

08윤리와 배포

좋은 테스트 점수가 배포 허가가 되는 것은 아닙니다. 훈련 데이터에 누가 대표되는지, 오류가 집단별로 불균등하게 발생하는지, 누가 결정에 이의를 제기할 수 있는지 물어야 합니다.

분포 이동은 훈련 후 세상이 변한다는 뜻이므로 성능이 저하되며 모니터링해야 합니다. 데이터, 지표, 한계를 문서화하고, 오류 비용이 높은 곳에서는 인간을 루프에 유지하십시오. 모델은 시스템의 구성 요소이며, 책임은 시스템이 집니다.

09트리 앙상블: 테이블 데이터의 챔피언

결정 트리는 단순한 임계값 질문으로 데이터를 분할하고 잎에서 평균 또는 다수결을 예측합니다. 트리는 쉽게 과적합되므로 앙상블은 많은 트리를 모읍니다: 랜덤 포레스트는 부트스트랩 표본과 무작위 특성 부분집합으로 트리를 키우고, 그래디언트 부스팅은 트리를 순차적으로 구축하며 각 트리는 지금까지 앙상블의 오차에 적합됩니다.

테이블 데이터 — 공학에서 흔한 측정값 표 — 의 경우 XGBoost와 LightGBM 같은 부스팅 트리가 보통 가장 먼저 시도할 모델입니다: 결측값과 혼합 단위를 처리하고, 튜닝이 적게 필요하며, 대부분의 작고 중간 크기 테이블에서 심층 신경망을 능가합니다. 주요 조정 대상은 학습률, 트리 깊이, 트리 수이며, 작은 학습률과 많은 트리가 기본 레시피입니다.

부스팅 앙상블
\[\hat{y} = \sum_{m=1}^{M} \eta \, h_m(x)\]
각 트리 h_m은 남은 오차에 적합되며, η는 학습률

10정직하게 수행하는 하이퍼파라미터 튜닝

하이퍼파라미터 — 깊이, 학습률, 정규화 강도 — 는 시행으로 선택되며, 각 시행은 채점에 사용된 데이터의 정보를 소비합니다. 테스트 세트가 아니라 검증 폴드에서 튜닝하십시오: 테스트 세트를 반복 사용하면 그것이 훈련 절차의 일부가 되어 최종 점수가 더 이상 편향되지 않은 추정치가 아닙니다.

  • 교차 검증이 핵심 도구입니다: 훈련 데이터를 폴드로 나누고, 하나를 제외한 모두로 훈련하고, 남겨둔 폴드로 검증하며 돌립니다.
  • 클래스가 불균형하면 층화 폴드를 사용하여 각 폴드가 동일한 클래스 비율을 유지하도록 하십시오.
  • 최고 점수 대신 폴드 점수의 평균과 분산을 보고하십시오.
  • 모델 결과가 중요할 때는 전체 탐색을 중첩 교차 검증의 외부 루프로 감싸십시오.
층화 k-겹 탐색
skf = StratifiedKFold(n_splits=5, shuffle=True) grid = GridSearchCV(pipe, param_grid, cv=skf, scoring='f1') grid.fit(X_train, y_train) final_score = grid.score(X_test, y_test)
튜닝은 훈련 데이터의 폴드만 사용하며, 테스트 세트는 한 번만 사용됨
테스트 세트는 접촉하는 순간 소모됩니다 테스트 세트를 본 후 내린 모든 결정 — 임계값, 특성, 모델 계열 — 은 그 점수를 낙관적으로 만듭니다. 정확히 한 번만 볼 수 있도록 계획하십시오.

11비지도 학습: 군집화와 PCA

레이블이 없으면 모델은 구조를 찾습니다.

  • k-평균 군집화는 각 점을 가장 가까운 중심에 할당하고 할당이 변하지 않을 때까지 중심을 재계산합니다. 군집 내 제곱 거리를 최소화하므로 군집 수 k는 모델링 선택이며, 목적 함수 대 k의 엘보 플롯은 군집 추가가 더 이상 이득이 없는 지점을 제안합니다.
  • 주성분 분석은 최대 분산 방향을 찾아 데이터를 그 방향으로 투영하여, 상관된 많은 열을 소수의 성분으로 압축합니다. 유지된 분산 비율은 투영이 보존하는 것을 측정하며, 누적 비율이 평탄해지면 성분을 버립니다.

군집화 결과는 탐색적입니다 — 점수를 인용하기보다는 하류 목적에 대해 검증하십시오.

k-평균 목적 함수
\[\mathrm{SSE} = \sum_j \sum_{x \in C_j} \lVert x - \mu_j \rVert^2\]

Key terms

지도 학습
입력에서 알려진 레이블로의 매핑을 학습하는 것으로, 숫자에는 회귀, 범주에는 분류를 포함합니다.
과적합
훈련 데이터에 너무 밀접하게 적합되어 모델이 새 데이터에서 성능이 나쁜 것.
정밀도
플래그된 사례 중 실제로 양성인 비율로, TP를 TP 더하기 FP로 나눈 값.
재현율
실제 양성 중 모델이 찾아낸 비율로, TP를 TP 더하기 FN으로 나눈 값.
교차 검증
훈련 데이터를 반복 분할하여 각 부분이 한 번씩 검증 역할을 하게 함으로써 더 안정적인 성능 추정치를 제공하는 것.
정규화
모델 복잡성이나 큰 가중치에 대한 페널티로 과적합을 줄이는 것.
분포 이동
배포 시 보이는 데이터가 훈련 데이터와 달라져 성능이 저하되는 것.
앙상블 학습
트리 같은 많은 기본 모델을 결합하여 분산이나 편향을 줄이고 예측을 개선하는 것.
군집화
레이블이 없는 데이터를 같은 그룹의 점들이 다른 그룹의 점들보다 서로 더 유사하도록 그룹화하는 것.
Worked example

스크리닝 모델의 혼동 행렬 읽기

한 모델이 1,000건의 구조물 점검을 스크리닝합니다. 실제로 60개 부품이 결함이 있습니다. 모델은 50개 부품을 플래그하며, 그중 40개는 실제로 결함이고 10개는 아니며, 20개 결함 부품은 놓칩니다. 정확도, 정밀도, 재현율, F1을 계산하고 어떤 지표가 결정을 이끌어야 하는지 말하십시오.

  1. 개수를 표시합니다: TP = 40, FP = 10, FN = 20, TN = 930.
  2. 정확도 = (TP + TN) / 전체 = (40 + 930) / 1000 = 0.97.
  3. 정밀도 = TP / (TP + FP) = 40 / 50 = 0.80.
  4. 재현율 = TP / (TP + FN) = 40 / 60 = 0.667.
  5. F1 = 2 × 0.80 × 0.667 / (0.80 + 0.667) = 0.727.
Answer정확도는 97%, 정밀도는 0.80, 재현율은 0.67, F1은 0.73입니다. 대표 정확도는 결함 세 개 중 하나를 놓친다는 사실을 숨기므로 재현율이 결정을 이끌어야 합니다: 더 많은 결함을 찾기 위해 임계값을 낮추고 더 많은 거짓 경보를 감수하며, 두 지표를 함께 보고하십시오.
