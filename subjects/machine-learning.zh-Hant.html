模型如何從數據中學習模式，以及如何判斷一個模型是否好用。內容涵蓋迴歸、分類、驗證、切合實際問題的指標、過擬合、神經網絡，以及部署模型時的倫理考量。

進度只儲存在此瀏覽器。

01學習就是擬合一個函數

機器學習是從範例中擬合一個函數，而不是手寫規則。

  • 監督式學習：每個範例都帶有標籤；迴歸預測一個數值，分類預測一個類別。
  • 非監督式方法在沒有標籤的情況下尋找結構——聚類、降維。
  • 強化式學習從獎勵中學習動作。

估計的好壞取決於樣本：有偏差或不具代表性的數據會產生一個在部署時自信地出錯的模型。

02迴歸與分類

線性迴歸以最小平方法對數值結果擬合一條直線；誤差項收集了直線未能解釋的部分。對於是/否的決策，邏輯迴歸將線性分數通過 sigmoid 函數，給出一個介於 0 與 1 之間的機率。

分數在零處定義了一個邊界；輸出是機率，不是判決。閾值將其轉換為類別，在偽陽性與偽陰性之間取捨。

線性迴歸
\[y = \beta_0 + \beta_1 x + \varepsilon\]
ε 是 y 中直線未能解釋的部分
邏輯（sigmoid）模型
\[p = \frac{1}{1 + e^{-s}}, \quad s = w \cdot x + b\]
p 是機率；類別由選定的閾值決定

03訓練：損失與梯度

訓練選擇參數，使預測接近標籤。

  • 損失函數衡量差距——迴歸用平方誤差，分類用交叉熵。
  • 梯度下降讓每個權重逆著損失的梯度微調。
  • 學習率是關鍵選擇：太小訓練緩慢，太大損失會跳動或發散。
  • 小批次以噪聲梯度換取速度；對數據的一次完整遍歷稱為一個 epoch。
梯度下降更新
\[w \leftarrow w - \eta \frac{\partial L}{\partial w}\]
η 是學習率；每一步都與梯度方向相反

04驗證與洩漏

在學習過的數據上評分的模型，等於自己改自己的作業。劃分為訓練集、驗證集和測試集；在訓練集上擬合，在驗證集上選擇超參數，最後只碰一次測試集。k 折交叉驗證輪換驗證折，使估計用到每一行數據。

洩漏是沉默的殺手：在劃分前縮放、跨集合的重複記錄，或在結果之後記錄的特徵。時間順序數據必須按時間劃分，而非隨機劃分。

分層劃分與擬合
X_tr, X_te, y_tr, y_te = train_test_split(X, y, test_size=0.2, stratify=y) model.fit(X_tr, y_tr) score = model.score(X_te, y_te)
stratify 保持兩部分的類別平衡；只在訓練行上擬合

05切合問題的指標

準確率是第一個指標，而且往往是錯的。在 1,000 個案例中只有 60 個為正，一個總是說「否」的模型得分 94% 準確率，卻什麼也沒抓到。

  • 混淆矩陣區分真陽性、偽陽性、偽陰性和真陰性，由此得出精確率和召回率。
  • F1 平衡兩者，而 ROC-AUC 衡量所有閾值下的排序質量。
  • 迴歸指標不同：RMSE 懲罰大誤差，MAE 保留原始單位，R² 是解釋的變異。
精確率與召回率
\[\mathrm{precision} = \frac{TP}{TP + FP}, \quad \mathrm{recall} = \frac{TP}{TP + FN}\]
精確率懲罰誤報；召回率懲罰漏報的正例
F1 分數
\[F_1 = \frac{2 \cdot \mathrm{precision} \cdot \mathrm{recall}}{\mathrm{precision} + \mathrm{recall}}\]
調和平均，因此任何一邊表現差都會拉低它
分類指標及各自的陷阱
指標它回答什麼單獨使用時的陷阱
準確率所有案例中正確的比例被多數類主導
精確率被標記的案例中，有多少是正確的忽略漏報的正例
召回率真實正例中，找到了多少忽略誤報
F1兩者的平衡掩蓋每種錯誤類型的代價
ROC-AUC跨閾值的排序質量在選定閾值下沒有決策

06過擬合與正則化

過擬合是學習訓練集而非模式：訓練誤差持續下降，而驗證誤差上升。它來自模型對於數據量而言過於靈活。

解決方法是更多數據、更簡單的模型，或對大權重施加懲罰的正則化。Dropout、早停和數據增強是其他形式的約束。欠擬合是相反的失敗，再多的調參也無法修復一個無法表達模式的模型。

正則化損失（L2）
\[L_{\mathrm{reg}} = L + \lambda \sum w^2\]
λ 控制大權重受懲罰的強度

07神經網絡

神經網絡堆疊加權和與非線性激活的層；深度讓它能表示線性模型無法表示的交互作用。ReLU 是常見的激活函數，而反向傳播計算梯度下降所需的梯度。

卷積層利用圖像中的局部結構，序列模型處理有序數據。網絡比經典模型需要更多數據和計算，且仍然難以解釋，這在決策影響到人時很重要。

08倫理與部署

好的測試分數不是部署的許可。要問訓練數據中代表了誰、錯誤是否不均地落在某些群體上，以及誰能質疑決策。

分佈偏移意味著訓練後世界會變化，因此性能會衰減，必須監控。記錄數據、指標和限制，並在錯誤代價高的地方保持人在迴路中。模型是系統中的一個組件，而系統承擔責任。

09樹集成：表格數據的冠軍

決策樹以簡單的閾值問題分割數據，並在葉子中預測平均值或多數類。樹容易過擬合，因此集成許多樹：隨機森林在自助抽樣和隨機特徵子集上生長樹，而梯度提升順序構建樹，每棵樹擬合迄今為止集成的誤差。

對於表格數據——工程中常見的測量表格——XGBoost 和 LightGBM 等提升樹通常是首先嘗試的模型：它們能處理缺失值和混合單位，需要很少的調參，並且在大多數中小型表格上勝過深度網絡。主要旋鈕是學習率、樹深度和樹的數量；小學習率搭配許多樹是默認配方。

提升集成
\[\hat{y} = \sum_{m=1}^{M} \eta \, h_m(x)\]
每棵樹 h_m 擬合剩餘誤差；η 是學習率

10誠實地進行超參數調優

超參數——深度、學習率、正則化強度——通過試錯選擇，每次試錯都消耗其所評分數據的信息。在驗證折上調優，而非測試集：反覆使用測試集會使其成為訓練過程的一部分，其最終分數不再是不偏估計。

  • 交叉驗證是主力：將訓練數據分成折，在除一折外的所有折上訓練，在留出的折上驗證並輪換。
  • 對於類別不平衡，使用分層折，使每折保持相同的類別比例。
  • 報告折分數的均值和離散度，而非最佳值。
  • 當模型的結果很重要時，將整個搜索包裹在嵌套交叉驗證的外層循環中。
分層 k 折搜索
skf = StratifiedKFold(n_splits=5, shuffle=True) grid = GridSearchCV(pipe, param_grid, cv=skf, scoring='f1') grid.fit(X_train, y_train) final_score = grid.score(X_test, y_test)
調優僅使用訓練數據的折；測試集只碰一次
測試集一碰就消耗 在查看測試集後做出的每一個決定——閾值、特徵、模型家族——都會使該分數過於樂觀；只預算一次查看。

11非監督式學習：聚類與 PCA

沒有標籤時，模型尋找結構。

  • k-means 聚類將每個點分配給最近的質心，並重新計算質心直到分配不再改變；它最小化簇內平方距離，因此簇數 k 是一個建模選擇，目標函數對 k 的肘部圖暗示了增加簇何時不再划算。
  • 主成分分析找到方差最大的方向並將數據投影到這些方向上，將許多相關列壓縮成幾個成分。保留的方差份額衡量投影保留了什麼；當累積份額趨於平緩時丟棄成分。

聚類結果是探索性的——根據下游目的驗證它們，而不是引用一個分數。

k-means 目標函數
\[\mathrm{SSE} = \sum_j \sum_{x \in C_j} \lVert x - \mu_j \rVert^2\]
每個點到其簇質心的平方距離之和

關鍵詞

監督式學習
學習從輸入到已知標籤的映射，涵蓋數值的迴歸和類別的分類。
過擬合
過於緊密地擬合訓練數據，以致模型在新數據上表現不佳。
精確率
被標記的案例中真正為正的比例，TP 除以 TP 加 FP。
召回率
真實正例中被模型找到的比例，TP 除以 TP 加 FN。
交叉驗證
反覆劃分訓練數據，使每一部分都作為驗證集一次，給出更穩定的性能估計。
正則化
對模型複雜度或大權重的懲罰，以減少過擬合。
分佈偏移
部署時看到的數據與訓練數據相比發生變化，導致性能衰減。
集成學習
結合許多基礎模型（如樹）以減少方差或偏差並改進預測。
聚類
將無標籤數據分組，使同一組內的點彼此之間比與其他組的點更相似。
計算示例

解讀篩查模型的混淆矩陣

一個模型篩查 1,000 個結構檢查。實際上 60 個構件有缺陷。模型標記了 50 個構件；其中 40 個確實有缺陷，10 個沒有，另有 20 個有缺陷的構件被漏掉。計算準確率、精確率、召回率和 F1，並說明哪個指標應指導決策。

  1. 標記計數：TP = 40，FP = 10，FN = 20，TN = 930。
  2. 準確率 = (TP + TN) / 總數 = (40 + 930) / 1000 = 0.97。
  3. 精確率 = TP / (TP + FP) = 40 / 50 = 0.80。
  4. 召回率 = TP / (TP + FN) = 40 / 60 = 0.667。
  5. F1 = 2 × 0.80 × 0.667 / (0.80 + 0.667) = 0.727。
Answer準確率為 97%，精確率 0.80，召回率 0.67，F1 0.73。標題準確率掩蓋了每三個缺陷中就有一個被漏掉的事實，因此召回率應主導決策：降低閾值以找到更多缺陷，接受更多誤報，並同時報告這兩個指標。

應試方法

  • 在計算任何分類指標之前先畫出混淆矩陣；算術更容易，錯誤也顯而易見。
  • 說出問題實際需要的指標，並用一句話解釋為什麼準確率會誤導。
  • 如果驗證分數看起來異常好，在報告結果之前檢查是否有洩漏。
  • 對於表格工程數據，在神經網絡之前先擬合梯度提升樹；它通常更強且需要更少調參。
