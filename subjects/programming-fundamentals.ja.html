プログラムのように考えるための入門コースです。値の保存、条件による分岐、処理の繰り返し、ロジックの関数へのまとめ、ファイルを通したデータの受け渡しを学びます。これらの習慣は、その後のすべての計算機系科目に活かされます。

01値、名前、型

変数とは、固定サイズのラベル付き箱ではなく、オブジェクトに結び付けられた名前です。Python は実行時に型を決めます。整数は int、小数は float、テキストは str、True または False は bool です。不明なときは type(x) を使い、int()、float()、str() で意図的に変換します。

選ぶ演算子によって結果が変わります。/ は常に float を返し、// は切り捨てて整数にし、% は剰余を返します。これは桁や偶奇に関する多くのテクニックの基礎です。

浮動小数点値は二進近似なので、0.1 + 0.2 を試しても正確に 0.3 にはなりません。等値比較ではなく許容誤差を用いて比較します。

商と剰余 
q, r = divmod(n, 10)
最後の桁を分離する

02入力、出力、書式設定

input() は、ユーザーが数字を入力した場合でも常に文字列を返します。算術を行う前に変換してください。そうしないと "7" + 1 は 8 ではなく TypeError を発生させます。

書式設定は解答の一部です。プロンプトや出力は正確に一致しなければならないことが多いため、f-string で組み立てます。f"{day:02d}" は日をゼロ埋めし、f"{total:.4f}" は小数点以下4桁を保持します。

整ったプログラムは、プロンプト、計算、表示を分離します。これらを混ぜるとデバッグや採点が難しくなります。

数値の読み取り 
n = int(input("Please enter a number: "))
input はテキストを返すため、算術の前に変換する

03if、elif、else による分岐

条件文は経路を選び、各条件は真または偽に評価される式にすぎません。分岐は最も具体的なものから最も一般的なものへと並べ、残りのすべてのケースがそこに属する場合にのみ最後の else を追加します。

定番の間違いに注意してください。
- = は代入、== は比較
- and は or より強く結合する
- if name: のようなテストは空でない文字列なら真であり、意図より広い範囲を対象にしがち

意図するケースをまずコメントとして書き、それからコードにします。この小さな習慣が、多くの論理エラーを発生する前に取り除きます。

04ループとアキュムレータパターン

for ループはシーケンスをたどり、while ループは条件が偽になるまで繰り返します。項目数が既知なら for、未知なら while を選び、while の条件が実際に偽になり得ることを確認してください。変化しないループ変数は無限ループを生みます。

初期のプログラミングで最も再利用されるパターンは アキュムレータ です。合計をゼロで開始し、ループ内で各項目を加え、ループ後に報告します。同じ形で、数え上げ、合計、フィルタリング、検索ができます。

更新行を明示して、読む人が何がいつ変わるかを正確に把握できるようにします。

累積合計の蓄積 
total = total + x
ループの前に total = 0 で初期化する

05関数と再帰

関数はロジックの一部に名前を与え、引数を受け取り、値を返します。関数内で出力するよりも結果を返すことを優先してください。返された値はテスト、再利用、組み合わせができます。各関数は1つの仕事に限定し、その動作に基づいて名前を付けます。

再帰は、自分自身のより小さな版を呼び出すことで問題を解きます。すべての再帰関数には、再帰せずに返す 基底ケース と、それに向かって進む再帰ステップが必要です。

フィボナッチ関数は標準的な例ですが、再帰はループでは独自のスタックが必要になる入れ子構造にも適しています。

再帰的フィボナッチ
\[\mathrm{fib}(n) = \mathrm{fib}(n - 1) + \mathrm{fib}(n - 2)\]
基底ケース fib(1) = fib(2) = 1 を伴う

06リスト、タプル、辞書

リストはゼロから索引付けされた順序付きの可変シーケンスなので、a[0] は最初の項目、a[-1] は最後の項目です。スライスは一部をコピーし、append、sort、remove はリストをその場で編集します。リストは参照で共有されるため、b = a はコピーしません。b = a[:] がコピーします。

タプルは不変のシーケンスで、座標のような固定の組に便利です。辞書はキーを値にマップし、事前チェックを要求せずにキーを遅延作成できるため、数え上げの自然な構造です。

入れ子のリストは行列を表します。まず行をループし、次に列をループします。

辞書による数え上げ 
counts[ch] = counts.get(ch, 0) + 1
別途のメンバーシップテストを避ける

tupleはいいいえ座標のような固定レコード

07文字列もシーケンス

文字列は文字のタプルのように振る舞います。不変で、索引付けとスライスが可能なので、text[2:5] は索引 2、3、4 の文字を返し、text[::-1] はそれを逆順にします。

述語メソッドは単一文字を分類します。isalpha()、isdigit()、isspace() はブール値を返し、ループ内でテストできます。

部分から出力を組み立てるのは繰り返し現れるパターンです。split() でテキストをトークンに分割し、'-'.join(tokens) で再結合し、strip() で余分な空白を削除します。メソッドは元を変更せず新しい文字列を返すため、保持したい場合は結果を代入します。

ループ内での文字の分類
if ch.isdigit(): digits += 1
文字列を一度走査し、文字クラスごとにカウンタを更新する

'-'.join(parts)1つの文字列出力行を組み立てる

08入れ子ループと二次元データ

リストのリストはグリッドまたは行列を表します。grid[r][c] は行 r、列 c の要素で、標準的な走査は行の外側ループと列の内側ループです。

同じ入れ子でパスカルの三角形のような三角形のパターンを出力できます。各内部要素はその上の2つの和です。

行列の積は試験の定番です。積の行 i、列 j の要素は、最初の行列の行 i と2番目の行列の列 j の内積です。まず形状を確認してください。n×m 行列と m×p 行列の積は n×p になります。索引を入れ替えるのが典型的な無言のエラーです。

パスカルの三角形の要素
\[T(r,k) = T(r-1,k-1) + T(r-1,k)\]
端は 1。各内部要素はその上の2つの和
行列の積
\[C[i][j] = \sum_{k} A[i][k]\,B[k][j]\]
共有される内側次元 k について総和を取る

09ファイルと簡単なデータ処理

ファイルは with ブロック内で開き、何か失敗しても閉じられるようにします。読み取りでは末尾の改行を含む行が得られるため、解析時はまず strip()、次に split() を行います。書き込みはそのままです。print は改行を追加しますが、file.write() は追加しないので、"\n" を自分で加えます。

実データは乱雑です。トークンを数値に変換するのは、数値に見えることを確認してからにし、無効な単語はクラッシュさせずにスキップします。

表形式データでは、csv モジュールやデータフレームライブラリが、壊れやすい手動分割の多くを取り除きます。解析と報告を分離し、各部分を単独でテストできるようにします。

10モジュール、ライブラリ、より大きなツールボックス

モジュールは再利用可能な定義のファイルです。import math はライブラリを取り込み、math.sqrt(x) は再実装せずに1つの関数を呼び出します。標準ライブラリは乱数、日付、ファイルパスをカバーし、pandas や matplotlib のようなサードパーティパッケージは、表形式データを数行で分析やグラフに変えます。

ライブラリは基礎を不要にしません。型を選び、正しくループし、入力を検証する必要は依然としてあります。ライブラリ呼び出しは、名前を付けてテストできるブラックボックスとして扱い、データの意味を知ることの代わりにはしないでください。

課題がライブラリを禁止している場合、それは基礎となるロジックを自分で示すことを求めています。本来インポートするはずのループを自分で書いてください。

pandas による表の読み取り
df = pd.read_csv('counting.csv') df.plot()
ライブラリがデータを解析、保存、プロットする。あなたの仕事は結果を確認すること

11デバッグは運ではなくスキル

トレースバックは下から上へ読みます。最後の行がエラー名を示し、その上の行が発生場所を示します。見つけられる最小の入力で失敗を再現し、2点で値を出力して最初に食い違う場所を問うことで範囲を絞ります。

境界を意図的に確認します。空の入力、単一の項目、許される最大値です。初心者のバグの多くは、off-by-one エラー、変換漏れ、次の関数によって変更されたリストです。

合格すべき小さなテストを1つ書き、変更のたびに再実行します。

Key terms

変数
オブジェクトを参照する名前で、型は事前に宣言されるのではなく実行時に決まる。
不変
文字列やタプルのように、作成後に値を変更できないオブジェクト。
アキュムレータ
ループの実行中に結果を集める変数で、通常はゼロまたは空のコレクションから始まる。
再帰
関数がより小さな入力で自分自身を呼び出す手法で、基底ケースによって停止する。
辞書
キーから値への可変マッピングで、波括弧で書き、角括弧で読む。
トレースバック
エラー発生時に Python が出力する報告で、コールスタックと失敗した行を列挙する。
スライス
シーケンスの連続した一部のコピーで、開始、終了、任意のステップ索引で書く。
モジュール
プログラムがインポートして名前で呼び出せる、再利用可能な定義のファイル。
Worked example

桁和関数のトレース

この関数を手作業でトレースし、digit_sum(274) の呼び出しで何を返すか述べてください。 def digit_sum(n): total = 0 while n > 0: total = total + n % 10 n = n // 10 return total print(digit_sum(274))

  1. 開始: n = 274、total = 0。ループテスト 274 > 0 は真。
  2. 1回目: total = 0 + (274 % 10) = 0 + 4 = 4、n = 274 // 10 = 27。
  3. 2回目: total = 4 + (27 % 10) = 4 + 7 = 11、n = 27 // 10 = 2。
  4. 3回目: total = 11 + (2 % 10) = 11 + 2 = 13、n = 2 // 10 = 0。
  5. ループテスト: 0 > 0 は偽なのでループは停止し、関数は total = 13 を返す。
Answer関数は 13 を返します。確認: 274 の桁は 2、7、4 で、その和は 13 であり、トレースと一致します。

Exam method

  • ループは変数ごとに1列を使って紙の上でトレースする。頭の中でコードを実行しようとしない。
  • 算術の前に入力を正しい型に変換する。これが最もよく失われる1点である。
  • エラーメッセージは最後の行から上へ読み、一度に1つのエラーを修正する。
  • 境界ケースをテストする。空の入力、1つの項目、許される最大値。
  • 問題が find() や count() を禁止している場合は、自分でループを書く。カウンタを初期化し、文字を走査し、条件に応じて更新する。

Whyinput() は常にテキストを返します。プログラムは算術の前に int() または float() で変換する必要があります。

Q0217 // 5 の値は何ですか？

Why// は切り捨て除算を行い、整数部分 3 を返します。通常の除算なら 3.4 になります。

Q03次のうち、作成後に変更できないコンテナはどれですか？

Whyタプルは不変ですが、リストと辞書はその場での変更をサポートします。

Q04file.write() について正しい記述はどれですか？

Whyprint() は改行を追加しますが、file.write() は追加しません。書き込む側が改行文字を追加する必要があります。

Q05text = 'abcdefg' のとき、text[2:5] は何を返しますか？

Whyスライスは開始索引を含み、終了索引を含まないため、索引 2、3、4 は文字 c、d、e になります。

Q06Python の文字列について正しい記述はどれですか？

Why文字列は不変です。strip() や upper() のようなメソッドは新しい文字列を返し、append() のようなその場で変更するメソッドは存在しません。
