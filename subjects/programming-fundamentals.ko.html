01값, 이름, 타입

변수는 고정된 크기의 라벨이 붙은 상자가 아니라 객체에 바인딩된 이름이다. Python은 런타임에 타입을 결정한다: 정수에는 int, 소수에는 float, 텍스트에는 str, True 또는 False에는 bool을 사용한다. 확실하지 않을 때는 type(x)를 사용하고, int(), float(), str()로 의도적으로 변환하라.

선택하는 연산자에 따라 결과가 달라진다. /는 항상 float를 생성하고, //는 정수로 내림하며, %는 나머지를 제공하는데, 이는 많은 자릿수 및 홀짝 트릭의 기초다.

부동 소수점 값은 이진 근사치이므로 0.1 + 0.2를 테스트하면 정확히 0.3이 나오지 않는다. 동등 비교 대신 허용 오차를 사용하여 비교하라.

몫과 나머지 
q, r = divmod(n, 10)
마지막 자릿수를 분리한다

02입력, 출력 및 형식 지정

input()은 사용자가 숫자를 입력하더라도 항상 문자열을 반환한다. 산술 연산을 하기 전에 변환하라. 그렇지 않으면 "7" + 1은 8을 주는 대신 TypeError를 발생시킨다.

형식 지정은 답의 일부다. 프롬프트와 출력은 종종 정확히 일치해야 하므로 f-string으로 작성하라: f"{day:02d}"는 날짜를 0으로 채우고, f"{total:.4f}"는 소수점 네 자리를 유지한다.

깔끔한 프로그램은 프롬프트, 계산, 표시를 분리한다. 이들을 혼합하면 디버깅과 채점이 어려워진다.

숫자 읽기 
n = int(input("Please enter a number: "))
input은 텍스트를 반환하므로 산술 연산 전에 변환하라

03if, elif, else를 사용한 의사 결정

조건문은 경로를 선택하며, 모든 조건은 단순히 참 또는 거짓으로 평가되는 표현식이다. 분기를 가장 구체적인 것에서 가장 일반적인 것으로 정렬하고, 모든 나머지 경우가 그곳에 속할 때만 마지막 else를 추가하라.

고전적인 실수를 주의하라:
- =는 할당하고 ==는 비교한다
- and는 or보다 더 강하게 바인딩된다
- if name:과 같은 테스트는 비어 있지 않은 문자열에 대해 참이며, 이는 종종 의도한 것보다 많다

의도한 경우를 먼저 주석으로 작성한 다음 코딩하라 — 이 작은 습관이 대부분의 논리 오류가 나타나기 전에 제거한다.

04루프와 누산기 패턴

for 루프는 시퀀스를 순회하고, while 루프는 조건이 실패할 때까지 반복한다. 항목 수를 알 때는 for를, 모를 때는 while을 선택하고, while 조건이 실제로 거짓이 될 수 있는지 확인하라 — 절대 변하지 않는 루프 변수는 무한 루프를 만든다.

초기 프로그래밍에서 가장 재사용 가능한 패턴은 누산기다: 합계를 0으로 시작하고, 루프 내에서 각 항목을 더하고, 루프 후에 보고한다. 동일한 형태가 세기, 합산, 필터링, 검색에 사용된다.

업데이트 줄을 명시적으로 유지하여 독자가 무엇이 언제 변경되는지 정확히 볼 수 있게 하라.

누적 합계 계산 
total = total + x
루프 전에 total = 0으로 초기화하라

05함수와 재귀

함수는 논리 조각에 이름을 부여하고, 매개변수를 받아 값을 반환한다. 함수 내부에서 인쇄하는 것보다 결과를 반환하는 것을 선호하라: 반환된 값은 테스트, 재사용, 구성이 가능하다. 각 함수를 하나의 작업으로 유지하고 수행하는 작업에 따라 이름을 지정하라.

재귀는 문제를 더 작은 버전의 자신을 호출하여 해결한다. 모든 재귀 함수에는 재귀 없이 반환하는 기저 사례와 그 기저 사례로 향하는 재귀 단계가 필요하다.

피보나치 함수는 표준 시연이지만, 재귀는 루프가 자체 스택을 필요로 하는 중첩 구조에도 적합하다.

재귀 피보나치
\[\mathrm{fib}(n) = \mathrm{fib}(n - 1) + \mathrm{fib}(n - 2)\]
기저 사례 fib(1) = fib(2) = 1과 함께

06리스트, 튜플, 딕셔너리

리스트는 0부터 인덱스된 순서가 있고 변경 가능한 시퀀스이므로 a[0]은 첫 번째 항목이고 a[-1]은 마지막 항목이다. 슬라이싱은 섹션을 복사하는 반면, append, sort, remove는 리스트를 제자리에서 편집한다. 리스트는 참조로 공유되므로 b = a는 복사하지 않는다; b = a[:]가 복사한다.

튜플은 변경 불가능한 시퀀스로, 좌표와 같은 고정 그룹에 유용하다. 딕셔너리는 키를 값에 매핑하며, 사전 검사를 요구하는 대신 키를 지연 생성할 수 있으므로 세기에 자연스러운 구조다.

중첩 리스트는 행렬을 나타낸다: 행을 먼저 반복한 다음 열을 반복하라.

딕셔너리로 세기 
counts[ch] = counts.get(ch, 0) + 1
별도의 멤버십 테스트를 피한다

07문자열도 시퀀스다

문자열은 문자의 튜플처럼 동작한다: 변경 불가능하고, 인덱싱 및 슬라이싱이 가능하므로 text[2:5]는 인덱스 2, 3, 4의 문자를 제공하고, text[::-1]은 이를 뒤집는다.

술어 메서드는 단일 문자를 분류한다 — isalpha(), isdigit(), isspace() — 그리고 루프 내에서 테스트할 수 있는 부울을 반환한다.

부분에서 출력을 구성하는 것은 반복되는 패턴이다: split()으로 텍스트를 토큰으로 분할하고, '-'.join(tokens)로 다시 결합하며, strip()으로 불필요한 공백을 제거하라. 메서드는 원본을 변경하는 대신 새 문자열을 반환하므로, 결과를 유지하려면 할당하라.

루프에서 문자 분류
if ch.isdigit(): digits += 1

08중첩 루프와 2차원 데이터

리스트의 리스트는 그리드 또는 행렬을 나타낸다: grid[r][c]는 행 r, 열 c의 요소이며, 표준 순회는 행에 대한 외부 루프와 열에 대한 내부 루프다.

동일한 중첩은 파스칼의 삼각형과 같은 삼각형 패턴을 인쇄한다. 여기서 각 내부 항목은 위의 두 항목의 합이다.

행렬 곱셈은 시험에서 인기 있는 주제다: 곱의 행 i, 열 j에 있는 요소는 첫 번째 행렬의 행 i와 두 번째 행렬의 열 j의 내적이다. 먼저 형태를 테스트하라 — n×m 행렬 곱하기 m×p 행렬은 n×p를 준다 — 인덱스를 바꾸는 것이 고전적인 무음 오류다.

파스칼의 삼각형 항목
\[T(r,k) = T(r-1,k-1) + T(r-1,k)\]
가장자리는 1; 각 내부 항목은 위의 두 항목의 합
행렬 곱셈
\[C[i][j] = \sum_{k} A[i][k]\,B[k][j]\]
공유 내부 차원 k에 대한 합

09파일 및 간단한 데이터 처리

with 블록 내에서 파일을 열어 무언가 실패하더라도 닫히도록 하라. 읽기는 후행 줄 바꿈을 포함한 줄을 제공하므로 구문 분석 시 먼저 strip()하고 두 번째로 split()하라. 쓰기는 문자 그대로다: print는 줄 바꿈을 추가하지만 file.write()는 추가하지 않으므로 "\n"을 직접 추가하라.

실제 데이터는 지저분하다. 토큰이 숫자처럼 보이는지 확인한 후에만 숫자로 변환하고, 충돌하는 대신 유효하지 않은 단어를 건너뛰어라.

표 형식 데이터의 경우 csv 모듈 또는 데이터프레임 라이브러리가 취약한 수동 분할을 크게 줄여준다. 구문 분석을 보고와 분리하여 각 부분을 개별적으로 테스트할 수 있게 하라.

10모듈, 라이브러리 및 더 큰 도구 상자

모듈은 재사용 가능한 정의의 파일이다: import math는 라이브러리를 가져오고, math.sqrt(x)는 다시 구현하지 않고 하나의 함수를 호출한다. 표준 라이브러리는 무작위성, 날짜, 파일 경로를 다루며, pandas 및 matplotlib과 같은 타사 패키지는 표 형식 데이터를 몇 줄로 분석 및 차트로 변환한다.

라이브러리가 기본을 제거하지는 않는다 — 여전히 타입을 선택하고, 올바르게 반복하며, 입력을 검증해야 한다. 라이브러리 호출을 이름을 붙이고 테스트할 수 있는 블랙 박스로 취급하되, 데이터의 의미를 아는 것의 대체물로 취급하지 마라.

작업이 라이브러리를 금지할 때는 기본 논리를 직접 시연하라는 요청이므로, 가져왔을 루프를 직접 작성하라.

pandas로 테이블 읽기
df = pd.read_csv('counting.csv') df.plot()
라이브러리가 데이터를 구문 분석, 저장, 플롯한다; 당신의 일은 결과를 확인하는 것이다

11디버깅은 기술이지 운이 아니다

트레이스백을 아래에서 위로 읽어라: 마지막 줄은 오류 이름을 지정하고, 그 위의 줄은 발생 위치를 보여준다. 찾을 수 있는 가장 작은 입력으로 실패를 재현한 다음, 두 지점에서 값을 인쇄하고 처음으로 불일치하는 곳을 질문하여 영역을 좁혀라.

경계를 의도적으로 확인하라 — 빈 입력, 단일 항목, 최대 허용 값. 대부분의 초보자 버그는 오프바이원 오류, 누락된 변환 또는 다음 함수에 의해 변경된 리스트다.

통과해야 하는 작은 테스트를 하나 작성하고 모든 변경 후에 다시 실행하라.

Key terms

변수
객체를 참조하는 이름으로, 타입은 미리 선언되지 않고 런타임에 결정된다.
불변

재귀
함수가 더 작은 입력에 대해 자신을 호출하는 기법으로, 기저 사례에 의해 중지된다.
딕셔너리
키에서 값으로의 변경 가능한 매핑으로, 중괄호로 작성하고 대괄호로 읽는다.
트레이스백

슬라이스
시퀀스의 연속된 섹션의 복사본으로, 시작, 중지 및 선택적 단계 인덱스로 작성된다.
모듈
프로그램이 가져와 이름으로 호출할 수 있는 재사용 가능한 정의의 파일.
Worked example

자릿수 합 함수 추적

이 함수를 손으로 추적하고 digit_sum(274) 호출에 대해 반환하는 값을 명시하라: def digit_sum(n): total = 0 while n > 0: total = total + n % 10 n = n // 10 return total print(digit_sum(274))

  1. 시작: n = 274이고 total = 0. 루프 테스트 274 > 0은 참이다.
  2. 첫 번째 패스: total = 0 + (274 % 10) = 0 + 4 = 4, 그리고 n = 274 // 10 = 27.
  3. 두 번째 패스: total = 4 + (27 % 10) = 4 + 7 = 11, 그리고 n = 27 // 10 = 2.
  4. 세 번째 패스: total = 11 + (2 % 10) = 11 + 2 = 13, 그리고 n = 2 // 10 = 0.
  5. 루프 테스트: 0 > 0은 거짓이므로 루프가 중지되고 함수는 total = 13을 반환한다.
Answer함수는 13을 반환한다. 온당성 검사: 274의 자릿수는 2, 7, 4이고 그 합은 13이며, 이는 추적과 일치한다.

Exam method

  • 종이에 변수당 하나의 열로 루프를 추적하라; 머릿속으로 코드를 실행하려고 하지 마라.
  • 산술 연산 전에 입력을 올바른 타입으로 변환하라 — 이것이 가장 흔히 잃는 단일 점수다.
  • 오류 메시지를 마지막 줄에서 위로 읽고 한 번에 하나의 오류를 수정하라.
  • 경계 사례를 테스트하라: 빈 입력, 하나의 항목, 최대 허용 값.
  • 질문이 find() 또는 count()를 금지할 때는 직접 루프를 작성하라: 카운터를 초기화하고, 문자를 순회하며, 조건에 따라 업데이트하라.

Q01Python 3에서 내장 함수 input()은 무엇을 반환하는가?

Whyinput()은 항상 텍스트를 반환한다; 프로그램은 산술 연산 전에 int() 또는 float()로 변환해야 한다.

Q0217 // 5의 값은 무엇인가?

Why//는 바닥 나눗셈을 수행하여 정수 부분 3을 제공한다; 일반 나눗셈은 3.4를 줄 것이다.

Q03다음 중 생성 후 변경할 수 없는 컨테이너는 무엇인가?

Why튜플은 변경 불가능한 반면, 리스트와 딕셔너리는 제자리 변경을 지원한다.

Q04file.write()에 대한 설명으로 올바른 것은?

Whyprint()는 줄 바꿈을 추가하지만 file.write()는 추가하지 않는다; 작성자가 줄 바꿈 문자를 추가해야 한다.

Q05text = 'abcdefg'일 때 text[2:5]는 무엇을 반환하는가?

Why슬라이스는 시작 인덱스를 포함하고 중지 인덱스를 제외하므로 인덱스 2, 3, 4는 문자 c, d, e를 제공한다.

Q06Python 문자열에 대한 설명으로 올바른 것은?

Why문자열은 변경 불가능하다: strip() 및 upper()와 같은 메서드는 새 문자열을 반환하며, append()와 같은 제자리 메서드는 존재하지 않는다.
