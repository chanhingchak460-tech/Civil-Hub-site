一門入門課程，教你像程式設計師一樣思考：儲存數值、控制決策、重複工作、將邏輯封裝成函數，以及透過檔案傳遞資料。這些習慣會延續到之後每一個電腦學科。

進度只儲存在此瀏覽器。

01數值、名稱與類型

變數是一個綁定到物件的名稱，而不是一個固定大小的標籤盒子。Python 在執行時決定類型：整數用 int，小數用 float，文字用 str，而 True 或 False 用 bool。不確定時可使用 type(x)，並刻意用 int()、float() 和 str() 進行轉換。

你選擇的運算子會改變結果。/ 總是產生浮點數，// 向下取整為整數，% 給出餘數，這是許多數字和奇偶技巧的基礎。

浮點數值是二進位近似值，所以測試 0.1 + 0.2 不會得到精確的 0.3；應使用容差比較而非相等比較。

商與餘數 
q, r = divmod(n, 10)
分離出最後一位數字

02輸入、輸出與格式化

input() 總是回傳字串，即使使用者輸入的是數字。進行算術運算前必須先轉換，否則 "7" + 1 會引發 TypeError 而不是得到 8。

格式化是答案的一部分。提示和輸出經常需要完全匹配，因此用 f-string 來建構它們：f"{day:02d}" 會將日期補零，f"{total:.4f}" 保留四位小數。

整潔的程式會將提示、計算和顯示分開；混在一起會使除錯和評分更加困難。

讀取數字 
n = int(input("Please enter a number: "))
input 回傳文字；進行算術前先轉換

03使用 if、elif 和 else 進行決策

條件語句選擇一條路徑，每個條件都只是一個評估為真或假的表達式。將分支從最具體到最一般排序，並且只在所有剩餘情況都屬於該分支時才加入最後的 else。

注意經典錯誤：
- = 是賦值，而 == 是比較
- and 的綁定比 or 更緊密
- 像 if name: 這樣的測試對任何非空字串都為真，這通常超出你的意圖

先將預期的情況寫成註解，然後再編碼——這個小習慣可以在大多數邏輯錯誤出現之前就消除它們。

04迴圈與累加器模式

for 迴圈遍歷序列；while 迴圈重複直到條件失敗。當項目數量已知時選擇 for，未知時選擇 while，並確保 while 條件最終能變為假——永不改變的迴圈變數會導致無限迴圈。

早期程式設計中最可重用的模式是累加器：從零開始設定總和，在迴圈內加入每個項目，迴圈結束後報告。同樣的形狀可用於計數、求和、過濾和搜尋。

保持更新行明確，以便讀者能清楚看到什麼在何時改變。

累加運行總和 
total = total + x
在迴圈前初始化 total = 0

05函數與遞迴

函數為一段邏輯賦予名稱，接受參數並回傳值。優先回傳結果而不是在函數內列印：回傳值可以被測試、重用和組合。每個函數只做一件事，並以其功能命名。

遞迴通過呼叫自身的較小版本來解決問題。每個遞迴函數都需要一個不回遞的基本情況，以及一個向基本情況推進的遞迴步驟。

斐波那契函數是標準示範，但遞迴也適用於嵌套結構，而迴圈需要自己的堆疊。

遞迴斐波那契
\[\mathrm{fib}(n) = \mathrm{fib}(n - 1) + \mathrm{fib}(n - 2)\]
基本情況為 fib(1) = fib(2) = 1

06列表、元組與字典

列表是一個有序、可變的序列，從零開始索引，因此 a[0] 是第一個項目，a[-1] 是最後一個。切片複製一個區段，而 append、sort 和 remove 會就地編輯列表。由於列表是透過引用共享的，b = a 不會複製它；b = a[:] 才會。

元組是一個不可變的序列，適用於固定組，例如座標。字典將鍵映射到值，是計數的自然結構，因為它可以延遲建立鍵，而不需要預先檢查。

嵌套列表表示矩陣：先迴圈列，再迴圈行。

使用字典計數 
counts[ch] = counts.get(ch, 0) + 1
避免單獨的成員測試
選擇容器
容器有序可變典型用途
list是是會增長和縮小的集合
tuple是否固定記錄，例如座標
dict插入順序是按鍵查找和計數
string是否文字、切片和搜尋

07字串也是序列

字串的行為像字元的元組：它是不可變的、可索引和可切片的，因此 text[2:5] 給出索引 2、3 和 4 處的字元，而 text[::-1] 將其反轉。

謂詞方法對單個字元進行分類——isalpha()、isdigit()、isspace()——並回傳可在迴圈內測試的布林值。

從部分建構輸出是一個反覆出現的模式：用 split() 將文字分割成標記，用 '-'.join(tokens) 將它們重新連接，並用 strip() 去除多餘的空白。方法回傳新字串而不是更改原始字串，因此當你想保留結果時，請賦值給變數。

在迴圈中分類字元
if ch.isdigit(): digits += 1
遍歷字串一次，並為每個字元類別更新計數器
值得記住的字串方法
方法回傳用途

08嵌套迴圈與二維數據

列表的列表表示網格或矩陣：grid[r][c] 是第 r 列、第 c 行的元素，標準遍歷是外層迴圈列，內層迴圈行。

同樣的嵌套可以列印三角形圖案，例如帕斯卡三角形，其中每個內部項目是其上方兩個項目的和。

矩陣乘法是考試熱門：乘積中第 i 列、第 j 行的元素是第一個矩陣的第 i 列與第二個矩陣的第 j 行的點積。先測試形狀——一個 n×m 矩陣乘以一個 m×p 矩陣得到 n×p——因為交換索引是經典的沉默錯誤。

帕斯卡三角形項目
\[T(r,k) = T(r-1,k-1) + T(r-1,k)\]
邊緣為 1；每個內部項目是其上方兩個項目的和
矩陣乘法
\[C[i][j] = \sum_{k} A[i][k]\,B[k][j]\]
對共享的內部維度 k 求和

09檔案與簡單數據處理

在 with 區塊內開啟檔案，以便即使發生錯誤也能關閉。讀取會給你包含尾隨換行符的行，因此解析時先 strip() 再 split()。寫入是字面的：print 會添加換行符，但 file.write() 不會，因此你需要自己添加 "\n"。

真實數據是混亂的。只有在檢查標記看起來像數字後才將其轉換為數字，並跳過無效單詞而不是崩潰。

對於表格數據，csv 模組或 dataframe 庫消除了大量脆弱的手動分割；將解析與報告分開，以便每個部分可以單獨測試。

10模組、庫與更大的工具箱

模組是一個可重用定義的檔案：import math 引入一個庫，math.sqrt(x) 呼叫一個函數而無需重新實現。標準庫涵蓋隨機性、日期和檔案路徑，而第三方套件如 pandas 和 matplotlib 可以在幾行內將表格數據轉化為分析和圖表。

庫不會移除基礎知識——你仍然需要選擇類型、正確迴圈和驗證輸入。將庫呼叫視為一個可以命名和測試的黑箱，而不是了解數據含義的替代品。

當任務禁止使用庫時，它要求你自己展示底層邏輯，因此寫出你本來會導入的迴圈。

使用 pandas 讀取表格
df = pd.read_csv('counting.csv') df.plot()
庫解析、儲存和繪製數據；你的工作是檢查結果

11除錯是一項技能，不是運氣

從下往上閱讀回溯：最後一行指出錯誤，上面一行顯示發生位置。用你能找到的最小輸入重現失敗，然後在兩個點列印值並詢問它們首次不一致的地方，以縮小範圍。

刻意檢查邊界——空輸入、單個項目和最大允許值。大多數初學者的錯誤是差一錯誤、缺少轉換或列表被下一個函數修改。

寫一個應該通過的小測試，並在每次更改後重新運行它。

計算示例

追蹤數字和函數

手動追蹤此函數並說明呼叫 digit_sum(274) 時它回傳什麼： def digit_sum(n): total = 0 while n > 0: total = total + n % 10 n = n // 10 return total print(digit_sum(274))

  1. 開始：n = 274，total = 0。迴圈測試 274 > 0 為真。
  2. 第一輪：total = 0 + (274 % 10) = 0 + 4 = 4，且 n = 274 // 10 = 27。
  3. 第二輪：total = 4 + (27 % 10) = 4 + 7 = 11，且 n = 27 // 10 = 2。
  4. 第三輪：total = 11 + (2 % 10) = 11 + 2 = 13，且 n = 2 // 10 = 0。
  5. 迴圈測試：0 > 0 為假，因此迴圈停止，函數回傳 total = 13。
Answer函數回傳 13。合理性檢查：274 的數字是 2、7 和 4，它們的和是 13，與追蹤結果相符。

應試方法

  • 在紙上追蹤迴圈，每個變數一列；不要試圖在腦海中執行程式碼。
  • 在算術前將輸入轉換為正確的類型——這是最常見的單一失分點。
  • 從最後一行向上閱讀錯誤訊息，並一次修復一個錯誤。
  • 測試邊界情況：空輸入、單個項目和最大允許值。
  • 當問題禁止使用 find() 或 count() 時，自己寫迴圈：初始化計數器，遍歷字元，並在條件成立時更新它。

Q01在 Python 3 中，內建函數 input() 回傳什麼？

解釋input() 總是回傳文字；程式必須在進行算術前用 int() 或 float() 轉換它。

Q0217 // 5 的值是什麼？

解釋// 執行向下取整除法，給出整數部分 3；普通除法會給出 3.4。

Q03以下哪個容器在創建後無法更改？

解釋元組是不可變的，而列表和字典支持就地更改。

Q04關於 file.write() 的哪個陳述是正確的？

解釋print() 會附加換行符，但 file.write() 不會；寫入者必須添加換行字元。

Q05對於 text = 'abcdefg'，text[2:5] 回傳什麼？

解釋切片包括起始索引並排除停止索引，因此索引 2、3 和 4 給出字元 c、d 和 e。

Q06關於 Python 字串的哪個陳述是正確的？

解釋字串是不可變的：像 strip() 和 upper() 這樣的方法回傳新字串，並且不存在像 append() 這樣就地修改的方法。
