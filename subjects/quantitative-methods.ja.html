01ばらつきこそがデータ

測定値は、測っている対象が変化しなくてもばらつく。したがって工学データには中心と広がりが必要である：標本平均は母平均を推定し、標本標準偏差は測定値の平均からの典型的な距離を推定する。

  • 変動係数 CV = s / x̄ は、単位や平均の異なるデータセット間のばらつきを比較する。
  • 要約には必ず標本サイズと単位を添えて報告する。
  • 広がりのない平均はリスクを隠し、平均のない広がりは尺度を持たない。この二つ組がデータセットの誠実な最小限の記述である。
標本平均
\[\bar{x} = \frac{\sum x}{n}\]
測定値の合計を標本サイズで割ったもの
標本標準偏差
\[s = \sqrt{\frac{\sum (x - \bar{x})^2}{n - 1}}\]
除数 n − 1 は標本からの推定によるバイアスを取り除く
変動係数
\[\mathrm{CV} = \frac{s}{\bar{x}}\]
相対的なばらつきの無次元尺度

02サンプリングと中心極限定理

標本は母集団を代表する場合にのみ有用である。無作為抽出、独立性、一貫した測定方法が推論を妥当にする仮定であり、偏った標本は n を大きくしても救えない。

  • 平均の標準誤差は SE = s / √n であり、標本サイズの平方根に比例して小さくなる。
  • 中心極限定理によれば、母集団の形状にかかわらず、n が大きくなるにつれて標本平均の分布は正規に近づく。
  • これが、データが正規でなくても中程度に大きな標本の平均に対して t および z の手続きが機能する理由である。
平均の標準誤差
\[\mathrm{SE} = \frac{s}{\sqrt{n}}\]
SE を半分にするには標本サイズを4倍にする必要がある

03信頼区間

信頼区間は推定値の周りに範囲を与える。母標準偏差が未知の平均の場合、区間は x̄ ± t s / √n であり、t は自由度 n − 1 の t 分布から求める。幅は信頼水準とばらつきが大きいほど広がり、標本サイズが大きいほど狭くなる。

解釈を誤りやすい。95% 区間は、μ がこの特定の区間の内側にある確率が 95% であることを意味しない。この方法で作られた区間の 95% が μ を含むという意味である。区間はパラメータを推定するものであり、個々の測定値を推定するものではない。

平均の信頼区間
\[\bar{x} \pm t\,\frac{s}{\sqrt{n}}\]
t は自由度 n − 1 の両側値

04仮説検定

仮説検定は、データが述べられた値と整合するかどうかを問う。帰無仮説 H0（効果なし、差なし）と対立仮説 H1 を設定し、有意水準 α を選び、検定統計量を計算する。平均の場合、t = (x̄ − μ0) / (s / √n) である。

  • p 値は、H0 が真であると仮定したとき、観測された結果以上に極端な結果が得られる確率である。p < α のとき H0 を棄却する。
  • 第1種の誤りは真の帰無仮説を棄却することであり、第2種の誤りは偽の帰無仮説を棄却できないことである。
  • 統計的有意性は実用的重要性ではない。微小で精密な差は有意でありながら無関係であり得る。
1標本 t 統計量
\[t = \frac{\bar{x} - \mu_0}{s/\sqrt{n}}\]
μ0 は仮説された平均；df = n − 1

052つの母集団の比較

2つの設計、2つの供給者、2つの養生方法は、その平均によって比較される。

  • 分散が同程度の独立標本の場合、標準偏差をプールし、2標本 t 検定を用いる。自由度は n1 + n2 − 2 である。
  • 対応のある観測（同じ供試体の前後、またはマッチングされたペア）の場合、差を検定する。これによりペア間のばらつきが取り除かれる。
  • p 値だけでなく、推定された差を信頼区間とともに報告する。
  • 0.2 MPa の有意な差は実在しても、仕様を変えるには小さすぎるかもしれない。区間は効果の大きさと精度の両方を示す。
プール分散
\[s_p^2 = \frac{(n_1 - 1)s_1^2 + (n_2 - 1)s_2^2}{n_1 + n_2 - 2}\]
2つの母集団の分散が同程度であると仮定する
2標本 t 統計量
\[t = \frac{\bar{x}_1 - \bar{x}_2}{s_p \sqrt{\frac{1}{n_1} + \frac{1}{n_2}}}\]
プール検定では df = n1 + n2 − 2

06ANOVA と計画実験

3つ以上の平均を比較するには、偽陽性の可能性を膨らませる t 検定の繰り返しではなく、分散分析を用いる。一元配置 ANOVA は全変動を群平均間の変動と群内の変動に分割する。F 比はそれらを比較し、大きな F は少なくとも1つの平均が異なることを示唆する。有意な F はどれが異なるかを示さない——事後比較がそれを示す。

  • 計画実験はさらに進む：実験順序を無作為化し、反復し、既知の nuisance 変動源をブロック化する。
  • 因子実験では因子水準のすべての組み合わせが試験されるため、主効果と交互作用を推定できる。
  • 交互作用とは、ある因子の効果が別の因子の水準に依存することを意味する。
F 比、一元配置 ANOVA
\[F = \frac{\mathrm{MS}_{\text{between}}}{\mathrm{MS}_{\text{within}}}\]
大きな F は群間変動が群内変動を支配していることを意味する
一元配置 ANOVA 表
変動源平方和自由度平均平方F
群間SSBk − 1MSB = SSB / (k − 1)F = MSB / MSW
群内SSWN − kMSW = SSW / (N − k)—
合計SSTN − 1——

07回帰と予測

回帰は応答 y と1つ以上の説明変数 x の関係を当てはめる。最小二乗直線 y = a + b x は残差平方和を最小化し、傾き b = S_xy / S_xx、切片 a = ȳ − b x̄ である。

  • 決定係数 r² はモデルによって説明される全変動の割合である。
  • 高い r² は因果関係を証明せず、観測範囲外での良好な予測を保証しない。
  • 残差に曲率、広がりの変化、外れ値がないか確認する。残差にパターンがあれば、モデルに何かが欠けている。
最小二乗傾き
\[b = \frac{S_{xy}}{S_{xx}}\]
S_xy は共分散和；S_xx は x の偏差の二乗和
決定係数
\[r^2 = 1 - \frac{\mathrm{SS}_{\mathrm{res}}}{\mathrm{SS}_{\mathrm{tot}}}\]
当てはめたモデルによって説明される変動の割合

08品質管理と工程能力

管理図は、工程に組み込まれた共通原因変動と、何かが変化したことを示す特殊原因変動を分離する。

  • 平均管理図は中心線の両側に3標準誤差の管理限界を置いて標本平均をプロットし、範囲管理図はばらつきを追跡する。
  • 限界外の点、または片側に連続する点は、すべての測定値を調整するのではなく調査を促す。
  • 工程能力は仕様と工程の広がりを比較する：Cp = (USL − LSL) / (6σ)、Cpk は工程が中心からずれていることを考慮する。
  • 能力のある工程は精密かつ中心化されている。高い Cp と低い Cpk は、広がりは問題ないが設定が間違っていることを意味する。
平均管理図の管理限界
\[\mathrm{UCL},\, \mathrm{LCL} = \bar{x} \pm \frac{3\sigma}{\sqrt{n}}\]
σ は工程標準偏差、n は部分群サイズ
工程能力
\[C_p = \frac{\mathrm{USL} - \mathrm{LSL}}{6\sigma}\]
USL と LSL は上限および下限仕様限界

09カイ二乗検定：度数が語ること

すべての問いが平均に関するものではない。データがカテゴリ内の度数である場合、カイ二乗の枠組みが t 検定と F 検定に取って代わる。

  • 適合度検定は観測度数が仮説分布に従うかを問い、独立性検定は2つのカテゴリ変数が関連するかを度数の二次元表を用いて問う。
  • どちらも観測度数を帰無仮説の下での期待度数と比較し、どちらも片側である：大きな不一致のみが問題となる。
  • 仮定が弱点である——カテゴリは相互排他的でなければならず、すべての期待度数は少なくとも5であるべきなので、検定前に疎なカテゴリを統合する。
カイ二乗統計量
\[\chi^2 = \sum_i \frac{(O_i - E_i)^2}{E_i}\]
大きな値は帰無モデルとの一致の悪さを示す
自由度
\[\text{fit: } k - 1 - m; \qquad \text{table: } (r-1)(c-1)\]
m はデータから推定されたパラメータの数
観測度数ではなく期待度数 カイ二乗近似には各セルでおおよそ5以上の期待度数が必要である。それ未満の場合はカテゴリを統合し、新しい自由度を明記する。

10重回帰

ほとんどの工学的応答には複数の要因があるため、モデルは y = β₀ + β₁x₁ + β₂x₂ + … + ε となる。各係数は偏効果である：他の予測変数を固定したときの、その予測変数の1単位増加あたりの y の期待変化量。これは単純な2変数傾きとは異なる量であり、両者を混同することは典型的な試験の誤りである。

  • 通常の R² は予測変数を追加するたびに上昇する（無用なものでも）ため、重回帰では各追加パラメータにペナルティを与える調整済み R² を報告すべきである。
  • 多重共線性——予測変数が強く相関しすぎてモデルがその効果を分離できない状態——を相関や分散膨張係数によって確認する。
  • 個々の係数を分析する前に、全体の F 検定でモデル全体を検定する。
重回帰モデル
\[y = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + \cdots + \varepsilon\]
調整済み決定係数
\[\bar{R}^2 = 1 - \frac{(1 - R^2)(n - 1)}{n - k - 1}\]
k 個の予測変数；予測変数がその地位に値する場合にのみ上昇する

11検出力、効果量、研究の計画

重要な効果を検出する機会がなかった研究では、非有意な結果はほとんど意味を持たない。検出力は、特定の対立仮説が真であるときに H₀ を棄却する確率であり、4つの量によって決まる：有意水準 α、真の効果量 δ、ノイズ σ、標本サイズ n。

  • 両側 z 検定の場合、必要な標本はおよそ (z_(α/2) + z_β)² σ² / δ² である。ここで 1 − β は目標検出力である。
  • この式を予算として読む：検出しなければならない差を半分にすると標本は4倍になり、よりクリーンな測定方法（より小さな σ）は反復回数を増やすのと同じくらい価値がある。
  • 棄却できなかった場合は常に、検出力と仮定した効果量を述べる。
両側 z 検定の標本サイズ
\[n \approx \frac{(z_{\alpha/2} + z_\beta)^2 \sigma^2}{\delta^2}\]
β は第2種の誤り率なので、1 − β が検出力

Key terms

標準誤差
推定量の標本分布の標準偏差であり、標本が母集団の値をどれだけ精密に推定するかを示す。
信頼区間
データから構築される値の範囲であり、繰り返し標本のうち定められた割合で真のパラメータを含む。
p 値
帰無仮説が真であると仮定したとき、データ以上に極端な結果が観測される確率。
第1種の誤り
実際には真である帰無仮説を棄却すること。その確率は有意水準 α である。
ANOVA
分散分析。全変動を群間と群内の部分に分割することで複数の群平均を比較する方法。
決定係数
回帰モデルによって説明される応答変動の割合であり、r² と書く。
適合度検定
観測度数が仮説分布またはモデルと一致するかどうかのカイ二乗検定。
検出力
指定された対立仮説が真であるときに、仮説検定が帰無仮説を棄却する確率。
Worked example

2つの養生方法の比較

2つの養生方法をそれぞれ10個のコンクリート立方体で比較する。方法 A は平均強度 42.1 MPa、標準偏差 2.0 MPa を与え、方法 B は 40.3 MPa、標準偏差 1.8 MPa を与える。平均強度が異なるかどうかを5%有意水準で検定せよ。自由度18の臨界 t 値を 2.101 とする。

  1. 仮説を述べる：H0: μA = μB；H1: μA ≠ μB。両側検定で α = 0.05、df = 10 + 10 − 2 = 18 を用いる。
  2. プール分散：s_p² = [(9)(2.0²) + (9)(1.8²)] / 18 = (36.0 + 29.16) / 18 = 3.62、よって s_p = 1.90 MPa。
  3. 差の標準誤差：s_p √(1/10 + 1/10) = 1.90 × 0.447 = 0.850 MPa。
  4. 検定統計量：t = (42.1 − 40.3) / 0.850 = 2.12。
  5. |t| = 2.12 は臨界値 2.101 より大きいので、H0 を棄却する。差は統計的に有意であるが、わずか 1.8 MPa であるため、実用的有意性には工学的判断が必要である。
Answer5%水準で H0 を棄却する：平均強度は有意に異なる（t = 2.12、df = 18、p は 0.05 をわずかに下回る）。推定された差は 1.8 MPa であり、より大きな標本ならより精密な推定が得られる。

Exam method

  • 電卓に触れる前に H0、H1、α を述べる。検定問題の得点の大半は正しい設定から来る。
  • 信頼区間は、パラメータがこの区間の内側にある確率としてではなく、繰り返しサンプリングの観点で解釈する。
  • t や F の結果を信頼する前に、独立性、正規性、等分散の仮定を確認する。
  • 有意な ANOVA の F は少なくとも1つの平均が異なることを示すが、どれかを示すわけではない。結論でそう述べる。
  • 重回帰では、解釈するすべての係数の横に「他の予測変数を固定したとき」と書き添える。
