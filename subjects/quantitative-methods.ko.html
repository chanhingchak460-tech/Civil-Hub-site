01변동이 곧 데이터다

측정값은 측정 대상이 변하지 않더라도 변한다. 따라서 공학 데이터에는 중심과 산포가 필요하다: 표본평균은 모평균을 추정하고, 표본표준편차는 측정값이 그 평균으로부터 떨어진 전형적 거리를 추정한다.

  • 변동계수 CV = s / x̄는 단위나 평균이 다른 데이터셋 간의 변동성을 비교한다.
  • 요약값과 함께 항상 표본 크기와 단위를 보고하라.
  • 산포 없는 평균은 위험을 감추고, 평균 없는 산포는 규모가 없다. 이 둘의 조합이 데이터셋에 대한 최소한의 정직한 기술이다.
표본평균
\[\bar{x} = \frac{\sum x}{n}\]
측정값의 합을 표본 크기로 나눈 값
표본표준편차
\[s = \sqrt{\frac{\sum (x - \bar{x})^2}{n - 1}}\]
나눗셈 인자 n − 1은 표본에서 추정할 때의 편향을 제거한다
변동계수
\[\mathrm{CV} = \frac{s}{\bar{x}}\]
상대적 변동성을 나타내는 무차원 척도

02표본추출과 중심극한정리

표본은 모집단을 대표할 때만 유용하다. 무작위 선택, 독립성, 일관된 측정 방법이 추론을 타당하게 만드는 가정이다. 편향된 표본은 n을 늘려도 구제할 수 없다.

  • 평균의 표준오차는 SE = s / √n이며, 표본 크기의 제곱근에 비례하여 줄어든다.
  • 중심극한정리에 따르면 모집단의 모양과 관계없이 n이 커질수록 표본평균의 분포는 정규분포에 가까워진다.
  • 이것이 데이터가 정규분포가 아니더라도 적당히 큰 표본의 평균에 t 및 z 절차가 작동하는 이유다.
평균의 표준오차
\[\mathrm{SE} = \frac{s}{\sqrt{n}}\]
SE를 절반으로 줄이려면 표본 크기가 네 배 필요하다

03신뢰구간

신뢰구간은 추정값 주위에 범위를 설정한다. 모표준편차를 모르는 평균의 경우 구간은 x̄ ± t s / √n이며, 여기서 t는 자유도 n − 1인 t 분포에서 나온다. 구간의 폭은 신뢰수준과 변동성이 클수록 커지고, 표본 크기가 클수록 작아진다.

해석은 틀리기 쉽다. 95% 구간은 μ가 이 특정 구간 안에 있을 확률이 95%라는 뜻이 아니다. 이런 방식으로 만든 구간의 95%가 μ를 포함한다는 뜻이다. 구간은 개별 측정값이 아니라 모수를 추정한다.

평균의 신뢰구간
\[\bar{x} \pm t\,\frac{s}{\sqrt{n}}\]
t는 자유도 n − 1에 대한 양측 값이다

04가설검정

가설검정은 데이터가 주어진 값과 일치하는지 묻는다. 귀무가설 H0(효과 없음, 차이 없음)와 대립가설 H1을 설정하고, 유의수준 α를 선택한 뒤 검정통계량을 계산한다. 평균의 경우 t = (x̄ − μ0) / (s / √n)이다.

  • p값은 H0가 참이라고 가정할 때 관측된 결과만큼 또는 그보다 극단적인 결과가 나올 확률이다. p < α이면 H0를 기각한다.
  • 제1종 오류는 참인 귀무가설을 기각하는 것이고, 제2종 오류는 거짓인 귀무가설을 기각하지 못하는 것이다.
  • 통계적 유의성은 실질적 중요성이 아니다. 아주 작고 정밀한 차이는 유의하면서도 여전히 무관할 수 있다.
단일표본 t 통계량
\[t = \frac{\bar{x} - \mu_0}{s/\sqrt{n}}\]
μ0는 가설로 설정한 평균이며, df = n − 1이다

05두 모집단 비교

두 설계, 두 공급업체 또는 두 양생 방법을 평균으로 비교한다.

  • 분산이 비슷한 독립표본의 경우 표준편차를 합동으로 추정하고 이표본 t 검정을 사용한다. 자유도는 n1 + n2 − 2이다.
  • 대응 관측값(같은 시편의 전후, 또는 짝지은 쌍)의 경우 차이를 검정하며, 이는 쌍 간 변동성을 제거한다.
  • p값만이 아니라 추정된 차이를 신뢰구간과 함께 보고하라.
  • 0.2 MPa의 유의한 차이는 실제일 수 있지만 사양을 바꾸기에는 너무 작을 수 있다. 구간은 효과의 크기와 정밀도를 모두 보여준다.
합동분산
\[s_p^2 = \frac{(n_1 - 1)s_1^2 + (n_2 - 1)s_2^2}{n_1 + n_2 - 2}\]
두 모집단의 분산이 비슷하다고 가정한다
이표본 t 통계량
\[t = \frac{\bar{x}_1 - \bar{x}_2}{s_p \sqrt{\frac{1}{n_1} + \frac{1}{n_2}}}\]
합동 검정의 df = n1 + n2 − 2

06ANOVA와 실험계획

세 개 이상의 평균을 비교하려면 반복된 t 검정 대신 분산분석을 사용해야 한다. 반복된 t 검정은 거짓 양성이 나올 가능성을 높인다. 일원배치 ANOVA는 전체 변동을 집단 평균 간 변동과 집단 내 변동으로 나눈다. F 비율은 이 둘을 비교하며, 큰 F는 적어도 하나의 평균이 다르다는 것을 시사한다. 유의한 F는 어느 평균이 다른지는 말해주지 않는다. 사후 비교가 그 역할을 한다.

  • 실험계획은 더 나아간다: 실험 순서를 무작위화하고, 반복하고, 알려진 방해 변동 원인을 블록화한다.
  • 요인배치 실험에서는 요인 수준의 모든 조합을 시험하므로 주효과와 상호작용을 추정할 수 있다.
  • 상호작용은 한 요인의 효과가 다른 요인의 수준에 의존한다는 뜻이다.
F 비율, 일원배치 ANOVA
\[F = \frac{\mathrm{MS}_{\text{between}}}{\mathrm{MS}_{\text{within}}}\]
큰 F는 집단 간 변동이 집단 내 변동을 지배한다는 뜻이다

07회귀분석과 예측

회귀분석은 반응변수 y와 하나 이상의 설명변수 x 사이의 관계를 적합한다. 최소제곱 직선 y = a + b x는 잔차 제곱합을 최소화하며, 기울기 b = S_xy / S_xx이고 절편 a = ȳ − b x̄이다.

  • 결정계수 r²는 모형이 설명하는 전체 변동의 비율이다.
  • 높은 r²는 인과관계를 증명하지 않으며, 관측 범위 밖에서 좋은 예측을 보장하지도 않는다.
  • 잔차에서 곡률, 변동 폭의 변화, 이상치를 확인하라. 잔차에 패턴이 있으면 모형이 무언가를 놓치고 있다는 뜻이다.
최소제곱 기울기
\[b = \frac{S_{xy}}{S_{xx}}\]
S_xy는 공분산 합이고, S_xx는 x 편차 제곱합이다
결정계수
\[r^2 = 1 - \frac{\mathrm{SS}_{\mathrm{res}}}{\mathrm{SS}_{\mathrm{tot}}}\]
적합된 모형이 설명하는 변동의 비율

08품질관리와 공정능력

관리도는 공정에 내재된 우연원인 변동과 무언가가 변했음을 알리는 이상원인 변동을 구분한다.

  • 평균 관리도는 중심선 양쪽 3표준오차에 관리한계를 두고 표본평균을 도시하며, 범위 관리도는 변동성을 추적한다.
  • 관리한계를 벗어난 점이나 한쪽에 연속으로 나타난 점은 모든 측정값을 조정하기보다 원인 조사를 촉구한다.
  • 공정능력은 규격과 공정 산포를 비교한다: Cp = (USL − LSL) / (6σ)이며, Cpk는 공정이 중심에서 벗어난 것을 반영한다.
  • 능력 있는 공정은 정밀하면서도 중심에 맞춰져 있다. Cp는 높지만 Cpk가 낮다면 산포는 괜찮지만 설정이 잘못되었다는 뜻이다.
평균 관리도의 관리한계
\[\mathrm{UCL},\, \mathrm{LCL} = \bar{x} \pm \frac{3\sigma}{\sqrt{n}}\]
σ는 공정 표준편차이고 n은 부분군 크기이다
공정능력
\[C_p = \frac{\mathrm{USL} - \mathrm{LSL}}{6\sigma}\]
USL과 LSL은 상한 및 하한 규격한계이다

09카이제곱 검정: 도수(개수)가 말하는 것

모든 질문이 평균에 관한 것은 아니다. 데이터가 범주별 도수(개수)일 때는 카이제곱 체계가 t 및 F 검정을 대체한다.

  • 적합도 검정은 관측도수가 가설화된 분포를 따르는지 묻고, 독립성 검정은 두 범주형 변수가 관련이 있는지 도수 교차표를 사용해 묻는다.
  • 둘 다 관측도수를 귀무가설 아래의 기대도수와 비교하며, 둘 다 단측 검정이다: 큰 불일치만 문제가 된다.
  • 가정이 약점이다. 범주는 상호배타적이어야 하고, 모든 기대도수는 최소 5 이상이어야 하므로 검정 전에 희소 범주를 병합하라.
카이제곱 통계량
\[\chi^2 = \sum_i \frac{(O_i - E_i)^2}{E_i}\]
큰 값은 귀무 모형과의 일치가 나쁘다는 것을 나타낸다
자유도
\[\text{fit: } k - 1 - m; \qquad \text{table: } (r-1)(c-1)\]
m은 데이터에서 추정한 모수의 개수이다
관측도수가 아니라 기대도수 카이제곱 근사에는 모든 셀의 기대도수가 대략 5 이상이어야 한다. 일부가 그보다 작으면 범주를 병합하고 새로운 자유도를 명시하라.

10다중회귀

대부분의 공학 반응에는 여러 동인이 있으므로 모형은 y = β₀ + β₁x₁ + β₂x₂ + … + ε이 된다. 각 계수는 편효과다. 즉 다른 예측변수를 고정했을 때 해당 예측변수가 한 단위 증가할 때 y의 기대 변화량이다. 이는 단순 이변수 기울기와 다른 양이며, 둘을 혼동하는 것은 전형적인 시험 실수다.

  • 단순 R²는 쓸모없는 예측변수를 추가해도 항상 증가하므로, 다중회귀에서는 추가 모수마다 벌점을 주는 수정 R²를 제시해야 한다.
  • 다중공선성(예측변수들이 너무 강하게 상관되어 모형이 그 효과를 분리할 수 없는 상태)을 상관계수나 분산팽창계수로 확인하라.
  • 개별 계수를 분석하기 전에 전체 F 검정으로 모형 전체를 검정하라.
다중회귀 모형
\[y = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + \cdots + \varepsilon\]
수정 결정계수
\[\bar{R}^2 = 1 - \frac{(1 - R^2)(n - 1)}{n - k - 1}\]
k개의 예측변수; 예측변수가 제 역할을 할 때만 증가한다

11검정력, 효과 크기, 연구 계획

연구가 중요한 효과를 탐지할 가능성이 없었다면 유의하지 않은 결과는 의미가 거의 없다. 검정력은 특정 대립가설이 참일 때 H₀를 기각할 확률이며, 네 가지 양에 의해 결정된다: 유의수준 α, 실제 효과 크기 δ, 잡음 σ, 표본 크기 n.

  • 양측 z 검정의 경우 필요한 표본은 대략 (z_(α/2) + z_β)² σ² / δ²이며, 여기서 1 − β가 목표 검정력이다.
  • 이 공식을 예산으로 읽어라: 탐지해야 하는 차이를 절반으로 줄이면 표본은 네 배가 되고, 더 깨끗한 측정 방법(작은 σ)은 반복 횟수를 늘리는 것만큼 가치가 있다.
  • 기각하지 못할 때는 항상 검정력과 가정한 효과 크기를 명시하라.
양측 z 검정의 표본 크기
\[n \approx \frac{(z_{\alpha/2} + z_\beta)^2 \sigma^2}{\delta^2}\]
β는 제2종 오류율이므로 1 − β가 검정력이다

Key terms

표준오차
추정량의 표본분포 표준편차로, 표본이 모집단 값을 얼마나 정밀하게 추정하는지 보여준다.
신뢰구간
데이터로부터 구성되며, 반복 표본추출에서 정해진 비율만큼 참 모수를 포함하게 되는 값의 범위.
p값
귀무가설이 참이라고 가정할 때 데이터만큼 또는 그보다 극단적인 결과를 관측할 확률.
제1종 오류
실제로 참인 귀무가설을 기각하는 것; 그 확률은 유의수준 α이다.
ANOVA
분산분석. 전체 변동을 집단 간 변동과 집단 내 변동으로 나누어 여러 집단 평균을 비교하는 방법.
결정계수
회귀모형이 설명하는 반응변수 변동의 비율로, r²로 표기한다.
적합도 검정
관측도수가 가설화된 분포나 모형과 일치하는지 검정하는 카이제곱 검정.
검정력
명시된 대립가설이 참일 때 가설검정이 귀무가설을 기각할 확률.
Worked example

두 양생 방법 비교

두 양생 방법을 각각 콘크리트 큐브 10개로 비교한다. 방법 A는 평균 강도 42.1 MPa, 표준편차 2.0 MPa이고, 방법 B는 40.3 MPa, 표준편차 1.8 MPa이다. 평균 강도가 다른지 5% 유의수준에서 검정하라. 자유도 18에 대한 임계 t 값을 2.101로 한다.

  1. 가설을 설정한다: H0: μA = μB; H1: μA ≠ μB. α = 0.05, 양측검정, df = 10 + 10 − 2 = 18을 사용한다.
  2. 합동분산: s_p² = [(9)(2.0²) + (9)(1.8²)] / 18 = (36.0 + 29.16) / 18 = 3.62이므로 s_p = 1.90 MPa이다.
  3. 차이의 표준오차: s_p √(1/10 + 1/10) = 1.90 × 0.447 = 0.850 MPa.
  4. 검정통계량: t = (42.1 − 40.3) / 0.850 = 2.12.
  5. |t| = 2.12가 임계값 2.101보다 크므로 H0를 기각한다. 차이는 통계적으로 유의하지만 1.8 MPa에 불과하므로 실질적 유의성은 공학적 판단이 필요하다.
Answer5% 수준에서 H0를 기각한다: 평균 강도는 유의하게 다르다(t = 2.12, df = 18, p는 0.05보다 약간 작음). 추정된 차이는 1.8 MPa이며, 표본이 더 크면 더 정밀한 추정이 가능하다.

Exam method

  • 계산기를 만지기 전에 H0, H1, α를 명시하라. 시험 문제의 대부분의 배점은 올바른 설정에서 나온다.
  • 신뢰구간은 모수가 이 구간 안에 있을 확률이 아니라 반복 표본추출의 관점에서 해석하라.
  • t 또는 F 결과를 신뢰하기 전에 독립성, 정규성, 등분산성 가정을 확인하라.
  • 유의한 ANOVA F는 적어도 하나의 평균이 다르다는 것을 말할 뿐, 어느 것인지는 말하지 않는다. 결론에서 이를 밝혀라.
  • 다중회귀에서 해석하는 모든 계수 옆에 '다른 예측변수를 고정했을 때'라는 말을 써 넣어라.
