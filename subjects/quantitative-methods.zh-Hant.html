工程師如何從有限的數據中得出結論：抽樣、置信區間、假設檢驗、設計實驗和迴歸分析。這是一門在測量數據有噪聲時保持決策誠實的學科。

進度只儲存在此瀏覽器。

01變異就是數據

測量值會變異，即使被測量的對象本身不變。因此，工程數據需要一個中心和一個離散度：樣本均值估計總體均值，樣本標準差估計讀數與該均值的典型距離。

  • 變異係數 CV = s / x̄ 用於比較不同單位或不同均值的數據集之間的變異性。
  • 始終在摘要中報告樣本量和單位。
  • 沒有離散度的均值掩蓋了風險，沒有均值的離散度缺乏尺度；兩者是對數據集的最低限度誠實描述。
樣本均值
\[\bar{x} = \frac{\sum x}{n}\]
讀數之和除以樣本量
樣本標準差
\[s = \sqrt{\frac{\sum (x - \bar{x})^2}{n - 1}}\]
除數 n − 1 消除了從樣本估計的偏差
變異係數
\[\mathrm{CV} = \frac{s}{\bar{x}}\]
無單位的相對變異性度量

02抽樣與中心極限定理

樣本只有在代表總體時才有用。隨機選擇、獨立性和一致的測量方法是使推論有效的假設；有偏的樣本無法通過增大 n 來挽救。

  • 均值的標準誤為 SE = s / √n，它隨樣本量的平方根減小。
  • 中心極限定理指出，無論總體分佈的形狀如何，隨著 n 增大，樣本均值的分佈趨近於正態分佈。
  • 這就是為什麼 t 和 z 程序適用於中等大樣本的均值，即使數據不服從正態分佈。
均值的標準誤
\[\mathrm{SE} = \frac{s}{\sqrt{n}}\]
將 SE 減半需要四倍的樣本量

03置信區間

置信區間在估計值周圍給出一個範圍。對於總體標準差未知的均值，區間為 x̄ ± t s / √n，其中 t 來自自由度為 n − 1 的 t 分佈。區間寬度隨置信水平和變異性增大，隨樣本量減小。

解釋很容易出錯。95% 區間並不意味著 μ 落在這個特定區間內的概率是 95%；而是說，用這種方法構建的區間中有 95% 會包含 μ。區間估計的是參數，不是單個讀數。

均值的置信區間
\[\bar{x} \pm t\,\frac{s}{\sqrt{n}}\]
t 是自由度為 n − 1 的雙尾值

04假設檢驗

假設檢驗詢問數據是否與一個陳述值一致。設定原假設 H0（無效應、無差異）和備擇假設 H1，選擇顯著性水平 α，並計算檢驗統計量。對於均值，t = (x̄ − μ0) / (s / √n)。

  • p 值是在 H0 為真的假設下，觀察到至少與觀測結果一樣極端的結果的概率；當 p < α 時拒絕 H0。
  • 第一類錯誤是拒絕了真實的原假設；第二類錯誤是未能拒絕錯誤的原假設。
  • 統計顯著性不等於實際重要性：一個微小但精確的差異可能顯著但仍然無關緊要。
單樣本 t 統計量
\[t = \frac{\bar{x} - \mu_0}{s/\sqrt{n}}\]
μ0 是假設的均值；df = n − 1

05比較兩個總體

通過均值比較兩種設計、兩個供應商或兩種養護方法。

  • 對於方差相似的獨立樣本，合併標準差並使用雙樣本 t 檢驗；自由度為 n1 + n2 − 2。
  • 對於配對觀測——同一試件的前後對比，或匹配對——檢驗差異，這消除了對間變異性。
  • 報告估計差異及其置信區間，而不僅僅是 p 值。
  • 0.2 MPa 的顯著差異可能是真實的，但太小而無法改變規範；區間顯示了效應的大小和精度。
合併方差
\[s_p^2 = \frac{(n_1 - 1)s_1^2 + (n_2 - 1)s_2^2}{n_1 + n_2 - 2}\]
假設兩個總體具有相似的方差
雙樣本 t 統計量
\[t = \frac{\bar{x}_1 - \bar{x}_2}{s_p \sqrt{\frac{1}{n_1} + \frac{1}{n_2}}}\]
合併檢驗的 df = n1 + n2 − 2

06方差分析與設計實驗

要比較三個或更多均值，使用方差分析而不是重複的 t 檢驗，後者會增加假陽性的機會。單因素方差分析將總變異分解為組間均值和組內變異；F 比率比較它們，大的 F 值表明至少有一個均值不同。顯著的 F 並不能說明是哪一個——事後比較可以。

  • 設計實驗更進一步：隨機化運行順序、重複，並區組已知的干擾變異來源。
  • 在因子實驗中，測試因子水平的每個組合，因此可以估計主效應和交互作用。
  • 交互作用意味著一個因子的效應取決於另一個因子的水平。
F 比率，單因素方差分析
\[F = \frac{\mathrm{MS}_{\text{between}}}{\mathrm{MS}_{\text{within}}}\]
大的 F 意味著組間變異主導組內變異
單因素方差分析表
來源平方和自由度均方F
組間SSBk − 1MSB = SSB / (k − 1)F = MSB / MSW
組內SSWN − kMSW = SSW / (N − k)—
總計SSTN − 1——

07迴歸與預測

迴歸擬合響應變量 y 與一個或多個解釋變量 x 之間的關係。最小二乘線 y = a + b x 最小化殘差平方和，斜率 b = S_xy / S_xx，截距 a = ȳ − b x̄。

  • 決定係數 r² 是模型解釋的總變異比例。
  • 高 r² 不能證明因果關係，也不能保證在觀測範圍之外有好的預測。
  • 檢查殘差是否有曲率、變化的離散度和異常值；殘差中的模式意味著模型遺漏了某些東西。
最小二乘斜率
\[b = \frac{S_{xy}}{S_{xx}}\]
S_xy 是協方差和；S_xx 是 x 偏差的平方和
決定係數
\[r^2 = 1 - \frac{\mathrm{SS}_{\mathrm{res}}}{\mathrm{SS}_{\mathrm{tot}}}\]
擬合模型解釋的變異比例

08質量控制與過程能力

控制圖將過程固有的普通原因變異與表明某些東西已改變的特殊原因變異區分開來。

  • 均值圖繪製樣本平均值，控制限設置在中心線兩側各三個標準誤處；極差圖跟蹤變異性。
  • 超出控制限的點，或連續點在一側，提示需要調查而不是調整每個讀數。
  • 過程能力將規範與過程離散度比較：Cp = (USL − LSL) / (6σ)，Cpk 考慮了過程偏離中心的情況。
  • 有能力的過程既精確又居中；高 Cp 但低 Cpk 意味著離散度良好但設置錯誤。
均值圖的控制限
\[\mathrm{UCL},\, \mathrm{LCL} = \bar{x} \pm \frac{3\sigma}{\sqrt{n}}\]
σ 是過程標準差，n 是子組大小
過程能力
\[C_p = \frac{\mathrm{USL} - \mathrm{LSL}}{6\sigma}\]
USL 和 LSL 是規範上下限

09卡方檢驗：計數說明了什麼

並非每個問題都關於均值。當數據是類別中的計數時，卡方框架取代 t 和 F 檢驗。

  • 擬合優度檢驗詢問觀察頻率是否服從假設分佈；獨立性檢驗詢問兩個分類變量是否相關，使用二維計數表。
  • 兩者都將觀察計數與原假設下的期望計數比較，且都是單側的：只有大的差異才重要。
  • 假設是弱點——類別必須互斥，每個期望計數應至少為 5，因此在檢驗前合併稀疏類別。
卡方統計量
\[\chi^2 = \sum_i \frac{(O_i - E_i)^2}{E_i}\]
大值表示與原模型吻合度差
自由度
\[\text{fit: } k - 1 - m; \qquad \text{table: } (r-1)(c-1)\]
m 是從數據估計的參數數量
期望計數，而非觀察計數 卡方近似要求每個單元格的期望計數約為 5 或更多；如果某些低於此值，合併類別並說明新的自由度。

10多元迴歸

大多數工程響應有多個驅動因素，因此模型變為 y = β₀ + β₁x₁ + β₂x₂ + … + ε。每個係數是一個偏效應：在其他預測變量保持不變的情況下，該預測變量每增加一個單位時 y 的期望變化。這與簡單的雙變量斜率是不同的量，混淆兩者是經典的考試錯誤。

  • 普通 R² 在添加預測變量時總是上升，即使是一個無用的預測變量，因此多元迴歸應引用調整 R²，它對每個額外參數進行懲罰。
  • 檢查多重共線性——預測變量相關性太強以至於模型無法分離其效應——通過相關性或方差膨脹因子。
  • 在剖析單個係數之前，用整體 F 檢驗測試整個模型。
多元迴歸模型
\[y = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + \cdots + \varepsilon\]
調整決定係數
\[\bar{R}^2 = 1 - \frac{(1 - R^2)(n - 1)}{n - k - 1}\]
k 個預測變量；只有當預測變量值得其位置時才會上升

11功效、效應量與研究規劃

如果研究沒有機會檢測到重要的效應，那麼不顯著的結果意義不大。功效是在特定備擇假設為真時拒絕 H₀ 的概率，由四個量驅動：顯著性水平 α、真實效應量 δ、噪聲 σ 和樣本量 n。

  • 對於雙側 z 檢驗，所需樣本量約為 (z_(α/2) + z_β)² σ² / δ²，其中 1 − β 是目標功效。
  • 將公式視為預算：將必須檢測的差異減半會使樣本量翻兩番，而更清潔的測量方法（更小的 σ）與更多重複一樣有價值。
  • 每當未能拒絕時，說明功效和假設的效應量。
雙側 z 檢驗的樣本量
\[n \approx \frac{(z_{\alpha/2} + z_\beta)^2 \sigma^2}{\delta^2}\]
β 是第二類錯誤率，因此 1 − β 是功效

計算示例

比較兩種養護方法

對每種養護方法各取 10 個混凝土立方體進行比較。方法 A 的平均強度為 42.1 MPa，標準差為 2.0 MPa；方法 B 為 40.3 MPa，標準差為 1.8 MPa。在 5% 顯著性水平下檢驗平均強度是否有差異。取自由度為 18 的臨界 t 值為 2.101。

  1. 陳述假設：H0: μA = μB；H1: μA ≠ μB。使用 α = 0.05 進行雙尾檢驗，df = 10 + 10 − 2 = 18。
  2. 合併方差：s_p² = [(9)(2.0²) + (9)(1.8²)] / 18 = (36.0 + 29.16) / 18 = 3.62，因此 s_p = 1.90 MPa。
  3. 差異的標準誤：s_p √(1/10 + 1/10) = 1.90 × 0.447 = 0.850 MPa。
  4. 檢驗統計量：t = (42.1 − 40.3) / 0.850 = 2.12。
  5. 由於 |t| = 2.12 大於臨界值 2.101，拒絕 H0。差異在統計上顯著，儘管僅為 1.8 MPa，因此實際顯著性需要工程判斷。
Answer在 5% 水平下拒絕 H0：平均強度顯著不同（t = 2.12，df = 18，p 略低於 0.05）。估計差異為 1.8 MPa，更大的樣本會給出更精確的估計。

應試方法

  • 在觸碰計算器之前陳述 H0、H1 和 α；測試題中的大部分分數來自正確的設置。
  • 用重複抽樣來解釋置信區間，而不是作為參數落在這個區間內的概率。
  • 在信任 t 或 F 結果之前，檢查獨立性、正態性和等方差假設。
  • 顯著的方差分析 F 表明至少有一個均值不同，而不是哪一個；在結論中說明這一點。
  • 在多元迴歸中，在每個解釋的係數旁寫上「其他預測變量保持不變」。
