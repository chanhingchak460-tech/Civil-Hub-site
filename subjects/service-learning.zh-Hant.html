與社區夥伴合作進行真實項目，並從工作本身中學習。內容涵蓋需求評估、共同設計、交付、誠實評估及結構化反思，強調互惠而非慈善。

進度只儲存在此瀏覽器。

01不止於義工服務

服務學習是一門與夥伴合作的課程。學生參與真實的社區項目，通常與學校、慈善機構或居民團體合作，而這段經歷因為透過反思和學習證據進行評核，所以可獲得學分。

與義工服務的分別在於互惠：社區得到它主動要求的東西，而學生獲得課堂上無法得到的知識。慈善是為人做事；服務學習是與人一起做事。

02從需求評估開始

未聆聽之前，切勿設計。需求評估要問：誰受影響、他們已擁有甚麼、以及他們說缺少甚麼。

  • 訪問將會使用成果的人，而不只是接待你的職員。
  • 親身到場視察，而非只閱讀資料。
  • 採取資產為本的觀點：學校可能缺乏設備，但有禮堂、時間表和了解學生的教師。
  • 記錄夥伴的要求，使項目簡介既是他們的，也是你們的。

03共同設計，而非由上而下交付

參與式設計讓使用者擁有真正的決策權，而非在最後才進行諮詢。

  • 及早且低成本地製作原型——紙模型、教案草稿、實地走訪——因為人們對具體事物的反應遠勝於抽象提案。
  • 留意語言、閱讀程度、行動能力、成本和時間安排方面的障礙。
  • 在工作坊開始前，先議定哪些是固定的、哪些是開放的，讓群體知道其權力實際所在。

04在真實限制下交付

服務項目仍然是項目：範圍、進度、預算和風險。夥伴有其日程、規則和忙碌的職員，而忽略學校考試期的計劃必然失敗。

  • 與兒童或弱勢成人合作時，須規劃保護措施和同意安排。
  • 在第一次活動前檢查保險和場地安全。
  • 建立能力，使工作在你離開後仍能延續：留下指示、材料和指定聯絡人。

05反思就是學習

反思不是發生事情的日記；它是將經歷連繫到理論和自身實踐的結構化思考。

Gibbs 循環提供一條路徑：描述情況、說出你的感受、評估哪些做得好、分析原因、總結你會如何做得不同，並承諾採取行動。有力的反思是具體的、承認困難的，並展示理解上的轉變。事件是證據；籠統的聲稱不是。

Gibbs 反思循環
Description → Feelings → Evaluation → Analysis → Conclusion → Action plan
最後階段是一項承諾，而非總結

06誠實評估影響

產出是可數的——舉辦了工作坊、建造了模型。成果是知識、行為或信心的改變；影響是較長期的差異。

  • 問夥伴他們將如何判斷成功。
  • 使用簡短的前後對比量度，而非僅憑印象。
  • 報告哪些行不通、誰被遺漏，以及你會改變甚麼。

誠實的評估比精心修飾的成功故事更能服務夥伴。

影響鏈
Output → Outcome → Impact
一步一步推進；已交付的活動並不自動等於改變

07快速反思框架

Gibbs 並非唯一路徑。What? So what? Now what? 框架將反思壓縮為三個步驟：描述事件、解釋其重要性及所學，然後承諾作出改變。它適合簡短反思和活動後的快速檢討。

無論採用哪種模型，證據測試都相同：好的反思指出一個事件、將其連繫到一個概念，並以改變了的意向作結。「學生很安靜」是日記；「學生一直很安靜，直到我們轉為動手建造，這讓我看到投入程度跟隨活動而來，所以下次我會減少講解」才是反思。

What? So what? Now what?
What happened → So what (why it matters) → Now what (what changes)
三個步驟，一個事件

08倫理、同意與位置性

你以大學身份作為外來者到來，因此要留意權力差距：位置性是誠實交代你在項目中的身份——你的背景、資源和假設——以及它如何塑造你所見。社區成員是自己生活的專家；視他們為共同擁有者，而非研究對象。

  • 拍攝或發布照片前取得書面許可，尤其是兒童的照片。
  • 讓參與者可隨時退出。
  • 報告發現時不點名個人或群體。
  • 如實記錄夥伴所說，而非你希望他們所說。
同意並非可有可無 未經書面同意而拍攝或點名參與者——尤其是未成年人——既違反信任，也違反保護規則；每次活動前都要檢查，而不只是第一次。

09靈活應變的活動：綵排與後備方案

每個活動都需要試行。製作活動原型並計時——團隊需九十分鐘的模型，一班新手會需要雙倍時間。大聲綵排指示，因為失去一群人的最快方法就是無人理解的任務。

然後準備後備方案：為損壞情況準備額外材料、為不同能力準備較簡單和較難的版本，以及時間緩衝，使一個緩慢步驟不會蠶食下一個活動。後備方案不是悲觀；而是對出席者的尊重。

活動計劃
Objective + Materials + Timing + Plan B
先寫目標；刪去任何不服務於目標的內容

10交接與可持續性

項目結束；社區仍在。交接讓夥伴能在沒有你的情況下繼續：書面指示、能經受正常使用的材料，以及夥伴一方了解工作的指定負責人。安排一次由他們主導、你觀察的活動。

可持續性也意味著對維護的誠實——需要每週照顧的感測器或花園是負擔，除非有人負責。在你離開數月後與夥伴議定跟進量度，使最終報告能說明實際持續了甚麼，而非承諾了甚麼。

交接套件
Instructions + Materials + Named owner + Follow-up check
留下能力，而非只是成品

計算示例

將請求轉化為項目簡介

一所夥伴學校要求學生團隊「教我們的學生關於可持續發展」。團隊有六週時間和少量預算。團隊應如何將此請求轉化為可行且成果可評核的項目？

  1. 問夥伴他們看到甚麼問題：也許學生覺得課題抽象，而非從未教過。
  2. 檢查已有甚麼——課堂、學會、天台花園——使項目建立在資產之上，而非重複。
  3. 與夥伴議定具體、可觀察的成果，例如學生能用自己的話解釋三個綠色城市特徵。
  4. 設計一個在有限時間和材料下測試該成果的活動，並先與小組製作原型。
  5. 議定如何判斷成功，然後撰寫反思，將結果連繫回課程概念。
Answer模糊的請求變成一份簡介，包含指定成果、議定受眾、單一可量度活動和夥伴界定的成功準則。反思便可針對該成果提供學習證據，而非羅列活動。

應試方法

  • 在描述你的方案之前，先指出夥伴的需求；評核者會尋找你先聆聽的證據。
  • 每篇反思聚焦於一個轉折點和具體事件，而非整個項目的總結。
  • 在評估題中將產出和成果分開；它們按不同準則評核。
  • 在倫理題中，區分法律上允許你做甚麼與夥伴認為尊重甚麼——同意和匿名可取得首輪分數。
