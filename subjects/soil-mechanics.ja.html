土は三相材料であり、その強度と沈下は有効応力、排水条件、応力履歴に依存する。本ページでは、基礎および斜面設計の基盤となる相関関係、分類試験、圧密理論、せん断強度を結びつける。

01三相の全体像

土は粒子の骨格であり、空隙には水と空気が存在する。間隙体積は V_v = V_w + V_a であり、相関関係はこれらの体積と重量を比較する。

  • 間隙比 e = V_v/V_s は緩さの度合いを表し、間隙率 n = e/(1+e) は体積分率として同じ考え方を表す。
  • 含水比 w = W_w/W_s は水の質量を固体の質量と比較し、飽和度 S_r = V_w/V_v は空隙がどの程度満たされているかを示す。
  • 比重 G_s は石英粒子で約2.65である。
  • 単位体積重量は相図から導かれ、湿潤単位体積重量 γ = (G_s + e S_r) γ_w/(1+e)、乾燥単位体積重量 γ_d = γ/(1+w) = G_s γ_w/(1+e) となる。

一貫性を保つことで後の誤りを防げる。

間隙比
\[e = \frac{V_v}{V_s}\]
固体の体積に対する間隙の体積
乾燥単位体積重量
\[\gamma_d = \frac{G_s \gamma_w}{1 + e}\]
γ/(1+w) とも表される

02分類とアッターベルグ限界

粗粒土はふるい分析で、細粒土は比重計試験で分類される。粒径加積曲線から D₁₀、D₃₀、D₆₀ が得られ、均等係数 C_u = D₆₀/D₁₀ が求められる。高い値は良好な粒度分布を持つ土を意味する。

細粒土では、アッターベルグ限界が挙動の変化する含水比を示す。

  • 液性限界 LL は土が流動しなくなる含水比である（フォールコーン試験で20 mmのコーン貫入）。
  • 塑性限界 PL は3 mmの土ひもが崩れる含水比である。
  • 塑性指数 PI = LL − PL は塑性挙動の範囲を表す。

高い PI は圧縮性の高い粘土を示し、塑性図はシルトと粘土を区別する。

塑性指数
\[\mathrm{PI} = \mathrm{LL} - \mathrm{PL}\]
塑性範囲の幅
均等係数
\[C_u = \frac{D_{60}}{D_{10}}\]
粒径加積曲線の広がり

03締固め

締固めは空気を追い出すことで土を密にし、通常はローラーで行う。室内プロクター試験はいくつかの含水比で試料を締固め、乾燥密度を含水比に対してプロットし、最適含水比でピークとなる曲線を得る。

乾燥しすぎると粒子同士が噛み合い、湿りすぎると水が土が本来満たすべき空隙を占める。

締固めは強度と支持力を高め、沈下と透水性を低減する。そのため盛土は薄層で敷きならされ、単に投下されるのではなく、指定された相対締固め度まで締固められる。

相対締固め度
\[\mathrm{RC} = \frac{\gamma_d(\text{field})}{\gamma_d(\text{max, lab})}\]
通常は百分率で指定される

04有効応力と浸透

強度と沈下は有効応力によって支配される：σ' = σ − u。ここで σ は上方の土と水の重量による全応力、u は間隙水圧である。同じ全応力でも間隙水圧が異なれば挙動は全く異なる。

  • 地下水位以下では u = ρ_w g h であり、有効応力は水中単位体積重量 γ' = γ_sat − γ_w を用いる。
  • 地下水位以上では、毛管水が負の間隙水圧を生じ、一時的に σ' を高めることがある。
  • 浸透は力を付加する。ダルシーの法則は v = k i および q = k i A を与え、動水勾配は i = Δh/L である。
  • 上向き浸透が水中重量に近づくと有効応力はゼロになる：限界動水勾配は i_c = (G_s − 1)/(1 + e) であり、これを超えると土は沸騰し、パイピングが始まりうる。
有効応力
\[\sigma' = \sigma - u\]
骨格が担う応力
ダルシーの法則
\[v = k i\]
透水係数
限界動水勾配
\[i_c = \frac{G_s - 1}{1 + e}\]
有効応力がゼロになる

05圧密と沈下

圧密は、過剰間隙水圧が消散するにつれて生じる飽和粘土の時間依存の圧縮である。荷重は最初は水が担い、排水が進むと圧力が土骨格に移り、間隙比が低下して沈下が生じる。

圧密試験（オエドメーター試験）は試料を段階的に載荷し、間隙比を対数圧力に対してプロットする。正規圧密線の勾配が圧縮指数 C_c であり、先行圧密圧力はこれまでに受けた最大応力を示す。過圧密比 OCR はその応力と現在の応力を比較し、過圧密の粘土ははるかに小さく沈下する。

沈下は s_c = C_c H/(1 + e₀) · log₁₀((σ'₀ + Δσ)/σ'₀) に従い、その速度は圧密係数 c_v に依存する。

一次元沈下
\[s_c = \frac{C_c H}{1 + e_0} \log_{10}\left(\frac{\sigma'_0 + \Delta \sigma}{\sigma'_0}\right)\]
層厚

06せん断強度とモール・クーロン

せん断強度は粒子間の滑りに対する抵抗である。モール・クーロンの破壊基準は τ_f = c' + σ' tan φ' であり、c' は有効粘着力、φ' は有効内部摩擦角、σ' は破壊面上の有効垂直応力である。

  • τ_f を σ' に対してプロットすると、切片が c'、勾配が tan φ' となる。
  • 破壊時のモール円はその包絡線に接し、破壊面は最大主応力面と 45° + φ'/2 の角度をなす。
  • 緩い砂の φ' は約30°、密な砂ではより大きい。
  • 飽和軟弱粘土を非排水でせん断すると φ_u = 0 のように振る舞い、その強度は非排水せん断強度 s_u である。
  • 直接せん断箱は強制的な面に沿って試料をせん断し、三軸試験は制御された拘束圧の下で円柱試料に載荷し、間隙水圧を測定できるため、全応力パラメータと有効応力パラメータの両方が得られる。
モール・クーロン基準
\[\tau_f = c' + \sigma' \tan \varphi'\]
排水条件、有効応力形式

07擁壁に作用する土圧

壁背後の土圧は壁の変位量に依存する。変位がない場合、土は静止状態にあり、σ'_h = K₀ σ'_v で K₀ ≈ 1 − sin φ' である。

  • 壁が外側に変位すると、土は 主働 状態に達し、K_a = tan²(45° − φ'/2) となる。
  • 壁を土に押し込むと 受働 抵抗が発揮され、K_p = tan²(45° + φ'/2) となり、通常は数倍大きい。
  • 水圧は別途加算しなければならない。

排水できない壁は間隙水圧を蓄積し、土骨格はそれを感じない。これが破壊の一般的な原因である。

主働土圧係数
\[K_a = \tan^2\left(45^{\circ} - \frac{\varphi'}{2}\right)\]
壁が土から離れる方向に移動
受働土圧係数
\[K_p = \tan^2\left(45^{\circ} + \frac{\varphi'}{2}\right)\]
壁が土に押し込まれる

08支持力と斜面安定

基礎は下部の土がせん断破壊するときに破壊する。支持力方程式は3つの項を組み合わせる：q_ult = c N_c + q N_q + 0.5 γ B N_γ。ここで N 係数は φ' に依存し、q は基礎底面位置の上載圧である。許容圧力は q_ult を約3の安全率で除したものである。

斜面は駆動せん断が利用可能な強度を超えると破壊する。安定性は FoS = 抵抗/駆動 である。

排水が最も強力な手段である：地下水位を下げると有効応力が増加し、間隙水圧が低下する。多くの斜面崩壊が豪雨後に発生するのはこのためである。

支持力
\[q_{\text{ult}} = c N_c + q N_q + 0.5 \gamma B N_\gamma\]
N 係数は φ' から求める
安全率
\[\mathrm{FoS} = \frac{\text{resisting shear}}{\text{driving shear}}\]
設計では1.5から3

09透水性：定水位試験と変水位試験

定水位試験は粗粒土に適する：長さ L、断面積 A の円筒を通る水位差 Δh の下での定常流を採取し、時間を計測すると k = QL/(A Δh t) が得られる。粗砂の室内試験では、温度補正 k₂₀ = k_T η_T/η₂₀ の後、k₂₀ ≈ 7.9 × 10⁻³ m/s が得られた。

細粒土は通水量が少なすぎて計測できないため、変水位試験では断面積 a のスタンドパイプが試料を通して排水するのを観察する：k = (a L)/(A t) ln(h₁/h₂)。風化花崗岩と風化火山岩の試料では 1.8 × 10⁻⁸ および 5.8 × 10⁻⁸ m/s が得られた。これは砂より9桁遅く、排水設計には土の性質を知る必要がある理由である。

定水位透水係数
\[k = \frac{Q L}{A \Delta h t}\]
時間 t の間に採取した定常流量
変水位透水係数
\[k = \frac{a L}{A t} \ln\frac{h_1}{h_2}\]
a はスタンドパイプの断面積、h₁ と h₂ は初期と最終の水位
温度補正
\[k_{20} = k_T \frac{\eta_T}{\eta_{20}}\]
標準20 °Cの値への粘度補正
典型的な透水係数
土k (m/s)適する試験
きれいな礫10⁻² – 1定水位
粗砂（室内）7.9 × 10⁻³定水位
細砂10⁻⁵ – 10⁻³定水位または変水位
シルト10⁻⁸ – 10⁻⁵変水位
風化花崗岩（室内）1.8 × 10⁻⁸変水位
粘土10⁻⁹ 未満変水位またはオエドメーター

10圧密試験の読み取り：t90 からの c_v

沈下の大きさは C_c から求まるが、速度には圧密係数 c_v が必要である。圧縮量を時間の平方根に対してプロットする：初期の読みは直線上にあり、そのゼロへの外挿が補正原点を与え、横軸が1.15倍大きい第2の直線が曲線と t90（90%圧密に要する時間）で交わる。

次に c_v = T_v H²/t90 で、T_90 = 0.848、H は排水距離である（両面排水では試料高さの半分）。

関連する体積圧縮係数は単位応力増加あたりの沈下を結びつけ、室内では粘土が硬くなるにつれて高い圧力段階で t90 が小さくなった。

圧密係数
\[c_v = \frac{T_v H^2}{t_{90}}\]
H は最長排水距離
90%圧密時の時間係数
\[T_{90} = 0.848\]
体積圧縮係数
\[m_v = \frac{\Delta e}{(1 + e_0) \Delta \sigma'}\]
単位有効応力増加あたりの体積ひずみ

11三軸試験：UU、CU、CD

三軸セルは排水を制御し、それが3つの標準試験を区別する。

  • 非圧密非排水（UU）：どの段階でも排水しないため、迅速かつ安価である。飽和粘土では φ_u ≈ 0 となり、強度は非排水せん断強度 s_u = (σ₁ − σ₃)/2 であり、非排水条件にのみ有効である。
  • 圧密非排水（CU）：試料はセル圧力下で圧密され、その後間隙水圧を測定しながら非排水でせん断されるため、有効応力パラメータ c′ と φ′ が得られる。
  • 圧密排水（CD）：全過程で排水し、ゆっくりせん断するため、砂および粘土の長期挙動に対する真の排水強度が得られる。

粒状土の室内CD試験では c′ = 0、φ′ ≈ 40° が得られた。

非排水せん断強度、UU
\[s_u = \frac{\sigma_1 - \sigma_3}{2}\]
全応力における破壊モール円の半径

Key terms

間隙比
間隙の体積を固体の体積で除したもので、土の緩さや密実さの基本的な尺度。
塑性指数
細粒土が塑性的に挙動する含水比の範囲で、LL − PL に等しい。
有効応力
全応力から間隙水圧を引いたもの。土骨格が担う応力であり、強度と圧縮を支配する。
過圧密比
過去の最大有効応力を現在の有効応力で除したもので、粘土がどの程度予圧密されたかを示す。
圧縮指数
オエドメーター試験から得られる間隙比対対数圧力プロット上の正規圧密線の勾配。
安全率
利用可能なせん断抵抗と破壊を引き起こすのに必要なせん断応力の比。
圧密係数
圧密層内で過剰間隙水圧が消散し沈下が進行する速さを支配するパラメータ c_v。
変水位試験
細粒土の透水試験で、スタンドパイプが試料を通して排水し、水位の時間的低下から k を求めるもの。
Worked example

新しい盛土下の粘土層の沈下

厚さ4.0 mの正規圧密粘土層は初期間隙比1.10、圧縮指数0.35である。中央深さでの初期有効鉛直応力は100 kPaである。盛土は一様な応力増加40 kPaを加える。この層の最終圧密沈下量を推定せよ。

  1. 沈下の式は s_c = [C_c H/(1 + e₀)] · log₁₀[(σ'₀ + Δσ)/σ'₀] である。
  2. 値を代入する：s_c = [0.35 × 4.0/(1 + 1.10)] × log₁₀[(100 + 40)/100]。
  3. 係数は 1.40/2.10 = 0.6667 m である。
  4. 応力比は 140/100 = 1.40 で、log₁₀(1.40) = 0.1461 である。
  5. したがって s_c = 0.6667 × 0.1461 = 0.0974 m ≈ 97 mm である。
  6. 妥当性確認：軟弱な正規圧密粘土に40%の応力増加で100 mm未満は妥当である。層厚が2倍なら沈下も約2倍になる。
Answer最終圧密沈下量は約97 mmで、過剰間隙水圧の消散に伴い時間をかけて到達する。大きさだけでなく速度も、構造物の不同変位に対する許容値と照査しなければならない。

Exam method

  • 強度や沈下の計算を行う前に、土層断面を描き、各層境界での全応力、間隙水圧、有効応力を計算せよ。
  • 試験が全応力パラメータか有効応力パラメータかを明記せよ。せん断強度の誤りの多くは両者を混同することから生じる。
  • 沈下の問題では、大きさと排水距離の両方を示せ。層厚と透水性が沈下の速さを支配するためである。
  • 単位を確認せよ：応力は kPa、単位体積重量は kN/m³、層厚は m である。1000倍の桁違いが入りやすい。
  • t90 には時間の平方根プロットと1.15オフセット線を用いよ。生の曲線上の推測した一次圧密終了点から c_v を求めるのは典型的な失点である。
