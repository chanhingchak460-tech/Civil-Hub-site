土壤是三相材料，其強度和沉降取決於有效應力、排水和應力歷史。本頁連接相關係、分類試驗、固結理論和抗剪強度，這些都是基礎和邊坡設計的基礎。

進度只儲存在此瀏覽器。

01三相圖景

土壤是由顆粒組成的骨架，顆粒間隙中充滿水和空氣。孔隙體積為 V_v = V_w + V_a，相關係比較這些體積和重量。

  • 孔隙比 e = V_v/V_s 衡量鬆散程度；孔隙率 n = e/(1+e) 是同一概念，表示為體積分數。
  • 含水量 w = W_w/W_s 比較水的質量與固體的質量，飽和度 S_r = V_w/V_v 表示孔隙被水填充的程度。
  • 石英顆粒的比重 G_s 約為 2.65。
  • 單位重量由相圖得出：濕密度 γ = (G_s + e S_r) γ_w/(1+e)，乾密度 γ_d = γ/(1+w) = G_s γ_w/(1+e)。

保持一致性可避免後續錯誤。

孔隙比
\[e = \frac{V_v}{V_s}\]
孔隙體積除以固體體積
乾單位重量
\[\gamma_d = \frac{G_s \gamma_w}{1 + e}\]
亦等於 γ/(1+w)

02分類與阿特貝格界限

粗粒土按篩分分析分類，細粒土按比重計試驗分類。級配曲線給出 D₁₀、D₃₀ 和 D₆₀，均勻係數 C_u = D₆₀/D₁₀：數值高表示級配良好。

對於細粒土，阿特貝格界限標誌著行為發生變化的含水量。

  • 液限 LL 是土壤停止流動的含水量（落錐試驗中 20 mm 錐入深度）。
  • 塑限 PL 是 3 mm 土條斷裂的含水量。
  • 塑性指數 PI = LL − PL 衡量塑性行為的範圍。

高 PI 表示壓縮性黏土，塑性圖可區分粉土和黏土。

塑性指數
\[\mathrm{PI} = \mathrm{LL} - \mathrm{PL}\]
塑性範圍的寬度
均勻係數
\[C_u = \frac{D_{60}}{D_{10}}\]
級配曲線的跨度

03壓實

壓實通過排出空氣使土壤密實，通常使用壓路機。實驗室普羅克特試驗在幾個含水量下壓實樣品，並繪製乾密度對含水量的曲線，得到在最佳含水量處達到峰值的曲線。

太乾則顆粒相互鎖定；太濕則水佔據土壤本應填充的孔隙。

壓實提高強度和承載力，減少沉降和滲透性，這就是為什麼填土分薄層鋪設並壓實至規定的相對壓實度，而不是簡單傾倒。

相對壓實度
\[\mathrm{RC} = \frac{\gamma_d(\text{field})}{\gamma_d(\text{max, lab})}\]
通常以百分比表示

04有效應力與滲流

強度和沉降由有效應力控制：σ' = σ − u，其中 σ 是上方土壤和水重量產生的總應力，u 是孔隙水壓力。相同的總應力和不同的孔隙壓力會產生完全不同的行為。

  • 在地下水位以下，u = ρ_w g h，有效應力使用浮單位重量 γ' = γ_sat − γ_w。
  • 在地下水位以上，毛細水可產生負孔隙壓力並暫時提高 σ'。
  • 滲流增加一個力。達西定律給出 v = k i 和 q = k i A，梯度 i = Δh/L。
  • 當向上滲流接近浮重量時，有效應力降至零：臨界水力梯度為 i_c = (G_s − 1)/(1 + e)，超過此值土壤會沸騰並可能開始管湧。
有效應力
\[\sigma' = \sigma - u\]
由骨架承擔
達西定律
\[v = k i\]
滲透係數
臨界水力梯度
\[i_c = \frac{G_s - 1}{1 + e}\]
有效應力降至零

05固結與沉降

固結是飽和黏土在超孔隙水壓力消散時隨時間發生的壓縮。荷載最初由水承擔；隨著排水，壓力轉移到土壤骨架，孔隙比下降，產生沉降。

固結儀試驗分級加載樣品，並繪製孔隙比對對數壓力的曲線。原始壓縮線的斜率是壓縮指數 C_c，前期固結壓力標誌著曾承受的最大應力。超固結比 OCR 比較該應力與當前應力；超固結黏土的沉降要小得多。

沉降按 s_c = C_c H/(1 + e₀) · log₁₀((σ'₀ + Δσ)/σ'₀) 計算，速率取決於固結係數 c_v。

一維沉降
\[s_c = \frac{C_c H}{1 + e_0} \log_{10}\left(\frac{\sigma'_0 + \Delta \sigma}{\sigma'_0}\right)\]
土層厚度

06抗剪強度與莫爾–庫侖

抗剪強度是顆粒間滑動的阻力。莫爾–庫侖準則為 τ_f = c' + σ' tan φ'，其中 c' 是有效黏聚力，φ' 是有效摩擦角，σ' 是破壞面上的有效法向應力。

  • 繪製 τ_f 對 σ' 的圖，截距為 c'，斜率為 tan φ'。
  • 破壞時的莫爾圓與該包絡線相切，破壞面與大主應力面成 45° + φ'/2。
  • 鬆砂的 φ' 接近 30°，密砂更大。
  • 飽和軟黏土在不排水條件下剪切時表現為 φ_u = 0，其強度為不排水抗剪強度 s_u。
  • 直剪盒沿強制平面剪切樣品；三軸試驗在受控圍壓下加載圓柱形樣品，並可測量孔隙壓力，因此總參數和有效參數均可獲得。
莫爾–庫侖準則
\[\tau_f = c' + \sigma' \tan \varphi'\]
排水、有效應力形式

07擋土牆上的土壓力

牆後的土壓力取決於牆的移動程度。無移動時土壤處於靜止狀態：σ'_h = K₀ σ'_v，K₀ ≈ 1 − sin φ'。

  • 如果牆向外屈服，土壤達到主動狀態，K_a = tan²(45° − φ'/2)。
  • 將牆推入土壤會動員被動抗力，K_p = tan²(45° + φ'/2)，通常大幾倍。
  • 水壓力必須單獨添加。

無法排水的牆會產生土壤骨架從未感受到的孔隙壓力，這是常見的破壞原因。

主動土壓力係數
\[K_a = \tan^2\left(45^{\circ} - \frac{\varphi'}{2}\right)\]
牆遠離土壤移動
被動土壓力係數
\[K_p = \tan^2\left(45^{\circ} + \frac{\varphi'}{2}\right)\]
牆推入土壤

08承載力與邊坡穩定性

當基礎下方的土壤發生剪切時，基礎破壞。承載力方程結合三項：q_ult = c N_c + q N_q + 0.5 γ B N_γ，其中 N 係數取決於 φ'，q 是基礎底面的超載。容許壓力是 q_ult 除以約 3 的安全係數。

當驅動剪力超過可用強度時，邊坡破壞；穩定性為 FoS = 抗力/驅動力。

排水是最有力的槓桿：降低地下水位提高有效應力並降低孔隙壓力，這就是為什麼許多邊坡破壞發生在大雨之後。

承載力
\[q_{\text{ult}} = c N_c + q N_q + 0.5 \gamma B N_\gamma\]
N 係數由 φ' 得出
安全係數
\[\mathrm{FoS} = \frac{\text{resisting shear}}{\text{driving shear}}\]
設計中為 1.5 至 3

09滲透性：常水頭與變水頭

常水頭試驗適用於粗粒土：在長度 L、面積 A 的圓柱體中，在水頭差 Δh 下收集並計時穩定流，得出 k = QL/(A Δh t)。對粗砂進行的實驗室試驗在溫度校正 k₂₀ = k_T η_T/η₂₀ 後得出 k₂₀ ≈ 7.9 × 10⁻³ m/s。

細粒土通過的水太少，無法計量，因此變水頭試驗觀察面積為 a 的測壓管通過樣品排水：k = (a L)/(A t) ln(h₁/h₂)。花崗岩風化土和火山岩風化土的樣品分別給出 1.8 × 10⁻⁸ 和 5.8 × 10⁻⁸ m/s——比砂慢九個數量級，這就是為什麼排水設計必須了解土壤。

常水頭滲透性
\[k = \frac{Q L}{A \Delta h t}\]
在時間 t 內收集的穩定流
變水頭滲透性
\[k = \frac{a L}{A t} \ln\frac{h_1}{h_2}\]
a 是測壓管面積，h₁ 和 h₂ 是初始和最終水頭
溫度校正
\[k_{20} = k_T \frac{\eta_T}{\eta_{20}}\]
黏度校正至標準 20 °C 值
典型滲透係數
土壤k (m/s)適用試驗
潔淨礫石10⁻² – 1常水頭
粗砂（實驗室）7.9 × 10⁻³常水頭
細砂10⁻⁵ – 10⁻³常水頭或變水頭
粉土10⁻⁸ – 10⁻⁵變水頭

10解讀固結儀：由 t90 求 c_v

沉降量來自 C_c，但速率需要固結係數 c_v。繪製壓縮量對時間平方根的曲線：早期讀數位於一條直線上，其反向延長至零得到校正原點，第二條橫坐標大 1.15 倍的直線與曲線相交於 t90，即 90% 固結的時間。

則 c_v = T_v H²/t90，其中 T_90 = 0.848，H 是排水路徑——雙向排水時為樣品高度的一半。

伴隨的體積壓縮係數將沉降與單位應力增量聯繫起來，在實驗室中，隨著黏土變硬，較高的壓力增量給出較低的 t90。

固結係數
\[c_v = \frac{T_v H^2}{t_{90}}\]
H 是最長排水路徑
90% 固結時的時間因數
\[T_{90} = 0.848\]
體積壓縮係數
\[m_v = \frac{\Delta e}{(1 + e_0) \Delta \sigma'}\]
單位有效應力增量的體積應變

11三軸試驗：UU、CU 和 CD

三軸壓力室控制排水，這是區分三種標準試驗的關鍵。

  • 不固結不排水（UU）：任何階段均不排水，因此快速且便宜；飽和黏土此時表現為 φ_u ≈ 0，其強度為不排水抗剪強度 s_u = (σ₁ − σ₃)/2，僅適用於不排水條件。
  • 固結不排水（CU）：樣品在圍壓下固結，然後在不排水條件下剪切同時測量孔隙壓力，因此可得出有效參數 c′ 和 φ′。
  • 固結排水（CD）：全程排水，緩慢剪切，給出砂的真實排水強度和黏土的長期行為。

對粒狀土進行的實驗室 CD 試驗返回 c′ = 0 和 φ′ ≈ 40°。

不排水抗剪強度，UU
\[s_u = \frac{\sigma_1 - \sigma_3}{2}\]
總應力下破壞莫爾圓的半徑

關鍵詞

孔隙比
孔隙體積除以固體體積，是衡量土壤鬆散或密實程度的基本指標。
塑性指數
細粒土表現塑性行為的含水量範圍，等於 LL − PL。
有效應力
總應力減去孔隙水壓力；它是土壤骨架承擔的應力，控制強度和壓縮。
超固結比
過去的最大有效應力除以當前有效應力，顯示黏土曾被預壓的程度。
壓縮指數
固結儀試驗中孔隙比對對數壓力圖上原始壓縮線的斜率。
安全係數
可用抗剪阻力與導致破壞所需剪應力之比。
固結係數
參數 c_v，控制固結土層中超孔隙水壓力消散和沉降進行的速度。
變水頭試驗
細粒土的滲透性試驗，測壓管通過樣品排水，由水位隨時間下降確定 k。
計算示例

新路堤下黏土層的沉降

一層 4.0 m 厚的正常固結黏土層，初始孔隙比為 1.10，壓縮指數為 0.35。中深度處的初始有效垂直應力為 100 kPa。路堤增加 40 kPa 的均勻應力增量。估算該層的最終固結沉降。

  1. 沉降公式為 s_c = [C_c H/(1 + e₀)] · log₁₀[(σ'₀ + Δσ)/σ'₀]。
  2. 代入數值：s_c = [0.35 × 4.0/(1 + 1.10)] × log₁₀[(100 + 40)/100]。
  3. 係數為 1.40/2.10 = 0.6667 m。
  4. 應力比為 140/100 = 1.40，log₁₀(1.40) = 0.1461。
  5. 因此 s_c = 0.6667 × 0.1461 = 0.0974 m ≈ 97 mm。
  6. 合理性檢查：軟正常固結黏土在 40% 應力增量下產生低於 100 mm 的沉降是合理的；厚度加倍的土層沉降約為兩倍。
Answer最終固結沉降約為 97 mm，隨超孔隙壓力消散隨時間達到。不僅是量值，速率也必須根據結構對差異移動的容許度進行檢查。

應試方法

  • 在進行任何強度或沉降計算之前，繪製土壤剖面並計算每個層邊界的總應力、孔隙壓力和有效應力。
  • 說明試驗給出的是總應力參數還是有效應力參數；大多數抗剪強度錯誤來自混淆兩者。
  • 對於沉降問題，同時給出量值和排水路徑，因為厚度和滲透性控制其發生速度。
  • 檢查單位：應力用 kPa，單位重量用 kN/m³，土層厚度用米；1000 倍的因子很容易出現。
  • 對於 t90，使用時間平方根圖和 1.15 偏移線——從原始曲線上的猜測主固結終點引用 c_v 是經典的失分點。
