構造物の文法：荷重が部材を通してどのように伝わるか、応力とひずみがどう関係するか、梁・軸・柱がどのように破壊するか。これは後のすべての設計科目の基礎となる。

01まず自由物体図から始める

構造のあらゆる問題は同じように始まる。注目する部分を切り出し、そこに作用するすべての力を描き、つり合いを適用する。自由物体図は飾りではない。反力や部材力が一つでも欠けていれば、その後に出る数値は無意味である。

平面構造では独立なつり合い式が三つある：ΣF_x = 0、ΣF_y = 0、ΣM = 0。まずこれらで反力を求め、次に必要な断面で構造を切断する。切断面での内力は常に正の向きで描く：軸力N、せん断力V、曲げモーメントM。

反力がつり合いだけで求められるとき、その構造は静定である。支点が余分にあると不静定となり、解くには適合条件、すなわち変形が互いに整合するという条件が必要になる。

平面つり合い
\[\sum F_x = 0, \quad \sum F_y = 0, \quad \sum M = 0\]

02応力、ひずみ、弾性係数

応力は力を強度に変換する：垂直応力σ = F/Aは断面に垂直に作用し、せん断応力τは断面に沿って作用する。ひずみはそれに対応する単位長さあたりの変形で、ε = ΔL/Lである。

線形弾性材料では、応力とひずみは降伏点まで比例する。その定数がヤング係数E = σ/εであり、強さではなく剛性の尺度である。材料は剛くても弱く、あるいは柔らかくても強くなりうる。鋼は剛くも強くもあり、ゴムは剛くも強くもないが、非常によく伸びる。

棒を引張ると細くなる。ポアソン比ν = −ε_lateral/ε_axialはその効果を表し、弾性定数を結びつける：G = E / [2(1 + ν)]。鋼のνは約0.30、コンクリートは約0.15〜0.20である。

垂直応力
\[\sigma = \frac{F}{A}\]
断面に垂直な力、単位はニュートン毎平方メートル
ヤング係数
\[E = \frac{\sigma}{\varepsilon}\]
応力–ひずみ曲線の線形弾性部分の勾配
せん断弾性係数
\[G = \frac{E}{2(1 + \nu)}\]

03軸変形と適合条件

長さL、断面積A、弾性係数Eの角柱棒が軸力Pを受けると、長さはΔL = P L / (A E)だけ変化する。これは不静定問題の主力である：各材の伸びを未知の力で表し、材が同じ節点で依然として接するという幾何学的条件を課す。

温度変化は自由膨張ΔL = α L ΔTを加える。その膨張が拘束されると、部材には熱応力σ = −E α ΔTが生じる。暑い日に両端を固定された鋼のレールは、何も触れていなくても圧縮状態にある。妨げられたのは動きであり、温度ではない。

軸変形
\[\Delta L = \frac{P L}{A E}\]
熱応力（完全拘束）
\[\sigma = -E \alpha \Delta T\]

04曲げ：曲げ応力式

曲げモーメントは断面にわたって応力勾配を生じる。中立軸は図心を通り、片側の繊維は圧縮、反対側は引張となる。

曲げ応力式はσ = M y / Iであり、yは中立軸からの距離、Iはその軸まわりの断面二次モーメントである。最大応力は最外縁繊維で生じるため、断面はしばしば弾性断面係数Z = I / y_maxで表され、σ_max = M / Zとなる。

長方形梁のせいを2倍にするとIは8倍になる。I = b h³ / 12だからである。せいは幅よりもはるかに効率的である。せん断力は消えない。梁では放物線状のせん断応力分布を生じ、最外縁繊維でゼロ、中立軸で最大となり、長方形ではτ_max = 3V/(2A)である。

曲げ応力式
\[\sigma = \frac{M y}{I}\]
弾性断面係数
\[Z = \frac{I}{y_{\max}}\]
断面二次モーメント（長方形）
\[I = \frac{b h^3}{12}\]

05たわみと剛性の検討

曲げは形状も変化させる。曲率はモーメントとEI v'' = Mで関係づけられ、EIは曲げ剛性、vは横方向変位である。2回積分すると傾きとたわみが得られ、定数は支持条件から決まる。

よくあるケースの結果は覚えておく価値がある：
- 中央集中荷重Pを受ける単純支持梁：中央でδ = PL³/(48EI)。
- 等分布荷重wを受ける単純支持梁：δ = 5wL⁴/(384EI)。
- 先端荷重を受ける片持ち梁：δ = PL³/(3EI)。

重ね合わせにより、応答が線形である限り、複合荷重に対してこれらのパターンを加算できる。たわみ制限は、特に長スパンの床や細長い屋根で、強度より先に設計を支配することが多い。

梁の曲率
\[E I v'' = M\]
中央集中荷重時の中央たわみ
\[\delta = \frac{P L^3}{48 E I}\]
等分布荷重時の中央たわみ
\[\delta = \frac{5 w L^4}{384 E I}\]

06円形軸のねじり

トルクTでねじられる円形軸には、半径に比例して増大するせん断応力が生じる：τ = T r / J。ここでJは極断面二次モーメントである。中実円ではJ = π d⁴ / 32なので、τ_max = 16T/(π d³)となる。

長さLにわたるねじれ角はθ = T L / (G J)である。中空軸が効率的なのはねじりのためである：ねじり抵抗の大部分は外側繊維にあり、中心付近の材料はほとんど寄与しない。

ねじり下で平面を保つのは円形断面のみであり、非円形断面はそりを生じ、その解析には別の手法が必要である。

ねじりせん断応力
\[\tau = \frac{T r}{J}\]
ねじれ角
\[\theta = \frac{T L}{G J}\]
一貫した単位ではθはラジアン

07柱と弾性座屈

細長い圧縮部材は、材料が圧壊するはるか前に座屈で破壊しうる。オイラー荷重はP_cr = π² E I / (K L)²であり、Kは端部条件に依存する：
- ピン–ピン：K = 1.0
- 固定–固定：K = 0.5
- 固定–自由：K = 2.0
- 固定–ピン：K = 0.7

座屈は強度ではなく細長さで支配される。短くずんぐりした柱は降伏し、長く細長い柱は座屈する。その遷移は細長比λ = K L / rで表され、rは断面二次半径である。

座屈荷重はIに依存するため、最小のIに対する座屈方向が設計を支配する。

オイラー座屈荷重
\[P_{cr} = \frac{\pi^2 E I}{(K L)^2}\]

08引張試験から設計へ

引張試験は理論を測定値に変える。軟鋼のような延性試験片は、初期の線形領域（E）、上下降伏点、プラトー、引張強さまでのひずみ硬化、そして最終的なくびれと破断を示す。高強度鋼は降伏プラトーをほとんど示さず、はるかに小さな伸びで破壊することがある。

延性が重要であるのは、それが警告を与え、力の再配分を可能にするからである。設計では安全率または部分係数を用いて使用応力を関連する限界以下に保ち、使用性の検討でたわみやひび割れを許容範囲に保つ。

剛性のない強度、または延性のない剛性は、工学の答えとして受け入れられることはほとんどない。

09トラスとゼロ力部材

トラスは軸力のみを伝えるピン接合棒の集合体であり、各節点は二つのつり合い式を満たさなければならない。

節点法はトラスを一周しながら各節点でΣF_x = 0とΣF_y = 0を立て、未知の棒力が最大二つである節点から始める。断面法は未知力の棒を三本以下で切断し、モーメントを取ることで、内部の棒に一手で到達する。

ゼロ力部材は計算前に見つけられる：
- 無載荷節点に非共線の棒が二本だけ集まるなら、両方ともゼロ力である。
- 棒が三本集まり二本が共線なら、節点に外力が作用しない限り三本目は力を伝えない。

実験室のトラスでは、測定した棒力を作用荷重に対してプロットすると原点を通る直線となり、ゼロ力棒はほぼ正確にゼロを示す。

断面法
\[F = \frac{M_A}{r}\]
都合のよい点まわりのモーメントを棒までの垂直距離で割ったもの

10梁のせん断応力

せん断力Vが作用する箇所では、せん断応力は深さ方向に変化する。一般式はτ = VQ/(Ib)であり、Qは考慮点より外側の面積の一次モーメント、bはその位置での幅である。

長方形では分布は放物線状であり、最外縁繊維でゼロ、中立軸で最大τ_max = 3V/(2A)となる。I形断面ではせん断のほとんどすべてがウェブで伝えられる。フランジはそこへ流れを供給するだけだからである。

せん断が細長い梁の設計を支配することはまれだが、短く深い部材、接合部の詳細、そして高いVが孔で減少した断面と出会う支点では重要である。

横せん断応力
\[\tau = \frac{V Q}{I b}\]
Qは考慮点より外側の面積の一次モーメント、bはその位置の幅
最大せん断応力（長方形）
\[\tau_{\max} = \frac{3 V}{2 A}\]

11複合荷重とモールの円

部材内の実際の点は通常、曲げ、軸力、ねじりせん断を同時に受ける。軸力と曲げによる直応力σ_xは、ねじりと横せん断によるせん断応力τ_xyと組み合わされる。主応力は以下で与えられ、最大せん断応力は平方根の項のみである。

したがって、複合トルクと曲げを受ける軸は、どちらか一方ではなく相当応力に対して検討される。モールの円は状態を図的に表す：中心は(σ_x + σ_y)/2、半径は√[((σ_x − σ_y)/2)² + τ_xy²]である。

主応力
\[\sigma_{1,2} = \frac{\sigma_x + \sigma_y}{2} \pm \sqrt{\left(\frac{\sigma_x - \sigma_y}{2}\right)^2 + \tau_{xy}^2}\]
最大せん断応力
\[\tau_{\max} = \sqrt{\left(\frac{\sigma_x - \sigma_y}{2}\right)^2 + \tau_{xy}^2}\]

Key terms

中立軸
曲げを受ける断面で応力がゼロとなり、繊維が伸びも縮みもしない線。
断面二次モーメント
材料が中立軸からどれだけ離れているかを表す幾何学的尺度であり、曲げ剛性と応力を支配する。
ヤング係数
応力–ひずみ曲線の線形部分の勾配であり、剛性を表す。
延性
材料が破壊前に塑性変形できる能力。
不静定
反力がつり合い式より多い構造であり、解くには適合条件を必要とする。
細長比
有効長さを断面二次半径で割ったもの。柱が座屈と降伏のどちらで支配されるかを予測する。
曲げ剛性
積EIであり、部材の曲げ変形に対する抵抗。
ゼロ力部材
力を伝えないトラス棒であり、計算前に節点の幾何学から特定できる。
主応力
せん断応力がゼロとなる面における極値の垂直応力であり、モールの円の作図から求められる。
Worked example

木製根太の最大曲げ応力

スパン6.0 mの単純支持木製梁が、自重を含む等分布荷重10 kN/mを受ける。断面は幅150 mm、せい300 mmである。最大曲げ応力を求め、許容曲げ応力18 MPaの木材が適切かどうかを述べよ。

  1. 等分布荷重を受ける単純支持梁の最大モーメントはwL²/8 = 10 × 6.0² / 8 = 45 kNm = 45 × 10⁶ Nmm。
  2. 中立軸まわりの断面二次モーメント：I = b h³ / 12 = 150 × 300³ / 12 = 3.375 × 10⁸ mm⁴。
  3. 最外縁繊維までの距離：y = h/2 = 150 mm。
  4. σ_max = M y / I = (45 × 10⁶ × 150) / (3.375 × 10⁸) = 20.0 N/mm² = 20 MPa。
  5. 断面係数による確認：Z = I / y = 2.25 × 10⁶ mm³、よってσ = M/Z = 45 × 10⁶ / 2.25 × 10⁶ = 20 MPa。
Answer最大曲げ応力は20 MPaであり、許容値18 MPaを超えるため、この根太は曲げに対して不適切である。よりせいの大きい断面か、より短いスパンが必要である。

Exam method

  • 公式集に触れる前にまずつり合い式を書く。失点のほとんどは代数ではなく、欠けた反力から生じる。
  • たわみの問題では、まず標準ケースを特定し、ゼロから導出するのではなく重ね合わせを使う。
  • 単位を一貫させる：最初にkNをNに、mmをmに変換し、すべての答えに単位を明記する。
  • 柱では座屈と降伏の両方を検討し、結論では小さい方の耐力を使う。
  • トラスの問題ではまずゼロ力部材を探す。それらを取り除くと未知数が二つだけの節点が現れ、いくつもの式を節約できることが多い。
