01計画は証拠の連鎖である

交通計画は、何人がどこへどの交通手段でどのリンクを通って移動するかを予測し、需要が発生する前にインフラとサービスを適切な規模に整える。古典的な四段階モデルは、発生交通量、分布交通量、交通手段選択、配分の順に進む。

各段階は異なる種類のデータを必要とし、最初の誤りは最後の巧妙なモデルでは修復されない。戦略計画は数十年先を見据え、戦術計画は数年先、運用計画は一季節先を見据える。

02計測と聞き取り調査

基本となる道具は分類別交通量調査であり、一定期間にわたる車種別・方向別の交通量を記録する。調査は手作業、一時的な自動計測（チューブ、ループ、レーダー）、または常設で行うことができ、短時間の調査は係数を用いて代表的な一日に拡大される。

起終点（O–D）調査はトリップの起点と終点を尋ねる。路側インタビュー、ナンバープレート照合、GPS軌跡、携帯電話網データなどがある。速度調査は地点速度または旅行時間を測定し、駐車調査は累積台数と駐車時間を記録する。

調査手法の選択
手法測定内容強み限界
分類別交通量調査車種別交通量安価で再現可能起点・終点がない
路側インタビューO–Dとトリップ目的計画上の問いに答える高コスト；停止車両に偏る
ナンバープレート照合O–Dと旅行時間大規模サンプル、インタビュー不要プライバシー制約；ナンバー誤読
フローティングカー旅行時間と遅延経路全体、実交通小規模サンプル；観測者効果

03サンプリング、拡大、誤差

どの調査もすべてを数えるわけではない。サンプルは母集団に拡大されるため、拡大係数はそのサンプリング誤差を伴う。サンプリング誤差はサンプルサイズの平方根に反比例して減少するため、サンプルを4倍にすると誤差は半分になる。

カバレッジバイアスはランダム誤差よりも深刻である。平日ピークのみを数えたり、インタビューに応じた運転者だけを数えたりすると、選択された集団を測定することになる。中立月と中立日が重要であり、祝日は除外される。

比率のサンプルサイズ
\[n = \frac{z^2 p (1 - p)}{e^2}\]
95%信頼度でz ≈ 1.96、pは期待比率、eは許容誤差

04発生交通量とO–D行列

発生交通量は、世帯または開発が何トリップを発生させるかを推定する。世帯人数、所得、自動車保有別の調査データ、または回帰から求める。出力はトリップ行列であり、行が起点、列が終点、対角成分がゾーン内トリップを表す。

行列はサンプルから母集団へ拡大され、行と列の合計がコントロール合計と一致するようにバランス調整される。粗すぎる、または位置が不適切なゾーニングは、下流のすべてを歪める。

05発生交通量モデル

発生交通量は、カテゴリー分析（各規模・所得階級の世帯または個人あたりの平均トリップ率）または回帰（世帯特性に対してトリップを当てはめる）のいずれかで推定される。典型的なモデルは、日トリップを世帯人数と自動車保有に回帰し、定数と各説明変数あたりの率を与える。

係数は事実ではなく、1つの調査に当てはめられたものであり、そのバイアスを引き継ぐ。小規模で代表性のないサンプルは、精密に見えて体系的に誤った率を生む。使用前に、大規模な都市全体の交通調査と当てはめ率を比較し、単位（1世帯1日あたりのトリップ数）をすべての係数に付記しておくこと。

線形発生交通量モデル
\[T = a + b_1 X_1 + b_2 X_2 + \dots\]
Tは1世帯または1人あたりのトリップ数、Xは説明変数、係数は最小二乗法で当てはめ
カテゴリートリップ率
\[r = \frac{T}{H}\]
Tはカテゴリーサンプルのトリップ数、Hは世帯または人数；T_i = r × H_iとして適用
精密な当てはめは正確な当てはめではない 小規模で均質なサンプルは回帰直線に美しく当てはまる一方で、母集団を誤って表す。予測に使用する前に、必ず大規模な交通調査とトリップ率を検証すること。

06分布と交通手段選択

分布交通量は、発生したトリップがどこへ向かうかを決める。重力モデルは、目的地の魅力度に比例し、到達コストに反比例してトリップを配分し、抑止関数は観測された旅行に対してキャリブレーションされる。

次に交通手段選択は、一般化費用（時間、運賃、待ち時間、快適性、信頼性を統合）を用いて各流動を自動車、公共交通、徒歩に分割する。ロジットモデルは各選択肢の効用を確率に変換するため、小さな費用変化はオール・オア・ナッシングの切り替えではなく段階的なシフトを生む。

重力モデル
\[T_{ij} = \frac{P_i A_j f(c_{ij})}{\sum_k A_k f(c_{ik})}\]
T_ijはiからjへのトリップ、P_iは発生量、A_jは魅力度、fはコストcの抑止関数
ロジット分担率
\[P_m = \frac{e^{U_m}}{\sum_k e^{U_k}}\]
Uは交通手段の効用であり、多くの場合、負の一般化費用

07配分とネットワーク均衡

配分は、行列をノード、リンク、ゾーン、セントロイドコネクタからなるネットワークに載せる。旅行時間は流動とともに増加するため、BPR曲線などの交通量–遅延関数が各リンクに適用される。

全か無か配分は混雑を無視し、最短経路を過負荷にする。均衡配分は、経路を切り替えても改善できない運転者がいなくなるまで流動を分散させる。これはWardropの利用者均衡である。SATURNやEMMEなどのソフトウェアはその状態に向けて反復計算し、結果は観測交通量と照合して検証しなければならない。

BPR交通量–遅延関数
\[t = t_0 \left[1 + \alpha \left(\frac{v}{c}\right)^\beta\right]\]
t₀は自由流旅行時間、vは流動、cは容量；α ≈ 0.15、β ≈ 4が一般的な既定値

08配分ネットワークの構築

配分ソフトウェアは数学よりも先にコード化されたネットワークを必要とする。ゾーンはセントロイドコネクタによってノードに接続され、ノードは自由流速度、容量、長さを持つリンクとして結合され、トリップ行列がゾーンに付加される。

各要素はコーディング誤差が潜む場所である。逆転した一方通行、欠落したコネクタ、容量ゼロは、静かに答えを破壊する。ワークフローが規律である。ネットワークを構築し、コンパイルし、行列を読み込み、配分を実行し、結果を観測交通量とGEH統計量に対して照合してから信じること。代替案も同じ方法で検証する。代替案をコード化し、配分し、直感ではなく基準ケースと比較する。

配分ワークフロー
code network → compile → load matrix → assign → validate against counts
すべての段階で確認が必要；結果はその背後にあるコーディングの質を超えられない

09駐車調査と回転率

駐車調査は累積台数（ある時点で駐車している車両数）と駐車時間（各駐車の長さ）を測定する。累積台数は車両の到着と出発に伴って変化し、ピーク累積台数が駐車供給量を決める。駐車時間は短時間滞在の買い物客と長時間滞在の通勤者を分け、両グループには異なる政策が必要である。

回転率は、ある期間に1つの駐車スペースが扱う異なる車両の数である。回転率の高い短時間スペースは多くの利用者にサービスを提供し、回転率の低いスペースは1人の通勤者に一日中サービスを提供する。取締り、料金設定、時間制限はすべてこの2つのギャップを対象とする。

駐車累積台数
\[A_t = A_{t-1} + \mathrm{arrivals}_t - \mathrm{departures}_t\]
調査期間を通じて追跡し、ピークを見つける
駐車回転率
\[U = \frac{V}{S}\]
Vは期間中の駐車車両数、Sはスペース数；例：100スペースに400台なら回転率は4

10土地利用、検証、判断

交通と土地利用は互いを形作る。高速なリンクはアクセシビリティを高め、それが開発を誘引し、それが交通を発生させる。これが誘発需要である。このフィードバックを無視するモデルは、需要を固定と仮定することで道路計画を過大評価する。

検証はモデル化された流動を観測交通量と比較し、しばしばGEH統計量を用いる。これはスケールに鈍感で適用が容易である。計画者は不確実性を報告し、シナリオを検証し、誤った場合のコストを誰が負うかを問う。なぜなら計画は未来についての議論であり、未来の測定ではないからである。

GEH統計量
\[\mathrm{GEH} = \sqrt{\frac{2 (M - C)^2}{M + C}}\]
Mはモデル流動、Cは観測流動；5未満は良好、10超は問題の兆候

Key terms

分類別交通量調査
車種、方向、時間帯別に交通量を記録する交通調査。
O–D行列
起点ゾーンと終点ゾーン間のトリップを表す表。
拡大係数
サンプル調査を母集団または代表的な一日に拡大する乗数。
BPR関数
流動容量比の関数としてリンク旅行時間を与える交通量–遅延関係。
重力モデル
流動が起点の発生量と終点の魅力度に比例し、旅行コストに反比例する分布交通量モデル。
GEH統計量
モデル流動と観測流動の差のスケールフリーな指標で、5が一般的な許容閾値。
トリップ率
1世帯、1人、または1台あたりの平均トリップ数で、カテゴリー分析でゾーン合計を拡大するのに用いる。
駐車回転率
ある期間に1つの駐車スペースが扱う車両数であり、駐車台数をスペース数で割った比率。
Worked example

モデル化されたリンクを観測値と照合する

あるリンクの自由流旅行時間は5.0分、容量は5,000台/時である。モデルはα = 0.15、β = 4を用いて4,500台/時を配分した。観測交通量は3,800台/時である。モデル旅行時間とGEH統計量を求め、このリンクに対するモデルを評価せよ。

  1. v/c = 4,500 / 5,000 = 0.9を計算し、(v/c)^4 = 0.6561となる。
  2. BPRを適用：t = 5.0 × (1 + 0.15 × 0.6561) = 5.0 × 1.0984 = 5.49分。
  3. GEH = √[2 × (4,500 − 3,800)² / (4,500 + 3,800)] = √(980,000 / 8,300) = √118.1 = 10.9。
  4. 通常の基準と比較する：5未満は許容、5〜10は調査が必要、10超は当てはまりが悪いことを示す。
  5. 予測を使用する前に、リンク周辺のゾーン負荷、セントロイドコネクタ、ネットワークコーディングを調査する。
Answerモデル旅行時間は5.49分、GEH = 10.9であり、このリンクは通常の検証基準を満たさない。モデルはここで流動を過大配分しており、計画評価の前に原因を特定すべきである。

Exam method

  • 手法の前に調査目的を述べること。O–Dの問いは、どれほど正確な分類別交通量調査でも答えられない。
  • 拡大とサンプリングの問題では、式を書き、代入し、カバレッジバイアスに言及すること。ランダム誤差だけが問題のすべてであることは稀である。
  • ネットワークの問題では、均衡を論じる前にv/cと交通量–遅延関数を確認すること。均衡結果はリンク曲線に依存する。
  • 発生交通量の各係数の単位（1世帯1日あたりのトリップ数）を明記すること。日、週、年の率を切り替えると点数を失う。

Q01トリップの起点と終点を直接測定する調査はどれか？

Why個々のトリップを追跡または尋ねる手法のみが起終点パターンを与える。

Q02BPR関数において、旅行時間が流動とともに増加するのはなぜか？

Why(v/c)^βの項は流動が容量に近づくにつれて増大し、自由流旅行時間を超える遅延を生む。

Q03モデル流動と観測流動の間のGEH値12は通常何を意味するか？

Why10を超える値は通常、当てはまりが悪いとされ、モデルとデータの確認を促す。

Q04サンプルサイズを4倍にすると、標準サンプリング誤差は約何分の1になるか？

Why誤差は1/√nに比例するため、サンプルを4倍にすると誤差は半分になる。

Q05回帰発生交通量モデルがT = 1.2 + 2.4 H（Hは世帯人数）を与える。平均3.1人の300世帯のゾーンが発生するのは約何トリップか？

Why1世帯あたり：1.2 + 2.4 × 3.1 = 8.64トリップ、300世帯では合計約2 590トリップ。

Q0680スペースの駐車場が07:00から19:00の間に240台の車両を扱う。その回転率は？

Why回転率は駐車台数をスペース数で割ったもの：240 / 80 = 期間中1スペースあたり3台。
