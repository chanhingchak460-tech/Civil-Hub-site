如何量度並預測出行。內容涵蓋分類交通量統計與起訖點調查、抽樣與擴展、四步驟需求模型、網絡分配，以及決定預測是否切合實際的土地用途回饋。

進度只儲存在此瀏覽器。

01規劃是一條證據鏈

交通規劃預測有多少人會出行、往哪裡去、用哪種交通方式，以及沿哪些路段行走，以便在需求出現之前確定基礎設施與服務的規模。經典的四步驟模型依次為：出行產生、出行分佈、方式選擇與分配。

每一步都需要不同類型的數據，而起始階段的誤差無法靠末端聰明的模型修補。策略性規劃著眼於數十年後，戰術性規劃著眼於數年後，而營運性規劃則著眼於一個季度。

02點算與訪問

基本工具是分類交通量統計，按車輛類型與方向記錄某段時間內的交通量。統計可採人手、臨時自動（膠管、感應圈、雷達）或永久方式進行；短時間統計會利用係數擴展至典型日。

起訖點調查詢問出行的起點與終點：路邊訪問、車牌配對、GPS 軌跡或流動網絡數據。速度調查量度地點速度或行程時間，而泊車調查則記錄累積量與時長。

選擇調查方法
方法量度內容優點限制
分類交通量統計按車輛類型的交通量便宜且可重複沒有起點或終點
路邊訪問起訖點及出行目的能回答規劃問題成本高；偏向被截停的車輛
車牌配對起訖點及行程時間樣本大，無需訪問受私隱限制；車牌誤讀
浮動車行程時間及延誤覆蓋整條路線，真實交通樣本小；觀察者效應

03抽樣、擴展與誤差

沒有調查能點算所有事物。樣本會擴展至總體，因此擴展係數會連同其抽樣誤差一併帶入。抽樣誤差隨樣本量的平方根下降，所以樣本增至四倍可將誤差減半。

覆蓋偏差比隨機誤差更嚴重——只點算平日高峰，或只訪問願意停車受訪的駕駛者，量度的只是一個被選定的群組。中性月份與中性日子很重要，而公眾假期須予剔除。

比例抽樣樣本量
\[n = \frac{z^2 p (1 - p)}{e^2}\]
95% 置信水平下 z ≈ 1.96，p 為預期比例，e 為誤差界限

04出行產生與起訖矩陣

出行產生估算一個住戶或發展項目產生多少出行，方法可根據住戶人數、收入與汽車擁有量的調查數據，或利用迴歸分析。輸出是一個出行矩陣：列為起點，欄為終點，對角線則為區內出行。

矩陣由樣本擴展至總體，並加以平衡，使列與欄的總和與控制總數一致。分區不當——過於粗略或位置錯誤——會扭曲下游的一切。

05出行產生模型

出行產生可透過類別分析——每個規模或收入類別中每住戶或每人的平均出行率——或透過迴歸分析估算，後者以住戶特徵擬合出行數。典型模型將每日出行數對住戶人數與汽車擁有量進行迴歸，得出一個常數加上每個解釋變數的比率。

係數並非事實；它們是擬合自某一次調查，並承襲其偏差。細小且不具代表性的樣本會產生看似精確但系統性錯誤的比率。使用前應將擬合比率與大型全市出行調查作比較，並在每個係數上保留單位——每住戶每日出行數。

線性出行產生模型
\[T = a + b_1 X_1 + b_2 X_2 + \dots\]
T 為每住戶或每人的出行數；X 為解釋變數；係數以最小二乘法擬合
類別出行率
\[r = \frac{T}{H}\]
T 為該類別樣本的出行數，H 為住戶或人數；應用為 T_i = r × H_i
精確擬合不等於準確 細小且同質的樣本能完美擬合迴歸線，卻同時錯誤代表總體——在預測中使用出行率前，務必以大型出行調查作驗證。

06分佈與方式選擇

出行分佈決定產生的出行往哪裡去。重力模型按目的地的吸引力成正比、按到達成本成反比來分配出行，並以觀察所得的出行數據校準 deterrence 函數。

方式選擇然後利用廣義成本——時間、票價、等候、舒適度與可靠度綜合——將每股流量分配至私家車、公共交通與步行。Logit 模型將每個選項的效用轉化為概率，因此輕微的成本變化會產生漸進式轉移，而非全有或全無的切換。

重力模型
\[T_{ij} = \frac{P_i A_j f(c_{ij})}{\sum_k A_k f(c_{ik})}\]
T_ij 為由 i 至 j 的出行，P_i 為產生量，A_j 為吸引量，f 為成本 c 的 deterrence 函數
Logit 方式分擔
\[P_m = \frac{e^{U_m}}{\sum_k e^{U_k}}\]
U 為某方式的效用，通常為負廣義成本

07分配與網絡均衡

分配將矩陣載入由節點、路段、分區與質心連接線組成的網絡。行程時間隨流量上升，因此每條路段會套用如 BPR 曲線的流量–延誤函數。

全有或全無分配忽略擠塞，使最短路線超載；均衡分配則分散流量，直至沒有駕駛者可透過轉換路線改善，即 Wardrop 用戶均衡。SATURN 或 EMME 等軟件會迭代趨向該狀態，而結果必須與統計數據核對。

BPR 流量–延誤函數
\[t = t_0 \left[1 + \alpha \left(\frac{v}{c}\right)^\beta\right]\]
t₀ 為自由流時間，v 為流量，c 為容量；α ≈ 0.15 及 β ≈ 4 為常用預設值

08建立分配網絡

分配軟件在需要數學之前，先需要一個編碼網絡。分區透過質心連接線連接至節點，節點以路段連接，附有自由流速度、容量與長度，而出行矩陣則附加至分區。

每個元素都是編碼錯誤可能隱藏之處：反向的單程路、缺失的連接線或零容量，都會無聲地破壞答案。工作流程就是紀律：建立網絡、編譯、載入矩陣、執行分配，然後在相信結果之前，將結果與統計數據及 GEH 統計量核對。方案選項亦以同樣方式測試——為選項編碼、分配，並與基準情況比較，而非與直覺比較。

分配工作流程
code network → compile → load matrix → assign → validate against counts
每個階段都需要檢查；結果的好壞取決於背後的編碼

09泊車調查與周轉率

泊車調查量度累積量——某一時刻停泊的車輛數目——以及時長，即每次停泊的長度。累積量隨車輛到達與離開而變化，而高峰累積量決定泊車供應的規模。時長區分短暫停留的購物者與長時間停留的通勤者，兩類群體需要不同的政策。

周轉率是某段時間內一個泊車位服務的不同車輛數目：高周轉率的短暫停泊位服務許多使用者，低周轉率的則全日只服務一名通勤者。執法、收費與時限均針對兩者之間的差距。

泊車累積量
\[A_t = A_{t-1} + \mathrm{arrivals}_t - \mathrm{departures}_t\]
在調查期間追蹤以找出高峰
泊車周轉率
\[U = \frac{V}{S}\]
V 為期間內停泊的車輛，S 為泊車位；例如 100 個泊車位有 400 輛車，周轉率為 4

10土地用途、驗證與判斷

交通與土地用途互相塑造。更快捷的路段提升可達性，吸引發展，繼而產生交通：誘發需求。忽略這種回饋的模型會假設需求固定，從而美化道路方案。

驗證將模型流量與統計數據比較，通常使用 GEH 統計量，它對規模不敏感且易於應用。規劃者亦會報告不確定性、測試情景，並追問誰承擔判斷錯誤的代價，因為規劃是關於未來的論證，而非對未來的量度。

GEH 統計量
\[\mathrm{GEH} = \sqrt{\frac{2 (M - C)^2}{M + C}}\]
M 為模型流量，C 為統計流量；低於 5 為良好，高於 10 表示有問題

關鍵詞

分類交通量統計
按車輛類型、方向與時段記錄交通量的交通統計。
起訖矩陣
起點分區與終點分區之間出行數目的表格。
擴展係數
將樣本統計放大至總體或典型日的乘數。
BPR 函數
一種流量–延誤關係，以流量對容量比率得出路段行程時間。
重力模型
一種出行分佈模型，流量隨起點產生量與終點吸引量增加，並隨出行成本下降。
GEH 統計量
模型流量與統計流量差異的無尺度量度，5 為常用接受門檻。
出行率
每住戶、每人或每車的平均出行數目，用於類別分析以擴展分區總數。
泊車周轉率
某段時間內一個泊車位服務的車輛數目，即停泊量對泊車位的比率。
計算示例

以統計數據核對模型路段

某路段自由流時間為 5.0 分鐘，容量為 5,000 veh/h。模型分配 4,500 veh/h 至該路段，採用 α = 0.15 及 β = 4。觀察統計為 3,800 veh/h。求模型行程時間與 GEH 統計量，然後判斷該路段的模型表現。

  1. 計算 v/c = 4,500 / 5,000 = 0.9，所以 (v/c)^4 = 0.6561。
  2. 套用 BPR：t = 5.0 × (1 + 0.15 × 0.6561) = 5.0 × 1.0984 = 5.49 分鐘。
  3. GEH = √[2 × (4,500 − 3,800)² / (4,500 + 3,800)] = √(980,000 / 8,300) = √118.1 = 10.9。
  4. 與常用範圍比較：低於 5 可接受，5 至 10 需調查，高於 10 表示擬合欠佳。
  5. 在使用預測前，調查該路段附近的分區載入、質心連接線與網絡編碼。
Answer模型行程時間為 5.49 分鐘，GEH = 10.9，因此該路段未能通過常用驗證範圍。模型在此處分配過多流量，應在評估方案前找出原因。

應試方法

  • 先說明調查目的，再說明方法：起訖點問題無法靠分類交通量統計回答，無論它多準確。
  • 在擴展與抽樣題目中，寫出公式、代入數值，並評論覆蓋偏差——隨機誤差很少是全部原因。
  • 在網絡題目中，討論均衡前先檢查 v/c 與流量–延誤函數，因為均衡結果取決於路段曲線。
  • 說明每個出行產生係數的單位——每住戶每日出行數——因為在每日、每週與每年比率之間轉換會失分。
