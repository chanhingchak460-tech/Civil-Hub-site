道路は、幾何構造、舗装、交通挙動が期待される速度と一致しなければならない経路の階層として設計される。このページでは、線形、視距、舗装、交通流を一つの設計ストーリーに結びつける。

01道路階層と設計管理

道路ネットワークは機能によって組織される：

  • 主要道路または幹線道路は、アクセスを制限して高速で長距離交通を担う。
  • 二次道路は地区を結ぶ。
  • 分配道路は交通を近隣地区に分散させる。
  • 局部道路は低速で沿道アクセスを提供する。

重要なトレードオフはモビリティとアクセスの間にある。高速路線に接続するすべての私道や側道は衝突点を増やすため、上位クラスではアクセスが意図的に制限される。

標識、標示、交差点は、運転者に自分がどのクラスの道路にいるかを伝え、速度と挙動が期待に一致するようにすべきである。一つの道路で機能を混在させることが、ほとんどの安全と容量の問題の始まりである。

02設計速度と幾何学的整合性

設計速度は幾何設計の基準として選ばれる速度であり、最小半径、片勾配、視距、縦断曲線長を定める。運転者は幾何構造を読み取り、快適と感じる速度に落ち着くため、道路はその速度で信頼できるものでなければならない。

幾何学的整合性は、個々の要素よりも重要である。長い直線の後に急カーブが続くと、カーブに過大な速度で進入してしまうため、要素は徐々に変化させるべきである。

横断面も同じ論理に従う：車道幅員、緊急停車帯、歩行者用の路肩、縁石、そして路面を排水するための片勾配または横断勾配である。

03停止視距と追越視距

停止視距（SSD）は、設計速度で予期しない物体の手前で停止するために運転者が必要とする距離である。反応距離と制動距離の和である：

SSD = 0.278 V t + V² / [254 (f + G)]

ここでVはkm/h、反応時間tは秒、縦断摩擦係数f、勾配Gは小数である。上り勾配は制動距離を短縮し、下り勾配は延長するため、検査には最も急な下り勾配を用いる。

追越視距はさらに長い。追越し操作では、追い越して安全に戻るのに十分な距離を見通す必要があるからである。確保できない場合、道路は安全な追越し場所を提供するか、追越し禁止の標示をすべきである。

停止視距
\[SSD = 0.278Vt + \frac{V^2}{254(f + G)}\]
Vはkm/h、tは秒、Gは上りを正とする

04平面線形と片勾配

平面線形は直線、円曲線、緩和曲線の連続である。半径Rの円曲線では、片勾配eと横摩擦fが合力として遠心力と釣り合う：

e + f = V² / (127 R)

ここでVはkm/h、Rはメートルである。したがって必要な片勾配は速度の二乗に比例して増加し、半径が大きくなるにつれて減少する。

緩和曲線は曲率の変化を緩和し、片勾配を徐々に適用できるようにし、運転者に操舵の時間を与える。急カーブではわずかに拡幅される。長い車両の後輪が前輪の内側を通るからである。

片勾配の釣り合い
\[e + f = \frac{V^2}{127R}\]
eとfは無次元比、Vはkm/h、Rはメートル

05縦断線形：勾配と曲線

縦断線形は勾配と放物線曲線を用いる。最大勾配は制限される。長い上り勾配は大型車を減速させ、急な下り勾配はブレーキに過負荷をかけるからである。凸曲線では、曲線が運転者の視線より下に路面を保たなければならない。

視距Sが曲線長Lより短い場合、

L = A S² / 647

ここでAはパーセントで表した勾配の代数変化である。視距が曲線より長い場合、L = 2S − 647/Aである。

凹曲線は快適性と前照灯視距によって支配され、L = A V² / 395のような基準を用いる。比K = L/Aは設計速度に対する最小値を超えるべきである。

凸曲線、視距が曲線より短い場合
\[L = \frac{A S^2}{647}\]
Aはパーセントで表した勾配変化、Sはメートルで表した視距
凹曲線の快適性基準
\[L = \frac{A V^2}{395}\]

06舗装構造と路床

舗装は車輪荷重を層を通して分散し、路床が支持できる応力を受けさせる。たわみ性舗装は粒状路盤と下層路盤の上のアスファルト表層を用い、剛性舗装は曲げで荷重を担うコンクリートスラブを用いるため、目地と荷重伝達装置が必要である。

路床の強度は通常、カリフォルニア支持力比によって特徴づけられる。これは締固めた供試体の貫入抵抗を標準砕石曲線と比較したものである：

CBR = (P / P_standard) × 100%。CBR、設計交通量、排水が一緒に層厚を決める。

水は路床を弱め、粒状層から細粒分をポンピングし、わだち掘れを加速するため、横断勾配と側溝が構造を保護する。

カリフォルニア支持力比
\[CBR = \frac{P}{P_{standard}} \times 100\%\]
Pは貫入抵抗力、P_standardは同じ貫入量における標準荷重
たわみ性舗装と剛性舗装の比較
特徴たわみ性舗装剛性舗装
荷重支持粒状層が荷重を分散コンクリートスラブが梁として曲げる
表層アスファルト、加熱施工コンクリート、型枠またはスリップフォーム施工
目地少ない、主に施工目地ダウエルバーとタイバーを備えた規則的な目地
補修影響範囲を迅速にパッチングパネルを切断して交換、より遅い
典型的用途ほとんどの都市および地方道路重交通および弱い路床

07設計交通量と四乗則

舗装厚は、それが担うべき交通量によって決まり、等価標準軸荷重（ESAL）で表される。異なる重量の軸は、四乗則を通じて標準80 kN軸の損傷に換算される：

RDF = (P / 80)⁴

したがって160 kNの軸は80 kN軸の16倍の損傷を引き起こし、軽荷重の軸はほとんど損傷を与えない。

設計供用期間、交通量の伸び、車両の軸荷重分布が組み合わされて設計ESAL数となり、層厚はその数と路床CBRおよび排水から決まる。

覚えておくべき残酷な非線形性である：20%の過積載は損傷をほぼ2倍にする。だからこそ計量所の取締りは舗装の保護であり、官僚主義ではない。

相対損傷係数
\[\mathrm{RDF} = \left(\frac{P}{80}\right)^4\]
PはkNで表した軸荷重、80 kNは標準軸

08アスファルト混合物と配合設計

アスファルト混合物は、アスファルトで結合された粒度調整骨材である：

  • 密粒度混合物は不透水性で強いが、騒音が大きい。
  • 開粒度混合物は水を排水し、スプレーと騒音を低減する。
  • ストーンマスチックアスファルトは粗骨材骨格を用いてわだち掘れ抵抗性を高める。

マーシャル配合設計は、安定性とフローのバランスをとり、空隙率（VTM）、鉱物骨材空隙率（VMA）、および結合材で満たされた空隙の割合を確認して最適結合材量を選ぶ：

VTM = (G_mm − G_mb) / G_mm × 100%。結合材が多すぎるとブリーディングし、少なすぎると混合物が乾燥して透水性になる。

温間混合物技術は製造温度を下げ、燃料使用と排出を削減する。

混合物全体の空隙率
\[VTM = \frac{G_{mm} - G_{mb}}{G_{mm}} \times 100\%\]
G_mmは理論最大密度、G_mbは締固めた供試体のかさ密度

09マーシャル手順の全体像

マーシャル法は暗記する価値のある固定された9段階の手順である：

  • 結合材量の範囲にわたって直径約101.5 mm、高さ63.5 mmの供試体を作製する — 約155 °Cで混合し、135–140 °Cで片面50回、毎分60回の打撃で締固める。
  • 空中、水中、飽和表面乾燥状態で質量を測定してかさ密度を求め、空隙率と骨材空隙構造を計算する：

VMA = VTM + Vb

ここでVTMは空隙率、Vbは結合材体積率であり、結合材充填率はVFB = (VMA − VTM) / VMA × 100%である。

  • 60 °Cの水浴後、各供試体を50.8 mm/minで圧裂する：ピーク荷重がマーシャル安定度、破壊時の変形がフローである。
  • 安定度、フロー、密度、VTM、VMAを結合材量に対してプロットし、最適結合材量を最大安定度、最大密度、目標空隙率（約4%）を与える含有量の平均として求める。
  • 最後に曲線に再入力して混合物が仕様を満たすことを確認する；そうでなければ再設計する。
鉱物骨材空隙率
\[\mathrm{VMA} = \mathrm{VTM} + V_b\]
VTMは空隙率、Vbは結合材体積、すべて混合物体積に対するパーセント
結合材充填空隙率
\[\mathrm{VFB} = \frac{\mathrm{VMA} - \mathrm{VTM}}{\mathrm{VMA}} \times 100\%\]
VMAとVTMはともにパーセント
密粒度アスファルト混合物のマーシャル目標値の目安（仕様が優先）
特性典型的目標値
安定度少なくとも約8 kN
フロー約2–4 mm
空隙率（VTM）3–5%
鉱物骨材空隙率（VMA）約13–15%以上
結合材充填空隙率（VFB）約65–78%

10交通流、交差点、安全

交通流は流量q、密度k、空間平均速度vを結びつける：

q = k v。密度が上昇すると流量は増加し、道路が容量に達するまで続く；それを超えると渋滞が発生し、流量と速度の両方が崩壊する。サービス水準は自由流から強制流までの状態を等級付けする。

交差点は主要な制約である：

  • 平面交差点は安価だが、すべての転向交通が衝突点となる。
  • 立体交差は土地と構造物のコストと引き換えに衝突を除去する。
  • 交通島は車両を規定の経路に導き、転向を予測可能にする。

安全は設計に組み込まれる：交差点の見通し線、寛容な路側余裕、すべり抵抗性舗装、設計段階での道路交通安全監査である。

基本的な交通流関係
\[q = k v\]
qは毎時車両数、kは每キロメートル車両数で表した密度、vはkm/hで表した空間平均速度

Key terms

設計速度
幾何設計の基準として用いられる速度で、半径、片勾配、視距、凸曲線長を定める。
停止視距
危険物の手前で停止するために運転者が前方に見通すべき距離で、反応距離と制動距離の和に等しい。
片勾配
水平曲線に適用される横断勾配で、重力が遠心力の釣り合いを助けるようにする。
カリフォルニア支持力比
締固めた土または粒状材料の貫入抵抗を標準砕石曲線と比較したもの。
サービス水準
自由流から強制流までの交通状態を等級付けした記述。
鉱物骨材空隙率
締固めたアスファルト混合物中の骨材粒子間の空隙空間で、結合材と空気に利用可能なもの。
マーシャル安定度
60 °Cで半径方向に圧裂した締固めたアスファルト供試体が担うピーク荷重で、フローとともに結合材量の選択に用いられる。
等価標準軸荷重
異なる重量の軸を四乗則を通じて標準80 kN軸の損傷に換算する設計交通量の尺度。
Worked example

視距と凸曲線長

地方道路の設計速度は80 km/hである。運転者の反応時間は2.5 s、縦断摩擦係数は0.35である。最も急な下り勾配では勾配が−3%である。停止視距を計算し、次に+3%から−3%への勾配変化に必要な凸曲線長を求めよ。

  1. 反応距離：0.278 × 80 × 2.5 = 55.6 m。
  2. 制動距離：V²/[254(f + G)] = 80²/[254 × (0.35 − 0.03)] = 6400/81.3 = 78.7 m。
  3. 停止視距 = 55.6 + 78.7 = 134.3 m。
  4. 勾配変化はA = 3 − (−3) = 6%である。
  5. 曲線が視距より長いと仮定する：L = A S²/647 = 6 × 134.3²/647 = 167 m。
  6. 仮定を確認する：134.3 m < 167 mであるから、凸曲線は確かに視距より長く、用いた式は正しい。
  7. K = L/A = 167/6 = 27.8 m/%で確認する。この速度の通常の最小値約30 m/%に近いため、曲線を切り上げる。
Answer約170 mの凸曲線を設ける；停止視距は134 mであり、凸曲線長を支配する。

Exam method

  • 縦断曲線上に視線を描き、SがLより長いか短いかを述べ、対応する式を選ぶ。
  • 単位を整然と保つ：片勾配の式ではVはkm/h、Rはメートル、eとfは単なる比である。
  • 配合設計では、VMA、VTM、結合材充填空隙率を一緒に報告する；一つの数値だけでは混合物を記述できない。
  • 交差点タイプを比較するときは、基準なしに利点を列挙するのではなく、衝突点を数える。
  • マーシャル法の問題では、安定度、フロー、密度、VTM、VMAの5つの曲線をすべてプロットし、仕様を確認する前に3つの結合材量の平均として最適値を読み取る。
